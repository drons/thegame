В этом каталоге мы храним ОДИН файл `md` для каждой задачи

Файлы задач именуются по сквозной нумерации `000001.md` до `999999.md`.

 * `done` - тут храним полностью завершённые задачи и отчёт по ним
 * `pending` - сюда складываем задачи, которые собираемся решить позднее, в том числе те, которые отдадим субагентам
 * `result` - тут промежуточный отчёт по задаче 

Перемещение задачи из `pending` в `done` ОБЯЗАТЕЛЬНО должно сопровождаться 
коммитом в git всех изменённых файлов (в том числе и файла задачи).

В конце выполнения задачи в `result` ДОЛЖЕН быть сформирован краткий отчёт о выполнении задачи

Перед написанием кода обязательно запускай агента для анализа задачи.
Если в результате анализа она оказывается слишком большой или там явно написано, что задачу нужно разделить,
то дели задачу на несколько и складывай в `pending`. Дочерняя задача должна иметь ссылку на родительскую.
А в файле результата родительской должны быть ссылки на порождённые дочерние задачи.

Для исключения конфликтов при мерже дочерние задачи должны именоваться по шабону `XXXXXX.YY.md`,
где `XXXXXX` это номер родительской задачи, а `YY` это номер порождённой дочерней.
Если дочерняя задача порождает подзадачи, то имя файла рекурсивно продолжается до `XXXXXX.YY.ZZ.md` и так далее.

Задачи закоммиченые в ветку master менять НЕЛЬЗЯ.
