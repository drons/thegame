Ретро по задачам (3 линзы × 7 задач)
------------------------------------
Каждая аналитическая станция покрывает ВСЕ 7 задач через свою
линзу (коммит `git show <sha>` vs master HEAD + ТЗ
tasks/done/<num>.md + отчёт tasks/result/<num>.md), а затем —
общий аудит:
* a1 (история/швы): по каждой задаче — всё ли из ТЗ сделано
  (ничего не пропущено/не добавлено сверх), швы «для будущего»,
  введённые коммитом; статус известных limitations (memory) после
  коммита; плюс общий аудит истории/CHANGELOG/memory.
* a2 (покрытие SPEC): по каждой задаче — где SPEC/spec/*.md
  следовало обновить и обновили ли; нет ли новых внутренних
  противоречий SPEC после правок; нет ли оставшихся устаревшими
  разделов; плюс общее покрытие (раздел SPEC → статус).
* a3 (код/тесты/UX): по каждой задаче — тестовое покрытие
  поведения задачи (что зафиксировано, что нет), ослабление
  существующих пинов в diff (удалённые/ослабленные ассерты),
  смежные регрессии (ДРУГИЕ потребители изменённого кода — grep);
  плюс общий аудит кода/тестов/опыта игрока.
Правило: каждое утверждение — с доказательством (file:line на
HEAD / git show / секция SPEC / номер задачи). Координатный дрейф
— ВСЕ координаты перепроверять на HEAD (master двигался с
написания ТЗ задач — урок RETRO-20261024: 3 случая дрейфа, все
разрешены на станции верификации).
