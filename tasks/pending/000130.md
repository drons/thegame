Панель персонажа: вкладки — саморегистрирующиеся модули (разбиение ui.js)

Инфраструктурная (родителя в SPEC нет; план:
memory/main-js-split-plan.md). Параллельна серии 000127–000129
(другой файл: src/ui.js), НО ОБЯЗАТЕЛЬНО до смержа
000098/000099/000101/000126/000083/000086 (вкладчатые задачи
цепочки 000051/000065/000046).

Цель: ui.js (~1239 строк) сейчас содержит ВСЕ вкладки панели
персонажа в одном файле — 6 следующих задач (000098 настройки,
000101 магазин, 000083 найм, 000086 отряд, 000126 крафт,
000099 на-лету) все правят один и тот же регион. Разбиение:
ядро панели остаётся в ui.js, каждая вкладка — отдельный модуль,
саморегистрирующийся при загрузке. Добавление вкладки = новый
файл + script-тег; ui.js при этом НЕ правится (нет
append-конфликтов).

-----------
1. Реестр вкладок: `Game.uiTabs = { register(tab), get(id), list() }`
   — где жить (в ui.js при загрузке или отдельный маленький
   src/ui-tabs.js) — в анализе; критерий: ui.js не правится при
   добавлении вкладки. Форма записи вкладки — в анализе + memory
   (кандидат: { id, имя, render(state), onKey?(code, state),
   isDefault? } — сверить с существующими вкладками:
   Снаряжение/Навыки/Инвентарь/Квесты (000100)/Магазин (setShop)).
2. Перенос существующих вкладок в модули:
   `src/ui-tab-inventory.js`, `src/ui-tab-skills.js`,
   `src/ui-tab-quests.js` (квесты — 000100, в master; переносится
   ПЕРВОЙ как демонстрация паттерна) и т.д. — набор файлов по
   анализу (можно 2–4 файла, не обязательно по одному на вкладку:
   критерий — следующая задача-вкладка добавляется БЕЗ правок
   ui.js и БЕЗ правок чужих вкладочных файлов).
3. Ядро ui.js: два столбца, переключение вкладок, тултипы
   (000097), [I]/Esc, проводка setShop/setQuests (main.js НЕ
   трогать, кроме минимального — проводка остаётся в main.js),
   рендер-цикл — остаётся.
4. `index.html`: script-теги вкладочных модулей ДО ui.js
   (саморегистрация до инициализации панели) — pin в
   tests/index-order.test.js.
