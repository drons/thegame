# Зубы цепи forbid-листов .22–.26: пины длин и set-включений по приёму 000371 [I]

Источник: ретро-b21, находка 000320.25 (debt 1) + кросс-тема Т2
(tasks/result/000320.25-retro-b21-20261113.md, tasks/result/b21-cross-retro-b21-20261113.md).

## Дефект
Guard-массивы запрет-листов в `tests/npc-000320.{22,23,24,25,26}.test.js` (T5-циклы)
не имеют НИ ОДНОГО пина длины, пина уникальности и пина set-включения к предыдущему
звену (проверено grep-ом на `6330d2ec`: `=== 75|79|83|87|91`, `list.length` — 0 хитов).
Число живёт только в ИМЕНИ теста-маркера («запрет-лист N подстрок»). Вырез или подмена
элемента в любом из пяти файлов молча зелёные — тот же класс, что закрыл 000371 для
`FORBIDDEN` в temples (находка M4b ретро-b20). Цепочка на диске сейчас цела:
67/75/79/83/87/91, уникальности, строгие включения, дельта = ровно 4 оборота предыдущего
NPC (переснято свипом ретро-b21).

## Цель
Любое изменение СОСТАВА массивов T5 в .21–.26 (вырез, дубль, подмена строки) обязано
краснеть на `node --test tests/` без ручного смотра.

## Требования
* T1. Распространить приём 000371 (пин длины + уникальность new Set + структурная сверка
  через чтение исходника) на звенья 75/79/83/87/91.
* T2. Проверить set-включение L(n) ⊋ L(n−1) с дельтой РОВНО 4 (формула наследования
  зафиксирована в memory/000320-sword_instructor.md / memory/000320-fist_instructor.md).
* T3. Архитектура на выбор аналитика (в ТЗ не навязывается): (а) зубья ВНУТРИ каждого
  своего файла (правятся 5 файлов-цепочки; у каждого следующего NPC-мержа конвенция
  ре-пина не растёт — файл и так свой) или (б) ЦЕНТРАЛЬНЫЙ tests/npc-forbid-chain-*.test.js,
  вычитывающий массивы из текстов семи файлов по образцу 000371 (один узел, но каждая
  новая волна .27+ обязана будет его ре-пиннуть — узкое место мержа при параллельных
  NPC-волнах). Обоснование выбора — в result.
* T4. ИМЕНА тестов-маркеров («запрет-лист N подстрок») и существующие TAP-маркеры
  СТАНЦИОННЫХ grep-рецептов (их счётчики зафиксированы в tasks/result/000320.2*.md)
  НЕ переименовывать: новые зубья — отдельными test() или assert'ами внутри существующих
  тел без изменения имён (иначе сломаются рецепты свежести базы будущих станций —
  прецедент Т5 ретро-b21 про имя T8).
* T5. Матрица мутаций обязательна: вырез элемента из каждого из пяти массивов, дубль,
  подмена строки — поимённый красный набор на каждую мутацию.
