# Заклинание школы защиты «Показать врагов»: окружности радиуса агрессии

Добавить заклинание школы **защиты** «Показать врагов»: включает отображение
на глобальной карте тонкой красной пунктирной полупрозрачной линии окружности
с радиусом агрессии моба (радиус — из задач 000172, 000233). По умолчанию
окружности не видны, пока кто-то из персонажей не активирует заклинание.
Действует `1 + Интеллект/10` игровых дней (округление — по конвенции формул
мира; длительности-в-днях уже существуют — найти прецедент баффов/эффектов).

Рендер: слой поверх карты (не канареечный рендер-контракт слоёв — 000340
subset-списки, 000344 туман — новые пиксельныеgolden'ы аккуратно); мобьи
радиусы читать из источника 000233, не дублировать константы. Тесты:
невидимость по умолчанию, активация, истечение по дням, корректный радиус.
