# Расстановка перед боем: скрыть джойстик движения (перекрывает угловые клетки) [I]

Задача пользователя (2026-11-13).

## Проблема
Во время расстановки персонажей перед боем экранный джойстик движения остаётся
видимым и перекрывает угловые клетки боевого поля — расставить юнитов в углы
невозможно/неудобно.

## Якоря (переснять с базы задачи)
* Экранный d-pad: `dpadEl = el('div', 'tc-dpad')` — src/ui.js ~:2340 (создание),
  видимость/каскад — src/ui.js ~:2526 (комментарий про display .tc-dpad block),
  стили — index.html ~:204–:217 (.tc-dpad, pointer-events ловят сами контролы).
* Окно расстановки (контракт 000260, memory/000260-combat-placement.md):
  src/combat-ui.js ~:190+ («латентное окно в боевом оверлее»), подтверждение
  «В бой» [Enter] ~:1194; режим расстановки уже перехватывает движение
  (000305: ~:1241 «перемещение НЕ начинает…»).
* Ключевое противоречие, снимаемое задачей: в режиме расстановки движение d-pad'ом
  семантически мертво (перехвачено 000305), но сам контрол визуально остаётся и
  оккупирует углы поля.

## Цель
На время активного окна расстановки джойстик (и только он — остальной тач-контрол
по усмотрению анализа) скрыт; после закрытия окна (подтверждение/отмена/гибридные
выходы по контракту 000260 — «обе точки, правило 000170») возвращается ровно в то
же состояние видимости, в котором был (условия показа touch-контролов не менять).

## Требования
* T1. RED-тест ДО правки: воспроизводимость на уровне DOM-контракта (jsdom/DOM-стабы
  по конвенции ui-тестов репо): при активации окна расстановки d-pad невидим
  (display/removed — по существующей конвенции скрытия контролов), при закрытии —
  восстановлен; покрыть ВСЕ выходы из окна (подтверждение, отмена, действия,
  закрывающие окно по :457, гибридные paths контракта 000260).
* T2. Условие видимости d-pad вне расстановки — 0-diff (телефон/тач-эвристика,
  полноэкранный режим и т.п. — не трогать; снять текущий предикат и запинить).
* T3. Мутационная матрица: удаление возврата джойстика → красный T1; распространение
  скрытия на обычный бой/мир → красный T2-пин; и т.п. по составу тестов.
* T4. CHANGELOG — буллет в секцию даты мержа (### Интерфейс; конвенция одной даты).

## Ограничения
* Файлы src/ui.js и index.html — горячие (панель [I] 000377, магазин 000345): НЕ
  запускать параллельно с 000377/000345; при ре-базе разрешать в пользу актуального
  мастера.
* Не менять геометрию боевого поля и хитбоксы клеток — только видимость контрола.
