Магазины: не отображать позицию при количестве 0

Источник: запрос пользователя (drons, 2026-11-05).

Цель: в магазинах, если количество товара стало 0, — не отображать эту позицию.

Что сделать:
* Рендер магазина (все экраны магазинов — магазины построек и/или NPC —
  по факту кода): позиция с количеством 0 НЕ РЕНДЕРИТСЯ (строка отсутствует,
  не «скрыта» и не «0 шт.»).
* Обновление ассортимента (респавн/refresh — по факту кода) возвращает
  позицию (регресс).
* Покупка последней штуки → после ре-рендера позиция исчезает.

Тесты (красные):
* Магазин с количеством 1 → покупка → позиция отсутствует (0 строк
  для предмета).
* Обновление/респавн → позиция вернулась.
* Прочие позиции — бит-в-бит (порядок строк, цены, иконки — 0-diff).

Ограничения:
* новый код — БЕЗ комментариев; memory/000314-<slug>.md (контракт
  «0 — не показываем», экраны, которые покрываются);
* CHANGELOG при мерже (игровой процесс/UI);
* RED → GREEN, полный прогон ТОЛЬКО в worktree (ps-проверка), W-08 до коммита;
* если описание экрана магазина в spec/npc-storage.md / spec/buildings.md —
  обновить + ре-пин В ТОМ ЖЕ коммите; 0-diff вне SCOPE.
