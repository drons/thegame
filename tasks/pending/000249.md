Бой: кнопка «последнее заклинание» у Флогистона, Эфира и
наёмных спутников (запрос пользователя, 2026-10-22;
приоритет P2; Зависимости: СЕРИЙНО с 000246/000248 (общий
src/combat-ui.js) — выполнять ПОСЛЕ 000246 и 000248)

Родительская: нет (пользовательский запрос).

Цель: кнопка, применяющая ПОСЛЕДНЕЕ ИСПОЛЬЗОВАННОЕ
заклинание из книги заклинаний, у Флогистона, Эфира и
наёмных спутников. Тип (id) заклинания СОХРАНЯЕТСЯ МЕЖДУ
БОЯМИ. Кнопка доступна СРАЗУ (у союзников). У Флогистона — в
начале боя кнопки НЕТ, пока он не использует магию (после
первого успешного каста появляется).

Что сделать
-----------
1. Анализ: (а) хранилище «последнего заклинания» — per
  персонаж (Флогистон / Эфир / наёмник); «последнее
  использованное» = последнее УСПЕШНО откастованное
  (неуспешный каст/отказ — не сбрасывает; решение
  зафиксировать в memory); сохранение между боями — где
  держать (hero/ally-объект + поле сейва); (б) каст из
  кнопки = ТОТ ЖЕ путь, что каст из книги (ман-чек, target-
  тип по заклинанию, причина отказа в лог) — без новой
  механики каста.
2. Кнопка: (а) Эфир/наёмник — доступна СРАЗУ, если у
  персонажа есть «последнее заклинание» И оно кастуемо
  (мана/free_cast); иначе — disabled с причиной (паттерн
  существующих disabled-кнопок); (б) Флогистон — в начале
  боя кнопка ОТСУТСТВУЕТ (не создаётся/скрыта) до первого
  успешного каста в этом бою, затем появляется (паттерн
  гейтов 000171/000178 — «кнопка создаётся только у
  носителя/включённая»).
3. Позиция в панели действий — по правилу ≤8-й кнопки
  (combat-ui.js ~L473) — решение анализа, зафиксировать.
4. Сейв: поле last spell (id заклинания) — опциональное,
  читаемое старыми сейвами (отсутствует = кнопки как до
  фичи: у союзников disabled/нет, у героя скрыта).

Тесты (красные)
---------------
* Красные (до фикса): (а) Эфир/наёмник: бой 1 — каст X →
  бой 2 — кнопка доступна СРАЗУ с тем же X (сейчас кнопки
  нет); (б) Флогистон: начало боя — кнопки нет → первый
  успешный каст — кнопка появилась (с тем же заклинанием).
* Каст из кнопки = семантика каста из книги: мана списана,
  эффект применён, лог-строка, target-тип (пины по
  существующим каст-тестам).
* Неудачный каст не сбрасывает «последнее» (пин).
* Сейв: save/load — last spell сохранён; СТАРЫЙ сейв без
  поля — без ошибок (кнопки в состоянии «до фичи»).
* node --test tests/ — полный зелёный.
