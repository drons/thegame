Реализация заклинаний в игровом коде (по каталогу assets/spells, задача 000023)


(В ветке task/data задача была под номером 000033; при мерже в master номер занят другой задачей — перепривязана.)
Спецификация закреплена в SPEC.md раздел «Заклинания» и каталоге
assets/spells (schema.json, 16 вариантов). Не пишем пока: только данные.

* src/spells-data.js — униформный JS-модуль-зеркало каталога (фолбэк
  file://), генерация скриптом (стиль src/skills-data.js).
* src/spells.js — чистый код без DOM:
  * книга заклинаний: список id, изучение (книга/свиток, наставник,
    рунический камень/обелиск), проверка условий (ранг школы,
    базовое заклинание для совершенствования);
  * ранги школы по уровню основного навыка (Ученик/Знаток/Мастер/
    Аркимаг — таблица SPEC.md);
  * применение в бою: действие «Применение заклинания» по атрибуту
    (пул Интеллект/Мудрость), расход маны, эффект по `действие`
    (числовые формулы — здесь, данные описательные);
  * в бою действует только высшая известная степень цепочки «база».
* index.html — подключить модули в правильном порядке (после
  global-settings.js, player.js, combat.js).
* Тесты: зеркало каталога, изучение/условия, ранги, применение в бою
  (мана, пул действий, эффекты), высшая степень цепочки.
* Если в каталоге предметов появятся фокусы/свитки (другая цепочка) —
  поддержать их как предметы изучения.
