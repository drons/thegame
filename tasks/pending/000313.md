Постройка «Склад»: прокрутка списка + интерфейс «магазин»
(инвентарь | склад, drag-n-drop, «Сложить»/«Вынуть»)

Источник: запрос пользователя (drons, 2026-11-05).

Цель: в здании «Склад» список предметов не помещается в экран:
* сделать прокрутку списка;
* интерфейс — по аналогии с инвентарём-снаряжением из вкладки персонажа,
  открываемой по [I]: слева предметы инвентаря, справа предметы на складе
  (используем механику магазина); перетаскиванием drag-n-drop предметы
  перемещаются между вкладками; во вкладке инвентаря у предметов — кнопка
  «Сложить», во вкладке склада — «Вынуть».

Что сделать:
* Прокрутка: контейнер списка фиксированной высоты, контент скроллится
  (склад-оверлей — по факту кода).
* Две панели: слева = инвентарь персонажа, справа = содержимое склада
  (механика склада — по факту кода, src/buildings.js «Склад: персонаж
  может сложить предметы из инвентаря и вынуть их обратно»).
* Перенос предметов между панелями: drag-n-drop + кнопки «Сложить»
  (панель инвентаря) / «Вынуть» (панель склада) — ОДНА и та же мутация
  (перенос предмета инвентарь ↔ склад); кнопки — доступная альтернатива
  drag-n-drop, результат идентичен.
* Механика магазина (строк-рендер, выбор, цены/лимиты — по факту кода,
  src/items.js / src/ui.js) — переиспользовать, не дублировать.

Тесты (красные):
* Список не помещается в экран → контейнер скроллится
  (scrollHeight > clientHeight, overflow).
* «Сложить» (клик и drag-n-drop): предмет уходит из инвентаря на склад —
  одна мутация, лог-строки по факту кода; инвентарь-строка исчезла,
  склад-строка появилась.
* «Вынуть» — зеркально.
* Drag-n-drop даёт тот же результат, что кнопка (паритет двух входов).
