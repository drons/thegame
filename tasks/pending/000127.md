Разбиение main.js (1/4): src/locations.js — состояние подземелья и города

Инфраструктурная задача (родителя в SPEC нет) — снижение
бутылочного горлышка src/main.js для параллельной разработки
(решение 2026-09-30; общий план: memory/main-js-split-plan.md).
Первая из серии 000127→000128→000129 (все трогают main.js —
выполнять ПОСЛЕДОВАТЕЛЬНО).

Цель: вынести домен «состояние и переходы подземелья/города» из
src/main.js в новый чистый модуль src/locations.js — БЕЗ смены
поведения (рефакторинг с регрессией). После этой и следующих
задач волны 000107/000109/000110 (города) и будущие dungeon-задачи
правят locations.js (маленький стабильный файл), а не main.js.

Что сделать
-----------
1. `src/locations.js` (НОВЫЙ, UMD — паттерн src/cities.js /
   src/dungeon.js): перенос из main.js (локации — по ИМЕНАМ
   функций, не по строкам — master меняется): makeDungeonState,
   maybeEnterDungeon, exitDungeon, dungeonMove, makeCityState,
   maybeEnterCity, exitCity, cityMove + связанные константы
   (MOVE_INTERVAL_MS — если используется только здесь).
   Архитектура: модуль ЧИСТЫЙ (взаимных require в момент загрузки
   нет — 000053; снапшот Game один раз — 000038; ленивые ссылки
   на map/player/clock/G — в момент вызова, rootRef-паттерн).
   Разграничение «чистое vs проводка» определить в анализе и
   зафиксировать в memory: чистая часть (фактории состояний,
   логика шага/выхода от переданного состояния) — экспортируется
   для node-тестов; main.js хранит ТОЛЬКО тонкую проводку
   (вызов maybeEnter* на шаге, cityMove/dungeonMove по клавише,
   присвоение dungeonState, hudFlash-сообщения).
2. `index.html`: script-тег src/locations.js ПОСЛЕ cities.js и
   dungeon.js, ДО main.js (уместность — в анализе; pin — тест).
3. `src/main.js`: удалённые блоки заменяются вызовами модуля;
   поведение БЕЗ ИЗМЕНЕНИЙ: детерминизм (ноль новых вызовов
   c._rng/RNG), сейвы (worldKey/prevX/prevY — та же форма), HUD
   (не трогать — его выносит 000129), [E]-гард
   (toggleNpcDialog — его выносит 000128; гард dungeonUI.isActive
   при переносе СОХРАНЯЕТСЯ в том же месте логики).
