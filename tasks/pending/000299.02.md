000299.02: уникальные действия и диалоги для Эфира и наёмных NPC в
постройках (дочерняя 000299, п.2)

Родительская: tasks/done/000299.md. Зависимости: 000299.01 (жёсткая —
резолвер активного персонажа в npcUI); после мержа .01 — rebase.

SCOPE:
1. Каталог: новый ключ опции диалога `для` (scope) —
   assets/npc/*.json + assets/npc/schema.json + regen
   scripts/sync-npc-data.js → src/npc-data.js (byte-identical).
   Семантика: отсутствует/`"все"` — доступен любому активному;
   `"efir"` — только Эфир; `"merc"` — любой наёмный; `{роль:
   "melee"|"ranged"|"shield"|"support"}` — наёмный с найм.роль.
   Данные: минимум 3-4 реальные опции у 2-3 NPC (таверна 44 — Берта:
   опция для Эфира + опция для support; храм 36 — Элдира: опция для
   наёмных); остальные NPC — без изменений.
2. src/npc.js dialogOptions(npc, character): фильтр по `для` по
   kind (hero/efir/merc) и найм.роль каталожного NPC переданного
   character (npc — из Party-записи/каталога; hero — роль null).
   Требования `харизма/навык/проверка` — по тому же character (без
   изменений).
3. src/ui.js npcUI: renderDialogTab и opt-ветка onOverlayClick —
   G.dialogOptions(npc, activeSheet), где activeSheet — резолвер
   000299.01 (rootRef.__game.state); c = o.character (hero) остаётся
   владельцем мутаций: золото платит Флогистон ВСЕГДА, предмет — в
   общий инвентарь (000194). Вкладка «найм» — без изменений.
4. SPEC: spec/npc-storage.md — буллет «диалог»: ключ `для` + семантика
   scope (~8-10 стр.); spec/companions.md — 2-3 строки (с кем
   взаимодействуют Эфир/наёмные в постройках).
