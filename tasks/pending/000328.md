Руны: нанесение/стирание на предметах (навык «Рунопись»),
лимит по редкости, 50+ эффектов, рунический камень

Источник: запрос пользователя (drons, 2026-11-05).

Цель: добавить возможность наносить/стирать руны на предметы (навык
«Рунопись»). Количество рун у одного предмета определяется его редкостью.
Руны могут давать бафы к навыкам или другие полезные эффекты
(дополнительная броня, здоровье, мана, эффекты заклинаний, + придумать
ещё 50 уникальных эффектов, можно немного юмора). Руны можно наносить
на предмет, если встать на рунический камень. Для каждой руны — описание
в виде JSON-файла в каталоге assets/runes, а в каталоге
assets/sprites/runes — иконки для рун.

Что сделать:
* Навык «Рунопись»: если отсутствует в дереве — добавить (координация с
  000325/000324 — не дублировать).
* Механика нанесения: предмет + персонаж стоит на руническом камне
  (новый объект карты / по факту кода в анализе: где располагаются камни,
  решение — в memory) → руна наносится на предмет (стоимость — решение в
  анализе, в memory). Стирание — на камне (стоимость — решение).
* Лимит рун на предмет = редкость предмета (таблица редкость → максимум
  рун — контракт в memory + SPEC).
* Каталог рун: assets/runes/*.json (id, название, описание, эффект) +
  assets/sprites/runes/<id>.svg (иконки — flat-SVG паттерн 000302).
  Эффектов: базовые (броня/здоровье/мана/эффекты заклинаний/бафы
  навыков) + 50 УНИКАЛЬНЫХ (можно немного юмора) — список — контракт в
  memory.
* Применение эффектов: на предмет/носителя (механика — по факту кода в
  анализе: derived-бонусы предмета/листа).
* Sync-зеркала + schema (поле предмета «руны», если руны хранятся в JSON
  предмета — решение в анализе, в memory).
* Сейв: руны на инстансе предмета — новые поля + санация absent →
  дефолт (паттерн 000298), форма v1 не меняется.

Тесты (красные):
* Нанесение: на руническом камне + навык → руна на предмете (строка в
  предмете, эффект применяется — derived-стат меняется по факту кода).
* Лимит: (N+1)-я руна отклоняется (причина в логе); таблица редкость →
  лимит (sweep).
* Стирание: руна снята, эффект снят.
* Sweep каталога: каждая руна — валидный JSON + иконка существует
  (паттерн 000302); 50+ уникальных эффектов (sweep списка).
* Save/restore: руны предмета roundtrip.
