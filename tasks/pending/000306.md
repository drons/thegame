JSON заклинания

Источник: запрос пользователя (drons, 2026-11-02).

SCOPE:
1. Урон заклинания зависит от степени (уровня) заклинания — значение
   фиксируется в JSON заклинания (новое поле или существующее поле
   урона — решение в анализе).
2. Обновить JSON заклинаний (урон по степеням: значения — в анализе,
   консистентно со SPEC).
3. Расчёт урона в бою читает JSON (никаких хардкод-констант по
   степеням в коде).
4. Красные: урон степени 1 < степени 2 < … по значениям JSON;
   контрпример — одинаковый урон у разных степеней.
