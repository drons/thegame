Бой: фреймворк «союзные юниты» (src/combat.js)

Родительская: 000065 («Найм» спутников: проработка и планирование).

Цель: ядро ЕДИНОГО фреймворка союзников — явное решение по Эфиру
(000035): Эфир и наёмники — одна модель союзного юнита (side 'ally').
Самая объёмная боевая подзадача — мержить с разнесением по времени.

Что сделать
-----------
* src/combat.js:
  - createCombat({allies: [...]}) — опция союзных юнитов: side 'ally',
    всегда 1×1, спавн рядом с игроком (низ поля) — поле 7×7 должно
    вместить игрока + 3 союзника + до 6 мобов = 10 юнитов
    (проверить unitAt/rectFree при размещении);
  - makeAlly(data) — союзник из данных: роль/статы/навыки/заклинания
    из `найм` (000078) или из данных Эфира (000081);
  - buildTurnOrder — ['player', ...allies, ...mobs]
    (очередь: игрок → союзники → мобы);
  - ИИ союзника (аналог mobAct, на нашей стороне): шаг к ближайшему
    врагу + атака по роли (переиспользовать stepToward / nearestMob /
    livingMobs); роль ranged — держит дистанцию; роль shield — блок
    (аналог моба); роль support — лечит самого раненого союзника,
    включая игрока (лечебные заклинания из spells);
  - союзники НЕ атакуют сторону игрока (проверка side в
    прицеливании/агрегации целей — сейчас мобы бьют только игрока:
    dealDamageToPlayer — расширить модель целей);
  - гибель союзника — покидает бой, это НЕ поражение; checkVictory,
    победа/лут/опыт игрока — без изменений;
  - мораль: урон ВСЕХ союзников × (1 + companionMoraleBonus) —
    подключить существующую заготовку (src/player.js:230,
    +5%/ур. Предводителя; сейчас нигде не используется). НЕ
    смешивать с ролью 'leader' у ВРАЖЕСКИХ мобов и флагом
    hasLeader — это разные сущности.
* src/combat.js — мержить ТОЛЬКО ПОСЛЕ 000045 (реализация
  заклинаний) с ребейзом на актуальный master (000046 крафт тоже
  правит combat.js — сверить перед мержем).
