Переименовать JSON каталогов ресурсов по ID/названию
(конфликты мержа параллельных волн)

Источник: запрос пользователя (drons, 2026-11-05).

Цель: крайне сложно проводить слияние веток при параллельном создании
JSON для ассетов игры из-за того, что JSON в каталогах игровых ресурсов
имеют сквозную нумерацию. Переименовать все JSON в соответствии с ID/
названием ресурса, который этот JSON описывает.

Что сделать:
* Аудит по диску: какие каталоги ресурсов имеют сквозную нумерацию
  (assets/items, assets/spells, assets/skills, assets/mobs, assets/npc,
  assets/buildings, assets/craft, assets/mob_groups, … — проверить все).
* Переименование: <номер>.json → <id>.json (id из поля «id» JSON; если
  каталог без «id» — поле названия; решение по каждому каталогу — в
  анализе, зафиксировать в memory).
* Обновить ВСЕ ссылки: sync-скрипты (src/*-data.js), лоадеры, тесты,
  spec, memory.
* Sweep ссылочной целостности: каждый JSON каждого каталога читается,
  имя файла == id из содержимого, межкаталожные ссылки не сломаны
  (sweep-тест — паттерн tests/svg.test.js).
* ЗАДАЧА БОЛЬШАЯ — в анализе допустить РАЗБИТИЕ ПО КАТАЛОГАМ: дочерние
  000318.YY (каждый — свой worktree/коммит), родительская ссылка в
  дочерних, ссылки на дочерних — в result родительской (tasks/CLAUDE.md).

Тесты (красные):
* Sweep: для каждого переименованного каталога: имя файла == id из
  содержимого; JSON валиден (schema); контент 0-diff (git rename
  detection: R100, не rewrite).
* РЕГРЕСС: sync:check зелёный, зеркала src/*-data.js идентичны,
  тесты каталогов цёлы.

Ограничения:
* контент 0-diff (только rename, без правки полей — кроме решений
  анализа, зафиксированных в memory);
* memory/000318-<slug>.md (список каталогов, правило именования,
  исключения);
* CHANGELOG — не требуется (ни игровой процесс, ни графика);
* если spec пинит пути/имена каталогов — обновить + ре-пин В ТОМ ЖЕ
  коммите; RED → GREEN, полный прогон ТОЛЬКО в worktree (ps-проверка),
  W-08; 0-diff вне SCOPE.

Ссылки:
* assets/* (аудит по диску), scripts/sync-*.js, src/*-data.js,
  tests/ (свепы каталогов), schema.json.
