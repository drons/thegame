# Задача 000343: Реюз Float32Array в buildFrame (RENDER-OPTIMIZE §5G, подход G1)

## Цель

Убрать пофреймовую аллокацию `new Float32Array(verts)` в buildFrame
(`src/main.js:3856` — `gl.bufferData(gl.ARRAY_BUFFER, new Float32Array(verts), gl.DYNAMIC_DRAW)`):
переиспользовать буфер-вместимость (capacity-буфер в замыкании цикла) либо
пропускать аллокацию при 0 вершин. Мелкий GC-win (оценка §5.1: эффект 2,
простота 8, риск 2), вывод — бит-в-бит.

## Что сделать

1. Реюз capacity-буфера (`bufferSubData` в уже выделенный ARRAY_BUFFER при
   неизменной capacity, `bufferData` при росте capacity) ИЛИ пропуск аллокации
   при пустых verts — решение за анализом, но с ГЛАВНЫМ ограничением:
   **пин RM-6 («на кадр ровно 1 rAF-планирование и ровно 1 clearRect») и пин
   RM-10 («ровно 1 bufferData + 1 drawArrays count=0» на пустом кадре,
   tests/global-map-draw.test.js) обязаны остаться зелёными БЕЗ ре-пинов** —
   если выбран путь «пропуск bufferData при 0 вершин», RM-10 краснеет: значит
   bufferData вызывается всегда (можно с length 0), а экономия только на
   аллокации. Нумерацию RM не переименовывать (память 000342-эрраты: RM-6 ≠
   bufferData, bufferData-пин несёт RM-10).
2. Новый тест `tests/render-buildframe-buffer-reuse-000343.test.js` (vm-харнес
   по образцу tests/frame-tiles-cache-000276.test.js /
   tests/render-frame-subsets-000340.test.js): gold-кадр бит-в-бит до/после
   (атрибуты bufferData deepEqual по серии кадров hit/rebuild/steady),
   счётчик НОВЫХ Float32Array-аллокаций на кадр (gl-стаб/счётчик в харнесе),
   пустой кадр — bufferData РОВНО 1 раз с count 0 (RM-10-паритет).
3. RED-then-GREEN; мутации (вернуть аллокацию / убрать bufferSubData-ветку) —
   краснота нового теста.

## Ограничения и приёмка

- SCOPE: `src/main.js` (только регион buildFrame/upload), новый тест, память
  `memory/000343-buildframe-buffer-reuse.md`, CHANGELOG без буллета (вывод
  бит-в-бит, не геймплей — прецедент 000340).
- Не трогать: skipBase/steady-гейт регион 000339, субсписки 000340,
  `src/dungeon-ui.js` (параллельная 000344), NPC/items/claстеры живых задач.
- Приёмка: полный зелёный прогон на финальной базе; RM-6/RM-10,
  render-steady-gate-skip-000339, render-frame-subsets-000340,
  frame-tiles-cache-000276 — зелёные в срезе и целом прогоне.
- Прецеденты: 000340 (харнес/мутации/«визуал бит-в-бит» без CHANGELOG),
  RENDER-OPTIMIZE.md §5G/§5.1 (G1) + эррата 000342 (RM-нумерация).
