Магазин: режим торговли — вкладки [I] «Инвентарь + Магазин»,
drag-n-drop с подтверждением продажи, «Продать»/«Купить»

Источник: запрос пользователя (drons, 2026-11-05).

Цель: при входе в режим торговли в магазине активировать вкладки
«Инвентарь» и «Магазин», которые доступны по кнопке [I]: слева предметы
инвентаря, справа предметы в магазине. Перетаскиванием drag-n-drop
предметы перемещаются между вкладками (осуществляется покупка и продажа,
но с подтверждением: «Вы хотите продать 'Название предмета' за X золота?»).
Кнопки «положить»/«взять» тоже должны остаться. Во вкладке инвентаря
у предметов — кнопка «Продать», во вкладке магазина — «Купить».

Что сделать:
* Режим торговли (магазин открыт): панель показывает две вкладки —
  «Инвентарь» (слева) и «Магазин» (справа), по аналогии с панелью [I]
  (механика — по факту кода, src/ui.js).
* Drag-n-drop: инвентарь → магазин = ПРОДАЖА; магазин → инвентарь =
  ПОКУПКА. Продажа — с диалогом подтверждения «Вы хотите продать
  'Название предмета' за X золота?» (X — цена продажи по формуле — по
  факту кода, 000299.03: цены по активному персонажу, платит Флогистон);
  «Нет» — ничего не происходит. Покупка — текущая логика (не хватает
  золота — отказ, лог по факту кода).
* Существующие кнопки «положить»/«взять» — остаются (НЕ удалять).
* Вкладка инвентаря: у предмета — кнопка «Продать» (продажа по цене
  магазина, подтверждение то же). Вкладка магазина: у предмета — кнопка
  «Купить» (покупка по цене магазина).
* Недоступные действия (нет предмета в магазине / не хватает золота) —
  кнопка неактивна, причина — как у текущей покупки (по факту кода).

Тесты (красные):
* Режим торговли: вкладки «Инвентарь» и «Магазин» существуют; слева —
  строки инвентаря, справа — строки магазина.
* Drag инвентарь → магазин: подтверждение показано (дословный текст
  «Вы хотите продать 'Название предмета' за X золота?»), «Да» → продажа
  (qty −1, золото += цена); «Нет» → состояние бит-в-бит.
* Drag магазин → инвентарь: покупка (сток −1, золото −= цена, предмет в
  инвентаре).
* Кнопки «Продать»/«Купить» = те же мутации, что drag; «положить»/«взять»
  цёлы (регресс).
