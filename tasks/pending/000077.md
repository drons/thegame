Родительская: 000064 (эффекты «особых» построек: проработка и
планирование)

Цель: один общий механизм «ежедневный контент» для двух построек —
магический круг (id 43, подтип слота 10 с 000073; флаг
`раз_в_день` в каталоге УЖЕ ЕСТЬ) и заброшенный храм (id 39,
подтип слота 8 с 000073; флаг добавить).

  id 39 — `{ даёт }` (флага нет — добавить).

Ключевые проектные решения (зафиксировано в SPEC «Эффекты
построек»)
* Единый детерминированный ролл по (tile, day), РАЗ В ДЕНЬ (флаг
  `раз_в_день`): сундук 60% / босс 30% / реликвия 10% (доли —
  каталог `особые_параметры.эффект.доли`).
* Сундук — лут таблицами подземелий (уровень — по тайлу/богатству;
  зафиксировать правило в задаче).
* Босс — НОВЫЙ рецепт в `GROUP_RECIPES` (группа 1–3 мобов из
  СУЩЕСТВУЮЩИХ `MOB_TYPES`, уровень по тайлу) — новых ассетов/мобов
  НЕТ; бой — через существующий `createCombat`.
* Реликвия — предмет id из `assets/items` (таблица id — каталог
  `эффект.реликвии`), кладётся в инвентарь.
* Повторное посещение тайла в тот же день — сообщение «круг
  молчит» (содержимое уже получено); состояние последнего ролла —
  в сейве (`buildingContent`: 'x,y' → { day, тип }).
