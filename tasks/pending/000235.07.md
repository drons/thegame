Общие требования контентных волн (контракт §6 — повторяется в
каждой волне):
1. 25 JSON assets/spells/NNNNNN.json — СЛЕДУЮЩИЕ СВОБОДНЫЕ
   номера ПОСЛЕ перебазирования (база 386caf1: с 000018; 25 на
   волну; ПЕРЕНОМЕРАЦИИ НЕТ, сейв v1); `параметры` по D1
   контракта; `вне_боя: true` у внебоевых (firelight,
   hearthfire); `здания` — по преобладающей ссылке школы
   (огонь — 17/18, D12); `предметы` — ссылка на СВОЙ свиток
   (паттерн fireball→свиток, 000133); icon/icon_prompt —
   ОБЯЗАТЕЛЬНЫЕ (схема required). Цепочки-совершенствования —
   ≤3 на волну (база = новое или старое заклинание школы
   (spark L1→fireball L2→flame_burst L3 ст2→inferno L4 ст3 —
   существующая цепочка), степень = +1; остальное — база null).
   `мани` (1..100) — калибровка исполнителя по формулам
   существующих 17 (castSpell spells.js:427-472; существующие:
   L1 3–5, L2 6–8, L3 10–15, L4 20) + баланс-пин 000119.
2. 25 SVG assets/spell-icons/<id>.svg — УНИКАЛЬНЫЕ (НЕ копии),
   24×24, #e8dcc0, тёмный фон (формат по существующим 17);
   sweep — tests/svg.test.js подхватывает автоматически.
3. 25 JSON assets/items/NNNNNN.json — kind spell_scroll,
   effect {kind:'spell', spell:<id>}, tier = `уровень` спелла
   (D8; поле `tier` в схеме items УЖЕ ЕСТЬ, 000157.01), weight
   0.2, value ~по уровню, desc; СЛЕДУЮЩИЕ СВОБОДНЫЕ номера
   ПОСЛЕ перебазирования (база 386caf1: с 000077; конкуренты —
   pending 000230.01–.15 (275 предметов) и 000232 (свитки
   крафта); ПЕРЕНОМЕРАЦИИ НЕТ).
4. Пул сундука: 25 свитков → СВОЙ пул — assets/dungeons/000003.
   json `предметы` (id-формы; механизм 000133: каждый свиток
   ровно в одном пуле); баланс пула (доля свитков) — пин в
   тесте волны.
5. Зеркала: npm run gen:spells + npm run sync:items (src/
   spells-data.js, src/items-data.js — регенерация,
   идемпотентность; «sync:spells» — НЕ СУЩЕСТВУЮЩИЙ npm-скрипт);
   дрейф-гейт CI — npm run sync:check (000054).
6. Тесты: tests/spells.test.js (репин «ровно N» — N = текущий
   каталог + 25; если волны серийно: 17→42→…→167; схема/
   ссылки/`вне_боя`-пин), tests/items.test.js (25 свитков:
   effect.spell валиден, tier = уровень спелла — пин), tests/
   dungeon-*.test.js (пул 000003: 25 новых id — пин), svg
   sweep, vm-e2e (сундук → свиток → изучение — после .05).

Примечания к таблице (§7 контракта):
* «партия»-эффекты в бою: цель — все живые союзники (паттерн
  mass-лечения) — в этой волне нет;
* внебоевые «радиус 5» — Chebyshev, как зоны 000135 — firelight
  (радиус света) и hearthfire (лагерь) — обработчики по id
  (switch из .02);
* flame_step (телепорт 10 тайлов) — обработчик по id (D7/D2):
  короткий телепорт в направлении взгляда/движения, детерм.,
  без RNG — детали определяет исполнитель (свой обработчик, не
  общий с gate/stone_anchor/recall).
