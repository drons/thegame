Боссы подземельй/пещер — размер 3x3 тайла + коллизии
в узких проходах

Источник: запрос пользователя (drons, 2026-11-05).

Цель: боссов на карте в подземельях и пещерах сделать размером 3x3 тайла
для явного выделения. При этом обратить внимание, что они не должны
заходить в проходы толщиной менее трёх тайлов (учитывать их размер при
коллизиях со стенами).

Что сделать:
* Боссы по факту диска (флаг/механика боссов подземельй — аудит):
  size {w: 3, h: 3} (паттерн больших мобов — bone_coloss/abomination,
  по факту кода, таблица мобов src/combat.js).
* Расстановка (паттерн placeUnits — по факту кода): 3x3 босс занимает
  3x3 клетки; ставится ТОЛЬКО в область со свободным 3x3 пространством.
* Движение/коллизии: 3x3 юнит не заходит в проходы шириной < 3 тайлов
  (проверка движения/стены — по факту кода).
* Рендер: размер босса 3x3 на карте (по факту кода рендера).

Тесты (красные):
* Босс ставится только в свободную 3x3 область (фикстюрная карта:
  коридор 3x2 — босс не ставится).

  2 — движение отклонено).
