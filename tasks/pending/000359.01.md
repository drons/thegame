# 000359.01: Экран крафта — исполнитель-спутник/Эфир (навыки крафта)

Родитель: tasks/done/000359.md (баг «Рунопись спутников не учитывается
в постройках»; рунический камень '40_inscribe'/'40_erase' исправлен
единой точкой craftExecutor = Game.LearnTarget.activeSheet).

Не закрытая родителем часть «единообразия по всем постройкам с
краптовыми действиями»: спец-действие 'craft' (экран крафта) во всех
постройках-мастерских — кузницы (8, 25), алхимия (3, 17, 18),
зачарование (12, 18, 25), столярное (5), резьба по камню (40, 48),
рунопись (40, 16, 42) — исполняет ТОЛЬКО для Флогистона:
src/craft-ui.js specialHandler/open/canCraft/craft и весь Game.Craft
(src/craft.js: evalCraft/canCraft/craft/craftLevel/craftCap/qualityMult/
qualityChance/isTypeLearned/addCraftXp, таблица CRAFT_TYPE_SKILL)
берут персонажа из ctx.hero/`hero`.

Требуется (по анализу 000359 — потому и вынесено отдельной задачей):
1) performer-параметр API src/craft.js: skill-сторона (isTypeLearned,
   craftLevel, craftCap, qualityMult, qualityChance, yieldChance,
   craftBonus, addCraftXp) — с листа-исполнителя; инвентарь/hasItem/
   addItem/ёмкость/манускрипты — остаются на герое (общий инвентарь
   партии, 000194);
2) поля craft/craftXp/craftTypes у листов: copyMercSheet/sanitizeMercSheet
   (src/companions.js) и serializeEfir/deserializeEfir (src/efir.js) +
   backfill — иначе прогресс крафта спутника ТИХО теряется при сейве
   (санитайзеры sanitizeCraft* уже есть в src/craft.js; сейв v1 не
   бампается — прецедент 000298);
3) designer-решение: зачарование тратит ману, а у merc/Эфир-листов mp
   НЕТ — вариант А: «не хватает маны» для листов без mp; вариант Б:
   мана героя. Зафиксировать в памяти;
4) craft-ui.js: performer = Game.LearnTarget.activeSheet(ctx.hero) при
   открытии экрана (fallback hero, D2 — контракты 000133/000147/000359);
5) тесты: RED на кузнице/алхимии (спутник forge=0 при hero forge=10 →
   отказ; спутник высокий → качество/кап/XP с листа; Эфир — тот же
   контракт) + расширение свип-реестра tests/building-craft-skills-
   000359.test.js строкой 'craft'.
