#Нарисовать новые высокодетальные графические SVG ассеты для мобов.

Развитие задачи 000047

На каждом ассете должно быть не менее 30 деталей на одну клетку площади моба: 
 1x1 - не менее 30 деталей
 2x2 - не менее 120 деталей
 ...
 5x5 - не менее 750 деталей

У каждого моба должно быть:
 * пара-тройка кадров анимации движения
 * пара-тройка кадров анимации удара
 * кадр в уничтоженном состоянии

Ассеты сложить в каталог assets/sprites/mobs

Воркфлоу для такой: 
 1) Разработать общие правила создания ассетов, сохранить в файл MOBS.md
 и дать на него ссылку в SPEC.md в разделе про мобов 
 2) Для каждого моба из каталога assets/mobs запустить отдельного субагента со следующими стадиями:
   - Создай детальное текстовое описание каждого моба и записать его в JSON файл, соответствующий этому мобу 
   - Сгенери высокодетальные SVG для каждого моба по описанию с предыдущего
   - Проверка соответствия SVG описанию и правилам создания мобов
   - Добавить загрузку новых ассетов для отрисовки мобов
   - В JSON файл, соответствующий этому мобу добавить ссылки на созданные SVG
   - Добавить тесты, проверяющие корректность этих ссылок
