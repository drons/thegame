Крафт предметов

* Виды крафта: кузнечное дело, алхимия, резьба по камню, столярное дело (придумать ещё другие виды)
* Принципы совершенствования крафтовых навыков
* Описание способов изготовления предметов (рецепты, чертежи, схемы, наброски)
* Совершенствование способов изготавления предметов (как особый вид крафта)
* Описание способов изготовления должно храниться в каталоге assets/craft
  В этом json файле кроме всего прочего должны быть ссылки на:
  - Предмет - результат крафта (assets/items)
  - Исходные предметы и их количество (assets/items)
  - Связанные с этим крафтом скилы (assets/skills)
  - Связанные с этим крафтом здания (assets/buildings)
  - Связанные с этим крафтом заклинания (assets/spells)
* Каждый вариант крафта хранится в отдельном JSON файле (000001.json, 000002.json), 
  структура файла должна быть закреплена в виде JSON-schema
* Дополнить SPEC.md про архитектуру крафта
