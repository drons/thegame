# Единый зуб-манифест глобального счётчика «base_price РОВНО у N» [I]

Источник: ретро-b21 — debt 000321.07 (п.3), кросс-тема Т3 (уточнение: держателей Девять,
не три — заявка per-merge аудита занижена, перепроверено кросс-агентом на tip `6330d2ec`).

## Дефект
Литерал глобального счётчика предметов с полем base_price («РОВНО у 252») продублирован
в ДЕВЯТИ тест-файлах: tests/scroll-trade-temples-000347.02.test.js T4,
tests/item-prices-000322.test.js R6, tests/items-potion-000321.07.test.js T8,
и шесть wave-файлов tests/items-{weapon,shield,armor,artifact,tool,ring}-000321.0{1..6}
(T10-канарейки). Десинхрон любой из девяти ловится ТОЛЬКО полным станционным прогоном
(прецедент: прогон №1 волны 000321.07 аннулирован именно этим — 27-файловые срезы
файл temples не накрывали). Механического гейта единства нет; ловушка описана только
прозой в memory/000321-potion-items.md.

## Цель
Один зелёный/красный индикатор: любой тест-файл с литералом счётчика base_price обязан
совпадать с живым числом каталога; рассогласование видно ОДИНОЧНЫМ прогоном одного файла
без знания, где ещё сидят держатели.

## Требования
* T1. Новый tests/base-price-manifest-000375.test.js: (а) живое число — вычислить тем же
  предикатом, что у держателей (дисковый свип assets/items/*.json на наличие base_price;
  сверить с зеркалом src/items-data.js); (б) ДИСКОVERY держателей: сканировать texts/
  на паттерн «base_price» + «РОВНО у <digits>» (и эквивалентные формулировки R6/T8 —
  снять с диска точные иглы), извлечь N, сравнить с живым числом; (в) исключающий
  self-match (файл манифеста свои строки не считает).
* T2. Состав держателей НЕ пиновать списком файлов (само-устареет на каждой items-волне;
  принцип — как у обнаружения, а не реестра). Пиновать только инвариант: множество
  найденных держателей НЕ пусто и содержит ожидаемые ЗАПРЕЩЁННЫЕ-к-потере имена
  (девятерка с диска базы задачи) — пропажа держателя = красный (это же закроет
  «молчаливое исчезновение канарейки»).
* T3. Мутации: (а) порча литерала в ОДНОМ держателе → красный манифест с именем файла;
  (б) вырез держателя-строки → красный по T2; (в) добавление base_price одному предмету
  → красный по (а) предикату, зелёный после пересъёма всех держателей (эмуляция волны).
* T4. Память: строка-ссылка на новый гейт в memory/000321-potion-items.md (ловушка
  «3 держателя» → девять + манифест) — по форме после 000373, не конфликтовать.
