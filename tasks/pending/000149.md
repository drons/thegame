В режиме боя кнопки применения боевой магии и лечения объединить в одну - открыть книгу заклинаний
 - В книге заклинаний должна быть возможность выбора заклинания для применения.
 - В книге должны отображаться те заклинания, которые знает активный персонаж (см. задачи 000139 и 000141), 
   в том числе должно отображаться описание заклинания и стоимость в мане 
   и прочих ресурсах (если они требуются для него)
 - Для каждого заклинания сгенерировать SVG иконку для отображения в книге заклинаний
 - Промпт для генерации иконки сохранить в JSON файле этого заклинания в каталоге assets/spells
 - Сcылку на иконку добавить в JSON файле этого заклинания
