Цель: общая механика «раз в день» и временных благословений (1 день)
+ состояние построек в сейве. Все последующие подзадачи эффектов
используют ТОЛЬКО этот слой (ни одна не хранит состояние сама).

  (src/main.js:431).

Ключевые проектные решения (зафиксировать в SPEC — раздел «Эффекты
построек» уже добавлен в 000064)
* Версию сейва НЕ поднимать: новые разделы — неломкое расширение v1
  (правило 000031); миграция не нужна.
* Состояние — по ЭФФЕКТУ, а не по постройке: ключ 'x,y:effectId'.
  Постройка с несколькими эффектами (фонтан: исцеление + монета) —
  независимые счётчики; «монета» НЕ наследует лимит «исцеления»
  (у неё флага `раз_в_день` в каталоге нет).
* Благословения — `{ источник: 'x,y', день: N, вид: 'damage'|'armor' }`;
  истечение — по дню (`buff.день < day`), очистка — в `clock.onDay`.
