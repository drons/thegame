Обобщение задач 000015, 000022, 000207, 000208, 000209

- В json файлах названия скилов, зданий, npc, заклинаний, предметов, рецептов крафта, 
  подземелий, мобов, групп мобов, visuals, заменить ссылками на соответствующие json файлы.
  Т.е. если что-то у нас имееет описание в виде json файла и это используется в другом json файле,
  то в исходном json файле должна быть ссылка на дочерний.
- Если объект, описываемый файлом json, имеет ассеты svg, то на эти svg тоже добавить ссылку в json.
- Файлы js запекать исходя из этих ссылок в файлах json.
- В тестах проверять целостность ссылок и соответствие json схемам всех json файлов.
