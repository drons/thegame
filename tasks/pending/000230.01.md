items-схема: поля slot/rarity/set/affixes для экипировки
(follow-up 000230 — расширение каталога предметов + валидация +
синк; приоритет P0; Зависимости: нет; от этой задачи зависят ВСЕ
контентные волны 000230.08–000230.15 и код-задачи .02–.07)

Родительская: 000230 (Исследование: система экипировки — части тела,
редкость, наборы).

Цель: расширить схему assets/items/schema.json и семантическую
валидацию (src/items.js) ОПЦИОНАЛЬНЫМИ полями для экипировки:
* `slot` — часть тела (enum): head, ears, neck, torso, forearms,
  right_hand, left_hand, palms, ring, legs, feet;
* `rarity` — редкость (enum): common, rare, epic, legendary,
  impossible (доли дропа 50/30/15/4.9/0.1 — ТЗ п.6; применение —
  000230.05);
* `set` — id набора (строка `[a-z][a-z0-9_]*`; бонусы наборов —
  000230.04);
* `affixes` — эффекты экипировки: массив объектов
  `{type: "skill", skill: <id из assets/skills>, amount: <число,
  может быть отрицательным>}` (повышение/понижение навыка — ТЗ п.7)
  и `{type: "free_cast", spell: <id из assets/spells>}` (заклинание
  без траты маны — ТЗ п.7).

Решения проекта (подробно — tasks/result/000230.md §5,
memory/000230-equipment-research.md §3):
* D1: единый kind `armor` для всех бронепчастей (head/neck/
  forearms/palms/legs/feet/torso — различает `slot`); новый
  subtype оружия `staff` (магический посох); новые kind:
  `shield` (левая рука), `artifact` (левая рука), `tool` (правая
  рука, инструмент крафта), `ring` (пальцы).
* D2: магазинная торговля НЕ расширяется новым видом: ассортимент
  `armor` (Бронник/Универсам) покрывает все бронепчасти;
  shield/artifact/ring/tool — в ассортимент `weapon` (Оружейная/
  Универсам). Таблица `виды` каталога построек — без изменений.
* D3: редкость экипировки — отдельное поле `rarity` (5 значений),
  НЕ пересечение с `tier` (1..4, редкость реагентов, 000157.01).
* D4: ссылки affixes на навыки/заклинания — проверка ФОРМЫ id в
  валидаторе, каталожность — тестом (прецедент spell_scroll,
  src/items.js:159-166).
* D5: данные наборов — в JSON предметов (поле `set` +
  `set_bonus` — 000230.04), НОВОГО каталога НЕТ (нет нового
  sync-скрипта, нет нового script-тега index.html).

Что сделать
-----------
1. assets/items/schema.json — ОПЦИОНАЛЬНЫЕ поля slot/rarity/set/
   affixes (enum'ы и формат по тексту выше); icon-паттерн — ОБЕ

3. scripts/sync-items-data.js — новые поля проходят в зеркало
   src/items-data.js (регенерация); идемпотентность (повторный

   меняются.

   значения (неизвестный slot/rarity, unknown skill/spell id,
