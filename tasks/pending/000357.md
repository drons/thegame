# Подсказки клавиш на боевых кнопках (в бою), «[Space]» → «[ ]»

В режиме боя добавить на кнопки подсказки о назначенных клавишах так же, как в
задаче 000356 для экранных кнопок. Исключение: вместо строки `[Space]`
отобразить `[ ]`.

Полный набор боевых кнопок и их клавиш взять из слоя боя на анализе. Единый
стиль с 000356. Тесты наличия/текстов, включая замену `[Space]` → `[ ]`.

Связано: 000356, 000351 (согласование верстки), 000355 (слой боя).
