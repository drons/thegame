Магазины: независимый ассортимент у каждого магазина
(по точкам глобальной карты / города)

Источник: запрос пользователя (drons, 2026-11-05).

Цель: у магазинов, находящихся в разных точках глобальной карты или в
разных точках города, должен быть независимый ассортимент. Например, если
мы купили все зелья у одного аптекаря, то у другого они не пропали —
можно купить ещё.

Что сделать:
* Сток магазина — на УРОВНЕ ТОЧКИ (уникальный ключ — по факту кода:
  координаты/ид постройки/ид NPC). Покупка списывает сток ТОЛЬКО этого
  магазина.
* Сейв: записи стока по магазинам (прецеденты serializeCampStocks и пр. —
  по факту кода); ФОРМА сейва не меняется (v1) — новые записи/поля,
  старые сейвы — санация absent → дефолт (паттерн 000298).
* Обновление ассортимента (refresh) — per-магазин, не глобально
  (по факту кода).

Тесты (красные):
* Два магазина одного вида, один и тот же предмет: выкупить весь сток
  первого → сток второго цёл (покупка возможна).
* Save/restore: стоки каждого магазина сохраняются раздельно (roundtrip;
  absent-запись → дефолт).
* РЕГРЕСС: одиночный магазин — сток/refresh бит-в-бит как текущее
  поведение (детерминизм).

Ограничения:
* новый код — БЕЗ комментариев; memory/000319-<slug>.md (контракт ключа
  точки, формата записей стока, refresh per-магазин);
* CHANGELOG при мерже (игровой процесс);
* если сейв/торговля описаны в spec — обновить + ре-пин В ТОМ ЖЕ коммите;
* RED → GREEN, полный прогон ТОЛЬКО в worktree (ps-проверка), W-08;
  0-diff вне SCOPE.
