Что сделать
-----------
1. src/efir.js (serialize/deserialize — базовые из 000085,
   расширяем): ФИНАЛЬНАЯ форма
   data.efir = { level: ≥1, xp: ≥0,
                 skillXp: { [skillId]: дробный ≥ 0 },
                 skills: { [skillId]: уровень ≥ 0 },
                 spells: [spellId…] }
   Поле skillXp (дроби практики — 000117) включено СРАЗУ: форма
   финальная, зафиксирована в SPEC; 000117 только начинает писать

   поднимать (000031; MIGRATIONS остаётся пустым).
   Чтение СТАРОЙ формы 000085 ({level, xp, skills} без
   spells/skillXp) → нормализация при чтении: spells пуст/нет →
   [spark, mend]; skillXp нет → {}; поле efir отсутствует →
   createEfir() по умолчанию (level 1, xp 0, skills {}, skillXp

   assets/skills; id заклинания не в assets/spells; spells — не
   массив; skills/skillXp — не объекты → тихий сброс ЗАПИСИ к
   дефолту + console.warn (паттерн 000029); битый раздел не
   роняет игру и не ломает прочий сейв.
