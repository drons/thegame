Скрывать стационарную группу мобов на глобальной карте после победы

Цель
----
После победы над стационарной группой мобов её спрайт должен
исчезнуть с глобальной карты и вернуться автоматически в день
респауна. Сейчас группа «повержена» по логике (бой не начинается,
статус тайла — «повержена»), но спрайт продолжает рисоваться все
`respawn_days` дней.

Состояние сейчас (сверено с master)
-----------------------------------
* Логика победы/респауна реализована (задача 000008) и работает:
  * `defeatedAt` — Map `'x,y' → день поражения` (src/main.js:242),
    сериализуется в сейв (`serializeDefeatedAt`/`restoreDefeatedAt`,
    src/day.js);
  * `maybeStartCombat` (src/main.js:700-702) не начинает бой:
    `if (defeatedAt.has(key)) return;` (key — тайл группы);
  * при смене дня `dueForRespawn` (src/day.js) + `defeatedAt.delete(k)`
    (src/main.js:517-518) — через `respawn_days` (по умолчанию 3)
    группа возвращается;
  * HUD-статус тайла показывает «Группа … повержена»
    (src/main.js:1134-1139).
* ПРОПУСК: отрисовка. В `drawSprites`, проход 3
  (src/main.js:1073-1081), спрайты групп рисуются БЕЗУСЛОВНО для
  каждого видимого тайла с `hasMobGroup` — без проверки `defeatedAt`:
  ```js
  for (const t of frameTiles) {
    if (!t.hasMobGroup) continue;      // ← defeatedAt не спрашивается
    const mf = G.mobFrames(t.mobGroup);
    ...
    s2.drawImage(m, ...);
  }
  ```
* `hasMobGroup` в `map.tileAt` детерминирован (hash координат) и не
  знает о `defeatedAt` (состояние живёт только в main.js) — поэтому
  отфильтровать «сверху», в map.js, нельзя; фильтрация — в слое
  отрисовки (main.js).
* main.js в node не грузится — прямых тестов на drawSprites нет;
  паттерн проекта: чистая функция в тестируемом модуле + vm-песочница
  (tests/global-settings.test.js) при необходимости.
* День респауна: `dueForRespawn` возвращает группу при
  `day - defeatedDay >= respawnDays` (src/day.js) — запись удаляется
  в момент смены дня, т.е. в день респауна группа снова «живая»
  по логике — спрайт должен вернуться ровно тогда же, без доп.
  состояния.
* Подземельные (блуждающие) группы не затронуты: они живут в
  `dungeonState.contents`, на глобальной карте не рисуются.

Что сделать
-----------
1. Чистая функция видимости группы — в src/day.js (там уже живут
   defeatedAt-утилиты: `dueForRespawn`, `serializeDefeatedAt`,
   `restoreDefeatedAt`), например:
   `groupVisible(defeatedAt, x, y)` — false, если запись `'x,y'`
   есть в `defeatedAt`, иначе true (принимает и Map, и восстановленный
   объект — как остальные утилиты).
2. `drawSprites`, проход 3 (src/main.js): рисовать спрайт группы,
   только если `G.groupVisible(defeatedAt, t.x, t.y)`. Остальной код
   прохода не меняется. Спрайт вернётся автоматически в день
   респауна — `defeatedAt.delete(k)` уже происходит при смене дня.
3. Альтернатива «мёртвый маркер» (рисовать на месте поверженной
   группы костёр/кострище) — НЕ делать в этой задаче; решение о
   маркере, если захочется, — отдельная задача. По умолчанию:
   полное скрытие до респауна.
4. Память: `memory/000122-mob-hide-after-victory.md` — где живёт
   фильтрация (слой отрисовки, не map.js) и почему (defeatedAt —
   состояние main.js, map.js детерминирован).
