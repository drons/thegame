# Заклинание школы природы «Притяжение»: сбор лута по площади

Добавить заклинание школы **природа** «Притяжение», применимое на глобальной
карте, в пещерах и подземельях. При применении происходит сбор всего лута
(сундуки, ресурсы, ягоды, грибы и т.п.) в радиусе `5 + Интеллект/10` тайлов
(округление — по существующей конвенции формул `Интеллект/10` в мире; найти
прецеденты, иначе floor).

Сбор = эквивалент ручного подбора каждой сущности (те же правила инвентаря,
перенос веса, события/достижения, зеркала сейва). Не должен поднимать лут
сквозь стены/преграды — только в топологической достижимости (уточнить на
анализе; если мир этого нигде не делает нигде — зафиксировать решение). Новый
assets/spells по схеме, тесты трёх контекстов применения + границы радиуса.

Связано: 000348 (тот же профиль формул), 000350 (третья «мировая» школа),
spec/spells.md, механика подбора лута (loot/gathering в src).
