Переформатировать экран поля боя: вписать в экран (десктоп + мобильные), SVG-иконки в 4 колонки, лог — оставшееся место

Цель
----
1) Поле боя (canvas) вместе со ВСЕМИ панелями управления должно
   вписаться в экран на десктопе и на мобильных устройствах —
   без скролла и обрезаний; поле боя по вертикали занимает весь
   экран (масштабируется под доступную высоту).
2) Надписи на кнопках действий заменить SVG-иконками и расставить
   кнопки в ЧЕТЫРЕ колонки вместо двух — правая часть становится
   компактнее.
3) Поле с текстовыми сообщениями (боевой журнал) занимает
   оставшееся место под кнопками (дополняет высоту правой панели).

Решения (зафиксированы для задачи)
----------------------------------
* «Вписать в экран» — АБСОЛЮТНОЕ требование: на любом вьюпорте
  (десктоп, портретный и альбомный мобильный) поле + все панели
  помещаются во вьюпорт без скролла страницы и без обрезания
  элементов.
* «Поле на всю высоту экрана»: canvas масштабируется (CSS) под
  доступную высоту экрана; на узких портретных вьюпортах, где
  полный по высоте КВАДРАТ (поле 7×7) не влезает по ширине, — поле
  масштабируется под доступную ширину (максимально возможный
  размер). Приоритет: вписалось > полная высота. Точные
  брейкпоинты/расстановка на узких экранах — на усмотрение
  реализации, зафиксировать в памяти.
* Кнопки: SVG-иконка БЕЗ текстовой подписи, 4 колонки
  (8 кнопок = 2 ряда), кнопки ~квадратные. Клавиша-подсказка
  [J] и т.п. с кнопки убирается (сами клавиши работают; таблица
  src/combat-keys.js НЕ меняется). Отключённая кнопка — как сейчас
  (opacity, title с причиной); aria-label = имя действия
  (доступность).
* Иконки (одна на действие, каталог assets/ui/, имена — на
  усмотрение, например `combat_attack.svg` …): attack — меч;
  fire — пламя; heal — крест/сердце; block — щит; quickItem —
  фляга (зелье); invItem — рюкзак; flee — бегущая фигура/стрела;
  endTurn — песочные часы. Светлый одноцветный рисунок под тёмный
  фон кнопки (#2c3040), стиль ЕДИНЫЙ с иконками 000123; итоговые
  силуэты — зафиксировать в памяти.
* Журнал: `flex: 1; min-height: 0` в колонке правой панели (под
  кнопками), `overflow-y: auto` сохраняется; фиксированные 170 px
  убираются.
* Правая панель: `display: flex; flex-direction: column`, высота —
  как у поля (экрана), компактная ширина, определяемая 4 колонками
  кнопок (≈ 240…280 px — на усмотрение реализации).
* Клик по клетке: координаты нормализовать по фактическому размеру
  canvas на экране (`getBoundingClientRect().width/height`), а не по
  константе CELL — обязательно (см. «Состояние сейчас»).
