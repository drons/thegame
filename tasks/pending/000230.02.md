Родительская: 000230 (Исследование: система экипировки — части
тела, редкость, наборы).

Цель: заменить двухслотовую модель (оружие/броня) моделью частей
тела: 11 групп слотов — head, ears, neck, torso, forearms,
right_hand, left_hand, palms, legs, feet + ring (8 слотов: 4 на
правой и 4 на левой руке — ТЗ: «до четырёх колец или перстней на
каждой руке»). Один предмет — в одном слоте своей части тела;
смена предмета возвращает предыдущий в инвентарь (как сейчас).
Боевые характеристики — сумма по ВСЕМ слотам. Старый сейв
неломко мигрирует (000031): `{weapon, armor}` →
`{right_hand, torso}`.

Что сделать
-----------
1. src/items.js — константа EQUIP_SLOTS (11 групп; ring — 8
   физических слотов ring_left_1..4 / ring_right_1..4);
   `c.equipment` — мапа slot→itemId; slotOf(item):
   `item.slot || (kind==='weapon' ? 'right_hand' :
   kind==='armor' ? 'torso' : null)` — существующие 10 предметов
   работают БЕЗ изменения их JSON; equip/unequip — по слоту
   (кольца: выбор конкретного из 8 слотов — при пустых — по
   порядку); equipmentBonus — мапа по слотам (backfill ключей
   weapon→right_hand, armor→torso).
2. equipmentStats(c) — damage/subtype/hitBonus/dmgBonus — из
   оружия в right_hand; armor — СУММА stats.armor всех слотов
   (torso + любая бронепчасть); интерфейс функции НЕ меняется —
   бой (combat.js) не трогается.
3. sanitizeEquipment/sanitizeEquipmentBonus — новая форма +
   backfill старой (weapon→right_hand, armor→torso); неизвестный
   слот/битое → null (паттерн 000029).
4. src/save.js — герой/состав: форма hero.equipment меняется
   только в коде; версию сейва НЕ поднимать (неломкое v1, 000031);
   старый сейв без новых слотов — валиден (absent = пусто).
5. UI — НЕ в этой задаче (000230.07); ядро API — готово.
