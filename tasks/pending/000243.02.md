Проблема (верифицировано ретро, 2026-10-28, на f2a508d)
-----------------------------------------------------------------
S1-B проверяет только общую структуру:
`loop.includes('n >= 1 && n <=')` (tests/final-repins-
000243.test.js:72) + deepEqual K-карты с live (L90).
Защитный fallback, напр. `n <= (SCHOOL_SCROLL_MAX[sch] ?? 99)`,
содержит подстроку 'n >= 1 && n <=' и не меняет K-карту —
пройдёт ОБА ассерта, но отменит задокументированный
«пин-арбитр» (новая школа не в карте → n <= undefined →
пин падает, fail-closed).

Цель: S1-B ловит точную отсылку к SCHOOL_SCROLL_MAX[sch]
без fallback, а не только форму «n >= 1 && n <=».
