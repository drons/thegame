## Решения (указатель: memory/000166-combat-resurrect-ui.md §1,
D1…D12)

1. **Выбор цели — на канвасе** (клетка/подложка + кольцо), НЕ
   список-пикер в книге: ТЗ «Тесты» прямо требует «клетка/
   подсветка»; паттерн таргетинга игры — клик по клетке.
2. **Мёртвый игрок — c.targetId = null** (автоцель; R-1 000163:
   единственный адресуемый «игрок-цель»-состояние); клик по
   клетке героя снимает явную цель.
3. **Прямой write c.targetId из UI** (ядро selectTarget
   союзников не меняем — 000080; evalSpell принимает; остальные
   читатели самовалидируют).
4. **ГЕЙТ — ПЕРВАЯ строка** каждого нового прохода/ветки (D2):
   без него — бит-в-байт (L1607/styleCalls/L1761).
5. **Новых цветов/ассетов нет**: существующие примитивы 000084/
   000124 (подложка ALLY_MARKER_UNDERLAY, подсветка #ffe27a),
   геометрия существующей подсветки цели моба.
6. **Без дальности** в UI (R-2 000163): цель в любом месте поля.
7. **Без новых клавиш/действий** (ТЗ: «если добавится»).
8. **Книга/keys/index.html — 0 строк** (data-driven 000149).
9. **Тесты: hero.mp = 50, «до-значения» mp/пул читаются ПЕРЕД
   кастом** (D11) — иммунитет к формулам derived и pre-roll 000167
   (координаты в сценах — динамические).
