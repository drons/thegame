# Отчёт по задаче 000304

Расстановка перед боем (механика 000260) запоминается в общем сейве
между боями: следующий бой стартует с последней расстановки. Порядок
расстановки показывается на вкладке «Отряд» [C] (G.squadUI, 000295).
Старые сейвы (v1, без поля) — fallback на якоря, версия сейва не
поднимается, миграций нет.
