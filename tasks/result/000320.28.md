## Решение (ВИЛКА (а) — данные обучения без диалоговой опции, наследует .27)

ТЗ-профиль «квесты» соблюдён РОВНО тремя опциями
(подсказка / квесты / подсказка+харизма 3 на последней); блок
обучение {навыки [swordsman, heavy] ≡ тренирует Арены, 25/40 — шкала
боевых школ} добавлен как ОБЯЗАННОСТЬ контракта «школы» для каждого
NPC здания-школы. Инертность данных: опции «обучение» нет →
train-вкладка UI недостижима; кузнечное наставничество отсекается
проверкой построек (typeBuildings('кузнечное_дело') = [8, 25] ∌ 7 →
reason 'нет постройки этого вида'). Всё запинено в T5/T6.
Отличие от .27: тренирует Арены в своих тестах пинится РЕЗОЛВЕННЫМИ
id навыков (rename-устойчивость к идущей волне .318.09), а не
numeric-путями.

Данные: имя Шрам (не фиксировано ТЗ — конвенция прозвищ батча), id
arena_challenger, роль «вызовший» (точная строка ТЗ), хук «Вызывает
чемпиона; его задания — подготовить к поединку» — последнее
предложение описания. Квеста ДВА: challenger_herbs (bring_item
herb_healing ×2 → 50/40 + mana_elixir ×2) → challenger_spiders
(kill_group группа 4 ×1 → 100/80 + greater_healing ×1), цепочка
«предыдущий» bring→kill (прецедент .23/.27). Запрет-лист диалога 99 =
дисковый .27 (95) + 4 оборота Кремня; свои 4 оборота зарезервированы
для .29 (цикл MINE в том же T5).
