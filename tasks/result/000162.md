## Решения (зафиксированы в memory и тестами)

* **R-1 (отложенный результат)**: синхронный роутер выбор в себя не
  влезает — resurrectPick открывает пикер и возвращает {ok:false}
  БЕЗ message (роутер молчалив); подтверждение мутации делает
  confirmResurrect САМ через ctx.world — единственная точка
  saveNow/flash/playerRender на успех (роутер на этом пути no-op).
* **Регидратация ДО мутаций**: reviveEntryFromRecord (чистая) →
  null = подделка/призрак = нулевые мутации (запись остаётся в
  deadMercs) — контракт §4.
* **Цена кандидата, не min** (контракт §4.2): «мало золота»
  проверяет золото против цены ВЫБРАННОГО — сценарий E3.
* **R-4 — дневного лимита нет**: per-эффект объект без ключа
  "resurrect" → hasDailyLimit fail-open false; отказ/успех НЕ
  жгут марку (E1/E4: в buildingOncePerDay нет «…:resurrect»).
* **Q-2**: отказ в confirm — пикер остаётся ОТКРЫТЫМ (выбрать
  дешевле / Esc); Escape — тихая отмена (без flash/save).
* **R-2**: «отряд полон»/«мало золота» — flash БЕЗ mark/saveNow/
  render (роутер-семантика отказов, BA4(d)).
* **Своя DOM-оболочка** (R-12): .resurrect-overlay/.resurrect-row/
  .resurrect-price/.resurrect-hint — чужие findOverlay/обработчики
  (combat/craft/inventory) пикер не видят.
* **000085**: roster/deadMercs — const live-ссылки; только
  splice/push, ссылки НЕ перезаписывать.
* **Определяемость**: 0 Math.random/Date в новом коде (цена —
  только Math.round в ЧИСТОМ ядре building-effects.js).
