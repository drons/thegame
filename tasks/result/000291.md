## Воспроизведение (красные, dde9de6)

Корень: `build()` (src/combat-ui.js) сидирует модульную карту
`lastSpells` из live-карты `ctx.lastSpells` ЦИКЛОМ С ПРОПУСКОМ
ИГРОКА (`u === ctx.combat.player` → continue — решение S3 000249).
Персистный выбор (live/сейв, ключ `'flogiston'`) не подхватывается
ни в бою N+1, ни на старте боя → `lastSpells.player` пуст →
`lastSpellVis` false → `display 'none'`, стаб-клик — «нет
выбранного заклинания».

Красные (3, все осмысленные — падение на assert контракта, не на
окружение):
* CU291-SHOW (vm) — live {flogiston:'spark'}: на ПЕРВОМ рендере
  боя кнопка ОБЯЗАНА быть видима/enabled + тап — сидовый «Искра»;
  зелёные guard (подделанный id — без сидинга, 0 console.error;
  сидовый + мана < 3 — видима, но disabled «не хватает маны (3)»).
* CU291-MEM (vm) — бой 1 успешный каст (live.flogiston='spark') →
  бой 2 (тот же live-объект и hero — паттерн main.js): выбор
  переносится, тап — ТОГО ЖЕ «Искра» (mp 13→10 — персистит).
* 291-E2E-HERO-START (vm-full) — зеркало баг-репорта в production
  (реальный main.js): сейв last_spells {flogiston:'spark'} → boot →

## Решение

**ФИКС = сидинг ГЕРОЯ в `build()` из `ctx.lastSpells['flogiston']`
— инверсия S3 000249** (явный запрос баг-репорта), ~+12 строк в
src/combat-ui.js:

```
const hp = ctx.combat.player;
if (hp) {
  const vP = ctx.lastSpells['flogiston'];
  if (typeof vP === 'string' && Array.isArray(hp.spells)
      && hp.spells.indexOf(vP) >= 0) lastSpells['player'] = vP;
}
```

Маппинг — тот же, что в recordLastSpell ('flogiston' → 'player');
гвард идентичен союзническому (строка + член hero.spells) —
забытый/подделанный id — без сидинга (legacy-путь, 0 ошибок).
Следствие (без отдельной правки видимости): (б) на первом ходе
кнопка видима с персистным выбором + бейдж пула сидового спелла;
(а) выбор из боя N / сейва виден в бою N+1. Рестор D3 000227
(запись на любом тапе) ОТКЛОНЁН — S1 000249 (только на успехе)
ЖИВА; бит-в-байт: castRow r.ok-ветка, FX-блок 000248,
spellBtnOf/lastSpellPress (бейдж-контракт 000227), S2/S4, сейв v1.
