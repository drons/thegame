## Решения

Контракт — memory/000272-summon-regen.md (указатель + ключевое):
* Формула тика — ТОЧНОЕ ЗЕРКАЛО mobAct-паттерна (+max(1, round(maxHP×0.1)),
  потолок maxHP), НЕ healAlly и НЕ +1/тик spell-«реген» — прямой
  присваивание защищает от дрейфа healAlly (ТЗ: «тот же моб-паттерн»).
* Место тика — конец тела ally-цикла startRound, ПОСЛЕ
  summonTurns-continue и после a.buff-«реген»-декремента:
  рассеивающийся призывной тика НЕ получает (принятый паттерн 000267 §7.4,
  не «чинить»); коммутативность min-капа — порядок тиков на результат не
  влияет.
* Тик молча (без log), 0 новых c._rng, 0 новых полей c.* — сейвы/RNG
  бит-в-бит (пин 000272-CTRL-1).
* Чтение a.traits.regen без &&-гарда — изоморфно моб-стороне; TypeError
  невозможен (все союзники через makeAlly, traits всегда присвоен,
  memory §4).
* CHANGELOG — дата = день мержа (2026-10-26), формулировка «3 раза за
  4 раунда жизни» по контракту 000272-DISP-1 (правки по итогам ревью).
