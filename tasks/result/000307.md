# Отчёт по задаче 000307

Опыт за применение боевых заклинаний игроком — пропорционально
потраченной мане и разности уровней кастера и опорного моба.

## Формула (зафиксирована в spec/skills.md)

`XP = round(мана × (1 + 0.1 × max(0, D)))`

- мана — реально потраченная (`spell.мани` каталога); free_cast
  (000230.17) — 0 → XP = 0.
- D = уровень персонажа − уровень опорного моба: цель применения
  (урон/ослабление/контроль/дебаф), если она моб; иначе — ближайший
  живой моб (`nearestMob`, детерминирован, 0 RNG); живых мобов нет — D = 0.
- Отрицательная разность (моб сильнее) — бонус нулевой, без штрафа.
- `Math.round`, без floor 1 (XP может быть 0).
- Навык — по школе: огонь → firelord, лёд → icelord, исцеление →
  meditation, природа → nature; Тень/Защита — навыка нет, опыта нет.
- Неудачный каст (`evalSpell` → `{ok:false}` до расхода пула/маны) —
  опыта нет (блок практики недостижим).
