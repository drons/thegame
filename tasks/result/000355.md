# Результат 000355 — полёт стрелы из лука виден на поле боя

## Диагноз (корень)

Не «система координат/масштаб слоя» (гипотезы ТЗ): бокс слоя
`.combat-atk-layer` тождествен border-box canvas-поля (одна CSS-формула
`min(100vh−32px, 100vw−304px)` база + portrait; пин AF6 сверяет слой
С canvas). Корень — ложная D11 из memory/000248: все 10 кастом-свойств
`--fx-*` в `syncAttackFx` записывались bracket-присваиванием
`el.style['--fx-x0']=v`. В реальном CSSOM custom properties — ТОЛЬКО
`style.setProperty`; bracket — JS-expando, в cascade не попадает ⇒
IACVT-цепочка: left/top стрелы = auto (static-угол слоя — «рисует вне
поля»), keyframes полёта нейтрализованы, `rotate(var(--fx-angle))` →
none, у `.combat-atk-hit` var'ы без fallback убивали ВСЮ animation
(вспышка удара не показывалась нигде), lunge transform = none, у моба
терялся 300ms-гонорар полёта. Пины 000248 были вакуумно-зелёными: мок
style = plain object round-trip'ит expando, ридеры читали той же
bracket-дыркой.
