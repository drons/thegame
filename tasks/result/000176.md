## Что сделано

1. **Диагностика (постмортем)**: 000011 (f34171d) наложил 2D-спрайт-слой
   (`drawSprites`, #sprites) поверх прежнего WebGL-мира и НЕ удалил
   прежний draw-путь — он рисовался БЕУСЛОВНО каждый кадр (src/main.js,
   до фикса): цветные тайл-квады, золотые маркеры построек, красные
   маркеры групп мобов (без учёта `G.groupVisible`/defeatedAt) и
   «светящийся ромб» Флогистона (6 вершин, PLAYER_COLOR). Отсюда брач:
   * «старые тайлы / фигура вместо героя» — когда спрайт-слой пуст/
     неполон (загрузка 299 ассетов, onerror конкретного ассета —
     retry/timeout в лоадере нет, частичная загрузка), единственный
     видимый слой = безучловный WebGL = точный вид до 000011;
   * «иногда» (штатный геймплей) — после победы над группой спрайт-
     слой скрывает её (000122), а красный WebGL-маркер ОСТАЁТСЯ;
   * «дублируется отрисовка / нагружает компьютер» — те же сущности
     дважды на кадр; при обзорном зуме 4 ~358k вершин + gl.bufferData
     каждый кадр под готовыми непрозрачными текстурами.
2. **Фикс (src/main.js — ЕДИНСТВЕННЫЙ файл кода, +197/−99)** —
   поэлементный гейт legacy-прохода по готовности спрайта: в
   `buildFrame(rp, now)` legacy-вершина каждого элемента рисуется
   ТОЛЬКО если спрайт-слой не может нарисовать элемент; селекторы
   готовности вынесены в ОБЩИЕ хелперы (`tileFrameImg`/`mobFrameImg`/
   `heroFrameImg`/`buildingAsset` + `buildingRec`, IIFE-уровень),
   которыми пользуются ОБА слоя — XOR-контракт: каждый элемент в
   кадре ровно 1× (спрайт ИЛИ legacy-фигура), дрейф исключён. Красный
   маркер дополнительно гейтится `G.groupVisible` (паритет со
   спрайт-проходом 3 — фикс «прола»). Штатное состояние: **0 вершин**
   в WebGL-проходе (пересборка Float32Array + GPU-загрузка убраны).
3. **Контракт 000011 сохранён**: элемент без готового спрайта → его
   legacy-фигура (герой остаётся ромбом, а не исчезает);
   `spriteLoader` null (нет sprites.js в цепочке) → legacy-сцена
   ПОЛНАЯ, игра не падает (все ЧЕТЫРЕ селектора с гардом
   `if (!spriteLoader) return null` — гард `buildingAsset` добавлен по
   ревью: без него первый кадр спавн-мира крашил rAF-цикл).
4. НЕ тронуто: index.html (новых модулей/script-тегов нет),
   WebGL-setup L124-191 и guard no-WebGL, движение/инпут в frame()
   (зона 000170), сейвы/детерминизм/RNG, бой и подземелья, SPEC.md
   (регион 000168; строки «WebGL+JS+HTML» и rgb 0..1 после фикса
   остаются верными).
