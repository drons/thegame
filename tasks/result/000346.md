# Результат: 000346 — цены ×8 на шаг редкости

## Решение

Множитель редкости ВЫЧИСЛЯЕТСЯ в резолвере, ассеты НЕ переиздаются
(`assets/` 0-diff, зеркала `src/*-data.js` 0-diff; прецедент 000322 —
`base_price`/`value` цена продавца, не канон; в SPEC.md слово «цена»
отсутствует, «цена==value» было только как тест-формула).

Единая точка — `src/items.js`:
`RARITY_PRICE_STEPS = {common:0, rare:1, epic:2, legendary:3, impossible:4}`,
`rarityPriceMult(rarity) = 8^шаг`, без `rarity`/неизвестная → `×1`
(`hasOwnProperty`-guard), экспорт рядом с `ITEM_RARITIES`. Множитель —
точная степень двойки ⇒ round не дрейфует, отношение соседей ровно 8.

Применён к БАЗЕ во всех четырёх ценовых функциях:
- `buyPrice` / `sellPrice` (`src/items.js`) — множитель и в оборонительной
  ветке `SELL_BASE_VALUE` (common-проба 000316 бит-в-бит);
- `npcBuyPrice` / `npcSellPrice` (`src/npc.js`) —
  `base = (base_price ?? value) × rarityPriceMult(rarity)`, ветка `!it → 0`
  сохранена, `mult_покупки/продажи` × derived — без изменений.

Свитки: без `rarity` → ×1; «×8 по уровню заклинания» — ортогональная 000347.
НЕ тронуты: боевой авто-голл (raw value), тултипы, сейв, `index.html`,
`src/craft*`.

Контент-факт по диску: 73 входа NPC-торговли / 44 уникальных предмета —
НИ ОДИН не имеет `rarity` (withRarity=0 на диске) ⇒ множитель численно ×1,
витрина NPC бит-в-бит; полосы `value` городских лавок по редкостям разнесены
~8-кратно.
