   ключа типа нет → console.error (1×/вызов) + fallback

   test.js L240/L347). Остальные гарды — дословно 1:1 (R6).

   < 1 мс); наблюдаемый порядок setShop → textContent сохранён
   (HU4). Строка побайтово для ЛЮБОГО чтения часов.
