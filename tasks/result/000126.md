## Что сделано

1. **src/craft-ui.js (НОВЫЙ, 441 строка)** — полноэкранный экран
   крафта (паттерн 000125/000030/000041: оверлей `combat-overlay
   craft-overlay`, панель `.craft-panel`, делегированный клик,
   [Esc]-слушатель, лог). UMD по образцу 000038 (чистый при
   загрузке, ленивый `globalThis.Game` в момент вызова через
   rootRef). Состав экрана: рецепты сгруппированы по видам
   (`CRAFT_TYPES`): «<вид> — уровень L» (craftLevel), «нужно ур. N /
   есть L», исходники с пометкой нехватки (`G.hasItem`), «Качество:
   X% Выход: Y%» (qualityChance/yieldChance), результат
   (`G.getItem(...).name`), кнопка «изготовить» (disabled + title по
   `canCraft`); у вида зачарование — пикер ТОЛЬКО изученных
   заклинаний (с маной), выбранный id ВСЕГДА передаётся явным
   `opts.spellId`. Действие — `Game.Craft.craft(hero, id,
   {building, spellId})`; результат в лог (предмет, качество, выход,
   xp/уровень виду) + `onChange` (сейв) + перерисовка +
   `G.playerUI.render()`. Публичная поверхность: `open()/close()/
   isActive()`. Саморегистрация спец-действия `'craft'` в
   `Game.buildingActions.specials` при загрузке (таблица 000128;
   гард — нет buildingActions → console.error, без краха).
2. **Строка «Крафт» в buildingUI (src/building-effects.js, +16)** —
   СИНТЕЗ в `buildingActions()` ПОСЛЕ цикла эффектов: у любого
   здания, чей `id` ∈ union `рецепт.здания` (11 зданий: 3,5,8,12,
   16,17,18,25,40,42,48), строка `{id:'craft', имя:'Крафт',
   доступен:true}` — С NPC и БЕЗ. Не запись EFFECTS, не правка
   каталога (решение 1 контракта: запись EFFECTS ломалась бы
   `раз_в_день: true` у 40/42).
3. **Наставники в диалоге NPC (src/npc.js +38/−1, src/ui.js +16)** —
   в `dialogOptions()` после опций `npc.диалог` ПРИДВИГАЮТСЯ опции
   «обучить <вид>» (решение (b): только если `обучение.навыки`
   маппятся в вид через `SKILL_CRAFT_TYPE` И NPC стоит в постройке
   этого вида; дедупликация по виду; `доступен/причина` —
   `canMentorCraft`). Клик — ветка `'обучить_крафт'` в
   `onOverlayClick` (ui.js) → `Game.Craft.mentorCraft` (+1 уровень
   виду за `цена_за_уровень`). Живой пример: Торн (Кузница,
   forge→кузнечное_дело).
4. **Проводка [E] (src/building-actions.js +4, src/main.js +8/−1)** —
   единый роутинг 000071/000128: [E] → buildingUI → «Крафт» →
   `onBuildingAction('craft')` → спец-хендлер → `craftUI.open()`.
   Закрытие/стек: гард craftUI в `toggle()` ([E] не открывает
   buildingUI поверх открытого экрана), keydown-гейт + `inCraft` в
   frame (движение заблокировано), 3× `G.craftUI.close()` в
   startCombatAt/maybeStartCombat/startDungeonCombat (бой закрывает
   экран). Все обращения — за `G.craftUI &&` (деградация 000053).
5. **index.html (+53)** — CSS-блок `.craft-*` в конце `<style>`
   (свой скоуп, общие `.cp-*`/.combat-* не тронуты; каскад:
   `.craft-overlay {display:block}` побеждает flex-center базы) +

6. **SPEC.md «Крафт» (+5/−5)** — примечание «UI отложен в 000126» →

7. **SVG — НЕТ** (решение 8: ТЗ не требует иконок; экран текстовый —
