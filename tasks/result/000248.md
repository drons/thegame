## Решения (указатель — memory/000248-combat-attack-fx.md)

* D1 FX = DOM-слой, не canvas (steady-state — ноль операций;
  pointer-events: none).
* D2/D3 масштабирование: слой 1:1 с `.combat-banner` (вкл.
  portrait), маркеры в % (лунж 0.5 клетки, стрела atan2 — слой
  квадратный, аспект сохраняется); пин 000248-SC держит тождество
  формул.
* D4 kind без побочных эффектов: герой — прямое чтение
  `equipment.weapon` → subtype 'bow' (equipmentStats НЕ вызывается —
  у него побочные эффекты); союзник/моб — u.role 'ranged'.
* D5 ОДИН melee-силуэт для всех melee (ТЗ допускает; в бою нет
  арта оружия).
* D6 цель = victim (снимок HP ДО run(), только attack) ||
  intended (c.targetId) || null; промах — без .combat-atk-hit.
* D8 длительность 600 мс (ритм BREATH/SPELL_FX_MS); окно моба 300 —
  существующее, не расширяется.
* D10 слой ленивый: 3 существующих пина box.children проходят БЕЗ
  правок (сцены без атак — проверено).
* F4 (задокументированное ограничение): атака моба по СОЮЗНИКУ —
  без FX (эвристика 000062 — только урон игроку; расширение требует
  события ядра c._uiEvents — «ноль правок ядра» + «не больше ТЗ»).
