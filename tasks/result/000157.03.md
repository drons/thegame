## Что сделано

1. **src/dungeon.js (+53/−3)** — `gatherDeposit(contents,
   depositId, canFit)`: атомарно (проверки → ОДНА мутация
   `dp.gathered = true`), паттерн openChest, БЕЗ RNG; причины
   отказов byte-в-точности: `'нет такой залежи'` / `'уже собрана'`
   / `'не влезает в инвентарь'`. Ёмкость — предикат `canFit`
   (инверсия зависимостей, dry-run 000046: ядро не видит
   items.js), проверяется ДО отметки gathered — отказ = ноль
   мутаций (залежь остаётся, повтор после освобождения).
   Экспорт ФЛАТ на Game (Game.gatherDeposit, паттерн openChest).
   `validateDungeonContents`: `deposits` — ОПЦИОНАЛЬНОЕ поле
   (паттерн `boss` в mobs): отсутствует → ключа нет в копии
   (старые сейвы валидны, DEP-4 deepEqual); присутствует →
   глубокая копия `{id, x, y, item, amount, gathered}`; битое →
   null (запись отбрасывается тихо). Версия сейва НЕ
   повышается — собранность персистирует в секции dungeonMemory
   ПРАВО как `opened` (ТЗ «ВНИМАНИЕ» выполнено: 000153.01
   смержена до .03).
2. **src/locations.js (+19)** — `interactDeposit(ds)`: 11-й
   экспорт, чистая (без мутаций/RNG — regex-гиена LOC-2): на
   клетке НЕСобранной залежи (dungeon) → `{type:'deposit', id}`,
   иначе null; шаблон interactExit.
3. **src/main.js (+52/−2)** — `locationOnInteract`: отдельный
   if-блок залежи ПОСЛЕ city-ветки: `interactDeposit` →
   `gatherDeposit(ds.contents, id, (it,n) => G.canAddItem(hero,
   it, n).ok)` → награда по сундуку-шаблону (без золота):
   `G.addItem(hero, id, r.amount)`, `ds.log.push('Залежь: +N
   <имя из каталога>')`, hudFlash 5 с, `playerUI.render()`.
   Отказ (единственный достижимый — «не влезает»): flash
   «Залежь: не влезает в инвентарь», БЕЗ строки в ds.log, БЕЗ
   авто-золота — предмет не теряется никогда. Fail-closed
   (UMD 000038): console.error ОДИН раз при загрузке (wiring-
   секция) + тихий typeof-гард call-time. Геттер `__game` +
   `contents` (live, null в городе). Ветвы выхода (000177) и
   города (000107/000148.03) — БУКВАЛЬНО НЕ ТРОНУТЫ; приоритет
   [E]: выход > город > залежь > no-op (stairs 000153.03 —
   вставится между городом и залежью при её мерже).
4. **src/dungeon-ui.js (+17)** — контекстная строка «Залежь —
   [E]» в HINT-элементе (hintEl/hintBase, пересчёт в render()):
   только стоя на клетке не-собранной залежи; вне залежи hint =
