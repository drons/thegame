1. **src/building-effects.js (+271/−3)** — чистые функции + запись
   реестра:
   * `linkTeleportCircles(circles, x, y, R, tieHash)` — ближайший круг по
     **RASСТОЯНИЮ CHEBYSHEV** (граница R включительно); якорный тайл
     исключён; равенство — MIN tieHash, финальный тай-брейк
     лексикографический (x, затем y; hash2 32-битный — коллизия
     теоретически возможна); порядок списка НЕ влияет на результат;
     пары нет — `{ pairId: null, reason: 'no_pair' }` («спит», не

     проходимый тайл в КОЛЬЦЕ footprint-соседства парного круга
     (dx -1..width, dy -1..height; внутренность footprint'а — не

## Решения (зафиксированы в memory)

1. **Парность — ближайший по Чебышеву в радиусе R (граница
   включительно)**, тай-брейк tieHash (TELEPORT_TIE_SEED) +
   лексикографический. Пары АССИММЕТРИЧНЫ: каждый круг — к СВОЕМУ
   ближайшему (A25; в seed-мире естественно: (-17,36)→(25,-50),
   (25,-50)→(94,-64)).
2. **Пары нет — «СПИТ»**, не ошибка: «круг молчит: нет пары вблизи»,
   строка disabled.
3. **Скан — ТОЛЬКО при первом подходе** (openBuildingUI) + кэш в
   сейве; повторного скана никогда. Предфильтр — necessary-условие
   якоря слота; формулу якоря фиксируют goldens 000073 — не менять
   без переписи скана.
4. **apply — чистый, по снимку**: dest и стоимость — НЕ в apply
   (dest — из снимка-кэша, стоимость — в main.js из каталога);
   перенос/списание — ханк r.teleport в onBuildingAction. Любой отказ
   (мало золота/«спит»/нет dest) — без saveNow/списания (000071).
5. **Разовая оплата**: первое — 25 золота (каталог), повтор —
   бесплатно; лимита раз-в-день НЕТ нигде (hasDailyLimit 000071
   работает без изменений).
6. **dest — КЛЬЦО footprint** (не внутренность), мир-оракль:
   проходим, не в building, без группы мобов (шаг в группу = бой),
   не тайл исходного круга. Все соседи непроходимы → переноса нет,
   золото не тратится (цель найдена ДО списания — при скане).
7. **Сейв `teleports`**: строки 'x,y'; версию НЕ бампить (неломкое v1,
   000031); restore fail-open, мусорная запись — отброс целиком.
8. **RESOLVE-БУГ** — единое выражение резолюции записи по buildingId —
   ОБЯЗАТЕЛЬНО для 000074/000076 (храмы) — те же строки.
