## Решения и отклонения от файла задачи

1. **iron_sword_ore, а не «база для перковки»** — id iron_sword занят
   рецептом перковки (wood_sword+sulfur); цепочка перковка→из руды
   невозможна правилом «исходники не меньше базовых», превращение в
   цепочку потребовало бы переписи master-данных. Два рецепта с одним
   результатом — существующий паттерн (iron_sword уже был двойным;
   moonstone теперь тоже: огранка + руны).
2. **Основной навык dexterity** в поле «навыки» столярных рецептов —
   таблица SPEC «Виды крафта» называет Ловкость для столярного дела;
   assets/skills содержит основные навыки, тест knownSkill их
   принимает. Задаче 000046 (реализация крафта): в «навыки»
   встречаются основные id, а не только вторичные.
3. **Рунопись сверх списка** — см. п. 3 «Что сделано» (требование
   покрытия всех шести видов).
4. **Стрелы отложены** — в задаче «если появятся как предмет»:
   предмета-стрелы нет, kind для снаряда в схеме не существует.
5. **copper_ore пока не участвует в рецептах** — торговый товар
   (соответствует описанию reagent в SPEC); рецепт на медь —
   отдельная задача.
