# 000028: перепутанные клавиши перемещения — проверка, исправление, тесты

Статус: выполнено. Тесты: 186 → 196 pass (новых 10, tests/controls.test.js).

## Что было (баг)

В `src/main.js` таблица `KEY_DIRS` смешивала ДВЕ независимые системы
идентификаторов клавишного события:

* `e.code` — ФИЗИЧЕСКАЯ клавиша, НЕ зависит от раскладки (spec UI Events):
  `ArrowUp`, `KeyW`, `KeyA`, `KeyS`, `KeyD` — работали.
* `KeyЦ`, `KeyФ`, `KeyЫ`, `KeyВ` — значения из мира `e.key` (символы
  раскладки) с префиксом «Key». Кириллических `e.code` не существует
  (code строится по US-раскладке), поэтому эти четыре связки были
  МЁРТВЫМИ: «ЦФЫВ» из заголовка/подсказок ни при каком нажатии не
  срабатывал по своей записи. Перемещение по русской раскладке всё же
  работало, но только «в лоб» — через физические `KeyW/A/S/D` (то же
  железо, что ЦФЫВ), т.е. задокументированные связки не соответствовали
  коду — перепутаны связки.

## Что сделано

* **Новый чистый UMD-модуль `src/controls.js`** (без DOM, без зависимостей;
  браузер — `Game.*`, node — require):
  * `DIR_DELTA` — имя направления → дельта в мировых координатах
    (y — вниз: up = [0,-1]);
  * `CODE_DIRS` — `e.code` → направление: стрелки + физические WASD
    (только канонические code, без кириллицы);
  * `KEY_DIRS` — `e.key` (lowercase) → направление: русские символы
    ц/ф/ы/в — фолбэк уровня символов;
  * `moveKeyForEvent(e)` → id клавиши перемещения (e.code, если он
    распознан, иначе нормализованный e.key) или null;
  * `deltaForMoveKey(id)` → [dx,dy] по id;
  * `deltaForEvent(e)` → [dx,dy] сразу по событию (удобно для тач/вирт.
    клавиатур: `{key:'ц'}` достаточно).
* **src/main.js** — локальная `KEY_DIRS` удалена; keydown/keyup/`tryMove`
  используют `G.moveKeyForEvent`/`G.deltaForMoveKey`. `keys` (Set) хранит
  id клавиш в порядке нажатий: у двух клавиш одного направления — два
  id, движение продолжается, пока удержана хотя бы одна (семантика как
  раньше, но без мёртвых записей).
* **index.html** — `<script src="src/controls.js">` перед main.js.
* **tests/controls.test.js** (10 тестов): дельты мировых осей; стрелки;
  WASD по code; русские символы по key (регистр не важен, code
  «Unidentified» — виртуальная клавиатура); приоритет code над key;
  РЕГРЕССИЯ — «KeyЦ/Ф/Ы/В» и прочие несуществующие code → null;
  не-перемещающие клавиши → null; согласованность таблиц (code — только
  канонические, key — только символы); согласованность id keydown/keyup
  при смене регистра (Shift).

## Ключевые решения

* Маппинг двухуровневый: `e.code` (физика, авторитет) → `e.key`
  (символ раскладки, фолбэк). Так ЦФЫВ работают в русской раскладке и
  через физические коды, и через символы (виртуальные клавиатуры,
  где code = «Unidentified») — это же API пригодится задаче 000018
  (тач-контролы).
* id в Set — конкретная клавиша (code или символ), а не имя направления:
  сохранено поведение «две клавиши одного направления, отпустил одну —
  вторая ведёт».
* См. memory/000028-keys-code-vs-key.md.
