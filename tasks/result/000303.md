D = m.level − hero.level

aggroChance(D)   = D ≤ 0 ? 0 : min(0.6, 0.1 · D)

## Механика

- На каждый успешный шаг игрока `wanderStep(contents, d, player
  {x, y, level})` (3-й аргумент): для каждой живой группы ПОСЛЕ
  legacy-ролла направления (ТОТ ЖЕ слот — слоты потока не сдвигаются)
  при D > 0 и 1 ≤ Чебышёв ≤ aggroDistance(D) — ОДИН доп. вызов rng():
  < aggroChance(D) — единичный шаг к герою (ось с большим |дельтой|,
  тир — горизонталь; занята/стена — вторая ось; обе — остаётся;
  legacy-ролл потреблён, значение игнорируется), ≥ — legacy-шаг;
- выход группы на клетку героя → `{ contents, landed }` →
  `{type:'combat', group}` → startDungeonCombat (мобы в бою level =
  уровень группы, mobLevel);
- 2-арг, D ≤ 0, D > 0 вне зоны — бит-в-бит legacy (AGG-4/AGG-7);
- босс ABYSS — участвует (обычная группа в contents.mobs);
- НОВЫХ полей нет — сейв бит-в-бит.
