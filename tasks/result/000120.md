## Решения (детали в memory)

* **Корневая причина дефектов 000062** — в генераторе
  `scripts/gen-mob-art.js`: вызовы `C.el.pth(d, fill, c, w)` и
  `C.el.curve(d, c, w, extra)` с перепутанными/отсутствующими
  аргументами (extra-строка в слоте цвета, w=undefined → NaN, лишняя
  строка перед `/>`). Генератор детерминирован: повторный запуск
  ПЕРЕГЕНЕРИРУЕТ 29 файлов снова сломанными. В этой задаче генератор НЕ
  чинился (ремонт — только атрибуты 29 файлов; перегенерация 36 мобов —
  за scope). Гейт против регенерации — npm test; кто будет править
  gen-mob-art.js — обязан починить эти вызовы (строки в memory).
* **Таблица viewBox по каталогам НЕ вводится**: единого источника правды
  размеров нет — риск ложных срабатываний; размеры мобов уже зафиксированы
  tests/mob-art.test.js.
* **Парсер общий, НЕ запрещает «тяжёлые» теги** (logo.svg легально
  содержит SMIL/`<text>`/xlink); запрещённые теги мобов — территория
  tests/mob-art.test.js, не дублируется.
