## Решения (указатель: memory/000174-mob-move-anim.md)

1. **Переиспользование пути A* — запись принятых шагов**:
   ядро пишет «to»-тайлы каждого выполненного шага в
   `c._uiMoves`, UI рисует именно эту последовательность.
   Пересчёт в UI отклонён (зависит от `c._rng` и позиций других
   юнитов — replay разойдётся); экспорт «полного пути» из ядра
   отклонён (реструктуризация 000155, угроза пинам R1–R10).
2. **Решение C — pre-roll НЕ анимируется** (действует до
   первого кадра — игрок «телепорт» не видит; иначе падали бы
   координатные пины первого кадра :518/:568).
3. **Поотрезочный easing** 300 мс/сегмент («шаг по клеткам»,
   паттерн 000033); multi-cell мобы — весь прямоугольник как
   одно; z-порядок — по финальной модели.
4. **Союзники/герой не анимируются** (ввод игрока — дискретно;
   фильтр drain `side === 'mob'`).
