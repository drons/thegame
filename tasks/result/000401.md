## Что сделано
1. `tests/changelog-day-structure-000389.test.js` — ядро: `parseDays` распознаёт
   заголовок как `^## \d{4}-\d{2}-\d{2}\b` (граница токена после дня, хвост
   строки — приписка даты). Ветка склейки не-датных `^## ` (исторический фикс
   T3 синтетика «ж») не тронута — побайтовое прежнее поведение.
2. Тот же файл, T3 — три synthetic-кейса в существующую таблицу (число test()-
   блоков T3 не меняет): «з: дата с припиской и дублем секции» → dup 1;
   «и: дата с припиской и нарушением порядка» → order 1 (не-вакуумность
   T2-плеча под припиской); «к: чистая дата с припиской» → dup 0 / order 0.
3. Тот же файл — НОВЫЙ блок `000401 T1` (дельта +1 тест; диск базы подтвердил
   ровно 4 существующих test(): Т1–Т4 → итог файла 5/5 = 4+1, карточка
   совпала с диском). Прямые проверки parseDays/предикатов: приписка даёт день
   с секциями (до фикса день не создавался вовсе — анти-вакуум); приписка +
   дубль → антидубль красный; приписка + «Исправления→Интерфейс» → порядок
   красный; не-датный `## Приложение` между приписочными датами расклеивает
   дни; «## 2026-11-165» и «## 2026-11-16extra» — НЕ даты (ловит ослабление
   `\b`); чистая дата с хвостовым табом — дата (покрытие `[ \t]*$` прежним
   контрактом); «## 2026-11-16-rc1» — день с припиской (дефис не word-символ,
   сознательное поведение по ТЗ «хвост игнорировать как приписку»).
   Существующие титулы T1–T4 НЕ переименованы (TAP-пины downstream не
   двигаются); T4 (пин живой CHANGELOG, собственный `dayMatch` без приписок)
   вне скоупа — не тронута.
4. `memory/000389-changelog-day-structure.md` — append-секция «Усиление
   parseDays (000401…)»: семантика `\b`/приписки, запиненные границы, и
   пункт 3 ТЗ: конвенция «порядок буллетов = порядок мержей» машинно НЕ
   запинена — сознательный отказ, строка ОТКРЫТОГО ДОЛГА (вторая половина
   D2 ретро-b25).
5. Карточка `tasks/pending/000401.md` → `tasks/done/` (git mv), этот result.
