## Вывод

Нарушений в смежных областях не найдено: затронутые модули (runAction, drawUnits, render, castRow, resurrectCast) проверены по всем областям — canvas-слой последний и изолирован, боевое состояние транзиентное (сэйвы не тронуты), 0 новых c._rng, зеркала ядра сверены строчка-в-строчку, окно 600 мс с ранним возвратом, все пины живы, три последующих мержа прошли ребейз с полным зелёным прогоном. Правка SPEC вытекает из ТЗ (re-pin spells.md 104→107 = +3 строки), но новый буллет имеет 2 minor-противоречия с поведением, зафиксированным же коммитом (аура для legacy-лечения — по факту полёт/вспышка на mostWounded; полёт/вспышка отсутствуют при автоцели без явной цели). Главное тестовое major: заявленная в коммите и CHANGELOG аура для toId='self' (лечение/защита ИЗ КНИГИ) не покрыта ни одним тестом, плюс не закреплённые детали (кольцо кастера, хвост полёта, не-тривиальные случаи зеркал autoResurrectId/healFxTargetId, гард R5 toId null).
