## Решения (ключевые, память §3)

- **D1 — строгий резолв**: НЕВАЛИДНАЯ ЯВНАЯ цель → «нет цели»,
  пул НЕ сгорает (валидация до списания), fallback на
  nearestEnemy НЕ происходит — HUD («Цели нет») и ядро
  согласованы (000037 «одна причина — одно поведение»), зеркало
  игрового пути.
- **D2 — единый хелпер `allyTarget`**: правило валидации в 4
  точках — один источник (анти-дублирование).
- **D3 — диспатч `c.selectTarget`**: валидатор
  `playerSelectTarget` переиспользуется; отдельного
  `allySelectTarget` нет; слот моба — null как раньше (D6).
- Дефолт цели (ближайший враг при входе в союзный слот) — без
  изменений (D5); лечение поддержки (H) — без изменений (D7);
  UI combat-ui.js — целиком не тронут (D8); 0 новых c._rng,
  сейвы, SVG, экспортов (D9).
