# Результат 000348 — заклинание школы тени «Декаданс»

## Достигнуто

Заклинание «Декаданс» (slug decadance, школа «тень», степень 1, атрибут
intelligence, уровень 3, мани 13, действие «телепорт», вне_боя true, база
null) — применяется ТОЛЬКО в пещере/подземелье: Флогистон мгновенно
переходит на этаж глубиной `текущая глубина + 5 + Math.floor(Интеллект/10)`
и появляется на клетке ВХОДА этого этажа. Промежуточные этажи не посещаются
и в память подземелья не пишутся; старый этаж фиксируется в памяти ДО
перехода; день не тратится. Вне подземелья — отказ «не здесь» без расхода
маны и без заряда; в бою — бесплатный отказ (действие «телепорт» ∈
внебоевых). Свиток обучения decadance_scroll (000764, value 115, tier 3,
без base_price), иконки 24×24 (spell-icons) и 64×64 (sprites/items).

Решение по ТЗ-оговорке «уточнить на анализе»: «5 + Интеллект/10 уровней
ниже» считается ОТ ТЕКУЩЕЙ глубины (модель (а)), вход целевого этажа =
точка выхода; обоснование — в memory/000348-decadance.md.
