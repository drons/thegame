# Результат 000356 — подсказки клавиш [I] [C] [E] [B] на экранных кнопках

## Решение

ВНУТРЕННИЙ `span.tc-key-hint` последним ребёнком каждой `button.tc-action`
в `#touch-controls` с точным текстом `'[E]'/'[I]'/'[C]'/'[B]'` (маппинг по
иконке) — вместо отдельного слоя: display-единица buttons скрывает
подсказку автоматически (applyVisibility 0-diff), дети корня не растут
(пины TV3/TV8/000332-B1/000351-T4 зелёные без правок), новой z-ступени
нет (оверлей книги z-35 остаётся сверху). ::after отвергнут (нужен
modifier-класс, ломает строгое `className==='tc-action'`).

- src/ui.js: хелпер `keyHint(btn, letter)` + 4 вызова (по кнопке, сразу
  за навеской pointerdown). applyVisibility/show/hide — 0-diff.
- index.html: `.tc-action` += `overflow:hidden` (клампинг подсказки на
  вырожденных B=13–18) + `user-select:none` (расширение 000352 —
  подсказка не выделяется); голое правило `.tc-key-hint`
  (absolute/right:6%/bottom:4%/11px/line-height:1/rgba(232,220,192,.75)/
  pointer-events:none/user-select:none, без z-index) — переиспользуемый
  класс для боевых кнопок (000357).
- 0-diff: src/controls.js (золотые {688,488}/{688,380}/{688,272}/
  {688,164,96,96}@800×600 бит-в-бит), src/main.js, assets/, spec/, сейв,
  зеркала. CHANGELOG — буллет «Подсказки клавиш на экранных кнопках»
  («## 2026-11-12» / «### Интерфейс»).

## Находка (код vs память)

memory/000352-btn-text-select.md утверждала «ре-пин T3 не нужен» — ЛОЖЬ
КОДА: цикл T3 требовал `tagName==='img'` для всех детей кнопки, span
красил его. T3 ре-пиннут честно: содержимое кнопки = ровно
[img, span.tc-key-hint] с текстом по иконке + CSS-гард user-select:'none'
у `.tc-action`. Единственный покрасневший существующий тест.
