## Решения (зафиксированы)

1. **Тултип навыка — отдельная пустая `td.cp-tipcell`** (не в
   `.cp-name`): render() переписывает textContent соседних ячеек —
   дочерний узел в занятой ячейке стёрся бы на первом же render().
2. **Тултип предмета — аддитивный 4-й аргумент `itemRow`**; только у
   заполненных строк; магазин без tip (зона 000101 — при мерже
   строки магазина получат tip тем же аргументом).
3. **Текст — только из каталогов** (assets/skills, assets/items):
   новые данные не добавлялись, ассеты/схемы не тронуты.
4. **Титул пересчитывается в render(), а не в build()**: он меняется с
   уровнем; узел `.cp-tip` сохраняется (DOM-контракт), текст —
   актуальный (тест).
5. **Touch-fallback — канал `.cp-notice` (flashNotice)**, контент —
   текст `.cp-tip`; решение зафиксировано тестом. Компактная
   постоянная мета-строка сохранена; on-screen-кнопка «I» не
   добавлялась (панель — по KeyI, как и до задачи).
6. **Показ — чистый CSS** (:hover/:focus-within), без JS: z-index 11 —
   внутри stacking-контекста `.char-panel` (z-10); корневая лестница
   5/10/15/20 не тронута; position:relative скоуплен под
   .char-panel (переиспользование .cp-itemrow в npcUI).
7. **Тултип — информация**: действий из него нет (кнопки — только
   существующие `.cp-btn`).
