# Отчёт: задача 000138 — стартовое окно: логотип + «Продолжить»/«Начать заново» (тройное подтверждение)

Новая функциональность; ТЗ — 8 строк (tasks/pending/000138.md →
done): окно с логотипом при загрузке вместо «Загрузка карты»,
кнопки «Продолжить» (зелёный фон) / «Начать заново» (красный фон),
по «Начать заново» — удаление локальных данных после ТРОЙНОГО

«Нет». Базовый коммит ветки — 0397799. Статус: выполнено.

RNG не тронуты: ноль новых RNG, бут не перезаписывает сейв

## Решения (контракты — memory/000138-start-window.md)

1. Окно — ОВЕРЛЕЙ z-40 (не гейт — 14 full-chain e2e, §4).
2. Схема подтверждения — Да/Нет/Да; Q2 — отрицательная
   формулировка «Продолжить игру (сохранить прогресс)?» → «Нет»;
   серия «Да, Да, Да» подтверждением НЕ является (§3).
3. Удаление — G.clear(SAVE_KEY) + полный location.reload();
   ин-памяти-сброс отклонён (десятки топ-переменных main.js,
   горячая зона 000135); «повторная загрузка — окно снова»
   выполняется автоматически (§5).
4. Re-сейв beforeunload — флагом resetPending (атомарнее
   removeEventListener, §6).
5. Кнопки «Да»/«Нет» — нейтральная стилистика (цвет бы вёл в
   заблуждение на Q2; цвета ТЗ — только у двух главных кнопок).
6. Гашение игровых клавиш при открытом окне НЕ сделано (ТЗ молчит
   — «не больше и не меньше»); кандидат на будущую мелкую задачу
   (§10).
