# 000040: размер мобов на боевом поле (1x1…5x5)

Статус: выполнено. Тесты: 216 → 225 pass (новых 9).

## Что сделано

* **Данные (source of truth — assets/mobs)**: поле `size: { w, h }`
  записано в JSON всех 36 мобов и добавлено в schema.json как
  обязательное (integer 1..7). Наборы:
  - 1x1 — все мелкие (волки, орки, скелеты, пауки, насекомые, имп,
    фея, суккуб, вампир и др. — 26 мобов);
  - 2x2 — тролль, пещерный медведь, саламандра, водный стихийник,
    низший демон;
  - 3x3 — костяной колосс, каменный голем, земляной/огненный
    стихийники, уродство.
  Драконов в каталоге нет → реальный максимум 3x3; схема допускает до
  7x7 под будущих (5x5 — чистые данные, код готов).
* **src/combat.js** — многоклеточная геометрия:
  - юнит занимает прямоугольник size.w×size.h (якорь — верхний левый
    угол); `makeMob` берёт size из описания (зеркало MOB_TYPES
    обновлено, идентичность с JSON держит тест);
  - `unitAt` — клетка внутри прямоугольника: игрок не может зайти ни
    на одну клетку моба;
  - `rectFree` — прямоугольник свободно (границы поля, не игрок,
    без наложений живых юнитов);
  - `unitDist` — Манхэттен от игрока до прямоугольника; для 1x1
    идентичен старому — поведение мелких групп не изменилось;
  - дальность атаки/лука/заклинаний, поведение дальних и melee-мобов
    считается по краю прямоугольника, а не по якорю;
  - `stepToward`/`stepAway` двигают целое тело;
  - `placeUnits`: крупные мобы — первыми (по площади) построчным
    обходом, мелкие — прежние якоря [1,3,5,0,2,4]/строки 0–1 со
    сдвигом при занятости. Детерминированно, без RNG;
  - формулы HP/урона и баланс (000027) не тронуты.
* **src/combat-ui.js** — отрисовка моба прямоугольником w×h (HP-бар,
  уровень, подсветка цели), клик-выбор цели по любой клетке тела.
* **Глобальная карта**: мобы рисуются одним тайлом (src/main.js),
  `size` туда не выходит — «всегда 1x1» выполнено конструктивно.

## Проверки (9 новых тестов в tests/combat.test.js)

* size есть во всех 36 JSON; волк/орк 1x1, голем/колосс крупнее;
  зеркало MOB_TYPES несёт size = JSON; боевой юнит получает size.
* На клетку многоклеточного моба зайти нельзя (все достижимые клетки
  границы); ближний бой по краю (якорь в 3 клетках — удар в
  дальности; 2 клетки от края — «слишком далеко»).
* Крупные двигаются целым прямоугольником 20 ходов: без перекрытий,
  в пределах поля, не на игроке.
* Расстановка: без перекрытий и в пределах поля (все 7 рецептов × 4
  сида).
* Крупная группа (3x3 + 2x2 + 1x1) бьётся «разумным» авто-игром.
* Балансовые тесты 000027 (всё 7 групп × 5 сидов, medium) — зелёные.
