## Решения

Все решения Проектирования (13 шт., memory/000211.09-craft-base-
refs.md §7) выполнены без отклонений: пин-таблица ЯВНАЯ (10/10;
«номер файла = id» из ТЗ НЕ ВЕРНО для craft — строковые id,
биекция id↔файл), хирургическая миграция (round-trip
переформатировал бы все 31 файл), guard `=== undefined` (spells-
ternary на null не копировать), R3 doesNotMatch — SCOPE на строку
данных `/база: "assets\/craft\/\d{6}\.json"/` + наследственный
000208-паттерн (глобальный /assets\/craft\// неверен — шапка
«// Рецепты (assets/craft/…)» легитимно содержит craft-путь),
R3-фикстура цели со ВСЕМИ 4 группами ссылок (иначе TypeError, а
не fail-closed exit 1), R4 — ровно 2 под-кейса ТЗ (общая
функция refId, ветки (3)/(4) уже покрыты 000208 R4), R2 — id
цели сверяется с ЗАКОММИЧЕННЫМ ЗЕРКАЛОМ (CRAFT_BY_ID[data.id].
база), без хардкода, JSON+schema+sync+тесты — ОДИН коммит
(000141: промежуточное состояние «ссылки в JSON, резолвера нет»
не должно быть в git), один коммит на ветке (RED→GREEN squash при
мерже — memory one-commit-per-task-squash).
