## Решения

Все открытые вопросы ТЗ + а1/a2/a3 зафиксированы в
memory/000263-chunked-render.md §3 (указатель):
1. Гейт — ПО ЧИСЛУ ВИДИМЫХ КЛЕТОК (8192 мир / 1024 подземелье), не по
   зуму: окно жёстко задано существующими пинами → НОЛЬ ре-пинов
   dungeon/city-тестов; города никогда не чанкуются (≤676).
2. Состав чанка мира — ТОЛЬКО однокадровые текстуры тайлов: вода —
   per-tile (мультикадровая, запекание заморозило бы анимацию),
   декорации/лут — per-tile (z-порядок + мутации), постройки — как есть.
3. Ключ (cx, cy, zoomBucket) + ТРИ гарда: zoom 1e-6 (FP-дрейф колеса),
   edgesEqual (бит-в-бит снап-сетка — наследие 000215/000228),
   readiness (readyCount / nullCount+isReady). ЛЮБОЕ изменение зума →
   re-bake (бакет — только ключ).
4. Подземелье — камерно-якорная сетка СОХРАНЯЕТСЯ: worldAnchored дал бы
   1px сдвиг (численное доказательство §3.4, TS-12); камера закреплена
   при полном вхождении сетки → 0 re-bake.
5. Fog — прозрачный bake + contentBaked-снапшот; targeted re-bake только
   затронутых чанков (explored монотонен 000136: ≤2 re-bake на клетку);
   FOG_DIM — динамический pass поверх, не тронут.
6. Память — LRU по пикселям, 16 MP на инстанс (отклонён счётчик
   чанков); мир — один глобальный, подземелье — на start().
7. WebGL-слой/buildFrame/frameTiles — НЕ ТРОГАТЬ (XOR-контракт 000176:
   legacy-квады под прозрачными дырами не-ready чанков — как сейчас).
8. Известное отклонение §3.10: чанк-гейт + z≥24 одновременно — при
   площади вьюпорта ≳ 4.5 MP (16:9): оверханг декораций 1–2px видим
   поверх соседа; на 1080p/1440p окно закрыто; задокументировано в
   SPEC/CHANGELOG/memory.
