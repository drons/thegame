# Отчёт: задача 000227 — БОЙ: кнопка последнего заклинания из книги + счётчик остатка (Флогистон, Эфир, союзные NPC)

Цель (ТЗ 000227): «Флогистону, Эфиру и союзным NPC добавить кнопку
применения последнего выбранного заклинания из книги заклинаний. На
этой кнопке, как и на остальных, отображать число, сколько осталось
раз применить в этот ход. Похожие кнопки у Эфира (четырёхлучевая
звезда) и у Миры (крест лечения) уже есть, их надо немного
переделать». Статус: выполнено — новая кнопка «Последнее заклинание»
(Флогистон) + переделанные «Каст»/«Лечение» (Эфир/любой наёмник с
книгой): тап/K/H применяет ПОСЛЕДНЕЕ выбранные кликом по строке книги
заклинание (выбор — на попытке, независимо от исхода); число на
кнопках — остаток пула «Заклинание» по атрибуту того заклинания,
которое кнопка применит СЕЙЧАС (с выбором → его пул; без выбора →
legacy strongestKnown/mostWounded, бит-в-бит).

Ветка task/000227; база master 28fb20a (baseline npm test =
2602/2602). ТЗ: tasks/pending/000227.md → tasks/done/ (коммит
реализации). Контракты D1–D15 + факт станции: memory/
000227-combat-last-spell-button.md.
