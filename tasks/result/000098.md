## Ревью (2026-10-02, 5 findings — все minor; вердикты)

1. **clampValue: 0.5 → 1 без заметки (clamped:false)** — РЕАЛЕН,
   ИСПРАВЛЕН. clamped считался по УЖЕ скруглённому значению
   (Math.round(0.5)=1, 1 < 1 → false), тогда как '-0' → 1 давал
   заметку. Правка (src/global-settings.js, минимальная):
   clamped: true — когда принятое значение отличается от входного
   (v !== given: int-round ИЛИ кламп в min/max); комментарии +
   контракт memory §2.1 обновлены. Заметка UI не менялась. Пины:
   S4 (r3: 40.6 → 41 clamped; r10: '0.5' → 1 clamped). Числовые
   значения и отказы НЕ изменились — только обратная связь.
2. **«Сложности боя» — 6 строк на листья, ТЗ дословно «3 строки
   easy/medium/hard»** — отклонение дословного ТЗ, НЕ ИСПРАВЛЯЕТСЯ
   (осознанно). Функциональный контракт ТЗ (тестовая секция: «8
   полей: select + 6 number», все редактируемы, float > 0) выполнен
