# Результат 000315 — режим торговли NPC: две колонки «Инвентарь | Магазин»

## Итог

Цели ТЗ достигнуты. Вкладка «торговля» оверлея NPC (src/ui.js,
renderTradeTab) — две колонки на СУЩЕСТВУЮЩИХ классах 000313
(`.storage-cols` / `.storage-col--inv` / `--shop`; index.html 0-diff):
слева «Инвентарь» (агрегат hero «имя ×N» в порядке слотов), справа
«Магазин» (legacy-строки бит-в-бит 000314: «ост. N», сток < 1 — строки
нет). dnd инвентарь → магазин — продажа с подтверждением «Вы хотите
продать 'Имя' за X золота?» (ASCII-апострофы; «Нет» — 0 мутаций/сейвов,
«Да» — мутация через ядро G.npcSell, stale-предмет → причина ядра в
логе); dnd магазин → инвентарь — покупка БЕЗ подтверждения, deep-equal
клику. Кнопки: «Купить» (npcact='trade-buy', disabled «мало золота
(нужно N)») на магазин-строках, «Продать» (npcact='trade-sell',
не-торгуемое — disabled «NPC не скупает такие предметы») на инв-строках;
СТАРЫЕ «купить»/«продать» (npcact='buy'/'sell') сохранены бит-в-бит
(немедленные действия — пины 000314 A3 / 000299.03 B5 / building-levels).
Цены — src/npc.js без изменений (base «Торговец» активного, 000299.03;
золото/мутации — всегда Флогистон, 000194). Магазин построек и склад
НЕ тронуты.
