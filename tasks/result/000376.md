# Результат 000376 — скрытие экранного d-pad на время окна расстановки

Задача пользователя (T1–T4 выполнены). Ветка task/000376, база e90bc26e.

## Решение (ортогональный флаг в ui.js-каскаде)

* `src/ui.js`: closure `dpadSuppressed`; запись dpad в `applyVisibility`
  — `(dpad && !dpadSuppressed) ? '' : 'none'` (композиция и здесь — кадр
  с изменением buttons не должен показывать d-pad); новый метод
  поверхности `setDpadSuppressed(on)` — строгий `=== true`, change-guard,
  пишет эффектив `(parts.dpad && !dpadSuppressed)`; null-guard'ы root/
  dpadEl (pre-init, keyboard-схема).
* `src/combat-ui.js`: хелпер `syncPlacementDpad(on)` через ЛЕНИВОЕ
  `liveGame().touchControls` (UMD-замена Game 000038 / motion-паттерн
  000174) + typeof-guard (mixed-версии → деградация «видим», не крах).
  Вызовы РОВНО в 4 точках: `true` — в build() после `placeOpen = true`;
  `false` — в closePlacementWindow() сразу после раннего return-гарда
  (покрывает result-ветку и хвост; все выходы 000260 идут через неё),
  finish(), catch startCombat (обе teardown-точки 000170).
* Т2 (0-diff): controls.js (чистый предикат 000150), main.js (клей),
  index.html (инлайн display поверх каскада), spec/, assets/, scripts/,
  golden/.
