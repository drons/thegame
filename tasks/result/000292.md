## Корень (контракт memory/000292-summon-spawn.md §1-§3)

Каст «призыв» (case 'призыв' src/spells.js, вызов placeAllies и
fail-closed гейт allyRoom ДО расхода пула/маны) исполняет free() в
src/combat.js (placeAllies/allyRoom) = «в границах && !occ», где
occ = клетка игрока + прямоугольники c.units. **c.obstacles не
читался** → призывной ложился на первый «свободный по occ» якорь
даже если там камень/стена. Мид-комбат-каст призыва — единственный
путь, где placeAllies/allyRoom исполняются при НЕПУСТОМ c.obstacles
(в createCombat placeAllies — ДО generateObstacles, Set пуст →
расстановка состава наёмники/Эфир бит-в-бит; generateObstacles
reserved уже не даёт камень на стартовом юните).

SCOPE 3 ТЗ: не-призванные мобы целы (общий корень тот же) →
дочерняя задача НЕ создаётся.
