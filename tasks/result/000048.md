## Решения

1. **KeyA — движение влево, как в мире** (решение по умолчанию из
   задачи): WASD/ЦФЫВ в бою двигают полностью; «Удар» перенесён с KeyA
   на KeyJ (правая рука, «джойстик» у Space).
2. **Дубли на новых физических клавишах**: KeyK (Л) = дубль KeyJ
   (attack), KeyU (Г) = дубль KeyT (invItem). Каждая клавиша — ровно
   одно назначение; существующие русские «дубли» (Й=KeyQ, К=KeyR,
   И=KeyB, У=KeyE, А=KeyF) — те же физические коды, ничего не добавляют.
3. **Движ. строки — переиспользование, не дублирование**: строится из
   `Controls.CODE_DIRS × Controls.DIR_DELTA` (node — `require`, браузер —
   `Game.CODE_DIRS`); инвариант «движение в бою = движение в мире»
   структурный. Битый порядок (controls.js позже) — `console.error`,
   CombatKeys не создаётся, combat-ui — второй `console.error`.
4. **dungeon-ui — только мёртвые записи**: после 000048 в боевом UI
   локальной таблицы нет вовсе (keyDir удалён, движение — из COMBAT_KEYS),
   поэтому в 000043 фактически остаётся только dungeon-ui.js.
5. **После боя**: не-закрытые не-мапнутые клавиши больше не
   «проглатываются» (handled=false вместо true) — на геймплей не влияет
   (main.js всё равно ранним return'ит, пока оверлей открыт).
