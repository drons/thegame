   общий хвостовой `});` ПОСЛЕ маркера закрывает только ОДИН из

   of input` (весь файл падает, 0 подтестов) — воспроизведено
   (merge-tree + node --check). Решение: сохранить ОБЕ секции
   (000151 ПЕРВОЙ, затем 000152) + ДОБАВИТЬ недостающий `});` после
   assert `iST < iBase` теста A4 (+ пустая строка-разделитель, по
   стилю файла). Проверено: diff с master = ровно вставка наших
   186 строк (0 удалений), node --check OK, 63/63 подтеста зелёные —
   C1/C2/G1 валидны на новом рендер-пути 000151 (в vm sx=sy=1,
   setTransform держит логические координаты; G1 — 0 console.error,
   т.к. master-версия loadCombatUi грузит combat-scale.js в цепочку).
