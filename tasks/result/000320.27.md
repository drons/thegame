## Решение (ВИЛКА (а) — данные обучения без диалоговой опции)

ТЗ-профиль «квесты» соблюдён РОВНО тремя опциями
(подсказка / квесты / подсказка+харизма 3 на последней); блок
обучение {навыки [swordsman, heavy] ≡ тренирует Арены, 25/40 — шкала
боевых школ} добавлен как ОБЯЗАННОСТЬ контракта «школы» для каждого
NPC здания-школы. Инертность данных: опции «обучение» нет →
train-вкладка UI недостижима; кузнечное наставничество отсекается
проверкой построек (typeBuildings('кузнечное_дело') = [8, 25] ∌ 7 →
reason 'нет постройки этого вида'). Всё запинено в T5/T6.

Данные: имя Кремень (не фиксировано ТЗ), id arena_champion, роль
«чемпион арены» (точная строка ТЗ), хук «Действующий чемпион; титул
защищает на арене» — последнее предложение описания (ТЗ-опечатка
«ДействУующий» не перенесена). Квеста ДВА: champion_proof
(bring_item hide ×2 → 50/40 + healing_potion ×2) → champion_pack
(kill_group группа 3 ×1 → 100/80 + mana_elixir ×1), цепочка
«предыдущий» bring→kill (прецедент .23). Запрет-лист диалога 95 =
дисковый .26 (91) + 4 оборота Костяшки; свои 4 оборота зарезервированы
для .28 (цикл MINE в том же T5).
