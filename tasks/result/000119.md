## Сеттинг симуляции (фиксирован, memory §3)

Герой — `midGameHero()` (L15, maxHP 62, 2 удара + блок — скрипт
000027), levelDeltaMax: 0 («герой уровня группы»). Эфир — свежий

## (b) hard — «hard остаётся сложным»

ПАССИВНЫЙ герой (только «ждёт», без ударов/блока) + Эфир L1: 35/35
'dead' — Эфир не спасает пассивного героя ни в одной группе; смерть
R12–R72 (avg 34.7), бой всегда завершается до бюджета 120 раундов.

## (c) бой не тривиален — зафиксированные метрики свипа (a)

* avg rounds = **8.40** ∈ [5, 12] (мин 3, макс 17) — бой не
  «мгновенный», но и не осада;
* avg hpFrac = **0.944** < 1.0 — герой ПОЛУЧАЕТ урон на уровне свипа;
* min hpFrac = **0.694** ≤ 0.80 (abyss_spirit, seed 4) — есть бой,
  где герой реально ранен.

Интерпретация (зафиксирована как обоснованное отклонение, memory D4):
(c) читается АГРЕГАТОМ свипа, а не «урон в каждом бою» — per-combat
«HP после < 100% в каждом из 35» недостижим: в слабых группах
(skeleton_den/wolf_pack/spider_nest) 13/35 боёв герой финиширует на
100% HP — мобы L15×0.45 бьют ≤ брони героя → урон 0. Это СВОЙСТВО
БАЗЛАЙНА 000027: без Эфира full-HP боёв 10/35, с Эфиром 13/35 —
Эфир танкует их удары на 16 HP. Единственный допущенный ТЗ рычаг
(medium.damage) не делает per-combat-вариант зелёным без пробоя
теста 000027 («разумно сильный герой побеждает ВСЕ группы на
medium»).

Контроль «без Эфира» (базлайн 000027, тот же бот — mob-only
эквивалентен без союзников): 35/35 victory, avg 8.91 раунда, avg
hpFrac 0.941. Вклад Эфира: бой на ~0.5 раунда КОРОЧЕ, среднее HP
героя 0.944 vs 0.941 (чуть БОЛЬШЕ урона — hardest-группы ранят
сильнее, когда Эфир занят) — НЕ тривиализация; цель «Эфир не
делает бой тривиальным» достигнута.

  (писался «без союзников»), не баг ядра и не баланс — поэтому

  правок (инвариант).
* **000118 (параллельно, общий tests/combat.test.js)**: обе секции —
