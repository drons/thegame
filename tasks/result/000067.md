## Решения (зафиксированы, детали в memory)

* **По mobId, а не по группе**: группы подземелья — 1–3 mobId (босс Бездны
  — 3: abomination + 2 lower_demon), мир-паттерн «одна группа = один
  спрайт» неприменим; существующие таблицы 000047.
* **Math.floor(frameIndex(...))** — дробные координаты (смещения юнитов,
  дробная точка игрока) дают дробный индекс кадра → frames[1.6] =
  undefined → молчаливый фолбэк. floor у мобов И у игрока.
* **Фолбэки пер-юнит, не пер-группу** (паттерн 000047).
* **Подсветка босса — ОДИН bounding-box-прямоугольник** под спрайтами,
  только при m.boss.
* **Сундук — ОДИН статичный SVG, состояния «открыт» нет** (не рисуется);
  анимации нет (за рамками).
* **Выход/вход НЕ спрайтятся** — решение из ТЗ (читаемость), чтобы экран
  не остался «наполовину современным» молча.
* **Без хардкода имён/числа кадров** — только MOB_FRAMES[kind].length /
  mobSpriteKind (000062 расширяет ассеты; код не знает деталей).
