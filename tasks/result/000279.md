## Решения (контракт — memory/000279-fright-practice.md)

* Величина XP — PRACTICE_XP.hit (D1): новый ключ 'fright' в
  экспортируемой константе — изменение поверхности без выгоды (значение
  совпадает); расстройка величин — будущее решение владельца.
* Поле `frightPractice` (D2) — топ-уровневое, условное, shape 4-ключа
  1:1 с `practice` (без `total` — как у weapon-записи). Отклонены:
  массив practices (ломает 35 property-ассертов + remap-пины R9/R10),
  вложенность в `practice` (меняет семантику «это практика оружия»),
  поле всегда (ключ в каждый hit-результат).
* Порядок внутри блока — ПОСЛЕ checkVictory (D3): behavior-neutral
  (checkVictory не трогает p, 0 c._rng в 'fled'-ветке), консистентность
  с weapon-путём.
* 000271-контракт «НОВОГО ПОЛЯ в return НЕТ» — ЛОК scope фичи 000271;
  000279 — ОСОЗНАННОЕ аддитивное расширение ПО ТЗ (retро-подзадача
  000271-шов (2)); для всех путей без паники контракт 000271 в силе.
* Отклонён отдельный seed-детерминизм-тест с снимком (a3 FP-7):
  мутация — чистая арифметика (0 c._rng — зафиксировано счётчиками
  FP-1/4/5/6), боевой seed-детерминизм пути паники пинится FR-7 (000271).
