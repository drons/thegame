## Формула и решения (кратко; полное — memory §2–§3)

* **P(D) = clamp(0.25 + 0.04·D, 0.05, 0.25)**, D = heroLevel −
  mobLevel (моб СТАРШЕ → D < 0 → вероятность НИЖЕ — знак по примеру
  пользователя 10/15 → 5% = P(−5), пол формулы ТОЧНО при D = −5).
* **ОДИН P(D)** для базового (per-mob) и редкого (общий) пулов.
* **Семантика «один предмет из пула» и число/порядок вызовов c._rng
  НЕ МЕНЯЮТСЯ** (гард L6: ровно 4 вызова на победу).
* **Свитки — БЕЗ ПРАВОК** (ТЗ п.3): их D_s = maxLvl − playerLevel
  ПРОТИВОПОЛОЖНОГО знака (000235.05, «сильнее моб — лучший свиток»);
  объединение не в scope (территория 000235.x).
* Редкость экипировки — pickRarityTier (000230.05, пины EQ* — не
  трогали); составы пулов — данные (территория 000230.10–.15/
  000235.10 — не трогали).
