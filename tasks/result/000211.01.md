## Решения

Все зафиксированы в memory/000211.01-json-ref-format.md (§1–§9):
ссылка — путь к целевому JSON-файлу ОТНОСИТЕЛЬНО корня
репозитория (а не id: dungeons id=0, именованные portraits, единый
формат для 11 каталогов, file:// — fetch невозможен → резолюция
только в sync-*.js при сборке); JS-зеркала ОСТАЮТСЯ в id-форме
(контракт потребителей + сейв v1); новое поле-ссылка =
расширение schema.json в ТОМ ЖЕ коммите + `pattern`
(additionalProperties:false, 000141); svg-sweep — только
root-пути «assets/…*.svg» (голые иконки portraits — волна 2);
негативные фикстуры — только в mkdtemp; битый путь — без
хардкода; резолвер без бросаний (reason-контракт).
