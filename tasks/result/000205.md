## Решения

Все — в memory/000205-combat-xp-split.md §1–§3, ключевые:
- «Участник» = ВСЕ side 'ally' на момент победы, в т.ч. погибшие в бою
  (ТЗ буквально «все кто в нём принимал участие»); доля погибшего
  мерса живёт в dead_mercs-записи.
- Погибший Эфир — в N и получает efirXp (000035#11 «БЕЗ условия
  выживания», e2e CB-8/CB-9).
- Остаток (xp mod N) — Флогистону (якорь-протагонист, детерминированно);
  «поровну» — с точностью до остатка (≤ 1 xp на участника).
- Эфир — НИКОГДА не в allyXp (свой канал efirXp) — строка «Спутники:
  +N опыта» не выведет 'efir'.
- «Учёный» — только к доле игрока; остаточный разрыв с Эфиром — по
  дизайну (бонус навыка).
- N = 1 (соло) — бит-в-бит с до-000205; xp = 0 — ветка 'fled', полей
  нет; неизвестный kind у союзника — в N, долю не получает.
- companion_xp_share — без миграций (session-only); новая настройка
  доли в будущем — НОВЫЙ ключ + META + S1-ре-пин (паттерн 000098).
