## Матрица угроз (эмпирика /tmp, станция a3 + воспроизведено станцией
реализации 2026-10-28)

Мутация S1-цикла (items.test.js L1640) на fallback-формы:

* `n <= (SCHOOL_SCROLL_MAX[sch] ?? 99)` — struct G / **exact R** /
  K-regex G → ЗАХВАЧЕН (пример ретро).
* `n <= (SCHOOL_SCROLL_MAX[sch] || 99)` — ЗАХВАЧЕН.
* `n <= Math.max(99, SCHOOL_SCROLL_MAX[sch])` — ЗАХВАЧЕН.
* Алиас карты (`const K_MAP = …`, `n <= K_MAP[sch]`) — ЗАХВАЧЕН
  двойно (exact + срыв regex извлечения K-карты).
* Промежуточная переменная (`const K = SCHOOL_SCROLL_MAX[sch];
  assert.ok(n >= 1 && n <= K)`) — ЗАХВАЧЕН (exact-пин не матчит
  `n <= K` — fail-closed ре-пин, не bypass).
* Резидуальный gap: `n >= 1 && n <= SCHOOL_SCROLL_MAX[sch] || 99`
  (без скобок, always-true) — ПРОХОДИТ все пины; ПРИНЯТЫЙ РИСК
  техники text-пинов (ТЗ п.4: зафиксировано в memory родителя §11.4
  + upgrade-point в контракте §5 — запятый-паттерн
  `n <= SCHOOL_SCROLL_MAX[sch],`, в .02 не применяется).
