## Решения

Все зафиксированы в memory/000225-dungeon-mob-vision.md:
* **D1** — строгая видимость БЕЗ explored-поминания: моб динамичен
  (wanderStep двигает группы каждый шаг героя) — explored-поминание
  зафиксировало бы СТАЛОЕ/неведомое положение; «затемнено, не скрыто»
  (000136) действует для статических слоёв, для мобов — «скрыто вне
  радиуса». Это поправка 000136 (memory/000136-*.md не редактируются —
  источник правды код, `git blame` на строке гейта → коммит 000225).
* **D2** — точный гейт: одна строка `!== 2` по КЛЕТКЕ ГРУППЫ; босс —
  в том же цикле после гейта; `!isCity &&` сохраняется (город: mask
  null, contents null).
* **D3** — скоуп: статические слои, затемнение, город, мировая карта,
  `__game.dungeon.mobs` (отдаёт ВСЕ живые мобы — от этого зависит
  e2e-навигация), логика боя/агро, сейвы/RNG/детерминизм — не
  тронуты. UX-побочка задокументирована: вступить в бой со скрытым
  мобом штатно (семантика тумана; ТЗ — только отрисовка).
