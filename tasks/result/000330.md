# 000330 — боссы подземелий/пещер: 3×3 тайла + коллизии по размеру

## Итог

Босс подземелья (по факту диска — ОДИН: босс Бездны, ABYSS) теперь
размером 3×3 тайла: расстановка fail-closed (только где все 9 клеток
дальнего центра — пол), движение/коллизии — по всем 9 клеткам
footprint (босс не заходит в проходы шириной < 3), бой — на любой
клетке footprint, рендер — точный 3×3-прямоугольник + 3 юнита на
разных клетках footprint. Размер НЕ персистируется (выводится из
флага `m.boss` константой `BOSS_SIZE` в src/dungeon.js, 1:1 с
`MOB_TYPES.bone_coloss/abomination.size` combat.js — structural pin).
Не-боссы 1×1/2×2 — бит-в-бит (0 новых c._rng в legacy-путях).

## Изменения

- **src/dungeon.js**: `BOSS_SIZE = {w:3,h:3}` + `mobFootprint(m)`
  (не-босс → ровно `[x,y]`, босс → 9 клеток) + `footprintFits(d, m)`
  (все 9 клеток inGrid+FLOOR); exports `+BOSS_SIZE, +mobFootprint`.
  `generateDungeonContents`: босс ABYSS ставится ТОЛЬКО если
  footprintFits (fail-closed); ВСЕ 9 клеток — в `occupied` ДО
  первого takeSpot (паттерн 000183, 0 новых rng). `wanderStep`:
  `taken` = объединение mobFootprint живых мобов; `selfFoot` (свой
  старый footprint — пропуск, порядок проверок для 1×1 идентичен
  legacy); `footprintFree(d, nx, ny, boss, taken, selfFoot)` — все
  клетки нового footprint; `chaseDir` через тот же чек; `landed` =
  клетка игрока ∈ новый footprint (для 1×1 == legacy). `stairsDownFor`
  — при встанущем боссе исключает 9 клеток (тот же predicate).
- **src/dungeon-ui.js**: рендер босса — ТОЧНЫЙ footprint 3×3
  `fillRect(P(m.x−1,m.y−1), 3·zoom, 3·zoom)` #b06ad4 ДО спрайтов;
  спрайты — 3 юнита на 3 РАЗНЫХ клетках (смещения (−1,0)/(0,+1)/(+1,0)
  из `live.BOSS_SIZE`); фолбэк без лоадера — тот же 3×3. Не-боссы —
  0-diff (MOB_UNIT_OFF, +3/+3 zoom−6 #d9483b).
- **src/locations.js**: helper `mobOnCell(G, m, x, y)` —
  `G.mobFootprint(m)` содержит клетку (fallback клетка == клетка);

  ascendFloor D10 (спуск не на клетке моба).

  размер выводится/не персистируется, fail-closed, 9-клеточные
