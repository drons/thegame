## Что сделано

* **`.github/workflows/ci.yml`** — workflow «CI и Pages»:
  * триггеры — push в master + ручной `workflow_dispatch`
    (перепубликация); `concurrency: group: pages,
    cancel-in-progress: true`;
  * job `test`: checkout@v7, setup-node@v7 (node-version 22),
    `npm test`, `node scripts/sync-all.js --check` (дрейф-гейт:
    рассинхрон JSON-каталогов ↔ src/*-data.js = красный CI);
  * job `deploy-pages` (`needs: test`): environment github-pages,
    permissions `pages: write` + `id-token: write` (OIDC, без
    токена); сборка сайта в `dist/` — явная копия
    `index.html + src + assets` (НЕ корень репозитория: tasks/,
    memory/, tests/, scripts/, .github/ не публикуются);
    configure-pages@v6, upload-pages-artifact@v5 (`path: dist` —
    ОДИН каталог), deploy-pages@v5.
  * `npm ci/install` нет — в проекте ноль зависимостей и нет
    package-lock.json.
* **`scripts/sync-all.js`** — общий запуск синк-скриптов
  `scripts/sync-*.js` (по конвенции имён, sorted) + дрейф-гейт
  `--check` (git status src/ до/после регенерации; git недоступен —
  fail-open с предупреждением, задокументировано). Новые каталоги
  (items/visuals — 000059) подключатся к CI автоматически, workflow
  не меняется. Общий атомарный вывод `scripts/lib/write-atomic.js`
  (tmp + rename) — конвенция, закреплённая тестом, распространяется
  на будущие sync-скрипты; sync-buildings-data.js и
  sync-spells-data.js переведены на него.
* **`package.json`**: npm-скрипты `sync:all`, `sync:check`.
* **`SPEC.md`**: раздел «CI и публикация на GitHub Pages».
* **Тесты**: `tests/ci.test.js` (вкл. структурная проверка
  YAML-подмножества `yamlSubsetErrors` — ноль npm-зависимостей),
  `tests/sync-all.test.js`.

## Что сделать пользователю после пуша (пуш делает пользователь)

1. `git push origin master` (github.com:drons/thegame; из worktree
   пуш запрещён — пушить только из основного чекаута).
2. GitHub → Settings → Pages → Build and deployment → Source:
   **GitHub Actions** (НЕ «Deploy from a branch»; ветку выбирать не
   нужно — деплой делает workflow).
3. Токен не нужен (OIDC; permissions заданы в workflow).
4. Первый деплой создаст environment `github-pages` автоматически.
5. Сайт: https://drons.github.io/thegame
6. Workflow — «CI и Pages» (`.github/workflows/ci.yml`): триггеры —
   push в master + ручной «Run workflow». Публикация идёт только при
   зелёных тестах и синхронных JS-бандлах. Пока Pages не включён
   (шаг 2), job deploy-pages будет падать с ошибкой Pages/OIDC — это
   ожидаемо.
7. Новый корневой файл сайта (favicon и т.п.) — добавить в шаг
   «Сборка сайта» ci.yml (в dist/ попадает только явная выборка).
