## Решения

Все зафиксированы в memory/000211.02-skills-refs.md (§1–§6):
* Паттерн поля-ссылки в schema.json = REF_RE.source (общий
  union, НЕ skills-only) — uniformity серии .02–.08 + пин
  === REF_RE.source без дублирования экранирования; семантика
  «таргет — навык» держится тестами SR2/SR3 + hard-fail sync +
  byte-гейтом зеркала (tighter-вариант осознанно отклонён).
* Ссылка ОБЯЗАТЕЛЬНА в sync (format-gate, а не passthrough):
  полумигрированный каталог красит CI sync-all --check;
  «идемпотентность в обе стороны» не гарантируется (окна
  «новый sync + id-форма» не существует — один коммит).
* Зеркало — id-форма (контракт потребителей + сейв v1);
  byte-идентичная регенерация = дрейф-гейт; «id таргета =
  прежнее значение» — тесты подзадачи, ground truth — зеркало
  (без хардкода таблиц).
* Цикличность верификации разбита: (а) byte-гейт зеркала,
  (б) таблица 45 ссылок сверена независимым read-only скриптом,
  (в) resolveRef — независимая реализация (json-ref.js).
* Шаблон для .03–.08 (зафиксирован в memory §5): паттерн =
  REF_RE.source; sync — резолюция ДО генерации + hard-fail;
  зеркала — id-форма (git diff пуст + sync-all --check);
  сверка id — тест подзадачи.
