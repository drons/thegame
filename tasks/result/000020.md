## Ключевые решения

* Значения захватываются зависимыми модулями при загрузке (как раньше —
  константы), единая точка правды — объект `SETTINGS` в global-settings.js:
  меняется до загрузки скриптов — влияет на всё, без перекомпиляции формул.
* Публичные оверрайды сохранены: `createClock({stepsPerDay})`,
  `dueForRespawn(..., respawnDays)`, `createCombat({levelDeltaMax})` —
  настройка это только значение по умолчанию.

## Ограничения

* Изменение `SETTINGS` после загрузки модулей не меняет уже загруженные
  значения (дизайн-решение, см. «Ключевые решения»).
* В node-режиме браузерный путь (без global-settings.js) не покрывается
  require-цепочкой — проверен через vm-песочницу в тестах.
