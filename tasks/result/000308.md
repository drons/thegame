## Что сделано

* `src/ui.js` — ядро `itemRow`: АДДИТИВНЫЙ 7-й аргумент `tipIcon`.
  .cp-tip строится с текстом первым (textContent-путь, бит-в-бит с 000097),
  затем при ненулевой строке tipIcon внутрь добавляется `img.cp-tipicon`
  (src = icon, alt = '') ПЕРВЫМ элемент-ребёнком: реальный DOM —
  insertBefore(img, firstChild) (float:left + source-порядок [img, текст]),
  DOM-стаб без insertBefore — appendChild (typeof-guard, паттерн placeTip).
  6-арг. вызовы — 0 DOM-diff (tipIcon === undefined).
* `src/ui-tab-inventory.js` — 7-й аргумент `iconOf(it)` в 5 точках: строки
  «Инвентаря», деградация «Снаряжения» (weapon/armor), addRow (сигнатура +
  проброс) → заполненный слот addSlot, секция «Быстрые слоты (бой)».
* `index.html` — ОДНО новое CSS-правило: `.char-panel .cp-tip .cp-tipicon
  { float: left; width: 44px; height: 44px; margin-right: 8px; }` (44px =
  ровно 2× мини-иконки строки 22px). Базовое .cp-tip / flip / :hover /
  :focus-within / .cp-itemicon — побайтово на месте.
* Скоуп: «Инвентарь» + «Снаряжение» целиком (19 слотов + деградация) +
  быстрые слоты. МАГАЗИН (tip = null), skill-тултипы (другой билдер),
  NPC-оверлей, лут победы — структурно не тронуты.
* Предмет без иконки — img в тултипе НЕТ (graceful, решение D6; заглушка
  отклонена). Код data-driven от it.icon — после 000302 тултипы всех
  193 без иконки обогащаются САМИ, код не правится.
* 000262 flip/clamp — JS не тронут (H — живым замером getBoundingClientRect).
* НОВЫХ модулей/script-тегов/SVG НЕТ → index-order/svg-тесты не
  задействованы; детерминизм/сейвы/RNG — не затрагиваются (чистый UI).
