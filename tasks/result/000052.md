# Отчёт: задача 000052 — города и деревни: проработка и разбивка

Статус: выполнено (исследовательская задача: код не писался).

## Почему задача разделена

Задача — большое направление: каталог 4 типов городов (1x1…7x7) +
генерация на глобальной карте + вход «как в подземелье» (движок
тот же) + внутреннее содержание (NPC, постройки, лавки, школы) +
взаимодействие + сейв/респаун состояния. Одна реализационная
задача не влезает (правило tasks/CLAUDE.md: «если задача слишком
большая — делим»); по паттерну мета-задач 000064/000065 задача
исполняется как проработка: игровой код в родительской НЕ
пишется, результат — подробные подзадачи в pending, новый
подраздел SPEC.md и memory.

## Номера дочерних задач

В анализе закладывался блок 000096–000107, НО параллельная задача
000051 (редизайн панели персонажа) при своём мерже (b5a9535)
заняла 000096–000101 (её 6 подзадач). По правилу
memory/task-numbering-conflicts.md («номера MASTER сохраняются;
новые номера — от следующего свободного на master») дочерние
000052 перепривязаны: **000102–000110** (9 задач). В каждом
файле подзадачи — пометка «Перепривязка: в анализе была №…».
Номера 000111+ свободны как перелив (сверено по tasks/pending,
tasks/done, tasks/result актуального master b5a9535 и по всем
известным worktree).

## Ключевые проектные решения (зафиксированы в SPEC «Города и
деревни», подзадачах и memory)

1. ГОРОД = ПОСТРОЙКА-ВХОД: категория «город» в assets/buildings,
   4 типа (хутор 1x1, деревня 2x2, город 5x5, столица 7x7 —
   размер ОДИН на тип; диапазоны закрыты верхней границей).
   Решение 000064 по мосту/воротам: отдельного объекта на
   глобальной карте не нужно; id 50 остаётся резервированным и
   элементом ВНУТРЕННОГО города не становится.
2. РАЗМЕЩЕНИЕ — отдельный «городской канал» в anchorAt
   (src/map.js): свой hash2(x, y, const) + порог редкости по
   шуму/альфе, проверяется ПЕРЕД слотовым hash; `hash % 13` и
   распределение слотов НЕ меняются (запрет 000064; 000073 —
   согласовано: слотовой hash не трогаем). Тип/размер —
   детерминированно из позиции и шума. Размещение через
   существующий пайплайн placeBuilding/isFreeForBuilding/
   entranceReachable → инварианты 000026 сохраняются.
3. ГОРОД НЕ СЖИМАЕТСЯ: sizeChain (buildings.js:675) молча сжимает
   >3x3 до 3x3/1x1 — для городов исключение (флаг `не_сжимать`
   в каталоге): не влез по полному размеру → не размещается.
4. ЛAYOUT — dungeon-совместимый, но город НЕ тип подземелья:
   новый чистый модуль src/cities.js (UMD, паттерн day.js;
   взаимных require в момент загрузки нет); seed = hash2
   (cityX, cityY, const) — от позиции, НЕ от totalXp (город не
   меняется при получении опыта); DUNGEON_TYPES/каталог
   assets/dungeons/фон боя не трогаются; dungeon_memory_days не
   применяется (город персистентен).
5. ВХОД/ВЫХОД — через dungeonState (kind 'dungeon'|'city'),
   экран — dungeon-ui (режим «город»), движение — общий движок
   000066. РЕШЕНИЕ: день на входе/выходе НЕ проходит (в отличие
   от подземелья — clock.event не вызывается; город — локация
   поверх мира).
6. СОДЕРЖИМОЕ — детерминированно от ПОЗИЦИИ: существующие типы
   каталога (квоты в `особые_параметры`, source of truth), NPC —
   по связи `постройки` каталога assets/npc, таверна — в каждом
   городе (найм 000065/000078 — не зависит от 000107).
7. ВЗАИМОДЕЙСТВИЕ — ТОЛЬКО через Game.buildingUI (000071) +
   npcUI; обход запрещён тестом (гард [E] в dungeonUI,
   main.js:498, сохраняется).
8. ЛАВКИ — стоки по (город, клетка): makeShop с офсетом
   координат (иначе все города делят сток — прецедент мировой
   npcStocks, ключ npcId, main.js:209-218, memory/000064).
9. СЕЙВ — раздел data.cities (неломкое v1, 000031; битый
   раздел → warn+отброс, 000029; имена не коллизировать с
   разделами 000072); дни АБСОЛЮТНЫЕ; респаун по
   city_respawn_days (global-settings) на слое 000072
   (serializeDayMap/restoreDayMap/canUseToday); обрезка
   просроченных записей (мир бесконечен); тест-фиксатор
   «_lastUnkillDay-регрессии».
10. ВИЗУАЛ — footprint через механизм 000042 (расширение на
    7x7), спрайты 4 типов (город — не слот, BUILDING_SPRITES по
    слотам не трогаются), HUD-имя (название_карты).
