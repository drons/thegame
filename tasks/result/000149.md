## Что сделано

1. **Кнопка «Книга заклинаний»** — одна вместо пары «Огонь»/«Исцел.»:
   7-я в панели боя (позиция fire), иконка `assets/ui/combat_spellbook.svg`
   (открытая книга), aria «Книга заклинаний», клавиши **KeyQ (primary) +
   KeyR** — обе открывают/закрывают книгу (дубль, прецедент KeyJ/KeyK).
   Из таблицы combat-keys.js (−fire/−heal в таблице, лейблах и подписях).
2. **Книга в бою** (combat-ui.js, DOM): контейнер `.combat-spellbook` в
   `.combat-side` между `.combat-actions` и `.combat-log`, скрыта
   `display:none`; строки `.combat-spellrow` (div, НЕ button — счётчик
   vm-стаба): иконка + имя + meta `Мана N · Заклинание
   (Интеллект/Мудрость)` + описание каталога дословно. Клик живой строки —
   каст; disabled-строка (`-off`, opacity .4, title = reason) — клик пишет
   причину в журнал, каст не идёт. Пустая книга — строка «—» (тоже -off).
   Перестроение строк ТОЛЬКО при изменении сигнатуры (блок-фикс ревью:
   пересоздание на каждый rAF-кадр убивало click в реальном браузере).
3. **`src/spellbook.js` (новый, UMD, 0 зависимостей)** —
   `Game.SpellBook.entriesFor(sheet, catalog)` — чистая функция строк
   (node-тестируется без DOM): порядок = `sheet.spells`, поля из каталога,
   некаталожное id → строка с голым id, мусор → `[]` без исключений.
4. **Каст** — существующий движок 000045: `G.Spells.castSpell(c, id,
   c.targetId)`; предпросмотр строки — `G.Spells.canCastSpell`; на успех —
   `c._fx={action:'cast',…}` + книга закрывается, ход не сгорает; на
   отказ — reason в журнал, книга остаётся открыта.
5. **`canDoAction(c,'spellbook')`** в combat.js — аддитивная ветка
   (после 'heal'): checkTurn → checkBlocked → пустая книга →
   «заклинаний нет». Единый источник доступности для кнопки И клавиш
   (контракт 000037); handleCode — без изменений.
6. **Данные**: 16 JSON `assets/spells` + поля `icon`
   (`assets/spell-icons/<id>.svg`) и `icon_prompt` (промпт генерации
   силуэта, формат в memory §4); schema.json +оба (properties+required,
   additionalProperties:false сохранён); sync KEYS + перегенерация
