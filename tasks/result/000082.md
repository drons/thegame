## Решения (зафиксированы в memory)

1. **Доля — от СЫРОГО боевого xp** (до бонуса «Учёный»): xpMult
   применяется ВНУТРИ P.addXp — «Учёный» спутникам НЕ идёт (навыков у них
   нет, v1).
2. **Math.round, не floor** (16×0.3 = 4.8 → 5) — паттерн gold-формулы.
3. **Доля — КАЖДОМУ выжившему независимо, НЕ делится на их число**:
   2 спутника × 0.5 = суммарно 100% сверх 100% игрока.
4. **ПОЛОЖИТЕЛЬНЫЙ фильтр kind === 'merc'** (не `kind !== 'efir'`) —
   устойчив к spelling kind Эфира ('efir' в SPEC/memory/000035, 'ether'
   в memory/000080 — опечатка); Эфир вне доли: собственный пул, 100% xp
   (000081) — исключение убирает двойной подсчёт (0.5 + 100%).
5. **id — data.id (для наёмника — npcId)** — 000087 маппит allyXp →
   roster по npcId.
6. **Повышения — while-цикл порогом xpForNext** (src/player.js, те же
   пороги, что у игрока: 50/141/260/…): один бой (мобы 10+: xp ≈ 192,
   доля 96) даёт 1–2 уровня; остаток копится в записи; потолка уровня в
   v1 нет (игрок тоже без потолка — SPEC).
7. **Рост статов ИМПЛИЦИТНЫЙ**: в запись статы не пишутся (форма
   зафиксирована под сейв 000085) — makeAlly пересчитывает maxHP/damage/
   armor из нового уровня при следующем createCombat (формулы makeMob БЕЗ
   combat_difficulties/hasLeader). Повышения СРЕДИ боя НЕТ — статы юнита
   фиксируются createCombat (уровень из roster на начало боя).
8. **НОЛЬ новых вызовов c._rng в checkVictory** — бит-в-бит поток RNG при
   0 союзников; детерминизм доли зафиксирован тестами.
9. **allyXp — ТОЛЬКО в outcome 'victory'** (с победами); 'fled'/'dead' —
   поля нет; 000087 гвардит outcome === 'victory' перед чтением доли
   (иначе NaN/undefined).
10. **applyCombatXp — чистая функция (паттерн payWages)**: тихий skip
    «призраков»/мусора без исключений; возврат {applied, levelUps, events:
    level_up} — 000087 → hudFlash + saveNow. Отдельных xp-событий НЕТ
    (текст «+N опыта» 000087 строит сам из c.result.allyXp; сообщения —
    только про выживших с xp > 0).
11. **Практика (PRACTICE_XP, c.skillXp) — ТОЛЬКО навыки игрока**:
    allyAttack/allyHeal НЕ вызывают P.skillPractice (зафиксировано
    красным тестом); опыт квестов — полностью игроку (main.js, вне
    combat.js). Очков навыков у спутников НЕТ (v1); набор навыков
    фиксирован из каталога найма (000078).
