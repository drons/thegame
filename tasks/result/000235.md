### 4.1 Формула лута свитков (контракт .05 + SPEC .06,
дословно)

Направление (уточнено станцией, a2 Q1): моб Сильнее игрока →
риск = награда. D = maxLvl(группа мобов) − playerLevel.

* Мобы (rollVictoryLoot, НОВЫЙ ролл ПОСЛЕ существующих,
  отдельный солёный rng-поток — goldens бит-в-бит):
  * P_scroll = 0.05 + 0.02·max(0, D), кап 0.25 (кап
    достигается при D ≥ 10);
  * Тир: при D > 0: T = min(4, 1 + floor(D/3)); при D ≤ 0:
    T = 1 + (rng < 0.5 ? 1 : 0) (T ∈ {1,2}, 50/50) — ветка
    D ≤ 0 ПЕРЕХВАТИТЕЛЬНА, базовая формула к ней не
    применяется (уточнение вериф. станции);
  * Школа — равномерная из 6 (из солёного потока);
  * Выбор свитка — из свитков школы+тира (нет → ближайший тир
    вниз, затем вверх);
  * Параметры — константы в src/combat.js (паттерн LOOT_*
    :1158-1172); формула дословно в spec (dungeons-storage
    «Лут» + items.md); пины: D=0/D=3/D=6/кап + детерминизм
    по сидам.
* Сундуки (dungeon.js:744, выбор ПО ГЕНЕРАЦИИ ЭТАЖА, не в
  openChest): CHEST_ITEM_CHANCE 0.4 БЕЗ ИЗМЕНЕНИЙ; пулы
  `предметы` БЕЗ ИЗМЕНЕНИЙ (волны добавляют свитки); выбор —
  среди элементов пула с ITEM_TIER ≤ T, где T = min(4, 1 +
  floor((depth-1)/2)) (паттерн залежей, dungeon.js:769-770);
  если пусто — любой; goldens СМЕЩАЮТСЯ (репин —
  задокументировать в result .05 + SPEC .06).
* Свиток без tier (8 старых до .05) = tier 1 (dungeon.js:
  55-57) — .05 проставляет tier по уровню заклинания.
