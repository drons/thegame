## Что сделано

1. **src/efir.js (+68/−2)** — `buildEfirUnit(efir, c)`: боевой
   профиль Эфира. АПГРЕЙД существующего юнита (не создание — D2):
   hp = maxHP, mp = maxMP (своя мана, полная на старте боя, БЕЗ
   регена в бою), урон «Касания духа» `max(1, round((2+0.5·Мудр)·
   мораль))` (мораль ВНУТРИ round — D6), пул `c.efs` {spellInt:
   1+floor(INT/10), spellWis: 1+floor(Мудр/10), touch: 1, move: 3},
   снапшот лордов `u.efirSkills` (4 id, D8), ссылка `c.efir`.
   Экспорт — 12-й, в хвост return-блока. state — только чтение.
2. **src/combat.js (+248/−0 — ТОЛЬКО вставки, горячий файл)**:
   * `efirTurn(c, u)` — ход Эфира: движение-эскорт (бюджет 3, цель
     выбирается ОДИН РАЗ: d до игрока > 3 → к игроку, иначе d до
     врага > 3 → к врагу, иначе стоим — D13), затем действия —
     приоритеты (1) лечение самого раненого (≤ 70% maxHP, союзник,
     включая игрока и самого Эфира) → (2) щит игрока (≤ 50% и
     c.efirShield не стоит) → (3) «самое сильное» урон-заклинание
     (огонь/лёд, дальность SPELL_MAX_DIST, лорд по школе) → (4)
     «Касание духа» (d ≤ 1, всегда попадает, игнор брони); пулы
     расходуются в этом порядке за ход, пока не пусты;
   * `strongestKnown(u, действие)` — «самое сильное» известное:
     МАКСИМУМ «мани» каталога, тай-брейк — лекс. меньшее id (D9);
   * `efirPool(s)` — единая точка выбора пула по полю «атрибут»
     каталога (D10, фикс ревью m2);
   * `mostWounded(c, frac)` — самая раненая цель (мин. hp/maxHP;
     при равенстве — игрок первым);
   * вставки: 1 строка-диспетчер в `allyAct` (`u.kind === 'efir' &&
     c.efs` → efirTurn; без c.efs — ветка 000080 бит-в-бит — D3),
     поглощение `c.efirShield` в `dealDamageToPlayer` (отдельный
     статус Эфира, НЕ c.ps.shield игрока — D4), refill `c.efs` +
     тик щита в `endPlayerTurn` после refillPools/тика c.ps.shield
     (D5), `combatInternals.dealDamageToAlly` (+1 член).
   * НУЛЬ новых вызовов c._rng — детерминизм по сиду сохранён.
   * Щит: заряд round(5+0.5·Мудр), ровно 2 раунда (тик в
     endPlayerTurn — живёт и после гибели Эфира), повторный каст —
     обновление, не кумуляция.
3. **src/combat-ui.js (+11/−0)** — `startCombat`: вызов
   `buildEfirUnit` сразу после `createCombat` (D1: createCombat
   остаётся независимым от efir.js; guard — тихая деградация).
4. **main.js / index.html / assets — 0 изменений** (efir в opts
   всех трёх точек входа — 000081; efir.js уже в цепочке script
   до combat.js; спрайты — 000034/000084). Гибель → 100% HP/MP —
   СТРУКТУРНО (D14): каждый бой — новый makeAlly + buildEfirUnit;
   обе точки входа (мир/подземелье) передают тот же `efir` — 0
   изменений кода, фиксация тестами.

Формулы L1-пины (ТЗ зафиксировано): Касание 4 (×1.5 → 5); урон
spark round((3+1.5)·1) = 5; лечение round(3+1.5+1) = 6; щит
round(5+1.5) = 7; пул 1/1/1/3; HP 16, своя мана 11 (p.mp игрока
НЕ трогается). vine (контроль) — в ИИ v1 НЕ используется
(зафиксировано: при необходимости — отдельная задача).
