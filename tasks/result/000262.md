## Решения

Все 15 — зафиксированы в memory/000262-tip-flip-clamp.md
(«Решения 1–15»); ключевые:

1. **JS-замер в обработчиках + CSS-класс flip** (чистый CSS
   невозможен — нет условия «позиция янкора во вьюпорте»);
   показ/скрытие остаётся чистым CSS.
2. **Граница = .cp-tabpane ∩ вьюпорт** (пани — самый строгий
   клиппер; .char-panel не клиппит).
3. **Горизонталь — изменений НЕТ** (проверено по ТЗ «по
   необходимости»): тултип навыка right:0 растёт ВЛЕВО от конца
   строки — правый край не может обрезаться; предмет left:0 —
   только экстремально узкий вьюпорт (< ~400px) — пресуществующее,
   вне скоупа (сообщён верхний край).
4. **Класс — только на .cp-tip; инлайн — только marginTop
   (clamp)**; строка в середине после hover — style пуст (бит-в-бит).
