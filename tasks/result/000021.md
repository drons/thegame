# 000021: декорации тайлов глобальной карты (травинки, цветы, кусты, камни, снег)

Статус: выполнено. Тесты: 192 → 200 pass (+8, tests/sprites.test.js).

## Что сделано

* **Каталог элементов** — `assets/visuals/000001..000013.json`
  (13 элементов) + **JSON-схема** `assets/visuals/schema.json`
  (стиль buildings/schema.json: additionalProperties=false, required,
  pattern, enum террейнов). Поля элемента: `id`, `название`,
  `террейны` (⊆ имён TERRAIN_NAMES), `спрайт` (путь
  assets/sprites/visuals/*.svg), `частота` (0..1), `размер`
  (0.05..0.5 — доля тайла).
  Наборы: трава — светлые/тёмные травинки, 3 цвета цветов, куст;
  лес — тёмные травинки, жёлтый цветок, куст, гриб; холмы — камень,
  камешек, сухая травка; горы — камень, камешек, снежный сугроб;
  песок — камешек, сухая травка; болото — тростинка; вода — кувшинка;
  глубокая вода — без декораций (по дизайну).
* **Спрайты** — `assets/sprites/visuals/` — 13 SVG 64x64 в стиле
  существующих тайлов/построек (плоские формы, палитра тайлов,
  мягкие тени).
* **JS-фолбэк `VISUALS`** в src/sprites.js (паттерн buildings.js:
  файл-игра под file:// без fetch()); тест требует deepEqual
  JSON-файлов с JS-каталогом.
* **`tileVisuals(tx, ty, terrain)`** (src/sprites.js) — детерминированная
  ЧИСТАЯ функция выбора/размещения: seed — `hash2` координат тайла
  (перевыдан из src/map.js):
  * появляется элемент, если (hash2(…) >>> 8)/2^24 < частота;
  * позиция — доли [0.08; 0.92] из двух других хэшей (не вылезает
    за тайл);
  * не более `MAX_VISUALS_PER_TILE = 3` на тайл (порядок каталога).
  Сид `VISUALS_SEED = 0x51a11ce5` отдельный от сида построек/мобов.
* Пути декораций добавлены в `allAssetPaths()` — загрузчик спрайтов
  подхватывает их вместе с остальными; декорации НЕ влияют на
  генерацию мира (tileAt чист, как и раньше).

## Тесты (tests/sprites.test.js, +8)

* Каталог: 13 элементов, id = позиция, нет дублей id и спрайтов.
* Каждый террейн (кроме глубокой воды) покрыт хотя бы одним элементом.
* JSON-файлы: ровно 000001..000013.json, содержимое = JS-каталог,
  и мини-валидация каждого объекта по schema.json (required, лишние

  min/max) — «проверка схемы» без внешних зависимостей.
* Спрайт-файлы существуют в assets/sprites/visuals.

  каждого элемента (id/спрайт/террейн/позиция/размер), потолок,
  без дублей на тайле (300 случайных тайлов × все террейны).
* Частота: элемент id=1 (0.35) встречается на ~0.35 травы (±0.05,
  N=4000).
* «Не штамп»: 200 разных тайлов дают ≥50 разных наборов.
* Критерий: провал загрузки всех ассетов (включая декорации) не меняет

## Ограничения

* Отрисовка в main.js (drawImage слоя спрайтов) — main.js вне файлов
  этой цепочки. API готов: для тайла `Game.tileVisuals(t.x, t.y,
