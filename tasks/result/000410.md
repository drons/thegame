# 000410 — ls-миграция счётчиков торговой цепи: результат

## Что сделано

Счётчики торговой цепи в tests/ (входы торговли / торгующие NPC /
уникальные торгуемые / свитковые свипы) переведены с точных пинов на
ls-полы + кросс-зубы синхронности «витрина каталога JSON ≡ зеркало
NPCS» и на ВЫВОД размеров витрин из ростера школа→продавец по
дисковому каталогу. Каскад ре-пинов торговых волн снят: волне больше
не нужно править чужие файлы цепи (000322/000346/000347.01/000347.02/
npc-refs) ради чисел.

Файлы (5, только tests/):
- `tests/item-prices-000322.test.js` — R1: титул без чисел, кросс-зубы
  диск≡зеркало (входы, торгующие), полы entries/traded; R6: кросс-зуб
  зеркало≡диск (jsonEntries) + пол; R7: пол торгующих. Титул/сообщение
  R6 (BP-игла 000375 «base_price ровно у 352») НЕ тронуты.
- `tests/item-prices-rarity-000346.test.js` — T4: титул без чисел;
  кросс-зуб «диск есть торговля ⇒ зеркало тоже» (закрыта дыра silent
  skip при несинхронном зеркале); полы entries/traded.
- `tests/scroll-prices-magic-000347.01.test.js` — T4: размеры витрин из
  `SCROLL_SELLER_SIZE` (ростер школ × диск) вместо литералов
  71/34/35/71; полнота свипа `other + scrolled ≡ 2×jsonEntries`
  (кросс-источник зеркало/диск); полы other/scrolled.
- `tests/scroll-trade-temples-000347.02.test.js` — `SELLER_COUNT`
  выводится из `SCHOOL_SELLER × diskScrolls()`; `count:`-литералы
  SUN/MOON/MOUNTAIN сняты; T5 ≡ 2×витринам ростера + пол; T6 титул —
  канон ls-предиката, полы entries/traders/traded; T7 сверяет витрину

- `tests/npc-refs.test.js` — титул без цепочки ре-пинов; полы trade/

Память: новый `memory/000410-trade-chain-ls-migration.md` (канон формы,
