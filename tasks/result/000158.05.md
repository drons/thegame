## Подводные камни (для мержа и будущих задач)

* Каналы лута — РАЗНЫЕ сиды: map.js LOOT_SEED («что лежит») vs
  sprites.js LOOT_VISUAL_SEED («как/где иконка») — НЕ смешивать;
  смена любого = перепин золотых (MLS-пины map.test.js /
  SP-LOOT-3).
* Контракт каталог ↔ ассеты: каждый item с полем loot (строгий
  фильтр terrains) — ровно 1 файл assets/sprites/loot/<id>.svg
  в allAssetPaths; расхождение любого из трёх пинов (28 в
  sprites.test.js, 'sprites/loot': 28 в svg.test.js, реальные
  файлы) = красный. Новый loot-item — новый SVG + авто-подхват
  (live-сканы, хардкода списков НЕТ) + репин счётчика
  svg.test.js.
* UMD: factory — АРГУМЕНТ IIFE (не тело) — не видит параметр
  root IIFE; live-ссылки на Game идут ТОЛЬКО явным параметром
  factory (паттерн map.js: `factory(Game, null, null, root,
  null)`; node — `undefined` на 4-й позиции). Упрощать/
  выносить `root.Game` из параметров нельзя (vm-ReferenceError).
* Дизайн-ловушка «гриб»: collectible mushroom_* ≠
  декорация visuals/mushroom.svg (000007, красная шляпа +
  белые точки) — закреплено силуэтами D9; новые грибные
  ассеты не должны их сливать.
* 000186 (сундук на карте) и будущие «видимые» механики карты:
  паттерн «пер-кадр флаг + typeof-гард + per-tile isReady-
  фолбэк + под-слой в проходе 1» — домовой для новых слоёв
  #sprites.
