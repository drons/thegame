## Что сделано

Правки ТОЛЬКО в src/efir.js + tests/efir.test.js (+ 1 техпин,
см. Тесты). Новых ассетов, SVG, модулей, script-тегов НЕТ
(состав пула/таблица/формулы — ДАННЫЕ МОДУЛЯ, паттерн 000053;
каталога assets/efir/ НЕ создавать — SPEC «Данные и ассеты»).

* **Собственные атрибуты** (не шесть основных игрока): чистая
  `efirStats(level)` — Инт = Мудр = Тел = 3 + floor((ур−1)/2);
  maxHP = 10 + 2·Тел; maxMP = 5 + Инт + Мудр. L1: 3/3/3, 16, 11;
  L3: 4/4/4, 18, 13; L5: 5/5/5, 20, 15 (пины T1). Мусор/<1 → 1;
  свежий объект на вызов.
* **Книга заклинаний**: данные `EFIR_SPELL_UNLOCKS`
  (5 light_heal, 8 frost_bolt, 10 fireball, 12 magic_shield,
  15 vine, 20 greater_heal, 25 ward, 30 nature_blessing) +
  чистая `efirSpellsByLevel(level)`; старт [spark, mend]
  (`EFIR_SPELL_START`, внутренняя константа). Поле `spells`
  (append-only) — ДАННЫЕ СОСТОЯНИЯ; `levelUp` ПОСЛЕ while-цикла
  автоматически достраивает книгу (нормализация битой формы +
  push отсутствующих, дублей нет; заклинания не удаляются).
* **Независимый пул навыков** {firelord, icelord, perception,
  precog} — `EFIR_SKILLS` (ДАННЫЕ МОДУЛЯ, ЗЕРКАЛО каталога
  assets/skills: id/primary/requires; порядок — зависимый:
  requires раньше зависимых). Поле `skillXp` (банк, дроби
  разрешены) + `skills` (КЭШ, пишется ТОЛЬКО переучётом).
* **Потолок** `efirSkillCap(state, id)` = основной атрибут
  НАВЫКА (из данных модуля) × 2 по ЕГО атрибутам (паттерн
  practiceCap, player.js:351; отдельная чистая функция —
  «у Эфира нет основных → потолок 0» не возникает):
  firelord/icelord — Интеллект·2, perception/precog — Мудрость·2;
  id вне пула → 0.
* **Кривая** `efirSkillXpForNext(level) = 15·(уровень+1)` —
  КОПИЯ игрока (000013), отдельная чистая функция (не
  переиспользование player-объекта, без ленивых ссылок).
* **Переучёт** `reprocessEfirSkills(state) → string[]`
  (id, чей уровень изменился): ведение С ТЕКУЩЕГО уровня
  (bank = остаток в пределах уровня; за потолком — overflow
  ХРАНИТСЯ в skillXp и конвертируется при росте cap);
  requires-невыполнен → уровень 0, банк ЦЕЛИКОМ (ничего не
  списано); идемпотентен (неподвижная точка структурна);
  нормализация битых значений; null → []. Точки вызова:
  levelUp (000111), deserialize (000115 — обязательно),
  practiceEfir (000117).
* **Проводка в бой** (минимальная, `efirAllyData`): `attrs`
  (3 собственных — св. копия) + `spells` (книга из состояния,
  копия; деградация на таблицу для state без поля). Явных
  maxHP/damage в данных НЕТ (решение D2 — неприкосновенный пин
  R7 combat.test.js; явные боевые статы hp/mp — скоуп 000112
  `buildEfirUnit`).
* **НЕ тронуто**: xp-механика 000081 (addEfirXp/пороги/100%/
  деградация — ТЗ «не переделывать»), UMD-обёртка (0 `require(`,
  0 снапшотов Game при загрузке — пин R1), ленивый xpForNext,
  src/combat.js, src/player.js, src/main.js, src/combat-ui.js,
  index.html, CSS, assets/**, SPEC.md, файлы задач.
