## Что сделано

1. **src/controls.js (+55/−1)** — чистая часть роутинга, без новых
   зависимостей:
   * `routeTouchScreen(screens) → 'combat'|'dungeon'|'map'` — ЧИСТАЯ
     функция от СНИМКА активных оверлеев `{combat?, dungeon?,
     dialog?, building?}`; приоритет **бой > подземелье > карта**;
     dialog/building — map-локальные оверлеи: принимаются в снимке, но
     НЕ потребляются (поведение = карта); мусор/не-boolean → 'map'
     (жёсткие `=== true`, деградация, не крах).
   * `TOUCH_KEY_CODES` + `touchKeyCode(action)` — ЕДИНАЯ точка
     маппинга тач→e.code: направления → стрелки (канон), 'interact' →
     'KeyE', 'inventory'/неизвестные → null ([I] не роутится, 000123).
2. **src/combat-ui.js (+24/−12)** — `handleCode(code)`: тело keydown
   ПЕРЕНОСИТСЯ 1:1 (не переписывается), keydown — обёртка;
   `if (consumed) render(); return consumed;`. ЕДИНСТВЕННЫЙ путь
   «code → действие боя» для клавиатуры и тача (единая таблица
   combat-keys.js, 000048 — без дублирования). Тап D-pad = ОДНО
   действие, БЕЗ повтора (в бою каждое действие тратит ход).
3. **src/dungeon-ui.js (+83)** — `touchHold`/`touchRelease` +
   `touchStepMs`/`touchHoldStep`: тап = один шаг (тело keydown 1:1,
   `deltaForMoveKey('touch:'+dir)` → `ctx.onMove` → render); повтор при
   удержании — в СУЩЕСТВУЮЩЕМ rAF-цикле (hook в tick, ДО step());
   интервал — live-чтение `move_interval_ms` (000063), дефолт 420,
   кламп ≥ 60; гарды каждого шага: оверлей активен + бой НЕ активен
   (бой начался при удержании → повтор стоптится, боевые действия НЕ
   выпускаются); сброс в start()/close(). keydown — БУКВАЛЬНО не
   тронут.
4. **src/main.js (+62/−7)** — переписан ТОЛЬКО тач-блок (L845-891):
   `touchScreens()` (снимок в момент события, ленивое чтение) +
   dispatch по роутеру в onHold/onRelease/onInteract (клей БЕЗ
   СОСТОЯНИЯ: onRelease — два идемпотентных вызова; таймеров в
   main.js нет). [E] по экранам: бой → quickItem (KeyE), подземелье →
   no-op (кнопка не скрывается), карта → `buildingActions.toggle()`.
   onInventory — без изменений (000123). keydown/keyup/blur/tryMove/
   frame-гейт — не тронуты.
5. **index.html (+11/−8)** — `#touch-controls` z-index 5 → **30**
   (лестница 10/15/20/30: оверлеи боя/подземелья z-20 НЕ перекрывают
   контролы — ТЗ п.5) + актуализация комментов. НОВЫХ модулей,
