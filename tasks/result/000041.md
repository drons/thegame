## Что сделано

1. **Копилка опыта практики в `.cp-level`** (src/ui.js, ветка
   вторичных навыков в `render()`):
   * `bank > 0 && lvl < 100` → «`lvl (bank/need)`», наипр. «3 (12/60)»;
     `bank = c.skillXp[skill]` (защита от старых сейвов без `skillXp`),
     `need = G.skillXpForNext(lvl)`;
   * пустая копилка (нет ключа / 0) → просто «`lvl`» (без «(0/N)»);
   * `lvl = 100` → просто «100» даже при `bank > 0` (порог на максимуме
     бессмысленен);
   * у основных навыков — как и раньше, просто число уровня.
2. **Пометка потолка практикой в `.cp-req`**: при `0 < lvl < 100` и
   `lvl >= G.practiceCap(c, skill)` — «потолок практикой: `
   <имя основного>` `cap/2`×2 — дальше растёт только очками и книгами»
   (напр. «потолок практикой: Сила 5×2 — …»). Показывается и при
   `lvl > cap` (уровни из книг — практика всё равно не работает).
   `lvl = 0` — требование (`requiresText`), как раньше; `lvl = 100` — пусто.
   Формулировка «дальше растёт только очками и книгами» добавлена по
   тексту задачи (в hunk'е черновика её не было).
3. **Правки по итогам ревью** (коммит 123844d):
   * «Вспышка» причины неудачи `raiseSkill` теперь пишется в `.cp-req`
     ПОСЛЕ `render()` (раньше `render()` её сразу перекрывал — вспышка
     была невидима), а `setTimeout` через 1.5 с вызывает `render()` —
     возвращает постоянный текст ячейки (пометка потолка / требование),
     а не затирает её пустой строкой (до фикса таймаут ставил `''`).
   * `sanitizeSavedHero` (src/player.js): `skillXp` теперь принимает
     только ЦЕЛОЕ `>= 0` (было: конечное число `>= 0`). Дробный опыт
     возможен только в подделанном сейве (в игре копилка всегда целая:
     `Math.round`, пороги 15·(lvl+1)) — иначе панель показывала бы
     «3 (2.5/60)».
