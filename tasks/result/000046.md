## Что сделано

1. **src/craft-data.js** (новый) — генерируемое зеркало каталога
   (`scripts/sync-craft-data.js`, `npm run gen:craft`; конвенция
   write-atomic): `CRAFT` (массив в порядке файлов), `CRAFT_BY_ID`
   (циклом, идентичность объектов — как SPELLS_BY_ID 000045).
   Браузер: `Game.CraftData`.
2. **src/craft.js** (новый, ~750 строк) — чистое ядро без DOM,
   `Game.Craft` (21 экспорт): уровни/опыт видов (`craft {вид: 1..100}`,
   копилка `craftXp`, порог `15×(L+1)`), потолок практикой
   (`craftCap = related_skill × 2`, CRAFT_TYPE_SKILL),
   `canCraft/craft` — ОДНА причина, общий evalCraft (уровень →
   здание → исходники → место в инвентаре), качество/выход
   (`qualityChance`/`yieldChance` — формулы в шапке модуля и красных
   тестах, в SPEC их нет — паттерн 000045), «совершенствование
   способа» (рецепт с `база`), наставники (`canMentorCraft`/
   `mentorCraft`, npc.js), книги (skill_book, hook в items.js),
   `reprocessCraftXp` — ленивый хук `craftReprocessHook` в
   player.js raiseSkill/_gainSkillXp и npc.js schoolTrain (UMD 000038).
   Guards (000038/000045): CraftData → player API → items API →
   buildings → spells, иначе console.error + модуль не создаётся.
3. **src/items.js** (+~270) — бонусные слоты инвентаря,
   `bookCraftXp`-хук, лимиты веса/слотов под крафт.
4. **src/player.js** (+27) — поля craft/craftXp, хук
   craftReprocessHook. **src/npc.js** (+15) — обучение (наставник).
5. **src/main.js** (+32) — sanitizeCraftLevels/sanitizeCraftXp из
   КОРНЯ Game в restoreFromSave (сейв: разделы craft/craftXp —
   неломкое расширение v1, без бампа версии).
6. **index.html** (+2 script-тега, порядок закреплён
   tests/index-order.test.js), **package.json** (+gen:craft),
   **SPEC.md** (+30 — раздел «Крафт» закреплён).
7. **Синхронизация**: scripts/sync-craft-data.js + tests —
   зеркало byte-совпадение с assets/craft (конвенция
   write-atomic, tests/sync-all.test.js).
