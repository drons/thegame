## Что сделано

1. **Layout — ОДИН тайл** (инвариант `d.exit` deepEqual
   `d.entrance`, оба поля живут — consumers читают оба):
   * cities.js — `createCityLayout`: дверь = `{x: col(), y: H−1}`
     (ОДИН вызов col() — позиция входа не меняется),
     entrance = exit = дверь; старая северная клетка выхода —
     WALL.
   * dungeon.js — `createDungeon`: exit := центр ПЕРВОЙ комнаты
     (`rooms[0]`); 0 новых вызовов rng — форма подземелья
     бит-в-бит как до задачи; safe-зона — ОДИН 5×5-блок
     (Set-дедуп точки входа-выхода).
2. **Выход — ТОЛЬКО [E]** (механизм уровень-независим; «между
   уровнями» — аналогично, этажей в игре нет):
   * locations.js — `interactExit(ds)` (10-й экспорт, чистая
     функция): герой на совмещённом тайле → `{type:'exit', name}`
     (город — `ds.name`, подземелье — DUNGEON_NAMES[type]);
     вне тайла / !ds → null. exit-ветки удалены из
     dungeonMove/cityMove — шаг на тайл = обычный moved.
   * main.js — `locationOnInteract()` — ЕДИНЫЙ [E]-путь (клавиша /
     тач / debug — три канала, один код): interactExit →
     `exitLocation(ds)` (инвариант 000170 try/catch/finally НЕ
     тронут — finally {dungeonState=null; dungeonUI.close();
     saveNow()}; механизм выхода ВНУТРИ инварианта) + flash
     «Вы вышли из \<name>.» (слово в слово, 5 сек). Вне тайла:
     город → buildingActions.interactCity (000107), подземелье →
     no-op (000121). cityOnInteract — удалена (тело влито в
     locationOnInteract). Спавн при входе — на едином тайле
     (enterLocation; `__game.dungeon` + prevX/prevY).
3. **Отрисовка**: dungeon-ui.js — ОДИН маркер портала на тайле
   (SVG по kind — DUNGEON_PORTAL — или фолбэк-квадрат с 'E');
   хинты «Дверь — вход и выход: встаньте на неё и нажмите [E].»
   и «Вход в пещеру — вход и выход…». sprites.js —
   DUNGEON_PORTAL {door, stairs, cave_mouth} + allAssetPaths.
   assets/dungeon/: door.svg / stairs.svg / cave_mouth.svg
   (64×64, прошли гейт svg.test.js ДО добавления в каталог).
4. **CHANGELOG.md** — буллит игрового процесса от 2026-10-10
   (программная часть не перечисляется).
