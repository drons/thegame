# 000322 — отчёт: базовая цена предмета — в JSON предмета, а не в JSON NPC

## Итог

База NPC-торговли вынесена из JSON NPC (цены) в JSON предмета
(`base_price`, опциональное, integer 1..100000, позиция — сразу после
`value`). Вход `торговля` NPC — `{предмет, mult_покупки? (по умолчанию
1), mult_продажи, количество?}`; `цена_покупки`/`цена_продажи` удалены
(schemas: additionalProperties false — старый формат невалиден).
Формулы src/npc.js — только источник базы: `base = base_price, фолбэк
value`; множители NPC и «Торговец» активного персонажа (derived,
src/sheet.js) — не тронуты. Магазин постройки (src/items.js) — формула
от `value` не тронута. Все 46 цен бит-в-бит сохранены
(base × mult === старая цена точно как double; 46×2×216 сравнений,
0 переворотов — R3).
