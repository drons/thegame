## Решения (зафиксированы в memory и тестами)

Полный контракт — memory/000267-noop-stat-consumers.md (§1–§8:
точки S1–S7, Z1–Z4, границы, бит-в-бит, подводные камни, стадии).
Ключевые решения:
* Зона «реген» — ПЕРИ-ТИК проверка Чебышёва от ФИКСИРОВАННОЙ клетки
  каста (радиус — живой параметр), а не безусловный самохил (Z1);
  тик ПЕРЕД декрементом → ровно N тиков, включая каст (Z3); тики
  молча (Z4); союзник в радиусе получает двойной тик (buff + зона) —
  ФАКТ, не баг (Z2).
* Вампиризм — только ФИЗИЧЕСКИЙ удар ИГРОКА (c.ps.buff) по фактическому
  урону после брони (r.dmg); баф союзника и урон-касты — НЕ
  потребляются (границы зафиксированы §2.2).
* Drain — гейт по НАЛИЧИЮ параметры.value (не по id спелла): будущее
  value-заклинание «урон» будет лечит автоматически — по дизайну
  (§2.3).
* Shroud — АДДИТИВ −0.25 в atkBonus-слоте (зеркало чтения дебафа
  моба; прецедента «мультипликатор шанса» в коде нет — единая
  система), только mobAttack → игрок (§2.4). id = «shroud»
  (000075 Теневая вуаль), НЕ shroud_of_night (000091).
* Lifesteal — FULL r.dmg (зеркало удара МОБА; 000087 «союзник с
  уроном и вампиризмом» = 100%); traits — дефенсивная КОПИЯ, не
  ссылка на объект каталога (§2.5).
* НОВЫХ МОДУЛЕЙ/ЭКСПОРТОВ/<script>-тегов/ассетов нет: index.html,
  svg, assets, CSS — 0 правок.
