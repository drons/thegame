## Что сделано

Реализован по SPEC.md (раздел «Навыки», «Повышение вторичных навыков», п. 2).
Переношено вручную из OLD-черновика `/home/sas/thegame-draft-000013.patch`
(база черновика устарела, `git apply` не работал) + 8 новых предметов из
`/home/sas/thegame-draft-000013-assets/`.

* **src/player.js** — ядро механики:
  - `c.skillXp[id]` — опыт внутри текущего уровня вторичного навыка.
  - `skillXpForNext(level) = 15*(level+1)`; `practiceCap = primary*2`.
  - `skillPractice` (до min(100, потолка)) и `skillReadBook` (игнорирует
    потолок, до 100). Остаток опыта, накопленный ниже потолка, хранится и
    применяется, когда потолок поднимется.
  - `reprocessSkillXp` из `raiseSkill` — при росте основного навыка
    застрявший в копилке опыт конвертируется в уровни до нового потолка.
* **src/combat.js** — источники практики: `PRACTICE_XP = {hit:3, block:2,
  spell:3}`; попадание мечом/луком/тяжёлым/кулаками, блок, каст огня и
  исцеления. Промашка — без опыта (только успешные применения).
* **src/items.js** — зелье +2 «Алхимик», еда +2 «Сердце природы» (за
  каждое применение); книги/свитки идут через `skillReadBook` (фрагмент
  книги из мастера заменён, не продублирован).
* **src/dungeon.js** — в сундуках каждого типа подземелья есть книга/свиток
  с опытом навыка (связка с 000009/000007).
* **assets/items/000025–000032.json** — 8 новых skill_book (fists, hide,
  firelord, icelord, heavy, archer, meditation, nature) + дубликат в
  фолбэке `src/items-data.js`.
