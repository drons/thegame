## Решения (зафиксированы)

1. **Параметры канала — global-settings** (SETTINGS.city_channel), не в
   `особые_параметры` каталога: SPEC «Размещение» предписывает
   global-settings; `особые_параметры` городов (000102) — параметры
   ВНУТРЕННЕГО содержания (доли_типов/мин_постройки) — другое.
2. **city ⊂ slot anchor** — через порог: 0.45 + 0.10·r ≥ 0.33 + 0.14·r
   при всех r ∈ [0,1] (проверено сеткой r) — город только на существующих
   слотовых якорях: детерминизм слотов цел, мир меняется «плавно» (часть
   зданий заменена городами), негорода — побайтово как до задачи.
3. **buildingId — новое поле** (id каталожной записи), не 14-й слот и не
   подтип 000073: building сохраняет чистую слотовую семантику (у города
   — NONE); buildingId слотовых записей — null, до 000073.
4. **Без слотового фолбэка для города**: не влез по полному размеру →
   пустой якорь (не 1x1, не слотовая постройка) — согласовано с
   не_сжимать (000102).
5. **Окно 7x7 — осознанно** (вывод из каталога: map_index ∪ города);
   фолбэк vm-песочницы без каталога — 3x3, как был.
6. **Сид канала — GLOBAL_SEED ^ 0x43495459** с golden-пинами hash2:
   смена константы = смена карты городов — недопустима без перепина.
7. **Ре-пин 4 golden-пинов** — единственное сознательное изменение
   существующего мира (пометка 000103 в тестах).
