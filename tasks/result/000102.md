## Решения (зафиксированы)

1. **Размер один на тип** = верхняя граница диапазона 000052: 1x1 / 2x2 /
   5x5 / 7x7. Промежуточные размеры (4x4, 6x6) — НОВЫЕ записи каталога,
   код не правится.
2. **У городов НЕТ map_index**: они не слот-типы; генерация карты
   (hash % 13, слоты 0..12) и окно поиска 3x3 не изменились. Размещение
   города на карте — 000103 (отдельный «городской канал», свой hash —
   детерминизм генерации не ломать, ловушка 000064/000073).
3. **`не_сжимать` — свойство ЗАПИСИ** (особые_параметры), строго
   `=== true` (не свойство категории «город», чтобы не сжимать
   «автоматически»): sizeChain — один полный размер; placeBuilding —
   целиком или null. Все остальные постройки — старая цепочка
   (3x3 → 1x1) без изменений (регрессии закреплены).
4. **Внутренний тип — существующая запись каталога**: доли_типов — id
   1/7/10/25/44; вложенных городов НЕТ (закреплено тестом: ключ не
   категории «город»). Хутор 1x1: весь footprint — стена и вход →
   мин_постройки = 0 (иначе 000106 получит невыполнимое требование).
5. **Доли ЧАСТОТЫ типов при размещении** (хутор част, столица редка) —
   параметр канала размещения: где живут (каталог vs global-settings) —
   решение 000103, не этой задачи.
6. **id 50 «Мост/ворота» НЕ тронут** (решение 000064: резерв).
7. **`название_карты` = имя типа** («Хутор», «Деревня», «Город»,
   «Столица») — HUD-имя; конвенция вывода (первая буква нижний регистр)
   — функция buildingNameUi (000055), данные не тронуты.
