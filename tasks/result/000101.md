## Что сделано

placeholder-строка «Магазина здесь нет» ВМЕСТО скрытия секции**.
Было: `display='none'` + ранний return, который НЕ чистил тело
(stale-строки — зафиксировано прогоном: 8 детей в скрытом _shopBody
после setShop(null)).
* src/ui-tab-shop.js (render, ветка !shop): секция остаётся видимой
  (`display = ''` — после правки 'none' не пишется НИГДЕ); тело
  чистится (`textContent = ''` — симметрия с shop-веткой); голый
  `div.cp-itemmeta` «Магазина здесь нет» (.cp-itemrow НЕ — это
  контракт строк предметов; CSS-класс уже существует → index.html
  не правится).
* shop ≠ null — ветка БЕЗ ИЗМЕНЕНИЙ (побайтово, «как есть»
  000096/000130): мета «<постройка>, богатство N/3», buy/sell-строки
  через ctx.itemRow, кнопки — только существующие .cp-btn[data-act],
  у строк .cp-tip НЕТ (пин ui-panel L980).
* **Перенос «Торговли» во вкладку «Магазин» НЕ выполнялся заново —
  выполнен ДОСРОЧНО в 000096/000130** (одноколоночной секции
  «Торговля» в DOM нет; «Состояние сейчас» и «Файлы» ТЗ устарели —
  d1–d5, memory §1). 000101 добавил только тест-фиксатор S3 (секция
  не вернётся) и placeholder.
* API G.playerUI.setShop (shopKey-гард — в ядре ui.js, hud.js зовёт
  КАЖДЫЙ кадр) / setCharacter / toggle / render / isOpen — без

## Решения (зафиксированы в memory §3 и тестами)

1. **Placeholder — строка ВНУТРИ _shopBody, секция ВИДИМА (variant
   A)** — конвенция кодовой базы 1:1 («Квесты»: «Журнал квестов
   недоступен.»; 000098: «Настройки недоступны»), ТЗ буквально
   «placeholder-строка», pane не теряет заголовок секции,
   минимальный diff.
2. **Форма — голый .cp-itemmeta** (не .cp-itemrow); CSS существует
   (index.html L100) → index.html БЕЗ правок вовсе (ни <script>, ни
   <style>).
3. **display-твинг** — симметричный `display = ''` в обеих ветках;
   'none' не пишется нигде (ни один тест не читает _shopSec.style).
4. **Лоадер** — переиспользование loadTabsUi() + CHAIN_000130
   (ui-tab-shop.js уже в цепочке index.html); новых стабов/CHAIN/
   лоадеров НЕТ.
5. **Имена/цены строк — из фикстуры** (G.getItem/G.buyPrice/
   G.sellPrice от того же shop-объекта) — без хардкода.
