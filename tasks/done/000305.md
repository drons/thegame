Бой начинать только кнопкой «Начать бой»: кнопки перемещения в
режиме расстановки бой не запускают

Источник: баг-репорт пользователя (drons, 2026-11-02).
Суть: при входе в режим боя активируется режим расстановки, но кнопки
перемещения персонажа сразу начинают бой — интерферирует с
перемещением по глобальной карте/подземелью.

SCOPE:
1. В режиме расстановки кнопки перемещения персонажа НЕ начинают бой.
2. Бой начинается ТОЛЬКО после нажатия кнопки «Начать бой»
   (src/combat-ui.js).
3. Поведение кнопок перемещения вне боя (глобальная карта,
   подземелья) — без изменений.
4. Красные: нажатие перемещения в режиме расстановки → бой НЕ начался
   (расстановка продолжается); кнопка «Начать бой» → бой начался.

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт (кто запускает бой);
* CHANGELOG — да (геймплей).

spec/ (контракт начала боя — сверить).
