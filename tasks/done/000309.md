Разборка предметов на составные части: возврат 20% → 90% с навыком
крафта, разборка качает навык сборки

Источник: запрос пользователя (drons, 2026-11-02).

SCOPE:
1. Возможность разбирать предмет на составные части. Для каждой
   части шанс возврата 20%, растёт с навыком крафта, которым
   собирается этот предмет (90% при навыке 100). Формула шанса и
   маппинг предмет→навык крафта — в анализе, ЗАФИКСИРОВАТЬ В SPEC
   (домашний стандарт для числовых механик).
2. Каждая разборка увеличивает навык крафта, который требуется для
   сборки такого предмета (опыт — по существующей механике
   крафт-навыков).
3. UI: где выполняется разборка (инвентарь/станция/постройка —
   решение в анализе; при необходимости новая станция по паттернам
   существующих построек).
4. Красные: возврат частей по формуле (детерминированный rng —
   паттерн репо); опыт начисляется в ВЕРНЫЙ навык (по рецепту
   сборки); контрпример — шанс не зависит от навыка.
5. SPEC: зафиксировать механику.

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт (формула, маппинг, UI);
* CHANGELOG — да (новый геймплей).

Ссылки: assets/craft/ (рецепты — маппинг предмет→навык), src
(инвентарь, крафт, опыт — поиск), spec/ (файл — в анализе).
