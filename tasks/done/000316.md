Магазины: продажа предметов вне ассортимента по типам +
выкуп из следующего обновления ассортимента

Источник: запрос пользователя (drons, 2026-11-05).

Цель: в магазинах должна быть возможность продать не только те товары,
которые там продаются, но и другие. Все предметы, ресурсы, свитки, книги
и прочее — разделить по типам и назначить им типы магазинов, где их можно
продать. Должна быть возможность выкупить товар из следующего обновления
ассортимента магазина.

Что сделать:
* Продажа по типу: предмет типа T продаётся в магазине вида K, если
  T ∈ sellable(K). Назначить типы предметов (ITEM_KINDS / kind предмета —
  по факту кода) типам магазинов (виды ассортимента — каталог построек
  ЕДИНЫЙ ИСТОЧНИК, 000060): таблица назначения — КОНТРАКТ (memory + SPEC).
* Цена продажи предмета вне ассортимента — по текущей формуле (по факту
  кода); если у предмета нет цены — базовая по типу (решение — в анализе,
  зафиксировать в memory).
* Выкуп следующего обновления: предметы НОВОГО обновления ассортимента
  (детерминированная генерация по циклу — по факту кода, refresh) можно
  покупать СЕЙЧАС: покупка списывает их из стока СЛЕДУЮЩЕГО цикла (товар
  «уходит в следующий список»), в текущем сток не фигурирует.
  Механика детерминированная, 0 новых RNG.
* Экран магазина: блок/пометка следующего обновления (по факту UI —
  решение в анализе, в memory).

Тесты (красные):
* Предмет типа T продаётся в магазине вида K ∈ назначения; в магазине
  вида вне назначения — не продаётся (кнопка неактивна, причина в логе).
* Выкуп следующего обновления: предмета нет в текущем стокe → покупка →
  предмет в инвентаре, сток следующего цикла −1, текущий сток цёл; после
  обновления — предмета в ассортименте нет (выкуплен).
* Sweep таблицы назначения: у КАЖДОГО типа предмета есть хотя бы один
  тип магазина (полнота покрытия каталога).
