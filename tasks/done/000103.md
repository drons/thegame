Тесты
* Детерминизм: якорь → тип/размер/запись (golden: фикс.
  координаты → фикс. город); повторный вызов tileAt — идентичен.
* Скан мира (сэмпл ±N от точки): все города — прямоугольники
  своего размера, ровно один вход, у входа есть свободный
  проходимый сосед, 0 пересечений footprint'ов (в т.ч. город ×
  постройка).
* ИНВАРИАНТ слотового hash: на тайлах, где города нет,
  `type % 13` совпадает с до-задачным значением (сэмпл).
* `не_сжимать`: 7x7-город на тесном месте — отсутствует, НЕ
  превращается в 3x3/1x1.
* Перформанс: тайлы ±200 (400x400 = 160k tileAt) в тайм-бюджете
  (зафиксировать бюджет тестом; fpCache учитывается).
* vm-песочница без каталога: фолбэк 3x3, города не
  генерируются (не краснеет при отсутствии 4 новых записей).
