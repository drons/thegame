Диалог NPC: растянуть на весь экран (особенно мобильные)

Цель
----
Диалог общения с NPC (оверлей с вкладками «диалог» / «торговля» /
«школа» / «квесты», задача 000010) растянуть на ВЕСЬ ЭКРАН: панель
занимает весь вьюпорт по ширине и высоте, на десктопе и на мобильных
устройствах. Контент на широких экранах остаётся читабельным
(колонка с max-width по центру).

Решения (зафиксированы для задачи)
----------------------------------
* Весь экран ВСЮДУ (десктоп + мобильные): панель — 100% вьюпорта по
  ширине и высоте; прежние 320 px-коробка и потолок 84vh — убираются.
  Тёмный «рамочный» фон оверлея вокруг панели не остаётся — панель
  и есть весь экран.
* Структура полноэкранной панели (flex-колонка, 100% высоты):
  * ЗАГОЛОВОК — «имя — роль» + кнопка «закрыть» — фиксированный
    сверху;
  * СТРОКА ВКЛАДОК — 4 вкладки — фиксированная под заголовком;
    обязана влезать при ширине 320 px (wrap или компактные подписи —
    на усмотрение реализации);
  * ТЕЛО (`.cp-items`) — `flex: 1`, `min-height: 0`,
    `overflow-y: auto` — всё среднее место, основной скролл;
  * ЛОГ (`.npc-log`) — фиксированная зона внизу (max-height
    ~25…35 vh — на усмотрение реализации), свой скролл,
    автораскрутка на последнюю строку (существующая,
    ui.js:897-898).
* Читабельность на широких экранах: колонка контента (вкладки,
  тело, лог) — max-width (~640…720 px) по центру; фон панели —
  весь экран.
* ДЕКЭПЛИНГ от боя: панель диалога получает СВОЙ класс
  (например `.npc-panel`) вместо `.combat-side` (правка
  `npcBuild()`, ui.js:847); CSS диалога — собственные правила
  в скоупе `.npc-overlay`/.npc-panel, НЕ зависящие от геометрии
  `.combat-side` (задача 000124). Класс `.combat-overlay` на оверлее
  NPC можно оставить (fixed/inset/z-20/фон подходят для всего
  экрана) — либо его тоже заменить; итог зафиксировать в памяти.
  Критерий: layout диалога не ломается при ЛЮБОМ порядке мержей
  000124/000125.
* Закрытие — как сейчас: Esc и кнопка «закрыть» (в заголовке —
  тапабельна на мобильном, доп. механизмы не нужны). Классы строк
  `.cp-*` (кнопки, строки, меты) — без изменений.
