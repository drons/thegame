Опыт за применение заклинаний: пропорционально мане и разности
уровней кастера и моба (формулу зафиксировать в SPEC)

Источник: запрос пользователя (drons, 2026-11-02).

SCOPE:
1. Применение заклинания даёт опыт в соответствующий навык (навык
   школы кастующего — решение в анализе).
2. Опыт пропорционален: (а) потраченной мане, (б) разности уровня
   применяющего и моба. ТОЧНАЯ ФОРМУЛА — в анализе, ЗАФИКСИРОВАТЬ В
   SPEC (включая поведение при отрицательной разности — пол/нуль —
   зафиксировать).
3. Красные: опыт по формуле — золотые значения; неудачный каст —
   опыт/нет (решение в анализе, зафиксировать).

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт (формула + связка навык-школа);
* CHANGELOG — да (геймплей).

Ссылки: spec/ (навыки/опыт — файл в анализе), src (применение
заклинания, начисление опыта — поиск).
