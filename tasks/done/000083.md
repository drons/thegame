UI: вкладка «найм» в диалоге таверны (Game.npcUI)

Родительская: 000065 («Найм» спутников: проработка и планирование).

Цель: интерактивная вкладка «найм» — найм/увольнение через диалог
(оболочка вкладки с читаемым списком кандидатов уже 000078).

Что сделать
-----------
* src/ui.js — Game.npcUI, вкладка «найм»:
  - список кандидатов (candidatesForTavern, 000079): имя, роль,
    навыки, цена контракта, жалованье/день;
  - кнопка «нанять»: вызов G.companions.hire (000079) с проверками
    (отряд < max, золото); при отказе — текст в логе диалога
    (npcLog); при успехе — обновление списка и лог;
  - блок «Отряд» — текущий состав (roster): имя, уровень, лояльность,
    жалованье/день + кнопка «уволить» (G.companions.dismiss);
  - open(...) расширяется: roster, deadMercs (вместе с существующими
    npc/character/book/tile/shop/onChange/day); onChange — хук на
    изменение состояния (сейв).
* src/main.js — toggleNpcDialog (~строка 467) и второй вызов
  npcUI.open (~строка 1151): передавать roster/deadMercs из game-state;
  onChange → saveNow (000079).
* src/npc.js — dialogOptions: прохождение действия «найм» уже 000078.
* index.html — тег companions.js (после npc.js, до combat.js —
  порядок: данные → логика отряда → бой).
* Сохранения: найм/увольнение — критические точки (saveNow, 000087).

Тесты (красные)
---------------
* tests/companions.test.js — расширение: кандидаты/увольнение
  (чистые функции, уже 000079);
* UI — вручную (паттерн 000010/000029): диалог тавернщика → вкладка
  «найм» → нанять/уволить, отказ в логе, обновление списка.

(000080/000081/000082) НЕ зависит — может мержиться параллельно с
ними. Конфликтует с 000051 (ui.js) — мержить с разнесением/ребейзом.
