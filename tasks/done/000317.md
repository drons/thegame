Город: улучшение постройки с магазином — расширение ассортимента

Источник: запрос пользователя (drons, 2026-11-05).

Цель: в городах при улучшении постройки, в которой есть магазин, —
расширение ассортимента предметов, которыми магазин торгует.

Что сделать:
* Улучшение постройки (город, механика по факту кода) → расширение
  ассортимента её магазина: ассортимент детерминированно расширяется с
  уровнем постройки (та же цепочка сидов, что у текущего детерм. ассортимента
  — по факту кода; 0 новых RNG вне существующей генерации).
* Расширение видно на экране магазина (новые строки после улучшения —
  по факту UI).
* Цены — не меняются улучшением вне существующих множителей (богатство и
  пр. — по факту кода).

Тесты (красные):
* Постройка уровня N с магазином → улучшение → ассортимент строго шире
  (⊇ при детерм. генерации) / расширяется по правилу (факт кода — в анализе).
* РЕГРЕСС: магазин без улучшения — ассортимент бит-в-бит как ДО изменения
  (детерминизм, цепочка сидов).
* Новая сессия (тот же мир) — тот же ассортимент (детерминизм).
