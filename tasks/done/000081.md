Эфир: постоянный союзник (src/efir.js)

Родительская: 000065 («Найм» спутников: проработка и планирование).

Цель: реализация решения по 000035 на фреймворке 000080: Эфир —
ПОСТОЯННЫЙ союзник (частный случай модели «союзный юнит» side 'ally').

Что сделать
-----------
* Новый чистый модуль src/efir.js:
  - createEfir() — «мини-персонаж»: level, xp, собственный НЕЗАВИСИМЫЙ
    пул навыков. Данные пула изолированы В САМОМ МОДУЛЕ (по умолчанию —
    скромный пул: огонь/исцеление): подзадачи 000035 будут уточнять пул,
    правя только этот файл — без касания combat.js/наёмников;
  - addEfirXp / levelUp — порог xpForNext (src/player.js), рост статов
    по уровню (паттерн makeMob, src/combat.js).
* Бой:
  - Эфир ВСЕГДА добавляется в allies при createCombat (вызовы в
    main.js / combat-ui.js — точка создания боя);
  - 100% боевого опыта — в его пул (независимая прокачка; не делится
    companion_xp_share — тот механизм для наёмников, 000082);
  - при HP 0 — покидает бой, НЕ умирает навсегда: в следующем бою
    возвращается со 100% HP;
  - жалованью и лояльности НЕ подлежит (вне механик 000079);
  - маркер морали действует: его урон — в companionMoraleBonus
    (000080, +5%/ур. Предводителя).
* Спрайт-плейсхолдер — текущий спрайт героя (по 000034: текущие
  ассеты Флогистона = Эфир; финальный дизайн спрайта — 000034).
* Файлы задач 000034/000035 (master/pending) — НЕ менять, только
  ссылаться; раздел SPEC об Эфире (дизайн, пул) добавляют они — здесь
  только механизм.

Тесты (красные)
---------------
* tests/efir.test.js (НОВЫЙ файл) — xp/уровень/пул: порог xpForNext,
  рост статов, 100% опыта в пул;
* tests/combat.test.js — Эфир всегда в allies при createCombat,
  после гибели возвращается в следующем бою со 100% HP, детерминизм
  хода Эфира (по сиде).
