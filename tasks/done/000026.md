Постройки на глобальной карте в зависимости от типа могут иметь разный размер (сейчас только 1x1 тайл)

Например, рунный камень - он маленикий - размер 1x1,
а замок короля орков - 5x4 тайла, но вход только с определённого тайла.

Также, надо продумать алгоритм генерации, который будет гарантировать отсутствие
пересечения построек между собой на глобальной карте.

Самый простой алгоритм - если большая постройка не помещается то на её место ставим поменьше.

Например: Замок короля орков (5x4) -> Усадьба продажного огра (3x3) -> Шалаш шамана (1x1)

Размеры постройки должны храниться в его описании в JSON
