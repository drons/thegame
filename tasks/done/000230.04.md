Родительская: 000230 (Исследование: система экипировки — части

Цель: ТЗ п.10 — некоторые предметы образуют наборы, дающие
дополнительные эффекты. Набор — поле `set` (id) в JSON предмета
(000230.01) + поле `set_bonus` в тех же файлах:
`{2: <эффект>, 3: <эффект>, 4: <эффект>}` — эффект в форме
affixes (000230.01/000230.03: skill-бонус/free_cast) или прямой
стат (armor/damage). Активация — число НАДЕТЫХ предметов
набора (каждый предмет — 1 предмет; кольцо — тоже 1). НОВОГО
каталога НЕТ (решение D5): данные наборов — в файлах предметов.

-----------

   ограничения, что affixes; additionalProperties: false).

   пороги set_bonus ⊆ {2,3,4}.
4. src/companions.js — set-бонусы наёмников (000230.06) — через
   тот же агрегат (общая функция).
5. UI-отображение активных бонусов — 000230.07 (тултип); здесь —
   ядро + данные.
