Сейв: отряд и Эфир (src/save.js, src/main.js)

Родительская: 000065 («Найм» спутников: проработка и планирование).

Цель: сохранить отряд и Эфира — неломким расширением сейва v1.

Что сделать
-----------
* Поля data сейва (v1, НЕМНОГО расширение — БЕЗ бампа CURRENT_VERSION,
  правило 000031: сейчас CURRENT_VERSION=1, MIGRATIONS пуст):
  - companions: [{npcId, level, xp, loyalty, hiredDay}];
  - efir: {level, xp, skills};
  - dead_mercs: [npcId].
* Старый сейв без этих полей → грузится с ПУСТОМ отрядом (версия
  остаётся 1, миграций НЕТ). Эфира в старых сейвах нет — появляется
  сразу уровнем 1 (ЗАФИКСИРОВАНО).
* Если какая-то реализация всё же ломает структуру сейва —
  ОБЯЗАТЕЛЕН CURRENT_VERSION=2 + миграция 1→2 + тест (000031).
* src/companions.js + src/efir.js — serializeRoster /
  deserializeRoster, serializeEfir / deserializeEfir (чистые функции).
* Валидация (паттерн «призрак», 000029):
  - npcId нет в каталоге (после будущих правок каталога) → запись
    отбрасывается тихо + console.warn;
  - битый раздел (не-массив/не-объект) → null → тихий сброс,
    игра НЕ падает.
* src/main.js:
  - collectSaveData (~строка 262) — добавить companions/efir/dead_mercs;
  - restoreFromSave (~строка 300) — восстановление roster/efir/dead
    (с валидацией «призрак»);
  - saveNow — критические точки: найм/увольнение, смена дня
    (жалованье/уход), гибель спутника в бою, уровень спутника
    (000087 собирает точки).
