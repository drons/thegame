Цель: финальная «сборка» — подвесить механики отряда (000079/000082/
000085) на точки игрового цикла в src/main.js.

Что сделать
-----------
* Смена дня (clock.onDay, src/main.js ~строка 425 — там уже
  restoreDay/респаун/saveNow):
  - G.companions.payWages / loyaltyTick (000079) ДО saveNow;
  - сообщения игроку (hudFlash, паттерн существующих):
    «Жалованье выплачено», «Не хватает денег на жалованье —
    лояльность падает», «X покинул отряд».
* Конец боя (result victory/defeat — обработчик в main.js):
  - опыт: игрок — 100% (без изменений), выжившие спутники — доля
    companion_xp_share, Эфир — 100% в свой пул (000082/000081);
  - гибель спутника → dead_mercs (окончательная; повторный найм
    НЕЛЬЗЯ) + saveNow.
* Повторный найм: после увольнения — можно, после гибели — нельзя
  (кандидаты — game-state roster + dead_mercs + каталог,
  candidatesForTavern 000079 — не только каталог).
* Сохранение в критических точках (паттерн saveNow): смена дня,
  конец боя, найм/увольнение (000083), гибель/уровень спутника
  (000085 собирает).
* Баланс: жалованье 3 спутников не должно съедать весь доход
  (квест ~50 золота) — проверить золотым сценарием; числа — из
  000078/раздела «Спутники» SPEC.md (при дисбалансе правятся ДАННЫЕ
  каталога, не формулы).
