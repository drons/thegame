Общие требования контентных волн (контракт §6 — повторяется в
каждой волне):
1. 25 JSON assets/spells/NNNNNN.json — СЛЕДУЮЩИЕ СВОБОДНЫЕ
   номера ПОСЛЕ перебазирования (после .07–.09: с 000093 при
   базе 386caf1; ПЕРЕНОМЕРАЦИИ НЕТ); `параметры` по D1;
   `вне_боя: true` у prayer/divine_protection/holy_light/
   miracle; `здания` — исцеление 19/21 (D12); `предметы` —
   ссылка на СВОЙ свиток; icon/icon_prompt — ОБЯЗАТЕЛЬНЫЕ.
   Цепочки — ≤3 (база = новое или старое (mend L1→light_heal
   L2→greater_heal L3 ст2 — существующая), степень = +1;
   остальное — база null). `мани` — калибровка по формулам
   существующих 17 (spells.js:427-472; L1 3–5, L2 6–8, L3
   10–15, L4 20) + баланс-пин 000119.
2. 25 SVG assets/spell-icons/<id>.svg — УНИКАЛЬНЫЕ, 24×24,
   #e8dcc0, тёмный фон; tests/svg.test.js sweep.
3. 25 JSON assets/items/NNNNNN.json — kind spell_scroll,
   effect {kind:'spell', spell:<id>}, tier = `уровень` спелла
   (D8), weight 0.2, value ~по уровню, desc; СЛЕДУЮЩИЕ СВОБОДНЫЕ
   номера ПОСЛЕ перебазирования (конкуренты 000230.01+.15/000232;
   ПЕРЕНОМЕРАЦИИ НЕТ).
4. Пул сундука: 25 свитков → assets/dungeons/000002.json
   `предметы` (D9: исцеление → склеп; ОБЩИЙ пул с тенью .09 —
   порядок мержа .09 до .10, id-формы не пересекаются, ребейз
   при конфликте); баланс пула — пин.
5. Зеркала: npm run gen:spells + npm run sync:items; дрейф-
   гейт — npm run sync:check (000054).
6. Тесты: tests/spells.test.js (репин «ровно N» +25), tests/
   items.test.js (tier = уровень — пин), tests/dungeon-*.
   test.js (пул 000002: +25 новых id — пин), svg sweep, vm-e2e
   (после .05).

Примечания к таблице (§7 контракта):
* «партия»-эффекты в бою: цель — ВСЕ ЖИВЫЕ СОЮЗНИКИ (паттерн
  mass-лечения) — blessing/divine_favor/guardian_blessing/
  swift_prayer/faith_shield/mass_heal/mass_holy_light;
* miracle — `действие: воскрешение` + `вне_боя: true`: цель —
  ВСЕ МЁРТВЫЕ в партии (кроме Эфира — он дух: 000230 п.5
  решений; spec/efir-spirit.md), 50% HP; механика внебоевого
  воскрешения — обработчик по id (switch
  из .02; боевое воскрешение resurrect/resurrectAlly — БЕЗ
  ИЗМЕНЕНИЙ);
* purify — снятие ВСЕХ дебафов с цели (статы юнита, .01);
* holy_ground — зона двойного действия: враги — урон_вниз,
  союзники — защищены (получаемый_урон −) — `параметры` по D1
  (зоны .01: эффект на врагов; союзники — расширение, детали —
  исполнитель);
* holy_light — радиус 5 (Chebyshev, 000135): туман раскрыт
  (000225) + зоны не триггерятся (механизм .03/.04) —
  обработчик по id.
