affixes экипировки: бонусы навыкам + заклинания без маны
(follow-up 000230 — эффекты экипировки в derived/бою; приоритет
P1; Зависимости: 000230.01, 000230.02; контентные волны
000230.08–000230.15 используют эту механику)

Родительская: 000230 (Исследование: система экипировки — части
тела, редкость, наборы).

Цель: ТЗ п.7 — предметы могут повышать (понижать) один или
несколько навыков, а также позволять использовать заклинания без
траты маны. «Для каждого навыка — несколько предметов, влияющих с
разной силой; более редкие — большая сила» (сила — данные
предмета, распределение — контентные волны, матрица —
memory/000230-equipment-research.md §6). Affixes (000230.01)
применяются в бою и на карте.

  (src/items.js:819-845). Навыков/маны от экипировки — 0.

  — 0 совпадений; мана — поле `мани` каталога spells

Что сделать
-----------
1. src/items.js — чистая функция equipmentAffixes(character):
   агрегат affixes ВСЕХ надетых предметов (все слоты, 000230.02)
   → `{skills: {<id>: <сумма amount>}, freeCast: Set(<spell id>)}`;
   пустая экипировка → `{skills: {}, freeCast: new Set()}`.
2. src/sheet.js / src/player.js — derived(): вклад affected-
   навыка (perLevel × уровень) масштабируется множителем
   (1 + Σ affix skills[id]) — ЕДИНАЯ точка (функция pct() или
   post-множитель; решение — memory §3 D4); отрицательный affix
   не уводит производную ниже её базового нуля (clamp).
3. src/combat.js / src/spells.js — free_cast: заклинание из
   freeCast кастуется с нулевой маной (действие «Заклинание»
   всё равно сгорает; логика книги рангов/степени — без
  изменений); у союзников — те же правила (000193).
4. Эфир — affixes НЕ применяются (экипировки нет — ТЗ п.4 «он
   дух»; guard в allyDataForEntry/makeAlly).
5. Отображение эффектов — НЕ в этой задаче (тултипы — 000230.07).
