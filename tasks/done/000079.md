Ядро отряда: найм, лояльность, жалованье (src/companions.js)

Родительская: 000065 («Найм» спутников: проработка и планирование).

Цель: новый ЧИСТЫЙ UMD-модуль src/companions.js (без DOM, без game-state,
паттерн src/npc.js) — все правила контракта: найм, отказ, увольнение,
жалованье, лояльность, уход.

Что сделать
-----------
* createRoster() — пустой отряд (массив записей спутника).
* canHire / hire:
  - размер отряда < max_companions (3);
  - золото ≥ цена контракта;
  - шанс отказа при найме: 30% − 2%×ур. Харизмы − 5%×ур. Артиста
    (min 0); при отказе — результат {refused: true} (для текста в
    логе диалога, 000083);
  - лояльность новичка: 50 + Харизма (1:1, cap 100); диапазон 0…100.
* canDismiss / dismiss: увольнение в диалоге, возврат денег нет,
  повторный найм после увольнения возможен.
* payWages / loyaltyTick (вызывается при смене дня, 000087):
  - подсчитать жалованье всего отряда;
  - золото ≥ жалованье → списать, каждому +2 лояльности;
  - не хватает золота → каждому −20 лояльности и проверка ухода:
    ≤20 — уйдёт верно, 21…40 — 50%, >40 — остаётся;
  - результат — список событий для сообщений игроку (000087).
* candidatesForTavern(roster, deadMercs): кандидаты — из каталога
  (000078): поле `найм`, building 44, не нанят сейчас, не мёртв.
* src/global-settings.js: max_companions (3) и параметры: старт
  лояльности 50, +2 за оплату, −20 за неоплату, пороги ухода 20/40,
  50%; отказ 30%, −2%/ур. Харизма, −5%/ур. Артист. (Долю XP
  companion_xp_share добавляет 000082.)
* Детерминизм (ВАЖНО, зафиксировано): в мире (main.js) «мирового»
  rng нет — НЕ вводить. Все новые случайные события (отказ найма,
  уход при неоплате) — seed = perlin.hash2(day, npcId), генератор
  perlin.mulberry32 (src/perlin.js) — воспроизводимость при том же
  (день, npcId), без глобального состояния.

Тесты (красные)
---------------
* tests/companions.test.js (НОВЫЙ файл) — все правила:
  - найм: лимит отряда, не хватает золота, отказ 0%/100% на границах
    Харизмы/Артиста (30% база), лояльность старта и cap 100;
  - жалованье: оплачено (+2), не оплачено (−20);
  - уход: ≤20 — уйдёт верно, 21…40 — 50% (детерминированно по сиде —
    фиксированный день/npcId дают фиксированный исход), >40 — остаётся;
  - увольнение → повторный найм возможен; погибший (deadMercs) —
    не в candidatesForTavern;
  - детерминизм: один seed → один результат; инварианты: золото ≥ 0,
    roster ≤ max_companions.
