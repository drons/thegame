Игровое время: дни, респауны, восстановление

Реализовать по SPEC.md (разделы «Мобы», «Навыки»):
* Игровой день: тикает при событиях (отдых, выход из подземелья, прохождение N шагов —
  уточнить и зафиксировать в SPEC.md).
* Респаун побеждённых стационарных групп через respawn_days.
* Восстановление здоровья/маны между днями (эффекты навыков «Медитация»,
  «Глубокий вдох», «Сердце природы»).
* Учёт «дней» для таймеров подземелий и «раз в день» эффектов (фонтан, круг).
* Тесты: смена дня, респаун групп, формулы восстановления.
