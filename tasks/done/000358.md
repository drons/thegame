# Список заклинаний: убрать из панели персонажа [I]; применимость по контексту в [B]

Убрать из панели персонажа [I] список заклинаний — полный список заклинаний
должен отображаться только в книге заклинаний, вызываемой по [B]. При этом на
глобальной карте и в подземельях можно применять только заклинания, возможные
в данный момент (боевые должны отображаться, но не применяться — не скрывать,
а помечать неактивными).

Анализ: текущая панель [I] и книга [B] — кто рендерит список; контексты
(город/бой/карта/подземелье) и правила применимости уже где-то живут (бой vs
мир) — унифицировать: единый источник «применимо сейчас», в мире боевые
видны-некликабельны. Тесты: absence в [I], presence+disabled-классы в [B] по
контекстам.

Связано: 000351 (кнопка [B]), 000348/000349/000350 (новые заклинания с
контекстными ограничениями применятся сюда же).
