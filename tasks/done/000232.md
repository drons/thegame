Рецепты крафта необходимо изучать, неизученные рецепты не должны отображаться в диалогах крафта.
В список предметов добавить особый вид предметов (свитков/чертежей) при использовании которых
персонаж изучит соответствующий вид крафта. В JSON файле этого предмета должна быть явная ссылка
на JSON с рецептом крафта.

Свитки можно покупать у соответствующих NPC, находить в сундуках, лутать с мобов.
