Цель: вес-гейт возврата предмета в ОБЩИЙ инвентарь героя
(unequip с наёмника / swap-возврат при equip — items.js
addItem → checkAdd → maxCarryWeight) должен использовать
maxCarryWeight САМОГО ГЕРОЯ (hero.primary + hero.secondary +
hero.equipment — полный derived), а не derived КОМПОЗИТА
(primary/secondary героя + equipment НАЁМНИКА). Семантика
владельца инвентаря (паттерн 000194: «предмет возвращается в
ОБЩИЙ инвентарь героя» — владелец = герой).
