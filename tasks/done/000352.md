# BUG: кнопки движения выделяются как текст при нажатии

При нажатии на некоторые кнопки движения происходит их выделение как текста —
это неудобно. Убрать выделение (user-select: none / preventDefault на
mousedown — выбрать средство по прецедентам мира) для всех экранных кнопок
движения, не сломав клики и тач.

Анализ: найти все кнопки движения (стрелки/WASD-экранные — см. UI-слой),
воспроизвести баг тестом уровня DOM/класса (RED), затем фикс.

Связано: 000351 (тот же блок кнопок), 000356/000357 (подсказки на кнопках).
