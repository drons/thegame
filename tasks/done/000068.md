Плавное движение персонажа в подземелье (mover из motion.js, как в мире — 000033)
(подзадача 000032, «движок не отличается»)

Родительская: 000032 (модернизация экрана подземелья).

Цель: персонаж в подземелье движется с глейдом prev→next, как в мире
(задача 000033, src/motion.js), а не прыжками между клетками —
«движок отображения для подземелья не должен отличаться от
глобальной карты» (000032).

Состояние сейчас
* Мир: ОДИН инстанс G.createMover({ x, y, intervalMs:
  MOVE_INTERVAL_MS }) (src/main.js ~206): глейд prev→next за
  интервал шага (stepProgress/easeInOut, src/motion.js), дробная
  точка renderPos(now) используется обоими слоями; teleport-снапы —
  спавн/сейв, побег/смерть из боя (main.js ~375, ~643).
* Подземелье: одна клетка на keydown (dungeonMove, src/main.js
  ~727): ds.x/ds.y меняется мгновенно, глейда нет; ds.prevX/ds.prevY
  — клетка перед шагом (побег/смерть из подземного боя: в onEnd
  startDungeonCombat — ds.x = ds.prevX, ~702).
* API мувера (createMover: position/step/teleport) уже достаточно —
  ядро src/motion.js менять НЕ нужно (покрыто tests/motion.test.js).
* Блуждающие группы (wanderStep, src/dungeon.js): на каждый шаг
  игрока группа сдвигается на клетку (детерминированно от номера
  шага и сида содержимого).
* Ввод в подземелье — keydown → onMove (dungeon-ui.js, 000043),
  НЕ RAF-цикл с Set нажатых клавиш (как мир): троттлинг/
  автоповтор — за ОС. Цикл НЕ унифицируется (см. ограничения).
