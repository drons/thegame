Расстановка перед боем: запоминание в общем сейве между боями +
порядок на вкладке Отряд [C]

Источник: запрос пользователя (drons, 2026-11-02).

SCOPE:
1. Результат расстановки перед боем запоминается в ОБЩЕМ сейве
   между боями: следующий бой стартует с последней расстановки.
2. Порядок расстановки показывается на вкладке Отряд [C].
3. Формат сейва: новое поле; старые сейвы (v1) — fallback на
   дефолтную расстановку, совместимость не ломать (миграция — в
   анализе).
4. Красные: расстановка → сейв → лоад → расстановка сохранена;
   порядок отображается на вкладке [C].

Зависимости: 000295 (кнопка/вкладка Отряд [C] — если панель ещё не
существует, эта задача после неё).

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт (поле сейва, миграция, порядок);
* CHANGELOG — да (геймплей).

Ссылки: src (сейв — поиск, формат v1), src/combat-ui.js (режим
расстановки), смежная 000295.
