Тултип предмета в инвентаре и снаряжении: крупная иконка при
наведении

Источник: запрос пользователя (drons, 2026-11-02).

SCOPE:
1. Наведение на предмет в инвентаре и в снаряжении — тултип содержит
   КРУПНУЮ иконку предмета (масштабирование из поля icon JSON
   предмета; размер «крупная» — решение в анализе, заметно больше
   миниатюр в списке).
2. Предметы без иконки (до 000302) — тултип без иконки (graceful) или
   с заглушкой — решение в анализе.
3. Красные: hover → в тултипе элемент-иконка с ожидаемым src (icon из
   JSON) и увеличенным размером.

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт (размер/поведение тултипа);
* CHANGELOG — да (UI).

Ссылки: src (инвентарь/снаряжение, тултип — поиск),
assets/items/*.json (поле icon).
