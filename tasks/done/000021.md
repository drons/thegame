На каждом тайле глобальной карты добавить отрисовку дополнительных небольших
графических объектов, расширяющих визуальное разнообразие.

Например на тайлах травы можно отрисовать дополнительные травинки другого цвета, небольшой куст иди цветок,
на тайлах гор можно отрисовать дополнительные камни или снег.

Как и для остальных игровых элементов для этих графических элементов надо разработать
JSON схему и проверять её в тестах.

Описание элементов хранить в assets/visuals, а их спрайты в  assets/sprites/visuals
