Исследовательская задача: Расширить количество предметов, которые можно одевать на персонажей:

Вот, возможно, неполный список предметов:
- Голова: шапки, шлемы, короны, обручи, платки
- Уши: серьги, гвозди
- Шея: ожерелья, амулеты, цепочки
- Тело: броня (уже есть), рубашки, кафтаны, робы, сутаны, халаты
- Предплечья: защита рук, различные налокотники
- Правая рука: оружие (уже есть), магические посохи, косы, вилы, инструмент крафта
- Левая рука: различные щиты, магические артефакты
- Ладони: перчатки
- Пальцы левой и правой руки: до четырёх колец или перстней на каждой руке
- Ноги: Штаны
- Ступни: Сапоги, ботинки, сандалии

1) Для каждой части тела разработать несколько предметов
2) Для каждого предмета создать уникальную иконку
3) В инвентаре и одетом снаряжении отображать иконки предметов
4) Добавить возможность надевать снаряжение на союзных NPC (на Эфира нельзя, он дух)
5) Для каждого предмета разработать рецепты крафта
6) Предметы (и их рецепты крафта) должны иметь разные уровни редкости выпадания из сундука или лута с моба: 
  - обычный (50%) 
  - редкий (30%)
  - эпический (15%)
  - легендарный (4.9%)
  - невозможный(0.1%)
7) Предметы могут повышать(понижать) один или несколько навыков, позволять использовать заклинания без траты маны.
   Надо постараться, чтобы для каждого навыка было несколько предметов, которые на него влияют с различной силой. 
   Более редкие предметы должны иметь большую "силу".
8) Иконки предметов разного уровня редкости должны в подсвечиваться в инвентаре рамками:
  - обычный - светло серый 
  - редкий - зелёный
  - эпический - синий
  - легендарный - фиолетовый
  - невозможный - жёлто-оранжевый
9) Количество предметов различной редкости для каждой части тела:
  - обычный - 10
  - редкий - 7
  - эпический - 5
  - легендарный - 2 
  - невозможный - 1
10) Некоторые предметы могут образовывать наборы, которые дают дополнительные эффекты
