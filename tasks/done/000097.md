Тултипы навыков и предметов в панели персонажа
(подзадача 000051, приоритет P1 — после 000096)

Родительская: 000051 (редизайн панели персонажа: два столбца,
широкие вкладки, весь экран, тултипы, не наезжать на кнопку
полноэкранного режима)
Зависимость: 000096 (двухколоночная вкладочная панель) — тултипы
вешаются на строки вкладок «Персонаж»/«Снаряжение»/«Инвентарь».

Цель: у КАЖДОГО навыка (основного и вторичного) и у КАЖДОГО
предмета (снаряжение, быстрые слоты, инвентарь) — тултип с
подробным описанием: элемент .cp-tip, показ ЧИСТЫМ CSS по hover.
Данные — УЖЕ ЕСТЬ в каталогах (assets/skills, assets/items): менять
ассеты и схемы НЕ нужно.

Состояние сейчас (сверено с кодом master)
* Навыки (src/skills-data.js, Game.SkillsData; source of truth —
  assets/skills/*.json + schema): основные { id, name, desc,
  combat («в бою»), world («в мире») }; вторичные { id, name,
  primary, requires, effect {stat, perLevel}, effectType, desc,
  names[6] }.
* Предметы (src/items-data.js, G.ITEMS; source of truth —
  assets/items/*.json + schema): у ВСЕХ предметов по схеме обязателен
  desc; есть weight, value, stats (у оружия/брони), effect (у
  расходников).
* В панели (src/ui.js) описаний НЕТ: строка навыка — .cp-name/
  .cp-level/.cp-req (краткое требование), строка предмета —
  .cp-itemname + .cp-itemmeta (краткая мета).
* CSS панели — index.html <style> (hunk владеет 000096 —
  правки только СВОИМИ классами .cp-tip*, не трогать чужие).
