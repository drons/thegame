(подзадача 000064, приоритет P4 — параллельно с 000094/000095,

Родительская: 000064 (эффекты «особых» построек: проработка и
планирование)

Цель: эффект «разведка» смотровой башни (id 46, подтип слота 12 с
000073): окрестности помечаются «исследованными» в сейве + HUD-
индикатор. МИНИКАРТА — ОТСРОЧЕНА: в игре миникарты нет вообще;
данные `explored` — заготовка для будущей задачи (новая задача
создаётся при потребности, НЕ резервировать номера).

Состояние сейчас (сверено с кодом master)
* Миникарты НЕТ (ничего, к чему подключаться).
* HUD — `hudUpdate` (src/main.js:949) — место для индикатора.
* Раздел сейва `explored` — имя зафиксировано в 000072 (паттерн
  разделов: свой try/catch, абсолютные данные).

Ключевые проектные решения (зафиксировано в SPEC «Эффекты
построек»)
* «Взглянуть» — тайлы радиуса R=20 (CHEBYSHEV) вокруг башни
  помечаются исследованными; НЕЗАВИСИМО ОТ ПРОХОДИМОСТИ (это
  данные разведки, не проходимость — непроходимые тайлы тоже
  помечаются).
* Повтор — ИДЕМПОТЕНТНО (объединение множеств, дубликатов нет).
* ОГРАНИЧЕНИЕ РОСТА СЕЙВА (ловушка localStorage): формат —
  КОМПАКТНЫЙ: на башню строка 'x,y;x,y;…' в разделе
  `explored[bашня 'x,y']`; радиус фиксирован R=20 → максимум
  41×41 = 1681 ключей на башню (закладка в тесте); сжатие
  (delta/RLE) — при необходимости в задаче, но не раньше
  (простота + тест ser/de roundtrip).
* Лимит «раз в день» — НЕТ (взгляд бесплатен и идемпотентен;
  флага в каталоге нет).
