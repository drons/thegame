Инвентарь, предметы и торговля

* Инвентарь: слоты, вес (ограничение «Крепкая спина»), использование предметов.
* Предметы: оружие (меч, лук, тяжёлое), броня, зелья, еда, книги навыков, реагенты.
* Описание типов предметов должно храниться в каталоге assets/items
* Каждый тип предмета хранится в отдельном JSON файле (000001.json, 000002.json), 
  структура файла должна быть закреплена в виде JSON-schema
* «Быстрые предметы» — закреплённые слоты для действий в бою.
* Торговля в магазинах (типы из SPEC.md): цены зависят от богатства постройки
  и навыка «Торговец»; покупка/продажа.
* Тесты: добавление/удаление предметов, лимит веса, применение зелий,
  расчёт цен с учётом навыков.
