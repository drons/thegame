   L1 3–5, L2 6–8, L3 10–15, L4 20) + баланс-пин 000119.

Примечания к таблице (§7 контракта):
* beast_friend — состояние companions-подобного сопровождения
  (обработчик по id; детали — исполнитель волны .12): зверь
  сопровождает героя 3 дня, раскрывает туман/мобов в радиусе 3,
  без боя (не боевой союзник); состояние —
  hero.outOfCombatEffects (паттерн .02) + рендер зверя рядом
  с героем (минимальный, существующие спрайты мобов);
* «партия»-эффекты в бою: цель — все живые союзники (паттерн
  mass-лечения) — heart_of_forest/nature_haste/vitality;
* vitality (max HP +10%) — временное изменение maxHP (3 хода),
  без изменения HP сверх текущих;
* treant (+root) — танк-союзник, действие root по врагу при
  атаке (статы моба из assets/mobs — ближайший по силе,
  уровень призыва = `уровень` спелла, .01);
* path_of_vines — плотная местность (лес и т.п.) не замедляет
  движение героя на 1 день (обработчик по id, детали —
  исполнитель; рендер не меняется).
