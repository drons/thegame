Архитектура: цена предмета — в JSON предмета, а не в JSON NPC

Источник: запрос пользователя (drons, 2026-11-05).

Цель (архитектурный баг): цена предметов должна храниться в JSON предмета,
а не в JSON NPC, который ими торгует.

Что сделать:
* Базовая цена (base price) — поле JSON ПРЕДМЕТА (assets/items/*.json +
  зеркало src/items-data.js через sync-скрипт).
* NPC/магазин применяет к базовой цене множители (богатство,
  buyPriceMult/sellPriceMult, активный персонаж — 000299.03, по факту
  кода): итоговая цена = f(базовая, множители) — ФОРМУЛЫ не менять,
  меняется источник базовой цены.
* Миграция данных: текущие цены в данных NPC (поле «торговля» / assets/npc
  — по факту диска) → базовая цена предмета; множители остаются у NPC.
  Если цена NPC отклоняется от единой базовой — отклонение выразить
  множителем NPC (решение — в анализе, зафиксировать в memory).
* schema.json: новое поле предмета — schema + валидация в том же коммите.
* Сейв: если цены НЕ в сейве (derived) — миграции нет; если в сейве —
  санация absent → дефолт (паттерн 000298), форма v1 не меняется.

Тесты (красные):
* Предмет с базовой ценой: цена в магазине NPC = базовая × множители
  (точная арифметика по формуле факта кода).
* Магазин постройки: та же базовая цена (не зависит от NPC).
* Sweep миграции: у КАЖДОГО предмета, которым торгует хоть один NPC,
  базовая цена есть в JSON предмета.
* РЕГРЕСС: существующие тесты цен (000299.03, shop-prices) — зелёные
  или ре-пин по факту диска (ре-пины — в том же коммите).
