Школы у NPC: убрать кнопку «Вернуть» (эксплойт прокачки чужого
навыка)

Источник: баг-репорт пользователя (drons, 2026-11-02).
Суть эксплойта: изучив и сбросив (вернув) один навык, можно качать
совершенно другой навык, несвязанный с текущим NPC.

SCOPE:
1. Убрать кнопку «Вернуть» (возврат изученного навыка) из школ у NPC.
2. Судьба механики возврата: возврат отменяется полностью (очки
   теряются) — решение в анализе, зафиксировать в memory/SPEC при
   изменении контракта.
3. Красные: кнопки в UI школы нет; старый сценарий (изучить → вернуть
   → выкупить чужой навык) невозможен.

Зависимости: 000296, 000298 (та же школа-UI) — при параллельном
запуске держать в одной lane.

Ограничения:
* полный прогон ТОЛЬКО в worktree (memory/test-runner-worktrees.md),
  ps-проверка до пуска;
* memory-контракт;
* CHANGELOG — да (геймплей).
