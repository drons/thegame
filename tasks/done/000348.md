# Заклинание школы тени «Декаданс»: экстренный выход из подземелья

Добавить заклинание школы **тени** «Декаданс», применимое только в пещерах и
подземельях. При применении Флогистон телепортируется ко входу в текущее
подземелье и спускается на `5 + Интеллект/10` уровней ниже (глубина входа
уменьшается/увеличивается по смыслу «сбежать глубже» — уточнить на анализе по
механике спусков, см. 000333 навигация; если «ниже» от входа невозможно —
зафиксировать решение в результате).

Оформление: новый assets/spells/NNNNNN.json по схеме каталога (slug-именование
— ref-шейп spells), школа/тип из существующих школ тени; стоимость/уровень —
по коридорам каталога; тесты применения в подземелье (dungeon-nav-000333
породы), запрет применения вне подземелий (RED-регрессия).

Связано: tasks/done/000333.md (навигация подземелий), 000253+ (школа тени —
уточнить по данным), spec/spells.md.
