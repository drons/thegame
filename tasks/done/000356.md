# Подсказки клавиш на экранных кнопках [I] [C] [E] [B]

На экранных кнопках инвентаря [I], панели группы [C], входа в постройку/сбора
лута [E] и открытия книги магии [B] добавить в правом нижнем углу подсказку о
назначенной клавише — строки `[I]`, `[C]`, `[E]`, `[B]` соответственно.

Стиль/размер подсказки — единый для всех четырёх (мелкий угол, не перекрывает
иконку). Не ломать хоткеи и хитбоксы. Тесты наличия/текста подсказок.

Связано: 000351 (размер/блок тех же кнопок — согласовать вёрстку),
000357 (тот же стиль для боевых кнопок).
