## result (отчёт о выполнении)

Сделано:
* Каталог `assets/skills`: 37 файлов — 6 основных навыков (`000001`–`000006`) и 31
  вторичный (`000007`–`000037`, по группам основного навыка) + `schema.json`.
* Структура файла закреплена в `assets/skills/schema.json`; схема использует только
  ключи минимального валидатора (задача 000015): `oneOf` из двух вариантов —
  основной навык `{ id, type, name, desc, combat, world }` и вторичный
  `{ id, type, name, primary, requires (опционально), effect { stat, perLevel },
  effectType, desc, names[6] }`. `requires` опущен в JSON, если требований нет.
* JSON-файлы — source of truth; униформный модуль `src/skills-data.js`
  (в браузере — `Game.SkillsData`, в node — `require()`) генерируется из каталога
  скриптом `scripts/sync-skills-data.js` (фолбэк для file://).
* `src/player.js` переведён на чтение каталога из `src/skills-data.js`;
  наружный API не менялся, `tests/player.test.js` прошёл без правок.
* `index.html`: добавлен `<script src="src/skills-data.js">` до `src/player.js`.
* `SPEC.md`: новый раздел «Архитектура хранения навыков» в конце файла.
* Тесты `tests/skills.test.js` (12): нумерация файлов каталога, полнота/известность
  полей, консистентность каталог ↔ skills-data.js ↔ player.js (навыки в обе стороны,
  эффекты и требования совпадают), ссылочная целостность дерева навыков,
  только допустимые ключи в `schema.json`, структура схемы, ранги 1..100 без разрывов.
* `npm test`: 90 тестов, все зелёные (старые + новые).
