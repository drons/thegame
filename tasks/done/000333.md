Заклинания навигации подземелья: путь к выходу на верхний этаж /
входу на нижний этаж (A*), разные цвета линий, свитки

Источник: запрос пользователя (drons, 2026-11-05).

Цель: добавить специальные заклинания, для применения в
пещерах/подземельях:
* показать путь до выхода на верхний этаж;
* показать путь до входа на нижний этаж.
При активации заклинания алгоритмом A* происходит поиск пути от текущего
положения игрока до входа/выхода (в зависимости от заклинания) и
отображается полупрозрачная линия. Для входа и выхода эти линии должны
быть разного цвета. Для этих заклинаний должны быть созданы и свитки.

Что сделать:
* 2 новых заклинания (JSON assets/spells; школа — решение в анализе,
  в memory; иконки — паттерн 000302).
* Механика: A* от позиции игрока до выхода (верхний этаж) / входа
  (нижний этаж) (карта этажа — по факту кода); результат —
  полупрозрачная линия на карте (рендер — по факту кода в анализе:
  overlay/подсветка тайлов, контракт в memory).
* Цвета РАЗНЫЕ: выход на верхний — один цвет, вход на нижний — другой
  (контракт в memory).
* Пути нет (выход закрыт/не найден) — заклинание не применяется
  (лог-строка — по факту кода в анализе).
* Свитки на оба заклинания (assets/items, вид spell_scroll — контракт
  ссылки по 000326).
* Детерминизм: A* — детерминированный алгоритм, 0 новых RNG; стоимость
  каста — по механике заклинаний (по факту кода).

Тесты (красные):
* Фикстюрное подземелье: путь к выходу существует → заклинание → линия
  (набор клеток = ровно A*-путь, фикстюра даёт точный ответ), цвет =
  «верхний этаж».
* То же для входа на нижний этаж, цвет = «нижний этаж» (цвета различны
  — ассерт).
* Пути нет → линии нет, лог-строка.
* Свитки: JSON валидны, «effect/spell» → ссылки на заклинания (паттерн
  000326).
