# HACKING.md — сборка, тестирование, архитектура

Задача 000160. Технические подробности проекта «Приключения Флогистона»,
вынесенные из README.md: как запустить, как тестировать, как устроен код.

## Запуск

- Двойной клик по `index.html` — игра открывается прямо из файла (file://),
  сервер не нужен. Данные каталогов продублированы в JS-модулях, поэтому
  `fetch()` локальных JSON не требуется.
- Для разработки удобнее поднимать локальный сервер: `python3 -m http.server`
  и открыть `http://localhost:8000/`.

## Тесты и утилиты

- `npm test` — запуск всех тестов (`node --test`, каталог `tests/`).
- `npm run gen:map` — генерация превью карты в `assets/map.png`
  (`scripts/generate-map-png.js`).

## Структура проекта

- `index.html` — входная точка (подключает модули `src/*.js` до `src/main.js`).
- `src/` — игровой код: униформные JS-модули (IIFE; в браузере складываются в
  `globalThis.Game`, в node — `module.exports`), чистое ядро без DOM.
- `assets/` — ресурсы: `logo.svg`, `map.png` (глобальная затравка карты).
- `tests/` — тесты на node (`node --test`).
- `tasks/` — задачи: `pending` (к выполнению), `done` (выполненные).
- `memory/` — заметки/контекст проекта.
- `SPEC.md` — спецификация игры; `CLAUDE.md` — правила работы.
