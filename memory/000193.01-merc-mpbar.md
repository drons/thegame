```js
    } else if (barUnit.kind === 'merc') {
      // 000193.01: мана наёмника — С ЮНИТА (снапшоты makeAlly
      // 000193/000193.01: u.mp/u.maxMP = 5+Int+Wis; тратят касты из

      mpVal = (typeof barUnit.mp === 'number'
        && Number.isFinite(barUnit.mp)) ? barUnit.mp : 0;
      mpMax = (typeof barUnit.maxMP === 'number'
        && Number.isFinite(barUnit.maxMP)) ? barUnit.maxMP : 0;
```

Контракт:
- `barUnit.kind === 'merc'` — ЯВНАЯ ветка (условие названо ТЗ

  (L1575-1576) и `kind === 'efir'` (L1577-1590, snap + legacy-
  fallback) — **БИТ-В-БИТ**, не трогаются.
- Финальный `else` (неизвестный kind) — историческая деградация D5
  (`MP —`/0%): новый ally-kind НЕ получает ману полосой
  спекулятивно (ТЗ-минимум).
- Деградация «без maxMP»: `mpMax = 0` → каскад без изменений:
  `mpFrac = mpMax > 0 ? clamp : 0` (L1594) → fill 0%, текст
  `mpMax > 0 ? 'MP x/y' : 'MP —'` (L1604-1605) → `MP —`. mpFrac-
  клайм и DOM-строки НЕ ТРОГАЮТСЯ.
- Гарды `typeof/Number.isFinite` — зеркало efir-ветки (L1585-1586):
  white-box `delete u.maxMP`, мусор/NaN — без краха и без
  `'MP undefined/9'`.
- Обновление — ТОЛЬКО в render() (контракт 000038/000047); rAF-цикл
  подхватывает; слушателей нет.
