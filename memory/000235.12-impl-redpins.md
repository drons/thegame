* Кадры подземелья ведёт rAF-цикл dungeon-ui.js (tick), а НЕ

  после X» невозможен абсолютно → ДЕЛЬТА: wBefore — до setDay(4),
  дельта 2 кадров = 0 (spутник ушёл).
* Фикстура (15,16) рабочая: mob-цикл dungeon-ui НЕ катит
  пер-моб viewport (off-screen мобы тоже drawImage'ятся);
  дальний волк рисуется при mask=2 с бонусом (cheb 7 ≤ 8).

### W-13 (spellbook-oc-e2e.test.js — wild_growth/restoreDay) — 2 правки

  вылетает запись СИНХРОННО — ассерт «запись жива после
  setDay(2)» неисполним. Перенесён ДО setDay(2) (day — аргумент
  предиката, реальный день пока 1).
* `G.derived(g.state.hero)` — TypeError (state-миллер героя
  БЕЗ `secondary`; main.js:4098) → `G.derived(saveHero(h))` в
  обоих местах (NO-OP + D+2) — тестовый собственный коммент
  «derived ЧЕРЕЗ СЕЙВ (live-JSON героя, CP-11)» так и
  предписывал.

## 3. Механические факты реализации (источник правды — код)
* maxHP-кап — ЕДИНАЯ точка unitMaxHPCap (combat.js): healAlly
  (игрок: при бафе maxHP — прямой min(cap, hp+amount), иначе
  P.heal; союзник — прямой кап), гейт «здоровье полное»
  (canDoAction heal), resurrectAlly (half buffed-кэпа).
  Stateless: мутации maxHP нет; на expires — кап = база.
  Low-HP-чек (40%, «Вдох Эфира») — БАЗОВЫЙ maxHP
  (P.derived, без бафа).
* beast_friend: визион — dungeon-ui.js `Math.max(radiusFor
  (mult), floorR) + Math.floor(bonusR)` (opts.visionRadiusBonus);
  radius читается из КАТАЛОГА getSpell('beast_friend')
  .параметры.radius (JSON — правка радиуса = e2e-ресимуляция).
  Спутник: мир (main.js drawSprites) + подземелье (dungeon-ui.js,
  proj(pos.x+1.5, pos.y+0.5), zoom*0.9, wolf_move_1.svg) —
  СТАТИЧНЫЙ спрайт, боевого союзника НЕТ (combat.js не
  трогается, кроме heal-капа).
* wild_growth: onDay — restoreDay ×1.1 ДО expire; OR с
  camp/prayer, без стекания.
* path_of_vines: состояние пишется (1 день), эффект — no-op;
  предикат isHeroPathOfVines СУЩЕСТВУЕТ — потребитель —
  tasks/pending/000235.12.01.md.
* sync:check (W-08, spells.test.js тест 80) — ЗАВИСИТ ОТ
  КОММИТА: sync-all.js --check отказывает при незакоммиченных
  изменениях в src/ (exit 1). Зеленеет после коммита.
