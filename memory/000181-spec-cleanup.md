## Финальный текст 3 правимых буллетов (дословно, переносы как в файле)

«Спутники → Бой», буллет 1 (фиксы 2 + 5):

```
  * Спутник — отдельный союзный юнит на мини-карте боя; на своём ходу
    спутником управляет игрок: движение — 1 клетка (наёмник; Эфир —
    3 клетки и свои пулы, см. «Дух Эфира → Бой»); удар (дальность
    по роли) ИЛИ лечение — 1 действие за ход (наёмник); support-наёмник
    лечит самого раненого из [игрок, союзники] (у Эфира — нет, см. «Дух
    Эфира → Бой»); блок/предметы/побег — только игрок.
```

«Дух Эфира → Бой», буллет управления (фиксы 1 + 3; первая часть сохранена):

```
  * На своём ходу Эфиром управляет игрок: движение — 3 клетки,
    «Касание духа» (J), сильнейшее известное урон-заклинание (K); на
    его ходу (v1) игрок не применяет лечение/щит Эфира — лечение в
    бою — авто-«Вдох Эфира» и спасение в окне смерти. «Сильнейшее» —
    заклинание с максимальным «мани» каталога, тай-брейк — id;
    дальность 4.
```

«Дух Эфира → Бой», буллет «Вдох Эфира» (фикс 4; только «на его ходу» →
«в НАЧАЛЕ его хода (до ввода)»):

```
  * Фирменное действие «Вдох Эфира» (вне шести школ — дух, а не
    маг): 1 раз за бой, авто-триггер в НАЧАЛЕ его хода (до ввода)
    (игрок ≤ 40% HP и маны Эфира ≥ 20): расходует 20 маны и весь ход;
    лечение ВСЕМ союзным round(10 + 0.8 * Мудрость) + ослабление ВСЕМ
    врагам (их урон ×0.8 на 2 хода).
```
