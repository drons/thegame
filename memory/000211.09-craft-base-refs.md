## 7. Решения Проектирования (решение — почему)

1. Формат — по контракту 000211 §2 как есть; пин-таблица
   id→файл ЯВНАЯ (10/10 перепроверено, id цели === прежнему
   значению) — «номер файла = id» неверно для craft (строковые
   id, биекция через каталог) — byte-идентичность зеркала
   гарантирована конструктивно.
2. Миграция — ХИРУРГИЧЕСКАЯ строковая замена по якорю
   `  "база": "<id>",` (строка 5, 10/10; ключ «база» — ровно 1
   раз в каждом файле — grep 10×1), НЕ round-trip — файлы
   неканонические (inline-объекты) — round-trip переформатирует
