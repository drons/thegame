# 000010: NPC — диалоги, квесты, обучение в школах навыков

Статус: выполнено (коммит — после проверки главным циклом).
Данные: assets/npc/000001.json … 000010.json + schema.json;
зеркало — src/npc-data.js (генерируется scripts/sync-npc-data.js).

## Решения

* **Авторитетная связь «постройка → NPC» — поле `постройки` NPC**
  (массив id зданий 1…50 из каталога buildings). У зданий поле
  `типичный_npc` — только описательная проза, связью не является
  (тест-инвариант — tests/npc-data.test.js).
* **Цель `kill_group` отслеживается по ТИПУ группы, а не по месту**:
  `notifyGroupDefeated(npcs, book, groupType)` в src/npc.js сравнивает
  `цель.группа` с типом победившей группы. main.js зовёт его при победе
  — и в наземном бою (t.mobGroup), и в подземелье (groupType).
* **Журнал квестов — сессионный**: `createQuestBook()` создаётся один раз
  в main.js (`questBook`, структура `{ active: {}, done: [] }`) и
  передаётся в `npcUI.open({..., book})`. Не более
  `MAX_ACTIVE_QUESTS = 5` активных квестов (src/npc.js). Состояния:
  «принят (active) → в работе → готов к сдаче (ready) → выполнен (done)».
* **Диалог — клавиша [E]** (KeyE) на тайле постройки с NPC; повторное
  нажатие закрывает. Не работает во время боя/подземелья.
* **Схема цели квеста — `oneOf` по типу** (assets/npc/schema.json):
  `kill_group` требует `группа` (0…6), `bring_item` требует `предмет`.
  До исправления цель без поля по типу проходила валидацию, но была
  невыполнима (softlock): `notifyGroupDefeated` сравнивает
  `goal.группа !== groupType` (undefined никогда не равен числу), а
  bring_item шёл в `hasItem(character, undefined, N)` — всегда false.
  Зафиксировано тестом «схема: цель квеста требует поле по типу».
* `refreshBringItems` зовётся в ui.js при открытии вкладки квестов —
  цель bring_item становится ready без отдельного события.
* Школы: кросс-инвариант «тренирует» здания = `обучение.навыки` NPC
  (по названию навыка) — tests/npc-data.test.js, пар не меньше 5.

## Тесты

tests/npc-data.test.js: каталог (нумерация, зеркало, схема, правила,
ссылочная целостность, школы, покрытие задачи) + тест oneOf-цели.
tests/npc.test.js: механика — доступность опций диалога по Харизме/
навыкам, торговля (цены и сток), прокачка/перенос в школе, квесты
(принять, kill_group по типу, bring_item, награда ровно один раз,
цепочки, лимит активных).
