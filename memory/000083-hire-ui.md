## 1. Новые параметры Game.npcUI.open (000083)

```
open({ npc, character, book, tile, shop, onChange, day,
       roster,      // НОВОЕ 000083: ОПЦИОНАЛЬНАЯ живая ссылка на
                    //   const-roster main.js (массив записей
                    //   {npcId, level, xp, loyalty, hiredDay})
       deadMercs }) // НОВОЕ 000083: ОПЦИОНАЛЬНАЯ живая ссылка на
                    //   const deadMercs main.js (массив [npcId])
```

* Снимок в open: `roster = Array.isArray(o.roster) ? o.roster : null;`
  (аналогично deadMercs) — null ≡ [] в рендере; существующие
  параметры (npc/character/book/tile/shop/onChange/day) — не
  меняются, вызовы без roster/deadMercs работают (null-safety,
  регрессия ui-panel/npc-hire).
* Сброс в npcClose: `roster = null; deadMercs = null;`
* Значение roster/deadMercs для вкладки «найм»:
  - interactive (кнопки + блок «Отряд») — при НАЛИЧИИ G.companions
    (typeof-guard на candidatesForTavern/canHire/hire/dismiss, в
    момент вызова) И Array.isArray(roster);
  - иначе — ровно рендер 000078 (читаемый список, без кнопок и без
    «Отряда»); console.error — только при отсутствии G.companions.
* day — снимок с open (кламп: целое ≥1 или null); найм в диалоге
  использует `Number.isInteger(day) && day >= 1 ? day : 1`.
* ЖИВОСТЬ: npcUI мутирует roster через G.companions.hire/dismiss
  (push/splice) — тот же массив, что в main.js и deps-бандле
  buildingActions (контракт 000128 §2.2).

## 2. Точки saveNow (найм/увольнение — критические, 000087/000085)

* onChange — уже = deps.saveNow (проводка openNpcDialog, 000029/
  000128): новый код 000083 НИКАКОЙ новой проводки сейва не
  добавляет — ветки найма/увольнения зовут `if (onChange)
  onChange();` ровно при успешных событиях:
  - найм ok → npcLog + onChange() + renderTab + playerUI.render;
  - найм refused / ok:false → npcLog + renderTab (БЕЗ onChange —
    состояние не менялось);
  - увольнение ok → npcLog + onChange() + renderTab (БЕЗ
    playerUI.render — возврата денег нет);
  - увольнение ok:false → npcLog + renderTab.
* Структура data сейва НЕ меняется (companions/dead_mercs — 000085).
