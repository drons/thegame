## 4. Ключевые решения (контракт исполнителей)

D1. Схема spells — расширение БЕЗ ломающего: `действие` enum +=
  7 значений → 13: баф, дебаф, призыв, создание, невидимость,
  телепорт, внебой. Старые 6 значений и формулы castSpell для них —
  БЕЗ ИЗМЕНЕНИЙ (chill остаётся ослабление с зашитыми
  {mult:0.75,turns:3}). Новое опциональное поле `параметры`
  (object, additionalProperties:false, ограниченная карта ключей:
  stat, value, turns, summon, object, radius, days, mode) и
  опциональное `вне_боя` (bool, default false). Атомарная тройка
  (schema/KEYS/spells-data.js) — в одном коммите (000149 §10.3-4).
  `параметры` по действиям:
  * баф {stat, value, turns} — stat ∈ урон|броня|ход|реген|
    вампиризм|отражение|попадание|получаемый_урон|иммунитет_контроля;
    цель — себя или союзника (выбор в бою как у лечение/защита).
  * дебаф {stat, value, turns} — stat ∈ урон_вниз|броня_вниз|
    попадание_вниз|получаемый_урон_вверх|dot|ход_вниз; цель — враг.
  * призыв {summon: id из assets/mobs, turns: 4} — временный боевой
    союзник по данным моба (паттерн makeAlly 000193); уровень
    призыва = `уровень` заклинания; баланс-пин (000119).
  * создание {object: стена|зона, turns, radius} — стена:
    непроходимый ряд тайлов на поле боя (паттерн препятствий
    000050), 5 ходов; зона: область radius (1..3) с эффектом
    (stat дебафа) 3 хода.
  * невидимость {days: 1..3} — внебоевое состояние (D6).
  * телепорт {mode: метка_установить|метка_вернуться|город} — D7.
  * внебой {days: 1..3, radius?: 1..5, эффект: id из
    ограниченного перечня} — мировая утилита (свет/лагерь/аура/
    сопровождающий и т.д., §7); обработчик по id заклинания в
    src/spells.js (switch).

## 8. Формула лута свитков (контракт .05 + SPEC .06)

Направление (уточнено станцией, a2 Q1): моб Сильнее игрока →
риск = награда. D = maxLvl(группа мобов) − playerLevel.

* Мобы (rollVictoryLoot, НОВЫЙ ролл ПОСЛЕ существующих, отдельный
  солёный rng-поток — goldens бит-в-бит):
  * P_scroll = 0.05 + 0.02·max(0, D), кап 0.25 (кап достигается
    при D ≥ 10).
  * Тир: при D > 0: T = min(4, 1 + floor(D/3)); при D ≤ 0:
    T = 1 + (rng < 0.5 ? 1 : 0) (T ∈ {1,2}, 50/50) — ветка
    D ≤ 0 ПЕРЕХВАТИТЕЛЕН, базовая формула к ней не применяется
    (уточнение вериф. станции: исходная запись выглядела как
    противоречие).
  * Школа: равномерная из 6 (из солёного потока).
  * Выбор свитка: из свитков школы+тира (нет → ближайший тир вниз,
    затем вверх).
