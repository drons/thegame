### 3.3 Клик-выбор (canvas click, build())
* Порядок веток ОПРЕДЕЛЁН: живой юнит (существующее, без правок) →

* Мёртвый герой: `c.targetId = null` (D4) + render().
* c.targetId — runtime-поле: не в форме сейва (save.js — проверено,
  targetId отсутствует), сброс «свежая цель на входе игрока»

* Все ядра-читатели самовалидируют (проверено по коду):
  * canDoAction 'attack'/'fire' (L1290/L1316): `!t || !t.alive ||
    t.fled || t.side==='ally'` → «нет цели» → кнопка disabled

### 3.5 Книга (БЕЗ ИЗМЕНЕНИЙ — контракты 000149 в силе)
* Строка 'resurrect' возникает сама (p.spells → entriesFor): имя
  «Воскрешение», meta «Мана 15 · Заклинание (Мудрость)», icon
  assets/spell-icons/resurrect.svg, desc — из каталога.
* rowChk: `canCastSpell(c, 'resurrect', {targetId: c.targetId})`:
  * targetId = мёртвый союзник → ok;
  * targetId = моб/живой → «нет цели» (строка -off, title);
  * targetId = null → авто (мёртвый игрок приоритетно, иначе первый
    мёртвый союзник) → ok, если есть любой мёртвый, иначе «нет цели»;
  * мана <15 → «не хватает маны (15)»; пул 0 → «действий
    «Заклинание» (Мудрость) больше нет».
* Выбор цели (клик клетки) → c.targetId меняется → chk меняется →
  bookSig меняется → строка ПЕРЕРОИСУЕТСЯ (off→ok) автоматически;
  клик по строке → castRow → castSpell(c, 'resurrect', c.targetId) →
  успех: c._fx {action:'cast'} + книга закрывается; отказ:
  logRejection + книга открыта. ТЗ «мёртвых нет — действие
  недоступно (reason)» — ЗАКРЫТО этим зеркалом.
