## 1. Механика (src/combat.js)

* Игрок (mobAttack): существующий гейт
  `u.traits.debuff && c._rng() < 0.25 / d.magicResistMult` (ролл НЕ
  тронут); ВНУТРИ гейта — ЧЕРЕД: чистое чтение слота бафа
  `c.ps.buff.stat === 'иммунитет_контроля' && c.ps.buff.turns > 0`
  → log «Иммунитет к контролю: контроль сорван.» (bind НЕ ставится),
  иначе `c.ps.bind = { turns: 1 }` + log «Скован: следующий ход
  пропущен.» ГЕЙТ ИММУНИТЕТА — ДО МУТАЦИИ (чистое чтение).
* Союзник (mobAttackAlly): НОВЫЙ канал
  `dealt > 0 && u.traits.debuff && c._rng() < 0.25` — мультипликатор
  1 (у союзника нет производных статов); иммунитет — по t.buff
  (тот же стат/turns > 0) → log «{name}: иммунитет к контролю —
  контроль сорван.», иначе `t.bind = { turns: 1 }` + log «{name}:
  следующий ход пропущен.»
* advanceQueue: игрок — тик `c.ps.bind.turns -= 1` + skip ДО
  fresh-target (log «Скован — пропускает действие.»); союзник — тик
  + skip ДО efirBreath (сгоревший ход «Вдох Эфира» не триггерит;
  log «{name} скован — пропускает действие.»).
* Состояние: `c.ps.bind = null` в инициализации player-state;
  `u.bind` — у юнита союзника. bind НЕ стакается (новый bind
  перезаписывает turns на 1).
* Сейв: bind В ФОРМАТ СЕЙВА НЕ ВНЕСЁН (src/save.js 0-diff) — контроль
  транзиентен (полный сьют зелёный — контракт сейва цёл).
