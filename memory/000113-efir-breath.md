### D3. healAlly(c, unit, amount) — новый internal (блок после
dealDamageToAlly, ~638)

```js
// Лечение союзника (000113, «Вдох Эфира»; export —
// combatInternals): игрок — P.heal (кап — derived maxHP; У
// ИГРОКА НЕТ поля maxHP — только hp), юнит — прямой кап maxHP;
// ФАКТИЧЕСКОЕ восстановление = hp после − hp до (000037).
// Возвращает факт (0 — цель на максе).
function healAlly(c, unit, amount) {
  const before = unit.hp;
  if (unit === c.player) {
    P.heal(unit, amount);
  } else {
    unit.hp = Math.min(unit.maxHP, unit.hp + amount);
  }
  return unit.hp - before;
}
```

* СИГНАТУРА ПО ТЗ. ТЗ-список «ВСЕМ союзным (side 'ally': игрок +
  наёмники + сам Эфир)» — игрок НЕ член c.units (это c.player) →
  дискриминация `unit === c.player` ОБЯЗАТЕЛЬНА (без неё
  `unit.maxHP` = undefined для игрока). Наблюдательный эффект
  идентичен ТЗ: все союзные получатели лечены.
* P.heal (player.js:511) — `c.hp = Math.min(derived(c).maxHP,
  c.hp + amount); return c.hp` — кап встроен; возвращает НОВЫЙ hp
  (НЕ факт) → факт считаем DIFF'ом до/после.
* Цели = c.player + livingAllies(c) (side 'ally', alive, !fled —
  Эфир side 'ally' 000080 ВКЛЮЧЁН: self-heal).
