## 2. Контракты и границы

* **Контракт ссылки (000211 §2, ЗАФИКСИРОВАН)**: ссылка = строка-путь к
  целевому JSON относительно корня репозитория; id целевого файла ===
  прежнее ссылочное значение (buildings — число, items — строка);
  якорные паттерны `^assets/buildings/\d{6}\.json$` /
  `^assets/items/\d{6}\.json$` (общий:
  `^assets/(items|skills|spells|mobs|mob_groups|buildings|craft|
  dungeons|npc)/\d{6}\.json$`).
* **Резолюция — ТОЛЬКО в sync (build time)**: в рантайме (file://) fetch
  невозможен (memory/000053); data-модули без require (vm-песочницы);
  новых src/-модулей и ленивых ссылок (rootRef) НЕТ — UMD-зеркало уже
  существует (§0 D3).
* **Зеркало — id-форма, побайтово**: потребители (src/npc.js
  npcsForBuilding :37-46, createNpcShop :260-273 (stock[p.предмет]),
  findQuest :338-342, refreshBringItems :417/:439, turnInQuest :449-458;
  src/main.js :1800 `npcs: NPCS`, :2736-2748; src/ui.js :573/:1171;
  src/companions.js; src/party.js) читают ТОЛЬКО зеркало; сейв v1 — id
  предметов (memory/000031).
