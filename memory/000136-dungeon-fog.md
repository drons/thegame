## Формула радиуса

```
R = Math.ceil(VISION_BASE_RADIUS × caveVisionMult − 1e-9)
VISION_BASE_RADIUS = 5
caveVisionMult = 1 + 0.1 × уровень «Кошачьего глаза»   (player.js:242,
                                                        skills-data.js:155-163)
```
* Метрика — ЧЕБЫШЁВ (квадрат): клетка (x, y) видна из центра (cx, cy)
  ⟺ `Math.max(Math.abs(x − cx), Math.abs(y − cy)) ≤ R`. cx, cy =
  playerPos(s, now) — точка спрапта/камеры игрока (000068), дробные при
  глейде.
* Пины: mult 1.0→5, 1.1→6, 1.2→6, 1.3→7, 1.5→8, 1.8→9, 2.0→10
  (уровень навыка 10 — потолок по каталогу → mult 2.0 → R 10).
* Граница — целое сравнение cheb ≤ R (клетка на расстоянии ровно R
  видна). Ceil + ε: уровень 1 УЖЕ даёт +1 клетку (5→6); 5×1.8 =
  9.0000000000000002 — без ε ceil ошибся бы на 10.
* live-чтение: ОДИН раз на кадр (паттерн liveLevelDeltaMax dungeon.js:170-177);
  источник — opts.visionMult (функция из main.js → G.derived(hero) →
  caveVisionMult; guard → 1).

## Семантика explored-визита

* `Set<'x,y'>` — модульное состояние dungeon-ui.js (визит), ключ 'x,y' —
  конвенция проекта.
* Заполнение: union видимых клеток — КАЖДЫЙ кадр в render все клетки маски
  со значением 2 (видимые) добавляются в explored; по всей сетке w·h
  (не только вьюпорт — при большом зуме видимое вне вьюпорта тоже
  исследуется).
* Сброс: start() — new Set() («вход в подземелье» = новый визит, ТЗ);
  close() — null (гигиена, утечек между подземельями нет).
* explored ⊇ visible всегда (после обновления кадра).
* Игровой смысл: «побывал рядом — помню контуры»: возвращение на
  исследованную клетку — затемнение, а не слепота (кейс ТЗ).

## Затемнение (как рисуется)

* Слой: один проход ОДИН раз на кадр ПОСЛЕ всех контурных слоёв
  (пол/стены/маркеры/сундуки/мобы) и ПЕРЕД игроком:
  `g2.fillStyle = FOG_DIM_FILL ('rgba(10, 13, 18, 0.65)')`; для каждой
  клетки viewport-диапазона с mask == 1 (исследованная, вне радиуса) —
  `fillRect(p.x, p.y, zoom, zoom)` (p = proj(x, y) — проекция клетки).
* Полупрозрачный (альфа 0.65) — контенты исследованных клеток (пол
  #182029, маркеры, сундуки, мобы) ПРОСВЕЧИВАЮТ под слоем: «затемнены,
  не скрыты» (ТЗ). Hue — тот же, что фон #0a0d12: клетка гаснет к фону,
  но остаётся читаемой; неисследованная клетка — чистый фон (фон
  оверлея), различимо.
* Игрок — ПОСЛЕ затемнения: никогда не затемняется (его клетка всегда
  mask == 2). stateEl/logEl не затемняются (это DOM, не canvas).
* города (kind === 'city') — прохода затемнения НЕТ (туман не
  применяется).
