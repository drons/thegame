## 1. Каноническое имя шкалы
**глубина** — целое ≥ 1, первый этаж = 1, код `d.depth`
(поле состояния подземелья, src/dungeon.js). Цель ссылки 000157
(«редкость растёт с глубиной (000153)» — world-map L26;
tasks/done/000157.md L7). В SPEC закрепляется в world-map-буллете
(первичное определение) + скобкой в dungeons-storage «размер» (D5).

## 3. Сейв (контракт 000153.01 + факт 000157.03 — документируется в
## H3/H4 dungeons-storage.md)
* Топ-раздел **`dungeonMemory`** (map): ключ **`'x,y:depth'`**
  (`dungeonMemoryKey(worldKey, depth)` = worldKey+':'+depth;
  `DUNGEON_MEMORY_KEY_RE = /^-?\d+,-?\d+:\d+$/`, :354-357) →
  **`{ contents, lastVisitDay, pos? }`**; по ОДНОЙ записи на
  посещённый этаж-вход; МНОГО записей (по этажам).
* Пишется **ВСЕГДА** (даже `{}`); **неломко**: версия сейва НЕ
  повышается (save.js CURRENT_VERSION=1, MIGRATIONS={}, зафиксировано
  tests/save.test.js :256), миграций нет; старый сейв без раздела →
  restore пустой, fail-open (0 warn).
* **ОБРЕЗКА** записей старше `dungeon_memory_days` (default 3,
  global-settings.js:68, live-read main.js:95-101) — и в serialize
  (:947-978), и в restore (:993-1006).
* **`contents`** = валидированная глубокая копия
  (`validateDungeonContents`, dungeon.js :835-904, зафиксировано
  построчно): **`{ seed, createdAtXp, step, mobs, chests }`** +
  **опциональный `deposits`** (000157.03: `{id,x,y,item,amount,
  gathered}[]`, присутствие/отсутствие сохраняется как есть, лишних
  ключей не создавать; собранность `gathered` — **ПРАВО как opened**).
  `stairsDown` НЕ в contents (поле формы — пересчитывается при каждом
  входе).
* **`pos`** — позиция героя только в **in-flight**-сейве
  (restore: re-anchor из pos, fallback — клетка-вход); activeRec
  merge «активный поверх» (activeDungeonMemoryRec main.js:1436-1450).
* **`dungeonState` не персистируется**: после перезагрузки герой в
  мире; повторный вход — world-step'ом; explored-маска НЕ
  персистируется (туман перестраивается).
* КОНСИСТЕНТНОСТЬ с H2 «## Залежи» (dungeons-storage :74): deposits —
  опциональный ключ, gathered — ПРАВО как opened, версия не
  повышается — в ОБЕИХ секциях файла (H3 + H4).
