## 1. Суть (одной строкой)

На спрайт-слое глобальной карты (2D-канвас #sprites, `drawSprites` в
src/main.js) — тонкая красная пунктирная полупрозрачная окружность
радиуса агрессии вокруг групп мобов, которые реально заагрят на
игрока на дистанции; нейтральные/трусливые группы (бой только на
своём тайле) окружности НЕ получают. НОВОГО МОДУЛЯ/ТЕГА/CSS/АССЕТОВ НЕТ.

## 2. Где берётся радиус агрессии (единый источник, без дублей)

* ИГРОВОЕ ОПРЕДЕЛЕНИЕ (зафиксировано решением D1): «радиус агрессии
  группы» = **дистанция триггера боя** (Чебышёв ≤ radius), т.е. поле
  `triggers` + `radius` ЕДИНСТВЕННОГО существующего источника —
  `G.groupZoneInfo(groupType)` (src/combat.js L424, экспорт L3087,
  задача 000135; контракт `memory/000135-mob-group-zones.md` §1;
  oracle — tests/mob-zones.test.js Z1). Чистая функция, без rng:
  по aggro ПЕРВОГО МОБА (mobs[0]) рецепта — aggressive/territorial →
  `{ radius: 2, triggers: true }` (5×5-зона); neutral/timid →
  `{ radius: 1, triggers: false }` (3×3, бой ТОЛЬКО на тайле группы);
  нет данных → `{ radius: 1, triggers: false }`.
* Таблица по группам (Z1): 0 orc_camp, 1 orc_raid, 4 spider_nest,
  5 elemental_circle, 6 abyss_spirit → triggers=true, r2; 2
  skeleton_den, 3 wolf_pack → triggers=false, r1.
* ЧТО ЭТО В ИГРЕ: findZoneCombat (combat.js L445-481) по dist>0
  рассматривает ТОЛЬКО группы с `info.triggers` (строка
  `if (!info.triggers) continue;`); neutral/timid дерутся только при
  dist 0 (игрок на тайле группы) — их радиус агрессии = 0. SPEC L162:
  «персонаж, зашедший в зону, провоцирует бой (для агрессивных) или
  может пройти мимо (для нейтральных)» — прямое подтверждение D1.
* СЛЕДСТВИЕ (D1): окружность — ТОЛЬКО для triggers=true групп;
  радиус в пикселях = `info.radius * zoom` (radius — в тайлах, zoom —
  px/тайл; при старте 2·80 = 160 px). 5×5-зона — квадрат, круг —
  упрощённая визуализация (ТЗ требует именно окружность). Радиус
  ЧИТАЕТСЯ НА КАДР из groupZoneInfo — НЕ хардкодится: будущая смена
  правил зон (серия «Застращивание», 000135 §5) авто-обновит
  отрисовку. Отклонён вариант a1-domain §4.9 «круги ВСЕМ группам,
  нейтральным r1» — красное кольцо вокруг пассивного моба ввело бы
  игрока в заблуждение (см. D1).

## 4. Реализация отрисовки (форма кода, main.js drawSprites)

### 4.1 Константы (топ-level, после `const PLAYER_COLOR` L52)

```js
// Задача 000172: окружность радиуса агрессии на глобальной карте —
// тонкая красная пунктирная полупрозрачная (4 прилагательных ТЗ):
// alpha < 1 — не заслоняет карту; lineWidth 1 экр. px — «тонкая»
// при любом зуме; dash — в пикселях экрана (не зависит от зума).
// Радиус НЕ здесь: из G.groupZoneInfo (combat.js, 000135) на кадр.
const AGGRO_CIRCLE_STYLE = 'rgba(255, 64, 56, 0.4)';
const AGGRO_CIRCLE_DASH = [6, 6];
```

### 4.2 Проход (в drawSprites, вставить ПОСЛЕ L2431, ПЕРЕД L2433)

```js
// Проход 2.5 (задача 000172): окружность радиуса агрессии — тонкая
// красная пунктирная полупрозрачная (AGGRO_CIRCLE_*, lineWidth 1).
// Радиус агрессии = дистанция триггера боя (000135, ЕДИНЫЙ источник
// G.groupZoneInfo): triggers=true (aggressive/territorial) — круг
// радиуса info.radius*zoom по центру тайла группы; neutral/timid
// бой ведут ТОЛЬКО на своём тайле (SPEC L162 «может пройти мимо») —
// радиус агрессии 0, окружности нет. Видимость — тот же фильтр, что
// Проход 3: поверженная сегодня группа (defeatedAt) не аггрит.
// Z-порядок (000042): тайлы/декорации < постройки < агро-окружности
// < мобы < Флогистон — под спрайтами, не заслоняет карту и героя.
// Тихий гард: экспорта нет (регрессия порядка загрузки) — прохода
// нет (load-time console.error уже есть, L1783-1788 — не дублируем).
if (typeof G.groupZoneInfo === 'function') {
  for (const t of frameTiles) {
    if (!t.hasMobGroup) continue;
    if (G.groupVisible && !G.groupVisible(defeatedAt, t.x, t.y)) continue;
    const info = G.groupZoneInfo(t.mobGroup);
    if (!info || !info.triggers || !(info.radius > 0)) continue;
    const c = toPt(t.x + 0.5, t.y + 0.5);
    s2.beginPath();
    s2.setLineDash(AGGRO_CIRCLE_DASH);
    s2.strokeStyle = AGGRO_CIRCLE_STYLE;
    s2.lineWidth = 1;
    s2.arc(c.x, c.y, info.radius * zoom, 0, Math.PI * 2);
    s2.stroke();
    s2.setLineDash([]); // гигиена: не оставлять dash-состояние в s2
  }
}
```

* Центр = центр тайла группы `toPt(t.x + 0.5, t.y + 0.5)` — та же
  единая проекция `G.worldToScreen` (000061), что и все слои;
  r = `info.radius * zoom`.
* Последовательность на круг: beginPath → setLineDash([6,6]) →
  strokeStyle → lineWidth → arc(0..2π) → stroke → setLineDash([]).
  БЕЗ fill (заливка заслоняла бы тайлы), БЕЗ анимации (мигание/
  бегущий пунктир ТЗ не просит — «не больше»).
* Стиль/пунктир выставляются ПЕРЕКРУГОВЫМ образом (внутри цикла)
  и сбрасываются после каждого stroke — состояние s2 никогда не
  «висит»; прочие проходы — только drawImage, stroke-state их не
  трогает, но гигиена явная (M3 пинит оба края: [6,6] до, [] после).
* `defeatedAt`, `frameTiles`, `zoom`, `cam`, `toPt` — уже в скоупе
  drawSprites (используются Проходом 3); новых локальных состояний
  НЕТ (владение состоянием: НОВОГО НЕТ — проход чистый).
