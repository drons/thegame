## 3. Контракты и границы

**Формула (dungeon-ui.js render, не-city)**:
`R = radiusFor(mult) + floorR + Math.floor(bonusR)`
- `radiusFor(mult) = max(1, ceil(5·mult − 1e-9))`, guards → 5
  (инвариант, FOG-A1);
- `floorR` — safe-call `ctx.visionRadiusFloor`: ТОЛЬКО функция
  (try/catch → 0; не-функция/'мусор'/throw → 0 ТИХО, без
  console.error — песочницы пинят errors.length === 0), затем
  guards: не-число/не-finite/<0 → 0, `Math.floor`;
- `bonusR` — safe-call `ctx.visionRadiusBonus`: функция ИЛИ число,
  тот же guards/floor (инвариант, 000235.12);
- без эффекта (floorR 0, bonusR 0): `R = radiusFor(mult)` —
  побайтово то же, что `max(radiusFor, 0)` (radiusFor ≥ 1 > 0) →
  FOG-B/E1/E2/W-11c/W-11 e2e — зелёные без правок;
- explored-union (mask == 2, dungeon-ui.js:681-685)
  автоматически подхватит увеличенный R (000136 D4); explored —
  in-memory, НЕ сейв;
- город (s.kind === 'city') — mask === null, тумана нет
  (инвариант; W-11b-город).

**Проводка (main.js startLocationUI, без изменений)**:
