- **Школы/дома NPC/история — следующие волны**: (а) школы конфликтуют с 000134
  (одни доли_типов-файлы 51-54 + один golden-пин tests/cities.test.js —
  параллельный ре-пин = гарантированный конфликт); (а2) дома NPC 26-30 + 5 NPC

  конфликт с 000134 по файлам НЕТ); (б) история (родной город,
  имена, главный квест, интро) — большая программа с open design-решениями
  (a2 #4/#5) и зависимостью «квест ← родной город»; (в) «Удача»/Акробатика/
