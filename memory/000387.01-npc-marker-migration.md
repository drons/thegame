# 000387.01 — миграция npc-счётчиков каталога на живые предикаты

Держатели счётчика `assets/npc` (маркер «ровно 50 файлов 000001..000050 подряд»
в 30 файлах + вне-маркерные npc-refs / buildings-rename-000318.06 T8 /
building-effects A60) переведены на ls-предикат: количество и непрерывность
префикса вычисляются с диска, число 50 осталось только как монотонный пол.
Волны 000320.30+ добавляют NPC своим файлом и синком — чужие тесты-держатели
при этом не двигаются.

Актуально на 832a5d81 (50 файлов каталога на этой базе; пол ≥50 = наследие базы).

## 1. Канон имени и тела (по нему пишут свои T1 волны .30+)

Имя теста-держателя:

    T1: каталог — ls-предикат: 000001..N подряд (N = счётчик диска); зеркало NPCS ≡ каталогу с <id-волны>

Тело (три зуба, порядок фиксирован):

    assert.ok(files.length >= 50, 'в каталоге NPC не менее 50 файлов (<цепочка-история>), факт: ' + files.length);
    // цикл непрерывности: files[i] === String(i + 1).padStart(6, '0') + '.json'
    assert.equal(NPCS.length, files.length, 'зеркало src/npc-data.js ≡ каталогу (sync не прогнан?), факт: ' + NPCS.length);

* Пол `>= 50` — односторонний рэтчет наследия базы: легитимный рост его не
  двигает НИКОГДА, массовое удаление файлов — красит. Поднимать пол волнам
  не нужно и не следует (в этом смысл миграции).
* Цикл непрерывности жил в файлах и до миграции — он и есть живой зуб
  префикса `000001..N`; при разрыве (пропуск среднего номера) краснеет
  «нумерация подряд без пропусков: индекс K».
* `NPCS.length === files.length` — зеркало ≡ каталогу: волна, забывшая
  `sync-npc-data.js`, красит ровно этот зуб. Это НЕ реестровая биекция
  (зеркало генерируется из каталога — контракт memory/000387 §3); зуба
  «реестр ≡ весь каталог» не заводили и заводить нельзя.
* Цепочка-история в сообщении пола и позиционные хвосты (`NPCS[41].id` и
  пр.) — декор и стабильные индексы: при appending-росте не сдвигаются,
  руками не ре-пинятся.

## 3. Что осталось литералом осознанно

* forbid-цепь T5/T9 (запрет-лист 103 подстрок, prev=99) — формула 000372.
* Ростер/оверлей Арены 5 (T7/T8 .25–.29) — население дома, не каталог.
* Счётчик построек (52/17) в `tests/npc-refs.test.js` — referrer-пин ссылок
  npc→здания: каждая волна со своей ссылкой двигает его СВОИМ изменением;
  бриф миграции прямо вывел его из скоупа.
* Торгово-числовой хвост T6 scroll-trade (234/20/202, окно slice(38,41)) —
  счётчики торговли, читаются живым свипом каталога.
* Пол ≥50 (тридцать раз) — устаревает только при удалении файлов ниже 50.
