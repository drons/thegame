## 1. Мёртвый код в move-ветке handleCode (src/combat-ui.js)

В else-разделе ветки `r.kind === 'move'` (вход при `placeGate()===false`)
остаточный блок 000260 «принятый шаг → c = ctx.combat; второй c.move»
(`if (mv && mv.ok) { if (closePlacementWindow()) { ... } }`) недостижим:
else входится при `!placeOpen || !ctx || ctx.combat.result`, и
`closePlacementWindow()` возвращает false во ВСЕХ трёх случаях (гарды
`!placeOpen || !ctx` и `c0.result`). Код синхронный — race невозможен.
Удалён: `if (mv && mv.ok) { if (closePlacementWindow()) { c = ctx.combat;
logRejection(c, c.move(r.dx, r.dy)); } } else { logRejection(c, mv); }` →
`if (!mv || !mv.ok) logRejection(c, mv);`. Поведенчески нейтрально:
сьют combat-ui зелёный ДО (225/225) и ПОСЛЕ (227/227 = 225 + 2 новых
пина) с тем же набором результатов, 0 новых fail.
