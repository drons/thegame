# 000021: декорации тайлов глобальной карты

Статус: выполнено и закоммичено (тесты 192 → 200 pass).

## Решения

* **Данные.** 13 элементов в `assets/visuals/000001..000013.json`,
  схема — `assets/visuals/schema.json` (стиль buildings/schema.json:
  additionalProperties=false, required, pattern). Поля: `id`,
  `название`, `террейны` (массив из имён TERRAIN_NAMES), `спрайт`
  (путь в assets/sprites/visuals/), `частота` (0..1 — вероятность
  попадания на тайл), `размер` (0.05..0.5 — доля ширины тайла).
  Покрытие: трава (6 элементов), лес (4), холмы (3), горы (3),
  песок (2), болото (1), вода (1, кувшинка); глубокая вода — без
  декораций (по дизайну, зафиксировано тестом).
* **Спрайты.** `assets/sprites/visuals/*.svg` — 13 файлов, 64x64
  viewBox, плоский стиль как у тайлов/построек, мягкие тени
  `rgba(0,0,0,~0.2)`.
* **JS-фолбэк** `VISUALS` в src/sprites.js (как BUILDINGS в
  buildings.js): игра открывается по file://, fetch() JSON не
  работает. Тест требует deepEqual JSON ↔ JS-каталог.
* **`tileVisuals(tx, ty, terrain)`** (src/sprites.js, чистая функция) —
  выбор и размещение декораций тайла. Детерминизм — seed из координат
  через `hash2` (перевыдан из src/map.js, perlin.js):
  * появление: roll = (hash2(tx, ty, VISUALS_SEED + id*0x9e3779b9) >>> 8) / 2^24
    < частота;
  * позиция: (hash2(…, seed+1), hash2(…, seed+2)) → доли [0.08; 0.92]
    (не вылезает за границы тайла);
  * потолок `MAX_VISUALS_PER_TILE = 3` (в порядке каталога по id).
* Декорации — чисто визуальный слой: tileAt/генерация мира не зависят
  от каталога и загрузки (тест «критерий: декорации не влияют на
  генерацию мира»). Пути добавлены в `allAssetPaths()` — загрузчик
  подтягивает их вместе с остальными ассетами.
* `VISUALS_SEED = 0x51a11ce5` — отдельный сид (не сида построек/мобов),
  чтобы декорации не коррелировали с фичами.

## Тесты

tests/sprites.test.js: +8 — каталог (13, id, без дублей id/спрайтов);
покрытие террейнов; JSON-файлы = JS-каталог + мини-валидация каждого
объекта по schema.json (required/лишние поля/типы/enum/pattern/
min-max — подмножество, достаточное для схемы, без ajv); существование
спрайт-файлов в assets/sprites/visuals; чистота tileVisuals + валидность
элементов + потолок + нет дублей на тайле; частота id=1 близка к 0.35
(±0.05 при N=4000); «не штамп» (≥50 разных наборов из 200 тайлов);
критерий независимости от мира.

## Ограничения

* Рендер декораций (drawImage в слое спрайтов) — в src/main.js,
  который вне файлов этой цепочки: API `Game.tileVisuals(tx, ty,
  terrain)` готов, остаётся в main.js для каждого тайла пройтись по
  результату и нарисовать `sprite` в (sx + x*zoom, sy + y*zoom)
  размером size*zoom (центр — точка x,y).
* Мини-валидатор в тесте покрывает подмножество JSON-Schema (то, что
  есть в schema.json); при усложнении схемы его нужно расширять.
