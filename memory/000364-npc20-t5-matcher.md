## ПРАВИЛО ДЛЯ ЦЕПОЧКИ .21+ (страховка)

forbid-лист T5 нового NPC-файла = **дисковый список непосредственного предшественника
ЦЕЛИКОМ** (python-диффом, не по памяти и не по формуле в шапке предшественника) **+ свои
резервы**. Литерал `'храме солнца'` (тема Милы, 000003.json hint_elder) обязан жить во всех
списках, начиная с .11. Орфография матчера — `'храме солнца'` (предложный падеж);
`'храм солнц'` — мёртвый пре-000360 литерал, в новые списки не вносится.

Приёмка соседей (для .20 на финальном диске): `.20` = 63 = 59 (.19) + 4 резерва Шафрана
(«до площади раньше колокола», «понюхай сначала», «каменная соль», «в самом конце»);
«в предшественнике, нет в потомке» = пустое множество; обратная разница = ровно свои резервы.

Сверка python-разбором (тот же ре-экспрессинг, что использовался в 000360/000364):

    python3 -I - <<'EOF'
    import re
    def arr(path):
        src = open(path, encoding='utf-8').read()
        m = re.search(r"for \(const w of \[(.*?)\]\) \{", src, re.S)
        return re.findall(r"'([^']*)'", m.group(1))
    a, b = arr('tests/npc-000320.19.test.js'), arr('tests/npc-000320.20.test.js')
    print(len(a), len(b), set(a) - set(b), sorted(set(b) - set(a)))
    EOF
