## Корневая причина (верифицирована симуляцией, не гипотеза)

`*/`-мина внутри CSS-комментария (index.html L457, добавлен коммитом 000199):

    /* Полоска MP (задача 000199): …
       базовые правила .combat-hpbar*/.combat-state/.combat-actions   ← МИНА
       переиспользуют подземелье/NPC/города (000124) — не трогаются. */

css-syntax-1: комментарий = `/*` … ПЕРВОЕ `*/`. Глоб `.combat-hpbar*` + слэш-
разделитель дают последовательность `*/` → комментарий ЗАКРЫВАЕТСЯ ДОСРОЧНО в
L457. Хвост «комментария» (L457–458, вкл. второй терминатор ` */` — уже как DELIM
`*` `/`) становится текстом верхнего уровня и СКЛЕИВАЕТСЯ с prelude следующего
правила. Браузер (consume a qualified rule) видит невалидный prelude (чужие
DELIM-токены) → ПОГЛАЩАЕТ И БРОСАЕТ весь блок:

    .combat-overlay--combat .combat-mpbar { position: relative; height: 16px;
      margin-bottom: 10px; background: #12262e; border-radius: 3px; overflow: hidden; }

Правила `-fill` (L467) и `-text` (L473) имеют ЧИСТЫЕ prelude — парсятся и
применяются НОРМАЛЬНО. Каскад: трек — position:static (правила нет), fill
(`position:absolute; left/top/bottom:0; width:100%; background:#8cf2fc` + inline
width из render()) берёт containing block = ближайший positioned-предок:
`.combat-side` (L257–263) position НЕ ИМЕЕТ, `.combat-overlay` (L238–240) =
`position: fixed; inset: 0` → **голубой #8cf2fc прямоугольник НА ВЕСЬ ЭКРАН**.
HP-полоса цела: её правила ГЛОБАЛЬНЫЕ (`.combat-hpbar*`, L313–335) — мина их не
касается (комментарий после них). Фон #8cf2fc существует только в этой CSS-полке
(grep index.html/src/assets: L291 — цвет ТЕКСТА .turn-token--hero; L471 — только
это правило; src — только canvas-рисовка) → «весь экран» = только mpbar-fill.

## Подводные камни

1. **В CSS-комментарии index.html НИКОГДА не писать `*/`** — в т.ч. в слэш-
   списках классов `.a*/.b` (баг этой задачи). Комментарий закрывается на
   ПЕРВОМ `*/` (css-syntax-1); хвост комментария склеивается с prelude
   следующего правила и правило отбрасывается браузером. Гард
   CU201-CSS-SELECTORS ловит этот класс по всему <style> (140 правил, вкл.
   @media). Сигнатура гарда (правки по итогам ревью): в prelude — терминатор
   `*/` (второй `*/` комментария после досрочного закрытия становится
   top-level-текстом) или несамостоятельное `*` (допущены: `*` в сложном
   селекторе, `:not(*)`/`:is(*)`/`:has(*)`, `[attr*=…]`; слэш сам по себе —
   НЕ нарушение, т.к. легален в `[attr="a/b"]`).
2. **Наивные regex-пины (cssRule) не ловят правило, сброшенное браузером**:
   селекторная строка в файле есть, мусор — в предыдущих строках «комментария».
   Для пинов «выживаемости» правил — comment-aware-разбор, не regex.
3. **Ложные `<style>`**: в index.html 3 вхождения строки `<style>` — два (L576,
   L635) — ТЕКСТ внутри CSS-комментариев; реальный блок ЕДИНСТВЕННЫЙ L10–886.

   итогам ревью зафиксировано АССЕРТОМ в styleBody(): реальных `<style>` в
