## 3. Решения D1–D8 (контракт исполнителей)

* **D1** — один kind `armor` для всех бронепчастей
  (различает `slot`: head, ears, neck, torso, forearms,
  right_hand, left_hand, palms, ring, legs, feet — 11
  групп; ring = 8 физических слотов ring_left_1..4 /
  ring_right_1..4); новый subtype оружия `staff`; новые
  kind: `shield`, `artifact` (left_hand), `tool`
  (right_hand), `ring`. Новые kind — ВСЕГДА с явным
  `slot` (slotOf-фолбэк: item.slot || weapon→right_hand ||
  armor→torso — покрывает только существующие 10 предметов).
* **D2** — ассортимент магазинов НЕ расширяется: armor-
  ассортимент покрывает все бронепчасти; shield/artifact/
  ring/tool — в ассортимент `weapon` (Оружейная/Универсам).
  Таблица `виды` — без изменений (result §7.1 — вопрос
  уточнения).
* **D3** — `rarity` (common/rare/epic/legendary/impossible)
  — отдельное поле, НЕ `tier` (1..4, только реагенты,
  000157.01, dungeon.js:212).
* **D4** — affixes: `{type:'skill', skill, amount:число
  (±)}` / `{type:'free_cast', spell}`. Валидатор —
  ФОРМА id (прецедент spell_scroll), каталожность —
  тестом. ЕДИНАЯ точка — derived(): вклад навыка ×
  (1 + Σ affix skills[id]), clamp ≥ базового нуля.
  free_cast: мана 0, действие «Заклинание» сгорает, книга
  рангов без изменений; союзники — те же правила (000193);
  Эфир — guard (affixes не применяются).
* **D5** — наборы: `set` (id) + `set_bonus {2,3,4}` В JSON
  предметов; нового каталога/синка/script-тега НЕТ.
  Активация — число НАДЕТЫХ предметов (каждый — 1).
  set_bonus без set → throw.
* **D6** — редкость дропа: таблица 0.50/0.30/0.15/0.049/
  0.001 (данные модуля, пин) → ролл редкости →
  детерминированный предмет этой редкости из фиксированного
  пула (000132). Моб — свой c._rng ПОСЛЕ существующих
  (goldens бит-в-бит); сундуки — свой rng-поток
  (000157.02). Расходники — без изменений.
* **D7** — наёмник: entry.sheet.equipment (та же форма,
  .02 generic); предмет — из ОБЩЕГО инвентаря героя
  (000194); найм-данные — база, экипировка — добавка;
  dead_mercs — sheet сейвится (000161) → экипировка
  сохраняется; Эфир — equip ОТКАЗ «дух не экипируется».
* **D8** — tool (инструмент крафта) — ВЫБРАН ВАРИАНТ:
  **обычная замена оружия на слоте right_hand** (игрок
  выбирает: бить или ковать). Обоснование — result §5.2
  (модель без под-слотов; инвариант «1 слот = 1 предмет»;
  предсказуемый бой). Аффикс tool = бонус к качеству
  соответствующего вида крафта, считаемый при ЭКИПИРОВАННОМ
  tool (craft.js; реализация — .03/.12). Альтернатива
  (tool + оружие одновременно) — отклонена, можно вернуть
  отдельной задачей (result §7.7).

## 6. Шкала силы affixes + матрица навыков

Шкала (amount на one affix): common **0.02–0.05**, rare
**0.05–0.10**, epic **0.10–0.20**, legendary **0.20–0.35**,
impossible **0.35+**. free_cast — только epic+ (1–2 шт. на
волну).

Группы affixes по части тела (приоритет для волны; навыки —
id каталога assets/skills):
* **head** — perception, precog, meditation, elder, scholar
* **ears/neck** — perception, precog, meditation, elder,
  orator, artist (ювелирная группа)
* **torso** — endurance, golem, hide, breath, meditation
* **forearms/palms** — swordsman, archer, heavy, fists,
  step, thief (группа рук/точности)
* **right_hand** — firelord, icelord, alchemy, runes,
  scholar + swordsman/archer/heavy (посохи — магические,
  косы/вилы — heavy/fists, tool — бонус крафта D8)
* **left_hand** — shield: endurance, golem, hide, breath;
  artifact: firelord, icelord, runes, scholar, perception,
  precog
* **ring** — широкие: все навыки, приоритет редкие/магические
  (firelord, icelord, runes, scholar, precog, unkill)
* **legs/feet** — step, endurance, hide, breath, golem

Правило покрытия: на КАЖДЫЙ из 37 навыков — несколько
предметов В СОВОКУПНОСТИ по всем волнам (275 предметов);
сила — по редкости (шкала выше). Исполнитель волны
фиксирует в своём result-отчёте: какие навыки закрыты.
