## ГЛАВНЫЙ ПОДВОДНЫЙ КАМЕНЬ: у spell_scroll НЕ БЫЛО base_price

В отличие от .11–.14 (торговля только готовыми предметами с
base_price), торговля свитками УПРАЛАСЬ в ловушку R1
(tests/item-prices-000322): свип требует base_price ∈ int ≥1 у
КАЖДОГО торгуемого предмета, а у ВСЕХ 160 spell_scroll base_price
ОТСУТСТВУЕТ (их продавали только городские магазины через value, R4).
Решение (в том же коммите): В assets/items/000043.json (fireball,
value 60), 000045.json (frost_bolt, 45), 000048.json (light_heal, 70)
вставлен "base_price" = value СРАЗУ ПОСЛЕ "value" (канон KEYS
sync-items-data) + перегенерирован src/items-data.js. base:=value
сохраняет семантику цены: формула NPC-цены src/npc.js берёт
base_price ?? value — цена идентична фолбэку R8; магазинные цены идут
от value (R4) и НЕ зависят от base_price (src/items.js его не
читает); стоки SHOP_GOLDEN (rng по составу/порядку каталога) не
двинулись — поле не сдвигает роллы (cities golden зелёные). Для .16+
(и любой будущей торговли свитками/не-торговыми kind): ПРЕЖДЕ чем
дать NPC предмет, проверять наличие base_price у него — иначе R1/R6
красные. Продавцов spell_scroll среди NPC ДО .15 НЕ БЫЛО — проверено
свипом.
