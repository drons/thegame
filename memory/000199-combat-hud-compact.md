## Что теперь в правом верхнем блоке боя (src/combat-ui.js, CSS — index.html)

- **stateEl — ровно 2 строки** (фикс. число, по контенту — обе без условия):
  1. `<groupName>, раунд N`
  2. строка цели (побайтово как до: живой / «— мёртв» / «(вы) — мёртв» / «Цели нет»)
  Убрано: «Ход: …», «HP|MP», «Шаги|Удар|Огонь|Леч», строка активного союзника,
  «Отряд: …», префиксы «БЛОК»/«ЯД» (D1). Рамка активного — 000197.
- **Полосы HP + MP** следуют за активным персонажем
  `barUnit = activeUnit(c) || c.player` (игрок → p/d.derived; Эфир → u
  (знаменатель маны — снапшот u.maxMP из buildEfirUnit, НЕ legacy-таблица
  efirStats — ревью 000199); наёмник → u, маны нет → fill 0%, текст
  «MP —»; фаза мобов → герой).
  Новая полоска `.combat-mpbar` — сразу ПОД `.combat-hpbar` (третий элемент
  .combat-side). Цвет: fill #8cf2fc, дорожка #12262e (пара .turn-token--hero);
  HP-цвет — hpBarColor(frac) как раньше. Canvas-миниполоса героя — геройская
  (не трогаем).
- **Счётчики на кнопках** — `<span class="combat-actcount">` (жёлтый #ffe27a,
  top-right, absolute):
  - «Удар» (attack) — ВСЕГДА видим: игрок `c.ps.attack` / наёмник
    `u.attackLeft` / Эфир `c.efs.touch` (guard null → 0) / фаза мобов —
    игрока.
  - «Книга заклинаний» (spellbook) — игрок и фаза мобов: `«int/wis»`;
    ход союзника — скрыт (книга союзнику недоступна — allyCanDo).
  - Счётчик «Шаги» НЕ выводится (кнопки движения нет — D4). Остаток шагов
    игрока НЕ отображается нигде: подсветки клеток для шагов ИГРОКА на
    canvas НЕТ (штриховка 000175 — досягаемость МОБА, G.mobReachCells);
    единственный сигнал — строка отказа в журнале «шаги на ход исчерпаны».
    Осознанное отклонение от буквального ТЗ — ратификация оркестратора
    (D4 ИЛИ подзадача 000199.01). cast/heal/resurrect и прочие кнопки —
    без бейджей (пины children.length===1).
