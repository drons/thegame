## 2. Контракты и границы

### 2.1 equipmentAffixes(character) — src/items.js
* ЧИСТАЯ функция: НЕ вызывает `ensureEquipment` (отличие от equipmentStats,
  который вызывает ensureEquipment :1164 — НЕ копировать). Читает
  `character.equipment` raw: не объект → `null`/пусто по контракту.
* Возврат: `{skills: {<skillId>: сумма amount}, freeCast: Set(<spellId>)}`.
  Пустая/отсутствующая экипировка → `{skills: {}, freeCast: new Set()}`.
* Итерация: ТОЛЬКО `EQUIP_PHYS_SLOTS` (18 физ. слотов, :107-111). Зеркальные
  ключи `weapon`/`armor` (алиасы right_hand/torso из 000230.02) НЕ итерировать —
  иначе двойной подсчёт.
* Для каждого `id = eq[slot]`: `id` falsy → skip; `getItem(id)` → `null` →
  skip; guards: `Array.isArray(it.affixes)`, для каждого a:
  `a && typeof a.amount === 'number' && Number.isFinite(a.amount)`.
* `skill`-affix: `a.skill` falsy → skip; `skills[a.skill] = (skills[a.skill]||0) + a.amount`.
* `freeCast`-affix: `a.spell` falsy → skip; `freeCast.add(a.spell)`.
* Упорядоченность: сумма коммутативна; Set — порядок не важен для `includes`.
  Детерминизм: функция чисто читает состояние, RNG не трогает.

### 2.2 Affix-множитель в derived() — src/sheet.js (ЕДИНАЯ точка, D-01)
* `pct(id)` становится affix-aware:
  ```
  const affixSkills = affixSkillsFor(sheet);           // 1 раз на вызов derived
  const pct = (id) => {
    const base = sk.SECONDARY_SKILLS[id].effect.perLevel * S(id);
    const a = affixSkills ? affixSkills[id] : undefined;
    return a ? base * Math.max(0, 1 + a) : base;
  };
  ```
* Формула `base * Math.max(0, 1 + a)`:
  * без affix (a falsy / affixSkills null/{}) — возвращает `base` БЕЗ
    умножения → бит-в-бит текущие derived;
  * отрицательный affix не уводит вклад навыка ниже её базового нуля
    (clamp по множителю, D-04);
  * для навыков с отрицательным perLevel (hide −0.05, merchant −0.05)
    масштабируется МОДУЛЬ вклада, знак не переворачивается;
  * все существующие полы (`Math.max(0.1, 1+pct('hide'))` :466,
    `Math.max(0.3, ...)` buy :486 и т.д.) сохраняются — мы меняем только `pct`.
* НЕ масштабируются (не через pct, осознанно): `maxMP` (flat),
  `armor = S('golem')` :446 (чистый уровень, не perLevel×уровень),
  moveCells/attackActions/spellActions*, equipmentDurabilityMult — формула
  `1 + pct('forge')` НЕ трогается, но forge-affix масштабирует её автоматически
  через pct (D-07; craft.js:220 работает без изменений).
* `dialogueBonus` :476 → `Math.round(pct('elder') + pct('orator'))` (D-10):
  perLevel elder/orator = 1, т.е. raw level ≡ perLevel×уровень → бит-в-бит
  без affix, affix-aware с affix.
* Все существующие потребители `P.derived` (player.js:195, efir.js,
  companions.js, combat.js, craft.js) получают affix-вклад автоматически —
  одна точка. player.js — БЕЗ ИЗМЕНЕНИЙ.

### 2.3 free_cast — снапшоты (D-05)
* `createCombat` (src/combat.js :3280, c-объект :3323-3377):
  `c.freeCast = [...(typeof I.equipmentAffixes === 'function'
    ? (I.equipmentAffixes(p).freeCast || []) : [])]` — plain-массив (Set→Array,
  JSON-safe, vm-invariant), транзиент (не сейвится), 0 `_rng`.
* `makeAlly` (src/combat.js :358-426, plain-поля):
  `freeCast: (data.kind === 'efir') ? []
    : (Array.isArray(data.freeCast) ? data.freeCast.slice() : [])`
  (D-09, D-12).
* Помощники (маленькие, локальные, без новых зависимостей):
  * combat.js `allyFree(u, id)` = `Array.isArray(u.freeCast) && u.freeCast.includes(id)`;
  * spells.js `isFreeCast(c, id)` = `Array.isArray(c.freeCast) && c.freeCast.includes(id)`;
  * ally-spells.js `isAllyFreeCast(u, id)` — тот же образ (локальный).
* Семантика каста (все 4 точки — 000037: eval+canCast+cast — одна причина):
  * eval: `if (!free && p.mp < spell.мани) return { fail: { ok:false, reason:
    'не хватает маны (...)' } }` — строка reason БЕЗ ИЗМЕНЕНИЙ (пин).
  * ok-возврат eval += поле `free` (boolean).
  * cast: пул ВСЕГДА сгорает (`c.ps[poolKey] -= 1` / `pools[poolKey] -= 1` /
    `u[pool] -= 1`); мана: `if (!free) p.mp -= spell.мани;`.
  * Действие «Заклинание»/«heal» ВСЕГДА сгорает — free_cast экономит только ману.
  * Логика книги рангов/степени — без изменений.
  * canCastSpell/canCastAllySpell — ЧИСТЫЕ ЗЕРКАЛА eval, НЕ трогаем
    (000037: зеркало повторяет условие; free-cast влияет на eval/cast одинаково).
* 4 каст-точки: (1) spells.js evalSpell/castSpell — книга героя;
  (2) ally-spells.js evalAllySpell/castAllySpell — книга союзника;
  (3) combat.js allyHealAction :2264-2299 — H-лечение:
  `let mana = Number(s['мани']) || 0; if (allyFree(u, s.id)) mana = 0;`
  (+ зеркало allyCanDo 'heal' :2415-2441, чек маны :2434-2437 → `mana = 0` при free).
* Legacy school-касты (playerSpell fire/heal :1397/:1424/:1718/:1749,
  efirCastAction/efirBreath/rescue/efirTurn) — free_cast НЕ применяется
  (D-08): они ключатся по школам, а freeCast — Set каталожных spell-id.

## 3. Ленивые ссылки и guards

### 3.1 Цикл require — ОПАСНО (подробнее в §7)
sheet.js НЕ может делать `require('./items.js')` в момент загрузки:
sheet → items → player → sheet (player при загрузке требует sheet и бросает
на частичном объекте). Решение — call-time thunk.

### 3.2 Ленивая ссылка sheet→items (D-02)
* УMD-фабрика sheet.js: `(skills, settings, rootRef)` → 4-й аргумент `itemsThunk`
  (slot свободен, никто не передаёт).
* Node-ветка: `module.exports = factory(require('./skills-data.js'),
  require('./global-settings.js'), null, () => require('./items.js'))`.
  Тхамк вызывается в момент вызова (не в момент загрузки) — items.js при
  загрузке derived НЕ вызывает (каталог :282-286 строит только validateItem) →
  частичность невозможна при любом порядке входа.
* Browser-ветка: 4-й аргумент `null`; чтение `rootRef.Game.equipmentAffixes`
  в момент вызова (items.js грузится в index.html :1060 до combat :1081 /
  spells :1083 → API на месте).
* Помощник `affixSkillsFor(sheet)`:
  1. `!sheet` или `sheet.equipment` не объект → вернуть `null` ДО резолюции
     (дешёвый выход, items не нужен);
  2. node: кэш `itemsApi` — `try { itemsApi = itemsThunk() } catch { itemsApi = {} }`
     (кэшируется только резоленый ref; require-кэш даёт тот же модуль);
  3. browser: `api = rootRef.Game || null`;
  4. `!api || typeof api.equipmentAffixes !== 'function'` → вернуть `null`
     **МОЛЧАЛИВО (0 console.error)** — D-11;
  5. иначе `a = api.equipmentAffixes(sheet)`; вернуть `a.skills` если объект,
     иначе `null`.
* Пустой РЕЗУЛЬТАТ НЕ кэшируется (vm-цепь может догрузить items позже);
  кэшируется только резоленый модуль (node).

### 3.3 Guards
* equipmentAffixes: `getItem(id)` null → skip; не-массив affixes → skip;
  не-число amount → skip.
* derived: `affixSkills` null/{} → `pct` бит-в-бит (a falsy → return base).
* free_cast: `Array.isArray(c.freeCast) && includes` — безопасен на c/u без поля
  (legacy-снапшоты, тесты-фикстуры).
* Эфир (D-09): makeAlly `data.kind === 'efir'` → `freeCast: []` (ЦЕНТРАЛЬНЫЙ
  guard); efirAllyData (src/efir.js :367-389) поле freeCast НЕ передаёт;
  лист Эфира equipment НЕ имеет → affixes 0 по построению. Тройной guard.
* companions.js allyDataForEntry :694-718 — `freeCast: []` (seam для .06;
  ТЗ «guard в allyDataForEntry»).

## 4. Решения (D-01…D-13)

* **D-01** Единая точка affix-множителя = `derived()`/`pct` в sheet.js.
  Почему: ВСЕ производные из perLevel×уровень уже идут через `pct`; внутренние
  вызовы derived в takeDamage/heal/restoreDay (sheet.js :505/:518/:525) должны
  видеть тот же вклад (обёртка на P.derived рассинхронизирует их); ~15 точек
  пламбинга ctx неоправданно; прямые вызовы `G.Sheet.derived` из efir.js/
  companions.js (для .06) работают автоматически. player.js — без изменений.
* **D-02** Ленивая ссылка sheet→items: node — thunk 4-м аргументом фабрики
  (call-time, try/catch, кэш резоленого ref); browser — `rootRef.Game` в момент
  вызова. Почему: require-цикл sheet→items→player→sheet ФАТАЛЕН при load-time
  require; call-time безопасен при любом порядке входа (items не вызывает
  derived при загрузке).
* **D-03** `equipmentAffixes` — чистая, без `ensureEquipment`. Почему:
  ensureEquipment мутирует персонажа (создаёт/нормализует оборудование) —
  функция-агрегат не должна иметь side effects; вызывается из derived (на
  каждый recompute) и из createCombat/makeAlly.
* **D-04** Clamp — `Math.max(0, 1 + a)` по МНОЖИТЕЛЮ вклада навыка, не
  per-value обёртки на каждой строке derived. Почему: масштабирует модуль
  вклада (включая отрицательные perLevel hide/merchant), не переворачивая
  знак; все существующие полы сохраняются (меняется только pct); без affix —
  бит-в-бит (возврат base без умножения). Пер-значение ~20 правок (вариант
  a1) — больше поверхность регрессии.
* **D-05** free_cast — СНАПШОТЫ (c.freeCast в createCombat из экипировки героя;
  u.freeCast в makeAlly), НЕ live-вызов equipmentAffixes в каждом касте.
  Почему: бой = замкнутое состояние (c/u транзиентны, не сейвятся); снапшот
  детерминирован на бой; live-вызов в 4 каст-точках — лишние обращения и риск
  рассинхрона при смене экипировки mid-combat (которая в бою не происходит).
* **D-06** Scope free_cast — ТОЛЬКО в бою (книга героя + книга союзника +
  H-лечение союзника). castOutOfCombat НЕ трогаем. Почему: активный параллельный
  000235.03 правит свитч в castOutOfCombat (горячая зона — риск мержа); ТЗ п.3
  «действие «Заклинание» всё равно сгорает» сформулировано вокруг боевого пула
  действий; «не больше и не меньше» → внебоевой free-cast = отдельная задача
  после 000235.03.
* **D-07** «Кузнечная рука» (equipmentDurabilityMult, sheet.js :489) — формула
  `1 + pct('forge')` НЕ трогается; forge-affix масштабирует её через pct
  автоматически. Почему: ТЗ «НЕ трогать» = не ломать связь craft.js:220;
  D8 родителя — affix-инструмента → качество крафта; одна точка pct покрывает
  это без правок craft.js.
* **D-08** Legacy school-касты (playerSpell fire/heal, efirCastAction/
  efirBreath/rescue/efirTurn) — free_cast НЕ применяется. Почему: они ключатся
  по школам (fire/heal), а freeCast — Set каталожных spell-id; каталожный путь
  — книга (evalSpell/evalAllySpell). Bit-for-bit.
* **D-09** Эфир — affixes/free_cast НЕ применяются. Triple-guard: makeAlly
  `kind==='efir'` → freeCast []; efirAllyData без freeCast; лист Эфира без
  equipment → equipmentAffixes → пусто. Почему: ТЗ п.4 «он дух» + явный guard.
* **D-10** `dialogueBonus` — В SCOPE (через `pct('elder')+pct('orator')`).
  Почему: perLevel elder/orator = 1 → `Math.round(pct+pct)` бит-в-бит без
  affix (S×1 ≡ perLevel×уровень) и affix-aware с affix; а1 (R-1) требует
  включить; без этого elder/orator-affixes из контент-волн .08–.15
  молча не работали бы. ОТКЛОНЕНИЕ от architecture.md («не масштабируется») —
  обосновано (ТЗ масштабирует «вклад perLevel×уровень»).
* **D-11** Деградация без items-API — МОЛЧАЛИВО (0 console.error).
  Почему: items — мягкая зависимость (derived полностью функционален без неё:
  affixSkills null → pct бит-в-бит); a3: существующие пины счётчиков
  console.error (UMD-degrade sheet.test.js :449-487 — по SkillsData/
  GlobalSettings) не должны ломаться; ни один существующий тест не
  достигает состояния «лист с экипировкой без items-API» (все тесты,
  надетывающие экипировку, имеют items.js в цепи) → молчаливое поведение
  безопасно и семантически верно (soft-optional dependency). ОТКЛОНЕНИЕ от
  a1/architecture («console.error 1×») — обосновано.
* **D-12** FreeCast союзников — из СОБСТВЕННОЙ экипировки (контракт .06).
  На .03 у союзников экипировки нет → все freeCast []. makeAlly: default [];
  явный эфир-guard. allyDataForEntry += `freeCast: []` (seam: в .06 станет
  `[...I.equipmentAffixes(entry.sheet).freeCast]`). Почему: ТЗ п.3 «у союзников
  — те же правила (000193)» + guard в allyDataForEntry; .06 проводит реальное
  значение.
* **D-13** Границы: 0 новых модулей/тегов/каталога/схем/иконок/полей сейва/
  `c._rng`; 6 src-файлов (items/sheet/combat/spells/ally-spells/companions) +
  5 тест-файлов; index.html и tests/index-order НЕ трогаем. Почему: ТЗ

## 7. Подводные камни

* **Цикл require sheet→items→player→sheet** — load-time require items в
  sheet.js ФАТАЛЕН (player при загрузке требует sheet, бросает на частичном).
  Только call-time thunk (D-02). items.js при загрузке derived НЕ вызывает →
  call-time безопасен.
* **Set→Array** — freeCast в equipmentAffixes = Set, в c/u = plain-массив
  (снапшот). JSON-safe (сейвы транзиентны), vm-invariant (Set в vm — ок, но
  снапшот в массив проще). Никогда не класть Set в c/u напрямую.
* **Зеркальные ключи weapon/armor** (алиасы right_hand/torso из 000230.02) —
  НЕ итерировать в equipmentAffixes (двойной подсчёт). Только EQUIP_PHYS_SLOTS.
* **000037 зеркала** — eval/cast/canCast = одно поведение на причину.
  canCastSpell/canCastAllySpell — ЧИСТЫЕ зеркала, НЕ трогаем (free-cast
  влияет на eval/cast одинаково; зеркало повторяет условие маны, которое мы
  не меняем строкой reason).
* **VM-цепи** — `VM_ITEMS_CHAIN_NO_ITEMS` + `sandbox.Game.ITEMS = fixtures`
  ДО `loadInSandbox('items.js')` (items-data.js в цепи ставит реальные 76 →
  перепишем fixtures; items.js G0-snapshot :load читает Game.ITEMS).
  items-каталог — Map, строится при загрузке → node-тесты не могут
  инжектить fixtures без vm.
* **Базовый флейк** — полный сьют: 2/4 ранов падал по map.test.js:1943
  (timing). Протокол: реран одиночного файла + запись. Не путать с реальным
  регрессом.
* **castOutOfCombat — горячая зона 000235.03** — НЕ трогать (D-06).
* **ensureEquipment** — НЕ вызывать из equipmentAffixes (D-03, side effect).
* **Пустой результат НЕ кэшировать** в affixSkillsFor (vm может догрузить
  items позже); кэшировать только резоленый модуль (node).
