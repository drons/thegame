## 1. Шкала: «глубина» (каноническое имя)

* Имя шкалы — **«глубина»**; целое ≥ 1, **первый этаж = 1**; код —
  `d.depth` (поле объекта подземелья, createDungeon dungeon.js:270).
* 000157 (редкость руд в пещерах) ссылается «растёт с глубиной
  (000153)» — tasks/pending/000157.md:7; имя закрепляется в SPEC в
  .05 (spec/world-map.md буллет «Процедурно генерируемый лабиринт»).
* Формулы — с сдвигами `(depth−1)` (при depth=1 все сдвиги = 0):

| величина | формула (зафиксировать .05) |
|---|---|
| размер стороны | `W = round(base · 1.1^(depth−1))` + CAP (решение .02) |
| уровень моба группы | `max(1, player.level + (depth−1) + floor(rng·(2δ+1)) − δ)` — сдвиг БАЗЫ |
| уровень босса ABYSS | `max(1, player.level + δ + (depth−1))` |
| gold сундука | `round(10 + rng·20·(1 + 0.2·(player.level + (depth−1))))` |
| кол-во сундуков | растёт с глубиной (база 2+floor(rng·4); формула — .02) |

  δ = level_delta_max (default 3, global-settings.js:75). «Площадь
  ~1.1×» ТЗ п.5 = **сторона ×1.1 → площадь ×1.21/этаж** (решение по
  finding B; зафиксировать в спеке .05). base — из JSON
  «размер» (dungeon.js:275; CAVE 25 / CRYPT 27 / RUINS 31 / DROWNED 27
  / ABYSS 35); schema 5..63 — для БАЗЫ; рост ТОЛЬКО в коде (ABYSS
  35·1.1⁷≈68 > 63), cap — решение .02 + перформанс-тест W>63.

## 2. Сиды (ТЗ п.6)

* **Сид формы**: depth=1 — старая формула БИТ-В-БИТ
  (dungeonShapeSeed dungeon.js:209-216: hash2(x,y,0xd0d6b5e5) ^
  |round(perlin(x·0.137+11.3, y·0.211+7.7)·1e6)| ^ пиксель). depth>1 —
  детерминированная функция от (сид формы depth=1, depth, соль) БЕЗ
  новых вызовов rng (конкретная соль/хэш — решение .01; паттерн
  wallObjFor dungeon.js:244-250 — hash2 с солью).
* **Сид содержимого — БЕЗ ИЗМЕНЕНИЙ** (dungeon.js:377: hash2(totalXp,
  d.seed, 0x5e11) ^ totalXp·2654435761): глубина наследуется через
  d.seed → «координаты + глубина» выполняется и для формы, и для
  контента.
* **BIT-IN-BIT depth=1 — жёсткий контракт**: новые формулы/поля
  свёртываются к текущим при depth=1 (cells/rooms/mobs/chests/
  wallObjs/seed — golden tests/dungeon.test.js:250-305, :89-101,
  :103-110, :661+). РЕПИНОВ golden НЕТ. stairs-down и любое новое
  поле — без новых вызовов rng в createDungeon/
  generateDungeonContents.
