### D1. [E]-резолвер — расширение `interactExit` (НЕ новая функция)
Альтернативы отклонены: a3-вариант «отдельный interactFloor +
interactExit без изменений» — ОТКЛОНЁН: 000177 «три канала, один
код» (клавиша/тач/debug → locationOnInteract → ОДИН доменный
резолвер «что делает [E] на этой клетке»); JSDoc interactExit
(:424-425) прямо помечает точку расширения: «между этажами —
аналогично». Две функции-резолвера = дублирование гейтов (kind,
ds.dg, клетка).
Тело (клетки взаимоисключаются — stairsDown ≠ exit):
```js
function interactExit(ds) {
  if (!ds || !ds.dg) return null;
  if (ds.kind !== 'city' && ds.kind !== 'dungeon') return null;
  const d = ds.dg;
  if (ds.x === d.exit.x && ds.y === d.exit.y) {
    const depth = (Number.isInteger(d.depth) && d.depth >= 1)
      ? d.depth : 1;
    if (ds.kind === 'dungeon' && depth > 1) return { type: 'ascend' };
    return { type: 'exit', name: ds.kind === 'city'
      ? ds.name : dungeonName(d) };
  }
  // 000153.03: лестница вниз (только подземелье; null — fail-open
  // 000153.02 §4 — дегенеративная форма без лестницы).
  if (ds.kind === 'dungeon' && d.stairsDown &&
      ds.x === d.stairsDown.x && ds.y === d.stairsDown.y) {
    return { type: 'descend' };
  }
  return null;
}
```
* Порядок exit-ПЕРВЫМ: city/depth=1 — побайтово текущее поведение
  (PE-3a, PE-1/2/3b, T5/T7/T8, CI-V5 зелёные без правок).
* stairsDown ≠ exit по построению: stairsDownFor = МАКС BFS-
  дистанции от entrance ∖ 5×5 safe (entrance=exit) ∖ босс (dungeon.
  js:358-395) — клетка на макс. дистанции не может быть entrance
  (дистанция 0) в реальных формах (5–8 комнат 4×4). ЭМПИРИЧЕСКИ
  проверено на pinned layout PE-3a (37,−12): depth 1 — exit (18,14),
  stairsDown (20,8), aside-кандидат (19,14) ≠ stairsDown; depth 2 —
  exit (13,17), stairsDown (21,7). НУЛЕВОЙ остаточный риск
  (детерминизм) + фиксируется N1/PE-3a.
* kind-гард `ds.kind === 'dungeon'` обязателен: у layout города
  (createCityLayout) stairsDown/depth — undefined (гард мёртв), но
  тестовые/дегенеративные city-фикстуры могут нести чужие поля.
* Чистота: без мутаций, без RNG (LOC-2 safe).

### D3. writeFloorMemory — вынесен из exitDungeon
```js
function writeFloorMemory(ds, opts) {   // {day, memory}
  const G = lazyGame();
  const depth = ds.dg && Number.isInteger(ds.dg.depth) && ds.dg.depth >= 1
    ? ds.dg.depth : 1;
  const memKey = G && typeof G.dungeonMemoryKey === 'function'
    ? G.dungeonMemoryKey(ds.worldKey, depth)
    : ds.worldKey + ':' + depth;
  if (!ds.memoryBanned) {
    opts.memory.set(memKey, { contents: ds.contents,
      lastVisitDay: opts.day });
  }
}
```
