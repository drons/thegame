## 2. ДИЗАЙН-РЕШЕНИЕ: АДДИТИВНЫЙ C2-канал в anchorAt (src/map.js)

Лагерь (id 47) — ОТЕПЕЛЬНЫЙ детерминированный канал в `anchorAt`,
паттерн городского (000103), НО АДДИТИВНЫЙ: срабатывает ТОЛЬКО там, где
слотовый якорь НЕ генерируется, ПОСЛЕ городского канала (города
первичны), по СОБСТВЕННОМУ смещению features-шума с порогом из
SETTINGS.camp_channel.

```
anchorAt(x, y) — новый hunk (между городским и слотовым):
  if (fb <= 0.33 + 0.14 * rarity) {          // слотового якоря НЕТ
    const cbd = campDerived();
    if (cbd) {
      const fc = features.fbm(x*FS + CAMP_FEATURE_OFFSET,
                              y*FS + CAMP_FEATURE_OFFSET, 3);
      if (fc > cbd.fbm + cbd.rarity * rarity)
        return { x, y, buildingId: CAMP_ID }; // 47, type = NONE
    }
    return null;
  }
```

Параметры:
* **CAMP_FEATURE_OFFSET = 733.7** — именованная локальная константа у
  FEATURE_SCALE (src/map.js), НЕ экспортируется (паттерн литералов
  511.1/222.9/444.1/903.7). Своё смещение — декорреляция размещения
  лагерей от плотностей слотов/мобов/wealth (пересечение множеств
  лагерей при 733.7 vs 611.3 = 0, замер станции анализа).
* **CAMP_ID = 47** — локальная константа (как CAMP_ID в main.js L261).
* **SETTINGS.camp_channel = { fbm: 0.45, rarity: 0.10 }** — редкость
  ТОЖЕ, что у города (city_channel {fbm: 0.45, rarity: 0.10}):
  «лагерь = по редкости как город». Зонд: 11 лагерей в BFS-70
  (e2e-семантика) против 13 городов и 72 слотовых якорей; 413 лагерей
  в ±300 (≈1 на 2400 тайлов).
* **НЕЗАВИСИМОСТЬ от города гарантирована порогами** (не только
  порядком проверок): лагерь требует fb(511.1) ≤ 0.33+0.14·r, город —
  fb > 0.45+0.10·r; пересечение порогов потребовало бы r > 3 —
  невозможно при r ∈ [0,1].
* **СВОЕЙ СИД-КОНСТАНТЫ НЕТ** (решение по openQuestion a3 §6.3): тип
  лагеря НЕ выбирается (всегда 47) — hash2-выбора нет, сеять нечего.
  Детерминизм позиции = (733.7, 0.45, 0.10, каталог 47, perlin+map.png).
  Избегаем путаницы с CAMP_STOCK_SEED = 0x43414d50 (src/items.js L820 —
  это сид СТОКА, другая подсистема). RED-тест CP-2 (a3) переделан:
  вместо «CAMP_SEED_CONST экспортирован + hash2-пины» — инвариант
  формулы канала (см. §6), детерминизм фиксируют golden-координаты
  (CP-4) и два createMap (CP-3).

Почему НЕ вариант полосы a1-анализа ({fbm: 0.44, rarity: 0.10} на ТОМ
ЖЕ смещении 511.1, лагерь ЗАБИРАЕТ слотовые якоря, слот-9 gate):
* C2 аддитивен → ВСЕ существующие якоря/пины не трогаются: зонд
  показал 819 пин-тайлов (GOLDEN_TILES 48 + building-effects 9 +
  городские footprint'ы + 4 кадровых окна) ПОБАЙТОВО неизменны, все 7

  требовал сознательного ре-пина голден-башни (-255,137) и менял 73
  слотовые постройки мира (8 домов NPC, 6 таверн — «ближайшая
  таверна» у будущих задач едет).
* Свой офсет 733.7 — лагерь не «подсвечивает» слотовую структуру;
  порог по ЧУЖОМУ шуму 511.1 делал бы лагерь тенью от плотности слотов.

Размещение — БЕЗ ПРАВок пайплайна: `buildingAtAnchor` (map.js L744+)
