## 2. Контракты и границы

### 2.1 castOutOfCombat(p, spellId, day, ctx) — src/spells.js

Чистое ядро (каталог — снапшот SPELLS_BY_ID :106-107; Game на загрузке не
читает). Порядок проверок ДО ЛЮБОЙ мутации (форма отказа 000037 —
`{ok:false, reason}`, ОДНА причина):

1. `getSpell(spellId)` → нет: «неизвестное заклинание»;
2. `knows(p, spellId)` → нет: «заклинание не изучено»;
3. `spell['вне_боя'] !== true` → «боевое заклинание» (фильтр по ФЛАГУ,
   гейт .01 по ДЕЙСТВИЮ — НЕ ТРОГАЕТСЯ);
4. дни: если `DURATION_ACTIONS.has(spell.действие)` или в
   `spell.параметры` объявлено `days` — `days` обязан быть integer 1..3,
   иначе «неполные параметры: days» (имя ошибки — конвенция .01);
   `DURATION_ACTIONS = new Set(['невидимость', 'внебой'])` (D1: у этих
   действий days — обязательная часть данных; «телепорт» — мгновенное
   действие, дней НЕТ — .04 не ломается);
5. `p.mp < spell['мани']` → «не хватает маны» (состояние НЕ изменилось).

Мутация (после ВСЕХ проверок):
* `p.mp -= spell['мани']`;
* лениво `if (!Array.isArray(p.outOfCombatEffects)) p.outOfCombatEffects = [];`
* при валидных days — ПЕРЕЗАКЛИНАНИЕ = ОБНОВЛЕНИЕ: запись со spellId
  найдена → `entry.expiresDay = day + days` (in place, БЕЗ дубля);
  иначе push `{spellId, expiresDay: day + days}`. КУЛДАУНОВ НЕТ (D2:
  частота ограничена маной и днями; второй каст в тот же день — ok).
* switch-каракас ПО id:
  ```
  switch (spellId) {
    default:
      break;
  }
  ```
  Точка расширения .03 ('invisibility') / .04 (gate/stone_anchor/recall/
  warding_circle): `ctx` (опционально, default `{}`) — доступ к map/cities;
  .02 игнорирует. Контракт кейсов (для .04): кейс МОЖЕТ вернуть
  `{ok:false, reason}` — тогда сам кейс ОБЯЗАН откатить `p.mp += spell['мани']`
  и удалить созданную запись из outOfCompletionEffects; нет return = успех.
  (В .02 падающих кейсов нет — default не возвращает.)

Возврат: `{ok:true, spell, expiresDay}` (expiresDay — null, если дней нет).

Практика XP вне боя — НЕТ (ТЗ молчит; скрытый источник прогресса не
вводится; боевой castSpell — не тронут). canCast-зеркало — НЕТ (ТЗ молчит;
книга получает reason из вызова каста).

### 2.2 expireOutOfCombatEffects(effects, day) — чистый

не-массив → `[]`; возвращает НОВЫЙ массив без записей с
`expiresDay <= day`. Граница: каст в день D с days=N → expiresDay = D+N,
эффект активен на днях D..D+N-1, в onDay(D+N) вылетает (живёт ровно N
дней; зеркало buff-чистки :1571-1573 `buff.day < day`). main.js:
`hero.outOfCombatEffects = G.Spells ? G.Spells.expireOutOfCombatEffects(
hero.outOfCombatEffects, day) : hero.outOfCombatEffects;` — ПЕРЕПРИСВОЕНИЕ
безопасно: state-зеркало — getter (пересобирается при каждом обращении),
collectSaveData читает live-hero, книга читает hero.outOfCombatEffects
live.

### 2.3 sanitizeOutOfCombatEffects(list) — зеркало sanitizeSpellBook :553-563

не-массив → `[]` (старый сейв без поля — OK, append-only v1); запись
живёт, если: объект (не null/не массив) && `typeof spellId === 'string'`
&& `SPELLS_BY_ID[spellId]` (призрачные id — отброс) &&
`Number.isFinite(expiresDay) && Math.round(expiresDay) > 0` →
`{spellId, expiresDay: Math.round(expiresDay)}`; дедуп по spellId —
последний wins (поз. первого вхождения); порядок сохранён.
