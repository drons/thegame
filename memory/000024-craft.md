# 000024: архитектура хранения крафта (assets/craft)

Статус: выполнено и закоммичено (тесты 194 → 203 pass).

## Решения

* **Шесть видов крафта** в enum схемы: кузнечное_дело, алхимия,
  резьба_по_камню, столярное_дело, зачарование, рунопись
  (задача требовала «придумать ещё» — добавлены зачарование и рунопись).
  Таблица «вид → навыки → постройки» — в SPEC.md; конкретные связи —
  в данных рецептов (поля `навыки`, `здания`, `заклинания`), тест
  сверяет ссылки с каталогами.
* **Уровень на вид крафта** (объект {вид: 1..100}), отдельно от дерева
  навыков. Рост: практика (опыт за изготовление), книги
  (skill_book, напр. alchemy_manual), наставники (NPC, `обучение`).
  Потолок практикой — как у навыков (связанный вторичный навык × 2).
  Уровень открывает рецепты (`уровень`) и даёт качество/выход.
* **Рецепт = файл.** Результат `{предмет, количество}` (id из
  assets/items), исходники — список `{предмет, количество}`
  (исходник ≠ результат — инвариант теста), `навыки` (непустой),
  `здания` (непустой), `заклинания` (опционально — id из
  assets/spells, реальные id: fireball, stone_skin, frost_bolt).
* **«Совершенствование способа» — поле `база`** (id базового рецепта),
  тот же паттерн, что у заклинаний (000023): тот же вид, тот же
  предмет-результат, уровень не ниже, исходники покрывают базовые
  (мульти-множество: количество каждого исходника ≥), без циклов.
  Улучшенный способ — отдельное игровое действие (особый вид крафта),
  не новый предмет.
* **Ограничение каталога, зафиксированное в SPEC.md**: в
  assets/items нет сырья (руда/дерево/камень/кожа), поэтому текущие
  10 рецептов — перковка/улучшение имеющихся предметов (мечи, молот,
  латы, лук) и варка зелий из реагентов; «с нуля»-рецепты столяра и
  камнереза — после задачи 000032 (сырьё в assets/items).
* Ссылки на заклинания в тестах читаются из JSON-каталога
  assets/spells через fs (src-модуля заклинаний пока нет — данные
  только; при появлении src/spells-data.js тест переключить на него).

## Тесты

tests/craft.test.js: 9 тестов — нумерация, чистота каталога, ключи
схемы (000015), валидность всех 10 файлов по схеме, правила
(уникальные id, enum вида = схема, исходник ≠ результат, дубли),
ссылки навыки/здания (player.js, buildings.js), ссылки
заклинания → assets/spells, улучшенные способы (база: вид, результат,
уровень, исходники ⊇, без циклов), покрытие (≥1 улучшенный,
≥1 рецепт со «заклинания», обязательные ссылки у всех).
