## Ключевые решения

1. **По mobId, а не по группе**: группы подземелья — 1–3 mobId (босс —
   3: abomination + 2 lower_demon), мир-паттерн «одна группа = один
   спрайт» неприменим; каждый моб — через СУЩЕСТВУЮЩИЕ таблицы
   mobSpriteKind/MOB_FRAMES (000047).
2. **Math.floor(frameIndex(...))** — дробные координаты (смещения
   юнитов, дробная точка игрока) → дробный индекс кадра → undefined →
   молчаливый фолбэк. floor у мобов И у игрока.
3. **Фолбэки пер-юнит, не пер-группу** (паттерн 000047): один
   неисправный кадр/вид не ломает всю группу.
4. **Подсветка босса — ОДИН bounding-box-прямоугольник** (не пер-юнит),
   слой под спрайтами; рисуется только при m.boss.
5. **Сундук — ОДИН статичный SVG, состояния «открыт» НЕТ** (не
   рисуется); анимации нет (за рамками).
6. **Выход/вход НЕ спрайтятся** — решение, зафиксировано в ТЗ
   (читаемость), чтобы экран не остался «наполовину современным».
7. **Без хардкода имён/числа кадров** — только таблицы MOB_FRAMES/
   mobSpriteKind и frames.length (000062 расширяет ассеты).
