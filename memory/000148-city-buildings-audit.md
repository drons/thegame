* **D2. Формула ×4: сторона layout = 4f−2** (интерьер 4f−4, площадь интерьера
  РОВНО ×4 при f≥2): f=1 → 2×2 (хутор НЕ меняется, вырожденный — интерьер 0),
  f=2 → 6×6 (интерьер 4×4=16), f=5 → 18×18 (16×16=256), f=7 → **26×26**
  (24×24=576). ВНИМАНИЕ: a3 (audit-report §2.2) содержит АРИФМЕТИЧЕСКУЮ
  ОШИБКУ «f=7→22×22 (20×20=400)» — 400 = 2.78×, неверно; принято 26
  (4·7−2), как в plan-000148.md. Глобальный footprint на карте (1/2/5/7) и
  якоря НЕ меняются → репины ТОЛЬКО cities-пины, пины карты НЕ трогаются.
* **D3. Строимый набор** — выводится из каталога (принцип 000053: код не
  хардкодит список; источник — запись с `map_index` ИЛИ `размещение.слот`,
  ИЛИ лагерь 47 со своим каналом) МИНUS исключения с зафиксированными
  причинами: **31–35** (входы в пещеры — отдельная dungeon-система: у
  построенного в городе входа нет мирового тайла выхода), **41**
  (телепорт-круг — пары сканируются на карте мира; круг в городе без пары =
  сломанный эффект), **47** (лагерь — мировая механика костра/барахолки,
  привязанная к мировому тайлу; переосмыслить можно позже — не в этой
  серии), **50** (мост/ворота — резерв мировой механики, 000064), **51–54**
  (города — само-вложение). Итог: **21 тип** (map: 1,2,3,4,7,8,10,11,25,36,
  40,44 = 12; подтипы: 37,38,39,42,43,45,46,48,49 = 9).
* **D4. Лимит 50%:** занятые интерьерные FLOOR-клетки ВСЕМИ постройками
  (базовые + построенные игроком; многоячейочная — по всем клеткам
  footprint) ≤ 50% интерьерных FLOOR-клеток (дверь исключена); потолок =
  floor(интерьер/2) — ГРАНИЦА ВКЛЮЧАЮЩАЯ: клетка №8 при потолке 8
  допустима (потолок достигнут), отказ — с 9-й. Хутор (интерьер 0) —
  НЕ застраивается (вырожденный,
  задокументировать). Побочный зафиксированный эффект: в деревне (16 клеток,
  потолок 8) здание 3×3 (9 клеток) НЕ влезает под лимит — поведение
  зафиксировать тестом.
* **D5. Цена:** золото + ингредиенты; данные — `особые_параметры.стройка`
  записей каталога: `{ золото: int>0, исходники: [{предмет, количество}] }`
  (формат «исходники» — как assets/craft/000001.json; схема не меняется).
  Золото РАСТЁТ с размером здания (каталожный «размер» w·h) и типом;
  масштаб — от стартовых 100 золота (первое здание достижимо за 1–3 дня
  игры). Тип ингредиентов семантически соответствует типу здания
  (кузница→iron_ore+coal; таверна/дома/школы→wood_log; колодец/башня/
  руины→stone_chunk; алхимия/храмы→herb_*/sulfur; магия→moonstone;
  стрельбище/арена→hide и т.п.) — ТАБЛИЦА В ДАННЫХ каталога, не в прозе.
  Разборка: ТОЛЬКО построенные игроком; возврат 30% ЗАТРАЧЕННЫХ (золото +
  предметы), округление floor; базовые не разбираются (затрачено = 0).
