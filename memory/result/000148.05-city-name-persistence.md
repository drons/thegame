## Отклонение от контракта (задокументировано)

**LOC-19, двухъязычный (two-level) lookup в `maybeEnterCity`**: контракт §3.6
предписывал lookup только по anchor-ключу, но фикстура LOC-19
(keyed cityStates по worldKey тайла героя '5,5', а не по anchor) требует
fallback. Реализовано: сначала `ctx.cityStates.get(anchorKey)`, затем
`ctx.cityStates.get(player.x + ',' + player.y)`. В продакшене anchor всегда
попадает (main.js пишет по anchor), fallback срабатывает только в
node-фикстуре теста. Поведение игры не меняется.
