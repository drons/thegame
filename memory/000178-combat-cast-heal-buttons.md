### 3.2 Видимость — display ''/'none' на ПЕРСИСТЕНТНОМ элементе
(ключевое решение)
«Появляется только на ходу X» = display переключается по ходу на
элементе, СОЗДАННОМ ОДИН РАЗ в build() под статическим гейтом
состава партии. Динамическое создание/уничтожение в render() НЕЛЬЗЯ:
урок ревью 000149 (строки книги) — rAF-тик между mousedown и mouseup
заменяет элемент → click приземляется на родителя без слушателя →
действие теряется. display:none вынимает кнопку из потока grid →
остальные рефлоу'ятся; на ходу игрока раскладка бит-в-байт (7
табличных + resurrect = 2 ряда). Состояния c.result/ход моба —
БЕЗ спецкейсов: видимость = «активный юнит — владелец»
(activeUnit → null → скрыта; при c.result activeUnitId держит
последний id — чисто косметика, все кнопки там disabled; resurrect
ведёт себя так же — без display-тогла).
