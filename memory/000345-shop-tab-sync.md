# 000345 — диалог торговца и вкладка «Магазин» [I]: единый сток точки

## Корень бага

Один и тот же мирский тайл постройки-магазина имел ДВА независимых
канала стока:

  * вкладка «Магазин» [I]: hud.update() → ctx.worldShopFor(x,y,t) →
    `g.worldShops['x,y']` (items.makeShop, сид hash2(x,y,0x154075)^(bt+1),
    персист в сейве, окно refresh городского типа city_respawn_days —
    000314/000319);
  * диалог NPC «торговля»: main.shopFor → npcShopFor →
    npc.createNpcShop (ЖЁСТКОЕ чтение блока «торговля» npc-профиля,
    ключ `npcStocks['<id>@W:x,y']`, респавна нет).

Отсюда расхождение: каталожное «количество» ≠ фактическая полка точки
(у Милы 12 каталожных строк против 5 позиций пересечения на полке
конкретной аптеки).

## Механизм починки (план A1)

src/main.js, shopFor(npc, t): НОВАЯ мирская ветвь МЕЖДУ городской и
каталожной:

    if (!ds && t && t.hasBuilding && npc && npc.торговля
        && Array.isArray(npc.торговля.предметы)
        && G.shopKindsFor(t.building)) {
      const ws = worldShopFor(t.x, t.y, t);
      if (ws) return { npc, stock: ws.stock };
    }

ФОРМУЛА: на тайле-магазине мира диалог = ЖИВАЯ ССЫЛКА на
`worldShopFor(...).stock` — прецедент города 000107
(`return { npc, stock: s.stock }`). Живость обязательна: списание
после каждой покупки видит и [I] (тот же объект), и сейв.

Ветку ловят ТОЛЬКО тайлы с непустым G.shopKindsFor(t.building):
виды 0 Оружейная, 1 Бронник, 2 Аптекарь, 3 Лавка магии, 11 Таверна.
Прочие тайлы (Храм 8, Кузница 5, Дом NPC 12, лагерь — building=-1)
остаются на каталожном канале npcShopFor/npcStocks — контракт 000319
«респавна нет» для них сохранён буквально.

Гард `G.shopKindsFor(t.building)` в самой ветви — ИЗБЫТОЧНАЯ защита:
worldShopFor внутренне проверяет то же самое и возвращает null для
не-магазина (мутирование «вырезать гард» эквивалентно — мутант НЕ
красит поведении; красится только статический шов S5).

## Принятые деградации

1. Смена дня при ОТКРЫТОМ диалоге: shopFor резолвится при открытии,
   запись точки после refresh (prune/refill) — новый объект;
   открытый диалог держит старый stock (списания уходят в осиротевший
   объект до перезахода). ИДЕНТИЧНО семантике города 000107 — принято.
2. «Полка vs прилавок»: [I] рендерит ВСЮ полку точки, диалог —
   пересечение каталога торговца с полкой. Совпадать обязаны остатки
   и согласованное ОТСУТСТВИЕ (qty<1 → нет строки, 000314), а не
   состав строк. Это и есть задуманный дизайн разных торговцев на
   одной постройке (см. S7: Бренн/Дарн в Оружейной).
3. F2 (Кочевник ↔ лагерная барахолка) в этой задаче НЕ тронута:
   тайлы лагеря имеют building=-1 → новая ветвь структурно их не
   ловит; расхождение лагерного канала — отдельная задача.
   ЗАКРЫТА 000383 (ветвь А, третья живая ссылка): диалог кочевника на
   тайле лагеря резолвит лагерь — сток точки campStocks; контракт —
   memory/000383-nomad-camp-stock.md.
