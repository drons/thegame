  деревянный меч), «train» (действие «обучение» — профиль ТЗ),

  (src/ui.js → renderTrainTab); цена шага школы считается ФОРМУЛОЙ
  20 + 10·L² (src/npc.js SCHOOL_TRAIN_BASE_COST) — поля цен NPC для

  опции «обучить_крафт» нет, поле — данные профиля.

  потребителя пока нет (фикстуры npc-party-training-000300).
