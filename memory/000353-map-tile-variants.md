## 2. Формула выбора варианта (чистая функция координат)

`tileVariant(terrain, x, y) = hash2(x, y, MAP_TILE_VARIANT_SALT ^ terrain) % pool.length`

- `MAP_TILE_VARIANT_SALT = 0x7d150353` — экспортируемая ЗАПЁРТАЯ
  константа (пин T3), ОТДЕЛЬНЫЙ канал: не GLOBAL_SEED / CITY / SUBT /
  LOOT / VISUALS_SEED / LOOT_VISUAL_SEED / FLOOR_TILE_SALT.
- hash2 — finalizer из perlin.js (реэкспорт map.js), 0 вызовов rng,
  0 времени/игрока — как 000323. Вариант не пишется в тайл/сейв/кэш —
  всегда on-the-fly.
- `tileFramePath(terrain, x, y, now)` — единый селектор текстуры:
  многокадровые (вода) → frameIndex(now,…)-ветка 1-в-1 прежняя;
  статичные → pool[tileVariant]; неизвестный террейн → null. now
  статичную ветку НЕ касается (M2a-мутация «+floor(now/1600)» красит
  T4/T5/T6).
- Единственная точка прокатки — src/main.js `tileFrameImg` (bake
  чанков и проход 1 читают один селектор; XOR-контракт 000176).
- ЗОЛОТЫЕ РЯДЫ индексов (T3, GRASS): x-скан y=7, y-скан x=−11,
  диагональ — зависят от длины пула (=4), соли и хэша; ЛЮБОЕ
  изменение числа вариантов (напр. 4→8 по образцу 3→8 из 000323) или
  соли = ОСОЗНАННЫЙ ре-пин рядов + счётчика tests/svg.test.js +
  анти-вакуумных чисел.

## 3. Швы (конструкция, как §3 000323)

- База варианта — 1-в-1 со своего `_1`: `<defs>`-блок и первый rect
  64×64 fill=url(#…) байтово идентичны (пин T2) ⇒ краевые пиксели
  всех вариантов террейна одинаковы (тот же градиент) — соседская
  пара любых вариантов бесшовна геометрически (000215 снап краёв не
  затронут).
- Общие во всех вариантах типа также большие силуэты, выходящие за
  край у `_1`: FOREST — блок тень-эллипсов; HILL — два холма;
  MOUNTAIN — пики с подсветками, снег, rect-подножие. Различаются
  варианты ВНУТРЕННИМИ деталями (все новые детали в [0.5,63.5]):
  у grass/sand/swamp у `_1` детали и так внутри — вариантовые блоки
  целиком свои.
- aggro-visibility (000172) не затронут: правило парсинга (первый
  64×64 rect → url(#id), стопы без stop-opacity) наследуется defs 1-в-1;
  distinct-стопа = прежние 16 (анти-вакуум ≥12/≥24 — нижние границы,
  растут молча: файлов стало 30).
- Автоматического теста контурной непрерывности нет (как у 000323) —
  контракт в этом файле + визуальная проверка в tasks/result/000353.md.
