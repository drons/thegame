## 2. Решение (финальная архитектура)

### 2.1. Точка вставки и z-порядок

Один блок в `render(now)` (dungeon-ui.js) — ПОСЛЕ цикла пола города
(после закрывающей `}` цикла :477-505), ПЕРЕД слоем стен (:507-524)
и маркером двери (:534). Z-порядок города: **фон → пол → ПОСТРОЙКИ →
(стены: в городе не рисуются) → маркер двери → игрок**. Игрок всегда
поверх постройки. В подземелье слой не входит (гард `isCity`).
start()/close()/stateEl/hint/экспорт G.dungeonUI — БЕЗ ИЗМЕНЕНИЙ.
index.html — БЕЗ ИЗМЕНЕНИЙ (buildings.js :875 и sprites.js :1032 уже
грузятся ДО dungeon-ui.js :1040 → tests/index-order.test.js не
затрагивается). main.js, src/cities.js, src/buildings.js — не
трогаем (BA7-пин 'onBuildingAction' в main.js не появляется).

### 2.2. Геометрия: ЦЕЛАЯ клетка 1×1

`g2.drawImage(img, p.x, p.y, zoom, zoom)`, где `p = proj(b.x, b.y)`
= `G.worldToScreen(b.x, b.y, cam.x, cam.y, zoom, w, h)` (map.js:1101:
x = vw/2 + (tx−camX)·zoom, y = vh/2 + (ty−camY)·zoom; y вниз) — угол
клетки, размер zoom×zoom. **Правило 1×1 (000106):** базовые
постройки размещаются внутри города 1×1, каталожный размер НЕ
уважается (Арена id 7 = 3×3 в каталогe → в городе 1×1; Храм солнца
36 = 3×3 → 1×1). Многоячейочный размер — контракт 000148.03 для
built (§5).

### 2.3. Куллинг (viewport-клип)

`if (!b || b.x < x0 || b.x > x1 || b.y < y0 || b.y > y1) continue;` —
1:1 паттерн слоя стен (:514); x0/x1/y0/y1 = `visibleTileRange(cam.x,
cam.y, w, h, zoom)` (map.js:1034, margin 2) с зажатым в границы
layout (d.width−1/d.height−1) — уже посчитаны в скоупе render (:436-
439). Для десятка построек не критично, но бесплатно и единообразно.

### 2.4. Резолв каталожный id → слот (нюанс ТЗ)

Локальный ЧИСТЫЙ хелпер в dungeon-ui.js (не экспортируется —
поверхность G.dungeonUI стабильна; тестируется через drawImage):

```js
// 000148.02: каталожный id постройки города → путь спрайта СЛОТА
// (общий набор с картой мира, assets/sprites/buildings/). buildingSprite
// ключируется ПО СЛОТУ (BUILDING_TYPES 0..12), cityContents.buildings —
// каталожные id: резолв через каталог (getBuilding): базовые типы —
// особых_параметры.map_index, субтипы — особых_параметры.размещение.слот
// (прецедент 1:1 — building-actions.js:678-681). live — Game в момент
// вызова (UMD-ловушка 000038). Нет каталога/спрайтов/слота — null
// (тихий skip слоя; id 5 «Лавка странника» — город-специфичный тип БЕЗ
// map-слота — нормальный skip, не ошибка).
function cityBuildingPath(live, buildingId) {
  if (!live || typeof live.getBuilding !== 'function'
      || typeof live.buildingSprite !== 'function') return null;
  const rec = live.getBuilding(buildingId);
  if (!rec) return null;
  const op = rec.особые_параметры || {};
  const slot = Number.isInteger(op.map_index)
    ? op.map_index
    : (op.размещение && Number.isInteger(op.размещение.слот)
        ? op.размещение.слот : null);
  return slot == null ? null : live.buildingSprite(slot);
}
```

// 000148.02 (G1): постройки внутри города — слой СПРАЙТОВ поверх

// НЕ читать (000109).
if (isCity && loader) {
  const bld = (s.cityContents &&
    Array.isArray(s.cityContents.buildings))
    ? s.cityContents.buildings : null;
  if (bld && bld.length) {
    for (let i = 0; i < bld.length; i++) {
      const b = bld[i];
      if (!b || b.x < x0 || b.x > x1 || b.y < y0 || b.y > y1) continue;
