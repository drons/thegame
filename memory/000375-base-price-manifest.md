## Решённые вилки

* **A-lenient** (принято): ТЗ T2 «состав держателей НЕ пиновать списком
  файлов… принцип — обнаружение, а не реестр». Новый держатель вне
  FORBIDDEN_TO_LOSE с ВЕРНЫМ числом — зелёный (автоматически покрыт BP1);
  с неверным — красный BP1 с именем файла. В FORBIDDEN_TO_LOSE зафиксирована
  только девятерка «запрещённых-к-потере» (ловля молчаливого исчезновения
  канарейки). Число 252 в манифесте НЕ пинуется нигде — иначе он сам стал бы
  десятым устаревающим держателем.
* **B-withhold** (принято): ТЗ T4 просит строку-ссылку в
  memory/000321-potion-items.md, но скоуп запуска — чужие memory 0-diff, и в
  очереди 000373 (память-эррата b21) правит именно тот файл (ловушка «3
  держателя»→девять). Ссылка-гейт — эта строка + имя файла теста; читатель
  эрраты .373 найдёт манифест. Если .373 вольётся раньше — конфликта нет
  (мы его файл не трогаем).

## Правило-резерв (директива волнам)

Форма «base_price … ровно у <число>» (в любом регистре, со/без тире)
ЗАРЕЗЕРВИРОВАНА за глобальным счётчиком числа предметов с base_price.
Wave-файл, описывающий ПОДСЧЁТ этой фразой (например subset-счётчик), обязан
выбрать другую форму — иначе BP1 краснеет (осознанный tripwire: ложный
красный дешёв, молчаливый зелёный дорог).

При легитимном изменении каталога (items-волна двигает счётчик): переснять в
том же коммите ВСЕ иглы держателей (18 мест на базе) + assert-числа + зеркала;
манифест подстроится сам (выводит живьём), его правка не нужна. При
переименовании/удалении файла-держателя — осознанно править
FORBIDDEN_TO_LOSE.

## Границы покрытия (честно)

1. Числовые литералы ВНЕ текстовой формы иглы манифестом не ловятся:
   item-prices-000322 :524 `assert.equal(withBase, 252, …)`,
   scroll-trade-temples-000347.02 :402 `assert.equal(mirrorBase, 252, …)`
   (форма «base_price у 252» без слова «ровно» — регэкспом не покрыта).
   Порчу там ловят собственные тесты-держатели (матрица M2).
2. Разрыв иглы между строками (concat-двухстрочие, грабли .318.08) = держатель
   «исчезает» → BP2 красный по имени файла (не молча зелёный), но починка —
   ручная пересъёмка формы.
3. Комплементарный счётчик «без — у 612» и «base_price ПОСЛЕ value»
   позиционные пины, subset-формы («stats.armor — РОВНО у 12») — вне иглы
   (проверено: ложных срабатываний на базе 0).
