# npm test и worktrees — подводный камень (найдено 2026-10-01)

`npm test` = `node --test` без аргументов сканирует каталог РЕКУРСИВНО,
включая git-worktrees из `.worktrees/` (каждый содержит свою копию
`tests/`). Последствия:

* Запуск из КОРНЯ репозитория при N worktrees запускает набор N+1 раз
  (наблюдаемо: 2 копии — 2379 тестов, 3 копии — ровно 3600 = 3×1200).
* При двух копиях на одном ранге наблюдался один ложный fail, который
  не воспроизводится на чистом перепуске (интерференция/флейк между
  параллельными копиями набора).

Правило: базовый набор мерить ВНУТРИ worktree (или в корне без
worktrees; в корне с worktrees — `node --test tests/`, чтобы не
сканировать `.worktrees/`). Чистый мастер: **1696/1696 зелёных,
~85 с** (замерено 2026-10-06 после мержа 000133, коммит master
de3fcac; ранее 1200/1200 на 2026-10-01, коммит 6874050).
Наблюдение 2026-10-06: корень с двумя worktrees (task-000133,
task-000139) → 5017 тестов = набор корня + копии обоих worktrees
(набор task-000139 в процессе — свой размер).

Связано: memory/main-js-split-plan.md (серия 000127–000130 работает в
worktrees `.worktrees/task-NNNNNN`).
