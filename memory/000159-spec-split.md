## 3. Контракты и границы

### 3.1 Формат подфайла
Первая строка файла == H1 оригинала ДОСЛОВО (`lines[0] === '# <H1>'`; без
шапки/пустых строк перед ним). Внутри — все строки до следующей H1 (вкл.
завершающую пустую строку раздела — часть блока). R2 пинает: строка 1 +
присутствие ВСЕХ H2/H3 раздела (карта §2).

### 3.2 Инвариант 1:1 (проверка стадии реализации, не перманентный пин)
`concat(22 блока в порядке TOC, '\n') === git show HEAD:SPEC.md` ПОБАЙТОВО.
Блоки 1-21 заканчиваются `\n` (пустая строка-разделитель — часть блока),
блок 22 (items.md) — БЕЗ `\n`. Тестовые конкатенации — ВСЕГДА `join('\n')`
(никогда `join('')`), чтобы H1 следующего файла гарантированно на новой
строке для `^# …` (m-режим).
