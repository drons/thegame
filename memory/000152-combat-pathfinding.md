## Где живёт A* (модуль/функции)

`src/combat.js` — ЕДИНСТВЕННЫЙ файл ядра (новых модулей/ассетов/тегов НЕТ):

* Блок «шагов» после `stepAway` (~:606), до `allyStepToward` (:612):
  * `PATH_DIRS = [[0,-1],[0,1],[-1,0],[1,0]]` (↑ ↓ ← →, канон stepAwayRect);
  * `pathField(c, u, goalTest)` — внутренняя, чистая: мульти-источниковый
    BFS (источники — проходимые клетки с goalTest; FIFO очередь массив+индекс;
    соседи 4 в PATH_DIRS; проходимость — `rectFree` c ignore=u) →
    `Map 'x,y' → dist`;
  * `probeGreedyStep(c, u, r)` — внутренняя, чистый 1:1-проб жадного шага
    (логика stepTowardRect, без мутации) → `{x, y} | null`;
  * `pathStepTo(c, u, r, reach)` — экспортируется (рядом `reachableCells` в
    return-объекте): поле → жадный проб с **вето поля** → A*-шаг (мин. поле,
    тай-брейк PATH_DIRS) → `true` (мутация u.x/u.y) / `false` (стоим);
  * `pathStepFrom(c, u, r)` — экспортируется: ретрит (goal = d > d0).
* Встраивание — closure в `mobAct` (:1335–1336).

Алгоритм — BFS-поле расстояний + одношаговый спуск («A* или схожий» — ТЗ
допускает): на равномерной 4-соседней сетке поле BFS = оптимальные пути,
значения поля единственны → детерминизм без приоритетных очередей.

## Тай-брейки (фиксированные)

* Выбор шага: минимальное значение поля BFS среди 4 rectFree-соседей;
  равенство — первое направление **PATH_DIRS** (↑ ↓ ← →), строгий `<`.
  ЕДИНСТВЕННАЯ точка выбора.
* Вето жадного: жадный (проб stepTowardRect) принимается ТОЛЬКО если
  `field(greedyCell) < field(current)` (строгое улучшение); иначе A*-шаг.
  Без вето — ливелок (3,3)↔(2,3) в главном RED-сценарии (a3, livelock-
  check.js).
* Запрещено: Math.random, c._rng в path*, итерация Map/Set в логике выбора
  (только get по ключу) — детерминизм боя и поток RNG не сдвигаются.
* Пин тай-брейка: «волк за камнем» — первый шаг (2,3) (левее раньше правее:
  f(2,3)=3, f(4,3)=3, f(3,2)=5, (3,4)=камень).

## Целевая дистанция (reach)

* **Ближний** (melee/shield/swarm/support/leader): reach=1 — дойти вплотную
  (rectDist ≤ 1 — граница атаки) и бить.
* **Дальнобойный** (ranged): reach=RANGED_MAX_DIST=4, И ТОЛЬКО в ветке
  dToP>4 («слишком далеко»): дойти до полосы d≤4 и ОСТАНОВИТЬСЯ; дальше —
  атака (d≤4) и паника-отступление (d≤1). reach=1 для ranged запрещён
  (осцилляция «подход-паника»).
* Ретрит (pathStepFrom, паника/TIMID-побег): без reach — любое «дальше
  текущего d0» (жёлтый шаг: шагaway жадный первым, pathStepFrom при false).

  u.role === MOB_ROLES.RANGED && dToP > RANGED_MAX_DIST ? 4 : 1);
const stepFromTarget = () => stepAwayRect(c, u, target) || pathStepFrom(c, u, target);

* Все ролевые ветки (RANGED :1359–1367, SUPPORT, LEADER, melee-цикл с

* Цели — `nearestPlayerSide` (игрок ИЛИ союзник, 000080) — без изменений.
* На чистом поле — бит-в-бит со старым жадным шагом (V3: 44/44 позиций) →
  потоки c._rng не сдвигаются; A*-логика срабатывает только при блоке/
