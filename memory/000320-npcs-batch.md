# 000320 — батч «100 NPC»: механизм мульти-NPC и распределение

Родительская задача: tasks/pending/000320.md (100 подзадач
000320.01–000320.100). Механизм «несколько NPC на постройку» и первый
NPC батча (Корд) — 000320.01 (memory/000320-blade_merchant.md,
tasks/result/000320.01.md).

## Механизм (готов, переиспользуется всеми подзадачами батча)

- src/npc.js `npcsForBuilding(npcs, buildingId)` — ВСЕ NPC постройки
  (поле `постройки` — id записей каталога зданий), ПОРЯДОК = порядок
  массива каталога = нумерация файлов assets/npc/NNNNNN.json;
  `npcForBuilding` = [0] (HUD «Здесь:», сток города — НЕ менялся).
- src/building-effects.js `buildingActions` — `npc` = объект | массив |
  null; на каждого NPC строка «Диалог: <имя>» (id первой 'dialog',
  остальных 'dialog:<id NPC>', поле npcId), затем эффекты.
- src/building-actions.js — toggle (мир) и interactCity (город)
  собирают список через `npcsForBuildingOrFallback` (fallback —
  [npcForBuilding] для тестовых фейков без npcsForBuilding);
  openBuildingUI вызывает buildingActions с `list.length ? list : null`
  (пустой массив truthy — городские фейки `if (npc) push` нал бы
  строку-призрак); onBuildingAction — маршрутизация dialog-строк по
  action.npcId; ветка делегирования (без buildingUI, вне [E]-пути) —
  НЕ тронута (npcForBuilding).
- spec/npc.md — H2 «Несколько NPC на постройку» (контракт порядка/
  подписи/id); 48 строк.

## Рецепт каждой подзадачи 000320.YY

1. Новый файл assets/npc/NNNNNN.json (следующий свободный номер!) с
   фиксированными Размещением/Ролью/Профилем из ТЗ; `постройки` —
   ССЫЛКА на файл здания (в зеркале — id); опции диалога — по профилю
   (действие enum: торговля / обучение / квесты / подсказка / найм;
   scope `для` — 000299.02; требования — харизма и т.п. по ТЗ);
   торговля (если в профиле) — формат 000322: {предмет,
   mult_покупки? (при 1 — ключа НЕТ), mult_продажи, количество 1–99},
   база — base_price предмета; roundtrip JSON каноничен (2 отступа,
   \n).
2. node scripts/sync-npc-data.js — перегенерировать src/npc-data.js
   (зеркало и JSON — в ОДНОМ коммите; sync:check красный до коммита).
3. Ре-пины: tests/npc-refs.test.js (файлов / ссылок построек / ссылок
   торговли / всего), tests/building-effects.test.js A60 (NPCS.length),
   deepEqual-пины оверлеев затронутых зданий (хоткеи Digit1..9 —
   строки 1..9; эффект за 9-й строкой — только клик), spec-split и
   wording — ТОЛЬКО если менялся spec/.
4. Уникальность id/имени/описания по всему каталогу — свип
   tests/npc-000320.01.test.js N3/N4 (расширять нельзя, он общий).
