## 6. Решения Проектирования (решение — почему)

1. Формат ссылки — по контракту 000211 §2 без изменений; per-catalog
   паттерны в схеме — единый формат 11 каталогов, ничего не
   изобретать (000211.01-сweep совместим: per-catalog — подмножество
   якорного).
2. Мигрированы ровно 4 группы полей (212 значения); `база`/
   `заклинания` — вне скоупа (ТЗ явно; §5.3 — где закрываются).
3. Резолв только в sync, рантайм не тронут — file:// (000053),
   data-модули без require, сейвы id-форма (000031).
4. Зеркало byte-идентично (не в диффе) — главный инвариант
   «без смены поведения»; доказано песочницей (diff пустой,
   идемпотентно); гейты: deepEqual-зеркало (resolved view),
   «пересборка не меняет модуль», vm-тесты, git diff + sync:check.
5. Строгий резолвер в sync (exit 1 на битую ссылку/не-JSON/без id/
   не по паттерну) — сборка = enforcement контракта (000141);
   детерминированно; на валидном каталоге не срабатывает.
6. БЕЗ CLI-root-аргумента в sync-craft-data.js; R3/R4 — tmp-репозиторий
   с копией реального скрипта (makeTmpRepo-паттерн sync-all.test.js;
   скрипт резолвит ROOT из __dirname) — CLI 1:1 с соседними
   sync-скриптами (прецедентов root-аргумента у отдельных sync-скриптов
   нет, кроме sync-all.js), тестируются точные байты файла.
7. Schema — 4 pattern-закрепления в ТОМ ЖЕ коммите (000141); здания
   integer→string — единственный type-брюк, недвойственность исключена
   (type до pattern).
8. Block «ссылки» — переписан под refId → id, RANGE 1..50 СОХРАНЁН на
   резолв-ид (000211.04 заменяет на membership по 54 — ТЗ 000211.04
   явно правит этот range «синхронно»; мерж строго после 000208).
9. Тест-хелперы ЛОКАЛЬНЫЕ (без scripts/lib) — 000211.01 был
   параллелен, зависимость = риск mержа в любом порядке (контракт
   000211 §1.4: «параллельность не блокируется ожиданием 000211.01»).
10. Миграция JSON — хИРУРГИЧЕСКАЯ замена значений в raw-тексте
    (якоря: `"предмет": "<id>"` в строках результат/исходники;
    строки `"навыки": […]`/`"здания": […]` — всегда inline
    single-line, проверено по 31 файлу), НЕ JSON-round-trip — все 31
    файла НЕКАНОНИЧЕСКИ (вложенные объекты в одну строку:
    `{ "предмет": "…", "количество": 1 }`), round-trip переформатирует
    все файлы (diff-шум, нарушение «только значения»). Per-file гейт
