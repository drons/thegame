## Цепочка гардов [Esc] (ревью раунды 2–3 — ВАЖНО для будущих оверлеев)

Панель вешает СВОЙ document keydown-слушатель, живёт только пока
панель открыта (attach на open, detach на close, guard isOpen()).
Esc — «закрыть верхний слой»: document-слушатель срабатывает ДО
window-слушателей оверлеев (bubble: document → window), поэтому
гарды — В СЛУШАТЕЛЕ ПАНЕЛИ, а не stopPropagation:
1. `G.npcUI.isActive()` — диалог NPC открыт → return (раунд 2);
2. `G.combatUI.isActive() && current().result` — оверлей
   РЕЗУЛЬТАТА боя (combat-ui.js, `current()` → ctx.combat) →
   return (раунд 3). Во время самого боя (result не установлен)
   Esc оверлей не закрывает — и тогда ЭТОТ гард не срабатывает:
   Esc закрывает панель (штатное управление панелью в бою).
НОВЫЙ закрываемый-по-Esc оверлей поверх панели — добавлять гард
по этому же паттерну (typeof-guards, терпимость к стабам).
