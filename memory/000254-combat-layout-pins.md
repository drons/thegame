## Решения (по каждому — почему)

1. (в) Пинить отсутствие И `flex-grow`, И шорткат `flex` (а не
   только flex-grow) — шорткат задаёт grow: future-правка

   под регрессию = тот же баг, что не пинатся сегодня.
2. (в) НЕ вводить `flex: 0 0 auto` в index.html — ТЗ: ноль
   CSS-диффа, «сейчас отсутствует — запинать отсутствие»;
   явное 0 0 auto добавит diff без изменения поведения.
3. (г) Ассерт min-height === '0', а НЕ правка текста сообщения
   пина — предписание ТЗ; текст portrait-пина L151–154
   («берёт min-height: 0 из скоупа») остаётся истинным без
   правки; ассерт делает декларацию закреплённой, а не
   «только упомянутой».
4. (е) Дуальная запись «N-й (idx M)» (первый вариант,
   предложенный в ТЗ) — red-сообщения описывают pre-fix master,
   где обе системы нумерации нужны читателю одновременно;
   везде idx — потеряло бы «из 7» (сколько всего детей).
5. (e) L1311 (ACT-LAST) НЕ трогать — не в списке координат ТЗ;
   «ПЯТЫМ из 7» самодостаточен (1-based + «из 7» = однозначно);
   ретро не ставило его в findings.
6. (f) 1 логическая строка = 2 физических (L13–14) из-за
