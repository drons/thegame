## 2. Пункт 4 — РЕШЕНИЕ: машинный запрет класса на ВСЕ tests/ (вариант A)

сиблингов):

  F1 `HEAD:`+`src` (литерал), F2 `'HEAD:'` + идентификатор вне allowlist, F3 `'HEAD:'`+`'src…'`,
  F4 ``HEAD:${`` (template-literal — ЗАКРЫТИЕ кросса C), F5 `'HEAD:'` + `(` (скобочная
  конкатенация — ЗАКРЫТИЕ кросса C), F6 `'HEAD:',` (голый элемент join/массивной сборки).

  `items-rename-000318.08.test.js: [LEDGER_I08_REL]` (T11 append-зуб реестра),
  `skills-rename-000318.09.test.js: [REGISTRY_REL_I09]` (T11 append-зуб реестра, digest-страховка 000396 T1),
  `items-spec-bytes-log-000386.test.js: [t]` (T5 append-only лог `memory/000230.16-c9/*.md`),
  `items-reagent-000321.10.test.js: [rel]` — ВРЕМЕННАЯ запись, см. п.3.
- Свип требует присутствия КАЖДОГО allowlist-файла в сканируемом списке (протухший
  allowlist при переименовании файла красён) + пол широты скана (анти-вакуум обхода).
- Постоянная таблица истинности детектора — блок `000395 T8` (красные F1–F6 + зелёные:
