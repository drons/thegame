# Раздел сейва `explored` (задача 000093) — контракт данных

Краткий контракт раздела; полный контракт задачи —
`memory/000093-explored-tower.md`.

## Форма

- Имя — `explored` — ФИКСАЦИЯ 000072 (список имён разделов; не
  переименовывать, не резервировать другие).
- Позиция — `data.explored` — plain object:
  `towerKey 'x,y'` (тайл башни) → строка `'x,y;x,y;…'` — ключи тайлов
  окна, Chebyshev-радиус R, **граница включительно**.
- R = 20 — ТОЛЬКО из каталога
  (`особые_параметры.эффект.радиус` в 000046.json, 000053); фолбэк 20 —
  только когда объект эффект есть, но радиус не integer ≥ 0.
- **Максимум 41×41 = 1681 ключей на башню** (закладка в тесте A60;
  защитный R-фильтр `markExplored` держит кап даже при «лишних» тайлах).
- Канонический порядок строки — **row-major: y по возрастанию, затем x,
  ЧИСЛЕННАЯ сортировка** — единая сериализация: roundtrip
  serialize→restore→serialize byte-identical, deepEqual-тесты
  детерминированы. (НЕ строковая сортировка: «10» < «9» сломало бы
  канонику при |координате| > 9.)

## Семантика

- **Независимо от проходимости**: окно — данные разведки, не проходимость;
  вода/горы/чужие постройки помечаются (в окне (36,-21) — 387
  непроходимых тайлов; e2e-пин — ровно 1681).
- **Идемпотентно**: повторное «Взглянуть» — объединение множеств,
  дубликатов нет (Set); повтор — тот же explored (deepEqual).
- **Без лимита раз-в-день** (ТЗ): взгляда днём может быть сколько
  угодно; `раз_в_день` в каталоге НЕТ, `разВДень` в реестре НЕТ →
  `hasDailyLimit('46') === false`.
- `towerKey` — тайл башни, на которой стоит игрок (конвенция [E]).
  Разные башни — разные строки раздела (мульtibашня — по башням).

## Состояние и сериализация

- Живая форма — `Map<towerKey, Set<tileKey>>` в **main.js**
  (не `__game.state`; паттерн 000072: buildingOncePerDay/buffs/teleports/
  buildingQuests).
- Снимок — `G.buildingEffects.serializeExplored(m)` (plain object,
  каноническая строка; пустая башня не пишется).
- Восстановление — `G.buildingEffects.restoreExplored(raw)` — ЧИСТОЙ,
  тихий fail-open (без throw, без console): не-object/Array/null →
  пустой Map; мусор в записи → сегменты фильтруются (XY_KEY_RE);
  пустая запись → отброшена. **console.warn — только в main.js
  restoreFromSave** (свой try/catch, паттерн teleports 000072):
  «Сейв: раздел explored некорректен — сбрасываю.» / «Сейв: explored —
  валидных записей нет — сбрасываю.» / catch — «…не удалось
  восстановить explored: …».
- Битый раздел — fail-open (000029): игра не роняется, раздел сброшен
  в пустой; следующий сейв запишет `{}`.
