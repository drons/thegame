# 000371 — тестовой зуб на состав FORBIDDEN (закрытие находки M4b ретро-b20)

## Дефект (зафиксирован ДО правки)

Константа `const FORBIDDEN` в `tests/scroll-trade-temples-000347.02.test.js`
(67 подстрок, переснято по диску базы `ebd538b7`: длина 67, дублей 0,
set-равна массиву T5 `tests/npc-000320.21.test.js`) нигде не была запинена по
длине/составу. Снапшот дефекта: вырез элемента `'звон'` из нетронутого файла
на tip — `node --test` по файлу даёт 8/8 ЗЕЛЁНЫЕ (/tmp/forbidden-teeth-defect-base.tap).
Единственный потребитель списка — цикл guard в T7 (подстроки проверяются
только против текстов жрецов; ослабление списка молча зеленовало).

## РЕШЕНИЕ: вычитывание массива T5 .21 из ИСХОДНИКА соседнего теста

Три канонических носителя — «set-равенство с T5 .21» — выбирались так:

1. `require` соседнего test-файла — НЕЛЬЗЯ: `test()` из `node:test`
   зарегистрировался бы повторно и удвоил бы TAP-число. Require между
   test-файлами в сьюте отсутствует (проверено свипом).
2. Core-хелпер `tests/scripts/*.js` по образцу `canon-items-sync-core.js` —
   НЕЛЬЗЯ без правки `tests/npc-000320.21.test.js` (перенос его массива в
   хелпер = ре-пин файла, запрещённый задачей; параллельная .320.25 и так
   трогает .21).
3. Sorted-манифест inline — можно, но дублирует 67 строк в том же файле и
   НЕ ловит расхождение самого .21 (цепочка продолжала бы держаться prose).

Выбран вариант вне списка ТЗ, но с прямым прецедентом конвенции: **чтение
текста соседнего test-файла** — `tests/canon-items-sync-000284.02.test.js`
читает `spec-000230.16-wording.test.js`, `tests/e9-header-canary-000274.test.js`
читает `items.test.js`, `tests/final-repins-000243.test.js` читает
`items.test.js`/`ui.test.js`. Зуб:

- `FORBIDDEN.length === 67` — ловит вырез (M1) и лишний элемент (M2);
- `new Set(FORBIDDEN).size === FORBIDDEN.length` — контроль уникальности;
- из текста `.21`: якорь `src.indexOf("test('T5:")` → первый `for (const w of [`
  до ближайшего `]` (ни одна из 67 строк не содержит `[`/`]` — скобок в
  оборотах нет, матчинг однозначен) → выборка кавычек `/'([^']*)'/g`;
- `list21.length === 67` — пин источника цепочки (сдвиг T5 .21 без синхрона
  в temples красит ЗДЕСЬ, а не молча разъезжается);
- `deepEqual(sorted FORBIDDEN, sorted uniq list21)` — set-равенство
  (ловит правку строки M3 в ЛЮБОМ из двух списков).

Всё — ВНУТРИ существующего T7 (новых test-блоков 0, TAP-число не меняется;
имена тестов и маркеры «запрет-лист 67 подстрок» не тронуты — в сообщениях
exact-фраза маркера намеренно НЕ встречается, чтобы не ломать TAP-счётчики
маркеров).
