Прежний порядок = порядок файлов = нумерация 000001–000055. У номеров не
осталось носителя после rename ⇒ порядок — по id (лексикография кодовых

расположения отличаются 53 позиции из 55 (старый первый stone_hide,
новый первый alembic_mark).

(src/building-effects.js): cands обходом G.RunesData.RUNES, пик =
hash2(x, y, RUNE_CRAFT_SEED ^ day) % cands.length. Контракт детерминизма

игроку изменение → буллет CHANGELOG (секция даты мержа).
Резолвы по id (ui.js runeLine/runeIconsOf, items.js canonicalRunes,
