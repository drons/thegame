  валидатор tests/json-schema.js, ключи схемы ⊆ ALLOWED_SCHEMA_KEYS.
* Формат файла — roundtrip-канон JSON.stringify(obj,null,2)+'\n',
  НОВЫЙ каталог — заморозка T8 БЕЗ исключений (прецедент 000326 T4;
  schema.json — вне roundtrip-скоупа, только NNNNNN.json).
* Эффект — объект с дискриминатором type, ДВА машинных типа (одинOf с
  const type — дизъюнктны, амбигуитет невозможен, T9 пинит «ровно одним
  вариантом»):
  (1) derived {type:'derived', stat:<1 из 37>, amount:<number −100..100>}
      — потребителя в коде ещё НЕТ: 000328.02 ОБЯЗАНА применять
      derived'(stat) = derived(stat) + amount к носителю; amount —
      БАЗОВОЕ значение (масштабирование runePowerMult — решение механики).
  (2) skill {type:'skill', skill:<secondary-id>, amount:<number −100..100>}
      — affix-стиль 1:1 с аффиксами предметов (mergeAffix src/items.js:
      1424–1441, pct() src/sheet.js:481–485): skills[skill] += amount,
      множит per-level эффект навыка (1+сумма). SKILL ∈ только 31 id
      type:'secondary' из assets/skills — pct() читает SECONDARY_SKILLS,
      school/primary-ссылка была бы мёртвым эффектом.
  Третий тип эффектов ЗАПРЕЩЁН решением анализа (нет потребителя до .02).
  Юмор — НЕ отдельный тип: несётся названием/описанием, механика real.
* Каталожность skill (∈ secondary) схемой НЕ проверяется (форма — схема,
  каталожность — тест T5; прецедент D4 affixes items).
* Название/описание: непустые (^\S(.*\S)?$) и ГЛОБАЛЬНО уникальны (T2);
  id уникальны (T2); эффекты уникальны по canonical-сериализации
  (сортировка ключей; T4; 55 уникальных ≥ 50 по ТЗ).
