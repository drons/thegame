# 000176 — Постмортем: дублирующийся/«старый» рендер глобальной карты

(2026-10-09; диагностика по коду master `3d5bac4` + git f34171d +
vm-песочница. Контракт фикса — `memory/000176-global-map-single-pass.md`.)

## Симптом (брач)

Иногда на глобальной карте — старые (цветные, без текстур) тайлы и
«геометрическая фигура» вместо Флогистона — вид до 000011; подозрение:
дублируется отрисовка, излишне нагружает компьютер.

## Корневая причина: два параллельных draw-прохода, левый — безучловный

000011 (коммит f34171d, «Ассеты — анимированная 2D-графика (SVG)»)
НАЛОЖИЛ новый 2D-спрайт-слой поверх прежнего WebGL-мира и **не удалил
прежний draw-путь** (коммит-сообщение прямо фиксирует: «фолбэк — прежние
цветные тайлы/маркеры»). Итог в src/main.js (мастер 3d5bac4, строки
до фикса):

* **WebGL-проход (до-000011 сцена, «фолбэк»)** — `buildFrame(rp)`
  L2253-2299, вызов в `frame()` L2576, `gl.drawArrays` L2577 — рисовался
  БЕУСЛОВНО каждый кадр:
  * цветные квад-тайлы: `pushQuad(…, TILE_COLORS[t.terrain] +
    map.brightness*0.05)` — L2265-2269, для КАЖДОГО видимого тайла;
  * золотые маркеры построек (`BUILDING_COLOR [0.98,0.83,0.30]`) —
    L2272-2273, по `t.hasBuilding`;
  * красные маркеры групп мобов (`MOB_COLOR [0.85,0.30,0.25]`) —
    L2274-2275, по `t.hasMobGroup` **БЕЗ учёта `G.groupVisible`/
    defeatedAt** (000122 спрайт-слой побеждённые скрывает, WebGL — нет);
  * «геометрическая фигура» — светящийся ромб Флогистона
    (`PLAYER_COLOR [0.55,0.95,1.0]`, s=0.28, 6 вершин, центр rp+0.5) —
    L2283-2291.
  WebGL setup — L124-191 (шейдеры, vbo, legacyOrtho); guard no-WebGL —
  L125-128.
* **Спрайт-проход (000011)** — `drawSprites(now, rp)` L2309-2475 на
  2D-canvas `#sprites` ПОВЕРХ: early-return `readyCount()===0` L2313,
  4 прохода по `frameTiles` (L2251, наполняется в buildFrame): текстуры
  тайлов+декорации (L2366-2391), постройки w×h от якоря (L2393-2431),
  мобы (L2433-2449), Флогистон (L2451-2474).
* Цикл — ОДИН: `frame(now)` L2505, rAF L2587 (старт L2805) — второго
  rAF/двойной подгрузки main.js нет (проверено).

Следствия — по пунктам брача:
1. **«Дублируется отрисовка / нагружает компьютер»** — структурно: те же
   сущности дважды на кадр. Нагрузка — в legacy-проходе: каждый кадр
   `new Float32Array(verts)` по всем видимым тайлам + `gl.bufferData`
   (GPU-загрузка). Цифры (спавн-мир, zoom 80, 1280×720): 198 тайлов →
   1242 вершины (ромб 6, постройки 18, мобы 30) + 394 drawImage
   спрайт-слоя; при обзорном зуме 4: ~58.6k тайлов → **~358k вершин на
   кадр** — всё под готовыми непрозрачными текстурами (SVG-тайлы
   полноформатны с непрозрачным фоном — прорыва в готовом состоянии нет).
2. **«Иногда старые тайлы … как до 000011»** — спрайт-слой пуст/неполон:
   старт/«Начать заново» (299 ассетов заново; до `readyCount()>0` слой
   пуст — L2313), onerror конкретного ассета (createSpriteLoader: retry/
   timeout НЕТ — зависший запрос живёт в 'loading' вечно), частичная
   загрузка. Тогда единственный видимый слой — безучловный WebGL = точный
   вид до 000011.
3. **«Фигура вместо героя»** — (а) упал спрайт Флогистона → герой = ромб;
   (б) **штатный геймплей (самый воспроизводимый «иногда»)**: после
   победы над группой на карте спрайт-слой скрывает её (000122, проход 3),
   а красный квадрат WebGL-маркера ОСТАЁТСЯ там, где мобы были —
   «геометрическая фигура» без причины.
4. Золотые маркеры/ромб в нормальном состоянии скрыты под большими
   спрайтами — дубли не видны, нагрузка остаётся.

## Фикс (000176)

Поэлементный гейт legacy-прохода по готовности спрайта (контракт —
`memory/000176-global-map-single-pass.md`): в `buildFrame(rp, now)`
legacy-вершина каждого элемента рисуется только если спрайт-слой не
может нарисовать элемент; селекторы готовности вынесены в общие хелперы
(`tileFrameImg`/`mobFrameImg`/`heroFrameImg`/`buildingAsset` +
`buildingRec`), которыми пользуются ОБА слоя — дрейф исключён. Красный
маркер дополнительно гейтится `G.groupVisible(defeatedAt, x, y)`
(паритет с проходом 3 — фикс «прола»). Контракт фолбэка 000011
сохранён (элемент без готового спрайта → его legacy-фигура; loader
null → legacy-сцена полная). Штатное состояние: 0 вершин в WebGL-проходе
— рендер мира = один проход (спрайты).

## Как верифицировать single-pass

* **Автоматически** — tests/global-map-draw.test.js (vm-песочница, цепочка
  index.html; усилённый gl-стаб пишет `glCalls`: bufferData→data.length,
  drawArrays→count; Image-стаб с rejectSet; e2e победы — паттерн
  mob-zones-e2e):
  * RM-3 (RED→GREEN): ready-кадр — **0 вершин** в WebGL-проходе;
  * RM-2 (RED→GREEN): ready-кадр — **0 вершин PLAYER_COLOR** И ровно
    1 drawImage спрайта Флогистона (hero exactly once, no legacy figure);
  * RM-7 (RED→GREEN): после победы над видимой группой (defeatedAt) —
    **0 вершин MOB_COLOR** (прол закрыт);
  * RM-1 (guard): hero drawImage ровно 1×;
  * RM-4 (guard): все ассеты failed → 0 drawImage, legacy-кадр полон
    (6 PLAYER-вершин + тайл-квады) — контракт 000011 жив;
  * RM-5 (guard): упал ТОЛЬКО спрайт героя → 0 hero-drawImage, ровно
    6 PLAYER-вершин (фигура = фолбэк, не пропажа), тайл-текстуры на месте;
  * RM-6 (guard): 1 rAF + 1 clearRect(#sprites) на кадр — второго цикла
    нет.
* **Вручную**: (1) перезапустить игру — на время загрузки видны цветные
  тайлы/ромб (осознанный фолбэк), затем текстуры и Флогистон появляются
  поэлементно; (2) в штатной игре — ромба/цветных тайлов ПОД спрайтами
  нет, после победы над группой красный квадрат НЕ остаётся; (3)
  performance/инструменты — при зуме 4 буфер вершин на кадр = 0 (было
  ~358k).
* **Регрессия**: весь npm test (база 1905) зелёный без правок — ни один
  существующий тест не смотрит в WebGL-буфер (стабы noop), геометрия
  спрайт-слоя побайтово зафиксирована main-visuals/camp-map-e2e.
