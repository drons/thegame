## Seed zone-боя

`G.hash2(gx, gy, 0x5eedc0de)` — от тайла ГРУППЫ, ТОТ ЖЕ salt, что
у seed строки (main.js :1628). Старт НА тайле группы =
hash2(player) — ЗНАЧЕНИЕ НЕ МЕНЯЕТСЯ (существующие createCombat-
пины не сдвигаются; соль в репо не пинится). Старт с края зоны —
новая точка (единственный якорь боя: tile/terrain/groupType/
key/quest — ВСЁ от тайла группы).

## HUD-строка (src/hud.js, ветка else-if после hasMobGroup)

* в зоне триггерящей группы (ВНЕ её тайла) —
  `'\nОсторожно: <группа> — зона'` (тире с пробелами, без «!»);
* на тайле группы — СТАРАЯ строка («Осторожно: …!» / «повержена.»)
  побайтово (пин HU4 h/i);
* вне зон / нейтральная группа в 3×3 / поверженная сегодня группа
  в зоне / подземелье-город — ТИШИНА (findZoneCombat фильтрует
  defeatedAt; dist 0 → suppress).
* поле ctx: `zoneGroup` — 17-е ОПЦИОНАЛЬНОЕ (ЗНАЧЕНИЕ, null вне
  зоны); поверхность Game.hud = 6 экспортов (без изменений).

## Guard defeatedAt (ОБЩИЙ, вынесен в начало maybeStartCombat)

Ключ = ТАЙЛ ГРУППЫ, формат 'x,y' → день (без изменений, сейвы
совместимы). `defeatedAt.has(key)` — зона И тайл не триггерят;
победа в zone-бое ставит тот же ключ. Респаун (dueForRespawn) —
как до: группа «вернулась» → следующий шаг в зоне → бой.

## Триггер — только на успешном шаге

`maybeStartCombat(scanZones)`: frame передаёт true; старт/restore/
телепорт — tile-only (не шаг). Бой > вход в локацию
(`if (!maybeStartCombat(true)) enterLocation()` — тайл входа в
зоне: два оверлея в одном кадре недопустимы, вход откладывается).
Spawn (0,0) в фолбэк-мире вне всех триггерящих зон (regression-пин
Z7).
