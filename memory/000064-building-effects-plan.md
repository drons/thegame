## Решения (дублируют SPEC «Эффекты построек» — коротко)

* buildingUI — единый оверлей (000071): [E] = «Диалог» (если NPC)
  + эффекты реестра (src/building-effects.js, чистый UMD).
  Счётчики «раз в день» — на ЭФФЕКТ ('x,y:effectId'), не на
  здание (фонтан: исцеление лимит / монета — нет).
* Сейв: новые разделы (buildingOncePerDay, buffs, teleports,
  buildingQuests, buildingContent, explored, стоки лагерей) —
  неломко, v1 без повышения; дни абсолютные (fastForward без
  слушателей); тест-фиксатор против «_lastUnkillDay-регрессии».
* ГЕНЕРАЦИЯ — ловушка: новые map_index (13→N) меняют слот на
  почти всех тайлах — ЗАПРЕТ. Подтипы слотов 8/9/10/11/12 —
  второй hash (seed ^ const) по долям каталога (размещение
  {слот, доля}); tileAt + buildingId; slot/footprint/спрайт —
  инвариант. Слот 9: вход 80 / развалины 20 — развалины НЕ вход
  (maybeEnterDungeon по buildingId); −20% входов сознательно.
* Храмы — действия buildingUI (NPC-схему НЕ расширять; enum
  жёсткий + коллизия 000065). Солнце: +5% урон 1 день (удар/
  стрельба/заклинания) — buffMods как параметр формул (derived
  не трогать); гора: +1 броня 1 день; луна: сон-подсказка
  (ближайший вход + dungeonTypeFor).
* Камень/обелиск: шанс min(1, 0.25+0.05·Рунопись), XP камня
  round((10+2·Рунопись)·runePowerMult) (явный потребитель
  существующего derived), обелиск — round((5+2·уровень мира)·xpMult) + квест
  постройки (источник 'building', лимит/логика NPC не ломать).
* Телепорт: Chebyshev R=100, тай-брейк hash, «спит» без пары;
  разовая оплата; скан — первый подход + кэш в сейве.
* Круг/заброшенный: ролл (tile,day) 60/30/10; босс — существующие
  MOB_TYPES (новый GROUP_RECIPES), реликвия — id assets/items.
* Таверна: отдых = clock.rest, слухи детерминированы; НАЙМ — за
  000065 (не описывать/не реализовывать).
* Фонтан: исцеление 25%/25% раз в день + монета min(1,
  0.2+0.05·Ловкость) без лимита («Удача» — плейсхолдер, навыка
  нет). Колодец: min(1, 0.15+0.05·Тать), предмет по (tile,day).
* Башня: explored R=20 (Chebyshev) в сейве (компактно, ≤1681
  ключей/башню), идемпотентно; миникарта — отсрочена (отдельная
  задача при потребности, номера не резервировать).
* Развалины: (tile,day) лут 40/ловушка 30 (урон 2, HP≥1, без
  боя)/запись 30 (порог Интеллекта — каталог).
* Лагерь: костёр = clock.rest; барахолка — сток по 000029 (сид
  (tile,day), respawn_days, wealth; ключ — тайл, НЕ id NPC);
  NPC «кочевник» — только новая запись (schema.json не трогать;
  при коллизии с 000065 — ждать).
* Мост/ворота (id 50): НЕ генерируются (проходы = MOB_GROUP_
  TYPES); элемент городов (000052); id 50 — резерв.
* Порядок: P0 000071+000072 (до них не мержить) → P1 000073 →
  P2 000074/75/76 → P3 000077/91/92 → P4 000093/94/95.
  000073 × 000055 (зеркало buildings.js: до — вручную, после —
  sync-buildings-data.js); 000095 и 000091 × 000065 (NPC-схема —
  000065 первая).
