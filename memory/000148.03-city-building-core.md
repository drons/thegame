## 4. (c) canBuildAt-контракт

`canBuildAt(layout, anchor, id, occupied)` → `{ok: true} | {ok: false, reason}`.
- layout — {width, height, cells, entrance} от createCityLayout (96-119: 4f−2,
  дверь южный периметр y=H−1, интерьер [1,W−2]×[1,H−2] весь FLOOR). Валидация
  формы — throw 'cities.js: …' (ошибка caller).
- anchor — {x, y} целые, ВЕРХНИЙ-ЛЕВЫЙ угол footprint (конвенция buildings.js
  placeBuilding :808 — tiles (x+dx, y+dy)).
- id — int, ∈ каталоге (иначе throw).
- occupied — Set<'x,y'> | Array (нормализуется в Set) — cityOccupied(
  ds.cityContents.buildings).
Порядок проверок: (1) space — все w·h клеток footprint в [1,W−2]×[1,H−2], FLOOR,
не в occupied (дверь — периметр — блокируется НЕ МОЖЕТ; защитный комментарий);
(2) cap D4 — occupiedInterior + w·h ≤ floor(interiorCount/2) ВКЛЮЧАЮЩИЙ;
(3) reach — reachOK(cells, W, H, entrance, Set(footprint)) === true (см. D-A).
Хутор — interior 0 → (1) сработает первым ('space').
