## 4. Модуль и позиция вкладки

* Форм: `{ column: 0, id: 'efir', label: 'Эфир', build(pane, ctx),
  render(ctx) }`; game-экспорта НЕТ (`m.game` нет — uniform
  `Object.assign({}, G0, m.game || {})`); node: `module.exports =
  factory(null, null)` → `{ tab }` (без регистрации).
* **Позиция — ПОСЛЕДНЯЯ (4-я) в левом столбце** (Персонаж → Инвентарь →
  Игровые настройки → Эфир). Script-тег — МЕЖДУ `ui-tab-quests.js` (L740)
  и `ui.js` (L741). Почему конец (а не 2-я позиция рядом с «Персонаж»,
  как рекомендовали архитектура/a3): ТЗ требует только «левый столбец»;
  конец минимизирует технические правки чужих тестов — helper
  `settingsPane` (ui-panel L2171, ДИНАМИЧЕСКИЙ CHAIN_000130) пинит
  `panes.length === 3` И индекс 2 (settings): при 4-й позиции правится
  ТОЛЬКО счёт (1 строка), при 2-й — счёт + clickTab(2→3) + panes[2→3].
  Инвариант «только технические правки под новый путь» — минимальная
  поверхность. Реестр (порядок = порядок тегов):
  [character, inventory, equipment, settings, shop, quests, **efir**].
* На загрузке — НОЛЬ DOM/RNG/require/console.error (правильный порядок);
  регистрация — побочный эффект браузерной ветки (канон 000130 §2,

  000130 §6.2). render — КАЖДЫЙ render(), in place, скрытые pane тоже.
