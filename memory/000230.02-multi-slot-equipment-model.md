### 2.9 equip(c, itemId) — по слоту
Порядок (side-effect-профиль СТУКИРОВАН со старым: ensure —
до проверок, как в старом :980-981):
1. `getItem(itemId)` → нет → 'неизвестный предмет: <id>';
2. `ensureEquipment(c)`, `ensureEquipmentBonus(c)`;
3. `group = slotOf(it)` → null → 'такое не экипируется'
   (СЦЕПОЧКА/ПОТРЕБНОСТИ — как в старом, текст сохранён);
4. группа === 'ring' → ПЕРВЫЙ ПУСТОЙ из RING_SLOTS
   (`!eq[r]`); все 8 заняты → `{ok:false,
   reason:'нет свободных слотов колец'}`; иначе slot = group;
5. `eq[slot] === itemId` → 'уже экипировано';
6. `hasItem` → 'предмета нет в инвентаре';
7. КОПИЯ — ПЕРВЫЙ слот инвентаря с id (000046, БЕЗ
   ИЗМЕНЕНИЙ); prev/prevBonus → eq[slot]/eb[slot]; splice;
   prev → addItem КОНЦОМ с prevBonus (note при неместе —
   как в старом); syncEquipmentMirrors(eq);
8. return `{ok:true, slot, item:itemId}` — slot = ФИЗИЧЕСКИЙ
   (для UI .07; пин .slot нет — grep).
«Один предмет — один слот» (ТЗ): 1 физ. слот = 1 id. Смена
возвращает предыдущий (ТЗ, как сейчас). Кольца: 2-я КОПИЯ
того же id → следующий пустой слот (8 копий → 8 слотов;
«уже экипировано» для колец недостижимо — slot пустой по
построению); 9-я → отказ. Порядок: полнота слота (состояние)
ПЕРЕД hasItem (запас) — симметрия старого «уже экипировано»
до hasItem.

### 2.11 equipmentStats(c) — ИНТЕРФЕЙС НЕ МЕНЯЕТСЯ
`{damage, subtype, hitBonus, dmgBonus, armor}` — бит-в-байт
для легитимных состояний старой формы (пин M7):
```
out = {damage:0, subtype:null, hitBonus:0, dmgBonus:0, armor:0}
if (eq.right_hand) {                      // было: eq.weapon
  it = getItem(eq.right_hand)
  if (it && it.stats && typeof it.stats.damage === 'number')
      // ГАРД — tool (D8: замена оружия в right_hand) без
      // stats.damage → damage 0/subtype null, НЕ NaN/TypeError
    out.damage = it.stats.damage + ((eb && eb.right_hand
                 && eb.right_hand.damage) || 0)
    out.subtype = it.subtype
    if 'sword' → hitBonus = d.swordHitBonus
    else if 'bow' → hitBonus = d.archerHitBonus,
                    dmgBonus = d.rangedDamageBonus
    else if 'heavy' → dmgBonus = d.heavyDamageBonus
    // staff → «иначе»: damage есть, hit/dmg-бонусов НЕТ
}
for (slot of EQUIP_PHYS_SLOTS) {          // armor — СУММА 18
  if (!eq[slot]) continue
  it = getItem(eq[slot])
  if (it && it.stats && it.stats.armor)   // дословный старый гард
    out.armor += it.stats.armor + ((eb && eb[slot]
                && eb[slot].armor) || 0)  // 000046 — ОБЯЗАТЕЛЕН
}
```
* damage/subtype/hitBonus/dmgBonus — ТОЛЬКО из right_hand
  (ТЗ п.2); легитимный weapon ВСЕГДА имеет stats.damage
  (валидатор) → для существующих 10 предметов формула
  идентична старой.
* armor — СУММА ВСЕХ 18 слотов (ТЗ «torso + любая бронепчасть»):
  СТАРЫЙ сейв (только torso) → сумма = одно слагаемое =
  бит-в-байт; right_hand в сумме — weapon без stats.armor не
  даёт слагаемого (schema stats: только damage/armor); ghost-id
  → getItem null → вклад 0.
