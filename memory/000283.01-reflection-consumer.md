## 1. Решение дизайнера (дословно, 2026-11-03)

* «Отражение» — ВАРИАНТ (a): ЛЮБОЙ урон. Consumer ПОСЛЕ факта
  урона — counter-урон атакующему `round(факт × value)` через
  существующий путь урона по мобым, 0 новых бросков RNG, лог.
  Игрок — mobAttack, союзник — mobAttackAlly.
* «Иммунитет_контроля» — ВАРИАНТ (iii): СПЛИТ. Потребитель НЕ
  ДЕЛАЕТСЯ; при финализации создана подзадача 000283.01.01. В
  SPEC/memory — R6-фиксация дословно: потребитель
  «иммунитет_контроля» НЕ ПОЯВИЛСЯ.

## 2. Consumer'ы — точные вставки (src/combat.js)

* Конец `mobAttack` — ПОСЛЕ succubus-блока (traits.debuff),
  ПЕРЕД закрывающей `}` функции (самая последняя точка:
  трейт-роллы отработали на живом мобе как в legacy; если
  counter убьёт моб — после него в функции ничего нет).
* `mobAttackAlly` — `dealDamageToAlly(c, t, dmg)` теперь читает
  возврат (число факта) в `const dealt`.

Формула (одинаковая в обеих точках):
`refl = Math.round(факт × c.ps.buff.value)` (игрок) /
`Math.round(dealt × t.buff.value)` (союзник),
гейт — `slot && slot.stat === 'отражение' && slot.turns > 0`,
гард `refl > 0` ОБЯЗАТЕЛЕН (dealDamageToMob имеет минимум 1
урона — без гарда «нулевое» отражение било бы на 1),
`ignoreArmor = false` (физика — броня моба действует),
лог `Отражение: −${r.dmg}.` (паттерн «Вампиризм: +${healed}.»
src/combat.js).

## 3. Семантика окон и гибели

* deathWindow: consumer НЕ срабатывает — гейт
  `if (dealt.deathWindow) return;` в mobAttack закрывает удар
  ДО consumer'а (канон 000164, паритет lifesteal-трейта);
  `dealt.dmg <= 0` — нет факта — тоже return до consumer'а.
* Гибель моба от counter — допустима: тот же путь, что dot-тик
  (dealDamageToMob: `повержен!` + checkVictory).
* Гибель СОЮЗНИКА от удара НЕ отменяет отражение — факт был
  (dealDamageToAlly возвращает число до проверки гибели).
* Окно turns — «ровно N раундов, включая каст»: тик — startRound
  (общий ритм c.ps.buff/t.buff); counter на ударах, где
  turns > 0 на момент удара (r2–r3 для turns: 3, r4 — нет).
* Позиция consumer'а ПОСЛЕ трейтов: мёртвый от counter'а моб не
  травит/не дебаффит/не вампиризирует в этом ударе (0 новых
  c._rng; legacy бит-в-бит).
