  данных `const BUILDINGS = [...]` в `src/buildings.js` из

  `// END GENERATED`; шапка файла — «GENERATED — не править руками,

  sync-npc-data.js); идемпотентно (повторный запуск — byte-identical,
  закреплено тестом). Без маркеров/шапки/файлов — exit 1. npm-скрипт
  `sync:buildings` (интерфейс единый с будущими sync:items/sync:visuals

* `assets/buildings`: 13 «картовых» записей (id 1,2,3,4,7,8,10,11,25,31,

* `src/map.js`: константы `BUILDING_COUNT` / `BUILDING_NAMES` /

  Фолбэк без каталога (vm-песочницы) — ровно 13/3/3: значения

## Ключевые решения

1. **Новое поле `название_карты`** (рекомендуемый вариант задачи): имя
   картового индекса — данные каталога, source of truth. Обобщённые
   (НЕ каталожные) имена намеренно заведены в JSON: idx 9 «Вход в
   пещеру» (тайл → любой из 5 типов подземелья — dungeon.js), idx 11
   «Таверна», idx 12 «Дом NPC» (общие для 6 домов).
2. **НАХОДКА: утверждение файла задачи «остальные совпадают с название
   (без учёта регистра)» НЕВЕРНО для idx 8**: каталог id 36 — «Храм
   солнца», а в map.js было «храм». Решение по принципу задачи (имя =
   каталожное, кроме намеренно общих 9/11/12): `название_карты` = «Храм
   солнца». **Следствие для UI: HUD «Здесь: храм» → «Здесь: храм
   солнца»** (панель торговли не затрагивана — храм не магазин,
   `shopKindsFor` → null). Если стейкхолдер против UI-изменения —
   альтернатива «Храм», но она противоречит принципу задачи.
3. **Конвенция регистра**: данные — каталожный регистр (с заглавной),
   UI-вывод — первая буква нижний регистр, реализуется ФУНКЦИЕЙ
   `buildingNameUi` (не данными); не whole-string lowercase («Дом NPC»
   → «дом NPC»).
4. **Ленивые функции, а не константы/getter'ы**: в index.html
   buildings.js грузится ПОСЛЕ map.js; между ними player/day/items
   делают `Object.assign({}, Game, …)` — значение getter'а застыло бы
   до каталога, функция переживает копирование по ссылке. Кэш ПУСТОГО
   вывода запрещён (иначе первый вызов «до загрузки» закэшировал бы
   фолбэк навсегда).
5. **Детерминизм сохранён**: значения не изменились (13, 3×3), но
   источник теперь каталог; golden-пин tileAt на 40 координатах
   (реальный assets/map.png) — до и после.
6. `DENSE` в buildings.js после генерации не используется (данные —
   литеральные массивы из JSON) — оставлен (часть не-данных логики).
7. Сейв v1: постройки не пишутся, `BUILDING_NAMES` не читается —
   версию не поднимать.
