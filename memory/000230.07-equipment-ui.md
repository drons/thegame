## 2. D-ROW-19: раскладка 19 строк «Снаряжения» (КЛЮЧЕВОЕ РЕШЕНИЕ)

ТЗ буквальное: «19 строк (11 частей + 8 колец)». Модель .02 — 18
физ. слотов (10 одиночных + 8 колец); 11 групп EQUIP_SLOTS включают
группу 'ring' (у которой НЕТ физ. слота — 8 физ. слотов = 8 строк
ниже). Численность слагается так:

* **10 одиночных строк** — по 1 физ. слоту (EQUIP_PHYS_SLOTS без
  ring_*): head, ears, neck, torso, forearms, right_hand, left_hand,
  palms, legs, feet — в канон-порядке .02;
* **1 сводная строка группы 'ring'** — позиция 9 (порядок групп
  EQUIP_SLOTS: после palms, перед legs), формат **«Кольца: N/8»**
  (N = число заполненных из 8 физ. ring-слотов); БЕЗ кнопки, БЕЗ
  .cp-tip, БЕЗ иконки/рамки;
* **8 строк RING_SLOTS** — КОНЦОМ, в канон-порядке .02:
  ring_left_1..4, ring_right_1..4.

Итого 10 + 1 + 8 = 19. Трактовка «11 частей тела» = 11 ГРУППОВЫХ
строк (10 одиночных + 1 сводная 'Кольца'); «8 слотов колец» = 8
физ. строк. Альтернативы отклонены: (a) 18 строк + заголовок —
нарушает букву ТЗ «11 частей» (группа ring исчезает); (c) ре-пин
ТЗ-числа на 18 — «Задачи, закоммиченные в master, менять нельзя» +
ТЗ-тест «19 строк» — source of truth.

`Левая рука` / `Ладони` / `Кольца` / `Ноги` / `Ступни` /
