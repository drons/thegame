## Доказательство сохранности (ре-используемый паттерн)

1. md5-снапшоты тайтлов / guard-массивов (`/for \(const w of \[([\s\S]*?)\]\)/g`)
   / MINE / anchors «000NN T5:» — равны базе (скрипт-снимок).
2. Strip-проекция: снять `//`-комментарии и схлопнуть все `'…'`-литералы в
   `''`, затем difflib по строкам HEAD/диск — ВСЕ отличия только на
   чистых строках-литералах/конкатенаторах (`^\s*[+-]{0,2}\s*''…$`).
3. tmp-гейт (вне tests/): G1 «202 БЕЗ»/«234 БЕЗ» = 0 по tests/; G2/G3 —
   реконструкция ЗНАЧЕНИЯ сообщения из строковых литералов зоны T5
   (join литералов от «тема чужого NPC (») — исходный file-level
   substring-проверкой нельзя: значение склеивается из нескольких строк;
   G4 — строки с 234/202 в .21–.26 только в тайтлах; G5 — анти-вычерк
   истинных переходов; G6 — атрибуция ≡ живому свипу assets.
4. Зубы 000424 (deepEqual guard-массивов реестру) + .39 T5/T9 краснеют на
   любом смещении байта в guard-массивах — живая проверка поверх (1).
