## 3. Нюанс: rarity (279) ⊊ slot (289) — формула ТЗ неприменима

10 legacy-remap имеют slot БЕЗ rarity — они уходят в skip-ветку RAR-G
(`it.slot !== undefined`) и НЕ входят в «прочие». M в RAR-G считается
по SLOT (others = 511 − 289 = 222) — ТЕЛО авторитетно (ТЗ: «ассерты тела
уже финальные — не трогать»). Счётная формула ТЗ «M = N − (число
предметов с rarity)» = 511 − 279 = 232 НЕПРИМЕНИМА: 232 ни в заголовок,
ни в шапку НЕ писать. (Аналогичный нюанс зафиксирован пином 000252:
заголовок обязан прийти к телу, не к ТЗ-срезам.)

## 4. Решение S1: K — per-school карта (НЕ единое число)

Факт per-school НЕРОДНОЕ: 27/27/26/26/26/26 (6 волн × 25 + 8 legacy:
огонь 2, лёд 2, тень 1 — chill НЕ лёд, исцеление 1, защита 1, природа 1).
ТЗ-прогноз «25 на школу — 5 волн» устарел; ретро-фоллоуп говорил
«n <= 27» (max) — факт требует карты.

* Форма пина (ТЗ «n >= 1 && n <= K» с K = «фактическое число свитков
  школы»): `assert.ok(n >= 1 && n <= SCHOOL_SCROLL_MAX[sch], …)`.
* `SCHOOL_SCROLL_MAX` — литеральный объект, BLOCK-LOCAL const внутри
  тела S1-теста (не module-level):
  `const SCHOOL_SCROLL_MAX = { огонь: 27, лёд: 27, тень: 26, исцеление: 26, защита: 26, природа: 26 };`
  — одна строка, без кавычек ключи (кириллица — валидные JS-
  идентификаторы; прецедент `.школа` в том же теле, items.test.js:1632).
  Block-local, а не module-level, ПОТОМУ ЧТО якорь S1-B source-пина =
  тест-блок (`test('S1. 000133:` → следующий `test(`): карта внутри
  блока = пин самодостаточен и извлекается из исходника для live-
  кросс-чека (пин = факт каталога).
* Нижняя граница `n >= 1` СОХРАНЕНО (ТЗ: «нижняя граница n >= 1
  остаётся»).
* Отвергнуто: единый K = 27 (max) — 4 школы (26) недопинуются: дрейф
  26→27 не ловится; `n === K(sch)` — сменяет нижнюю границу (ТЗ велит
  оставить n >= 1).
* Fail-closed: будущая школа, отсутствующая в карте →
  `n <= undefined` = false → пин падает = сигнал «новая контент-задача
  не отрепинила пин» (каталог запечатан).
* Закрытие фоллоупа: memory/000235.07 §5 «per-school pin — n >= 1 …
  БЕЗ ДАЛЬНЕЙШИХ ПРАВОК (решение R13)» и R12 (строки 414/451/698) —
  пометка «без правок» СНИМАЕТСЯ задачей 000243 (правится в том же
  коммите: граница восстановлена по финальному каталогу, волн больше не
  будет).
