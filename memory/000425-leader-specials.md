## Данные (карточка п.1 — флаги живут в данных моба)

- `MOB_TYPES.ant_queen.traits = { swarmRout: true }`;
  `MOB_TYPES.orc_chief.traits = { reinforce: 'orc_grunt' }`.
  Значение reinforce — **id моба из того же каталога** (строка, не булев
  флаг): логика обобщённая, спавнится `MOB_TYPES[u.traits.reinforce]`.
- Выбор `orc_grunt` («Орк-шестёрка»): тематическая «шестёрка» вождя из
  орочьей линейки каталога; 1×1; инициатива 3 < инициативы вождя 4 —
  подмога не перекрывает очередь носителя трейта.
- Зеркало ОБЯЗАТЕЛЬНО (эррата брифа «0-diff assets/» — ложь, тот же класс
  ошибки, что бриф 000420 до аменда): tests/combat.test.js
  «assets/mobs: зеркало в combat.js идентично JSON-каталогу» —
  двусторонний deepEqual; schema.json traits += swarmRout(boolean) +
  reinforce(string, `^[a-z][a-z0-9_]*$`). Моб-каталог вне sync-генерации
  (sync-mobs нет) — зеркало руками, три носителя в ОДНОМ коммите
  (прецедент 000420 spider/web).
- Пассивка роли leader (LEADER_DMG_MULT=1.05) не тронута.

## Семантика

- Разбег = ТОЛЬКО существующий флаг fled (alive=true) — контракт
  «без лута/XP» 000271/TIMID: fled-юниты вне livingMobs/targeting/killed
  ⇒ XP/лут/gold только за реально убитых; checkVictory не правится
  (Матка мертва ⇒ killed.length≥1 ⇒ victory, НЕ «fled»-исход).
- «ЕЁ группа» = сторона mob боя (контракт движка: 1 бой = 1 группа).
- Призыв: 8 чебышёвских соседей вождя в каноническом **row-major**
  порядке (dy внешний), фильтр rectFree (границы + клетка игрока +
  c.obstacles + живые не-fled — контракт 000292); РОВНО ОДИН c._rng на
  выбор клетки — строго под гейтом traits+флага+cells. hasLeader для
  статов подмоги — пересчёт по живым лидам стороны mob (вождь жив ⇒ ×1.05,
  LEADER_DEF_MULT). id `'m' + c.units.length` уникален (mN < изначального
  числа мобов ≤ длины; спелл-саммоны — 's'/'a'-префиксы).
- Новый юнит входит в очередь со СЛЕДУЮЩЕГО раунда (пересборка
  buildTurnOrder в startRound; прецедент resurrect 000163).
- RNG-доктрина 000235: бои без ant_queen/orc_chief — НОЛЬ новых бросков
  (все ветки гейтятся трейтами/флагом); пинованный след T6.
