## 2. Контракт «те же механики» (зеркало 000037/000045)

**Порядок проверок castAllySpell** (c — бой, u — активный союзник; зеркало

u.attackLeft — НЕ трогается (Д-D); c.ps/мана ИГРОКА не тратятся (ре-пин CU179).

## 3. Модель: makeAlly + startRound

makeAlly (src/combat.js L336-381) — 3 поля после `attackLeft: 1` (наёмник и
Эфир — один путь; юнит Эфира — makeAlly(efirAllyData), затем buildEfirUnit
перезаписывает u.mp = stats.maxMP — та же формула → то же значение):

```
mp: 5 + ((data.attrs && data.attrs.intelligence) || 0)
    + ((data.attrs && data.attrs.wisdom) || 0),
spellInt: 1 + Math.floor(((data.attrs && data.attrs.intelligence) || 0) / 10),
spellWis: 1 + Math.floor(((data.attrs && data.attrs.wisdom) || 0) / 10),
```

- attrs: наёмник — все 6 ключей (allyDataForEntry 000167 D7.2 — свежая копия
  sheet.primary), Эфир — 4 ключа {intelligence, wisdom, constitution,
  dexterity} (efirAllyData). Фикстура {dexterity:4, intelligence:4} → mp 9,
  spellWis 1 (ре-пины CANDO-3/ALLY-2).
- startRound, livingAllies-цикл (L2525-2528) — round-rollover (зеркальная
  формула рефила c.efs):

```
a.spellInt = 1 + Math.floor(((a.attrs && a.attrs.intelligence) || 0) / 10);
a.spellWis = 1 + Math.floor(((a.attrs && a.attrs.wisdom) || 0) / 10);
if (a.shield && a.shield.turns > 0) a.shield.turns -= 1;
```

- **poolsOf(c, u)** (в модуле): `u.kind === 'efir' && c.efs ? c.efs : u` (Д-C).
  У Эфира канон — c.efs (рефилл/ритм зафиксированы EF-3/CB-*); a.spellInt/
  spellWis у Эфира пишутся безвредно (poolsOf выбирает c.efs).
- Сейвы: боевые юниты НЕ сериализуются (data.companions — sheet/roster
  000085/000143; Эфир — sheet) — схема сейва и версия НЕ меняются.

- Ставится: castAllySpell «защита» → `u.shield = { armor: 1 + степень, turns: 3 }`
  (1:1 c.ps.shield 000045).
- Поглощение: dealDamageToAlly (L1035-1052) — `const dmg` → `let dmg`,
  после вычисления с бронёй:

```
if (t.shield && t.shield.turns > 0) {
  dmg = Math.max(0, dmg - t.shield.armor);

```

  Плоское поглощение, может до 0 (зеркало dealDamageToPlayer L924:

  поглощения — это путь без щита, не меняется). Маг-резист (opts.magic,
  perception) — до брони, как сейчас (порядок: резист → броня → щит).
