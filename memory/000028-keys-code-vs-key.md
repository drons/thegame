# 000028: клавиши перемещения — e.code vs e.key, маппинг в src/controls.js

Статус: выполнено и закоммичено (тесты 186 → 196 pass).

## Решения

* **Перепутанные связки:** `KeyboardEvent.code` — физическая клавиша, НЕ
  зависит от раскладки (spec UI Events; кириллических code не существует —
  список code строится по US-раскладке: KeyA…KeyZ, Digit0…, Arrow*).
  `KeyboardEvent.key` — символ текущей раскладки. Старая таблица `KEY_DIRS`
  в main.js смешала обе системы: `KeyЦ/KeyФ/KeyЫ/KeyВ` — это значения из
  мира `e.key` с префиксом «Key» — они НИКОГДА не приходят в `e.code` и
  были мёртвыми связками. Русская раскладка всё же «работала», но только
  потому, что физические WASD (= ЦФЫВ по железу) маппились через `KeyW` и
  т.п.
* **`src/controls.js`** (чистый UMD, без зависимостей; браузер — `Game.*`,
  node — require; в index.html перед main.js):
  * `DIR_DELTA` — up/down/left/right → дельты в мировых координатах
    (y растёт вниз: up = [0,-1]);
  * `CODE_DIRS` — e.code → направление (стрелки + физические KeyW/A/S/D);
  * `KEY_DIRS` — e.key (lowercase) → направление (ц/ф/ы/в) — фолбэк;
  * `moveKeyForEvent(e)` → id нажатия: e.code, если распознан, иначе
    lowercase-символ e.key; null — если не перемещение. Регистр
    нормализуется, чтобы keydown (Shift+«Ц» → 'Ц') и keyup (после
    отпуска Shift → 'ц') давали одинаковый id;
  * `deltaForMoveKey(id)`, `deltaForEvent(e)` — дельты.
* **main.js:** `keys` (Set) хранит id клавиш (code или символ), не имена
  направлений — две клавиши одного направления дают два id, движение
  продолжается, пока удержана хотя бы одна (как раньше). keyup удаляет
  только свой id. `tryMove` берёт дельту через `G.deltaForMoveKey`.
* Приоритет: e.code > e.key — физическая клавиша авторитетнее символа.
* Фолбэк по `e.key` покрывает виртуальные клавиатуры (code =
  «Unidentified») — пригодится задаче 000018 (тач-контролы: тач-кнопка
  может вызвать `deltaForEvent({key:'ц'})`).

## Тесты

tests/controls.test.js — 10 тестов: мировые оси; стрелки; WASD по code;
русские символы по key (регистр, «Unidentified»); приоритет code;
РЕГРЕССИЯ — «KeyЦ/Ф/Ы/В» не маппятся (таких code нет); не-перемещающие
клавиши → null; согласованность таблиц (код — только канонические code,
ключ — только одиночные символы); id keydown/keyup при смене регистра.
