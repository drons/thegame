## 1. Что видит игрок

Игрок изучил «Воскрешение» (000163/000147 — храм, 300 Г, 400 опыта).
В бою:

* **Книга заклинаний** (KeyQ / кнопка «Заклинания» — 000149) содержит
  строку **«Воскрешение»** (появляется, когда заклинание изучено —
  data-driven через entriesFor 000149 + каталог 000017). Строка:
  имя «Воскрешение», подпись «Мана 15 · Заклинание (Мудрость)»,
  SVG-иконка `assets/spell-icons/resurrect.svg`, описание из каталога.
* **Мёртвый союзник на поле** (миникарта) получает **подложку
  «свой»** (голубой, как живые союзники) — маркер «тут можно
  воскресить». Клетка мёртвого героя (Флогистона), если он мёртв, —
  тоже с подложкой.
* **Клик по клетке мёртвого союзника** = выбор цели: на нём
  **подсветка-кольцо** (жёлтая, как у цели моба). HUD-строка:
  `Цель: <имя> (ур. N) — мёртв`.
* **Клик по клетке мёртвого героя** = выбрать его: кольцо на клетке
  героя, HUD: `Цель: Флогистон (вы) — мёртв`.
* Если **мёртвых нет** — строк-целей нет, подложек нет, в книге
  строка «Воскрешение» с пометкой «нет цели» (клик → лог «нет цели»,
  мана/действия НЕ тратятся — зеркало canCastSpell, паттерн 000149).
* **Каст**: в открытой книге клик по строке «Воскрешение» →
  `castSpell(c, 'resurrect', c.targetId)` (ядро 000163): цель
  возвращается **с 50% HP**, лог «Возвращён в бой.», тратится 15
  маны + 1 действие «Заклинание» (Мудрость), эффект каста (000149),
  книга закрывается, ход игрока НЕ сгорает.

## 2. Как устроен выбор цели (механика)

* **Мёртвый СОЮЗНИК (юнит c.units, side 'ally', !alive, !fled)**:
  клик по его клетке → `c.targetId = u.id` (прямой write из UI —
  ядро `selectTarget` союзников отклоняет, а resurrection-ветка
  evalSpell (000163) мёртвого союзника ПРИНИМАЕТ; все остальные
  читатели c.targetId самовалидируют — атака/огонь/целенаправленные
  спеллы на мёртвом дадут «нет цели»).
* **Мёртвый ИГРОК**: не в c.units (поля id нет, R-1 000163), поэтому
  адресуется как **`c.targetId = null`** — «автоцель»: двигатель
  evalSpell без явной цели воскрешает **мёртвого игрока приоритетно**,
  иначе первого мёртвого союзника. Клик по клетке героя снимает любую
  явную цель (targetId = null) → кольцо/строка показывают автоцель.
* **Дальности нет** (000163 R-2): цель — в любом месте поля.
* **Приоритет при авто (targetId = null)**: мёртвый игрок → первый
  мёртвый союзник по порядку c.units.
* **Живет один ход**: c.targetId сбрасывается «свежая цель» в начале
  хода игрока (как у атаки); поле runtime-only — НЕ уходит в сейв
  (save.js), детерминизм не затрагивается.
* **Гейт**: все маркеры/клики работают, ТОЛЬКО если носитель знает
  'resurrect' (canResurrect через unitOf — следует за будущим 000168).
  Без него сцена — бит-в-байт, как до 000166.
* **Мёртвые МОБЫ** целями НЕ являются (только side 'ally');
  клик по мёртвому мобо — бездействия.
* **Кольцо**: у мёртвого союзника — когда `u.id === c.targetId`;
  у героя — когда `c.targetId === null` (автоцель = вы). Подложка —
  у всех мёртвых союзников/мёртвого героя (в гейте).
