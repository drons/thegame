# 000299.03 — цены магазина по «Торговцу» активного персонажа

## Контракт
Цены покупки/продажи (NPC-торговля в npcUI и «Магазин» [I] у
постройки) — по навыку «Торговец» (secondary.merchant) АКТИВНОГО
персонажа партии (000299.01/000299.02: активный — closure
`activeCharId` в ui.js + LIVE `__game.state`, 000145). Владелец
покупки/продажи — ВСЕГДА Флогистон: золото списывается/начисляется
в `c.gold`, инвентарь — общий (000194). Множители богатства
(wealth) — без изменений. Формулы buyPriceMult/sellPriceMult —
`derived()` в src/sheet.js (000194/000284); применение — src/npc.js
(npcBuyPrice/npcSellPrice) и src/items.js (buyPrice/sellPrice).

## Механика: priceChar/owner
Мутации и цены разведены аргументами: функции торговли принимают
ХВОСТОВОЙ ОПЦИОНАЛЬНЫЙ `priceChar` (5-й аргумент), дефолт = owner:
* `N.npcBuy(shop, character, itemId, qty, priceChar = character)`;
  `N.npcSell(...)` — аналогично. Цена — `npcBuyPrice/npcSellPrice`
  с `priceChar`; ВСЕ мутации (gold, stock, инвентарь) — на
  `character` (owner).
* `I.buyItem(shop, c, itemId, qty, priceChar = c)`; `I.sellItem(...)`
  — аналогично.
Вызовы на 3/4 аргументах (npc.test.js, items.test.js, ui-panel) —
бит-в-бит: priceChar = owner → те же цены, что до 000299.03
(регресс A5/B3).

## Два экрана, два резолвера (один источник)
* [I]-панель / «Магазин» (src/ui.js renderItems→doItemAction,
  src/ui-tab-shop.js): `activeSheetFor(c)` (000147, LearnTarget —
  единая точка «активного» для панели; fallback на c, если
  learn-target.js не загружен — цепочки без него бит-в-бит).
  В ctx панели — live-getter `activeSheet` (пересчёт КАЖДЫЙ кадр —
  смена активного между кадрами видима без re-build).
* npcUI «торговля» (src/ui.js): `activeSheetNow()` (000299.02,
  partyMembersFor + activeCharId) — тот же резолвер, что вкладка
  «диалог» 000299.02 (ОДИН источник «активного» в npcUI).
Оба резолвера читают один и тот же closure `activeCharId` + LIVE
`__game.state` → оба экрана и диалог согласованы.

## Ловушки
* NaN-ловушка: лист наёмника (`Sheet.createSheet('merc')`) НЕ ИМЕЕТ
  поля `gold`. Передавать `priceChar` в мутации нельзя — золото
  всегда `c.gold` (c = owner = hero). Тесты фиксируют
  `merc.gold === undefined` после покупки/продажи.
* priceChar — ЛЕВЫЙ лист (с derived buyPriceMult/sellPriceMult),
  owner — правый (мутации). Не путать в новых call-sites.
* `saveNow` в ui.js НЕ вводится (структурный пин 00100).
* Стale-цены: при открытой вкладке «торговля» смена активного кликом
  по портрету раньше не пересчитывала цены (ин-плейс ре-рендер
  000299.02 был только для «диалога»). РАСШИРЕНИЕ 000299.03
  (рекомендация аналитиза, ТЗ молчало): ветка клика по портрету —
  `if (tab === 'dialog' || tab === 'trade') renderTab()`. Без этого
  изменения открытая «торговля» показывала цены прежнего активного.
* ui-tab-shop.js — БЕЗСОСТОЯТЕЛЬНА (000130): цена берётся из
  `ctx.activeSheet` (getter) в render; render 30 раз/с — getter
  дёшевый (Party.list + state, без DOM).
