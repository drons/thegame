## 1. Корень (сверено с кодом и ассетами, числами проверено)

Два независимых дефекта:

(А) ВЕРТИКАЛЬНЫЙ ШОВ. База тайла — вертикальный linearGradient из двух
НЕРАВНЫХ стопов (верх светлее низа): цвет зависит только от y.
Горизонтальный стык (рядом по x) — фазы совпадают → шва нет; вертикальный
стык (ряд на ряде) — тёмный низ верхнего тайла встречается со светлым верхом
нижнего → линия шва через весь ряд. Пол cave: #6e655a→#4b443b (ΔL 0.074);
стены rock/stalactite: #7d7468→#4e463d (ΔL 0.115) — тот же механизм у стен.
Дополнительно: cave_2.svg радиальное пятно `<ellipse cx="15.1" cy="17.2"
rx="15.7">` выходит за левый край на 0.6 px (bbox x=−0.6) — микроразрыв
контракта бесшовности 000069. Генератор допускал это: пятна — `inner(rnd,14)`
+ rx до 16 → до 66 px; crack — центр до 54 + dx до 1.8·7 = 66.6 + stroke 0.5
(потенциальный вынос жёсткого stroke, у текущих сидов не проявился).

(Б) СТЕНЫ = ПОЛ. Диапазоны яркостей баз пересеклись: пол cave L 0.0595..0.1336,
стены L 0.0634..0.1785; минимальный WCAG-contrast по всем парам стоп =
1.036 (пара #4e463d×#4b443b). Единственная отметка «стена» — тонкая кромка
(свес #948a7b@0.55 + линия #332c25@0.4).

## 3. Контракт бесшовности (общий паттерн; закрепляется тестами CT-1..CT-4b)

Тайл 64×64 бесшовен в ОБА направления тогда, когда:
(1) база — постоянный цвет: линейный градиент с ДВУМА РАВНЫМИ стопами
(top == bottom). Форма «2 равных стопа» (не плоский fill, не 3-стопный
симметричный градиент) — ПОТОМУ ЧТО пин baseGradientPair
(tests/sprites.test.js:1874-1883) требует ровно 2 стопа у ПЕРВОГО
linearGradient у полов И стен; равные стопа проходят без правки пина.
Плоская база = стыковость в обе оси математически (цвет любого края — один
тон). Запрет 3-стопного градиента (dark-bright-dark) — сломал бы пин.
(2) все элементы тела (детали, включая fade-пятна) — bbox СТРОГО ВНУТРИ:
пол ⊆ [0.5, 63.5]² (тестовая граница; генератор даёт [3,61]), центр стены
⊆ [10.5, 53.5]² (центр 12..52 + r ≤ 1.4, конвенция 000258). На стыке двух
тайлов соприкасаются только «база↔база» и «база↔чисто-база-у-соседа» →
непрерывность цвета в обеих осях. ВАЖНО: fade-пятно, ПЕРЕСЕКАЮЩЕЕ край,
НЕ бесшовно (opacity на границе ≠ 0 — fade до 0 в границе bbox пятна, а она
за краем тайла) — поэтому пятна кламнятся внутрь, а не «разрешены»
(поправка к формулировке a1 D3-3, прецедент cave_2 −0.6 px).
(3) у стен кромка (edgeBand/cornerBand) рисована ВНУТРЬ плитки от края
(свес 4 px + линия 1.5 px) и по битам маски (бит = «сосед — пол») никогда
не встречает кромку соседнего wall-тайла: два смежных wall-тайла на
общей границе оба имеют плоскую базу (их бит на этом соседе = 0) →
структурно бесшовно, не менять.
(4) угловые c*-плитки: stroke шва может на ~0.75 px выходить за угол тайла —
обрезается SVG-вьюпортом (диагональный сосед = пол), дизайн 000258 не
меняется (known-следствие §8.3).
