## 2. Формула (дословно)

```
XP = round(мана × (1 + 0.1 × max(0, D)))
```

* мана — реально потраченная мана заклинания: поле каталога
  `мани`; free_cast (000230.17) — потрачено 0 → XP = 0
  (в коде: (free ? 0 : spell.мани), free = isFreeCast(c, spellId)).
* D = p.level − уровень опорного моба (mob.level). Опорный моб:
  цель применения, если она моб (t && t.side === 'mob' — действия
  урон/ослабление/контроль/дебаф); иначе — ближайший живой моб
  nearestMob(c) (детерминирован, 0 RNG); живых мобов нет — D = 0.
* D < 0 (моб сильнее) — бонус нулевой, БЕЗ штрафа (max(0, D)).
* Math.round; минимального floor 1 НЕТ (XP может быть 0).
* 0 новых вызовов c._rng.
