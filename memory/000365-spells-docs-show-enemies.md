## Отступление от буквы ТЗ (решение A.design B) — ЗАФИКСИРОВАТЬ

ТЗ П.1/П.3 формулирует эффект как «ПОВЕРХ базовой отрисовки показывает окружности
радиуса агрессии ВСЕХ видимых мобов; базовое поведение триггерящих групп не меняется».
Код делает иначе, и в spec/ записана версия кода:

- `src/main.js` Проход 2.5 целиком обёрнут в гейт `seOn` (:4185–4188 —
  `isHeroEnemiesShown(hero, clock.day)`; `if (seOn && …)`), то есть вне эффекта круги НЕ
  рисуются. «Поверх базовой отрисовки» было бы ложью: базовой отрисовки кругов по
  умолчанию нет (инверсия дефолта, авторизованная ТЗ 000350; запинено S-VM-OFF-8 в
  tests/spell-show-enemies-000350.test.js).
- Внутри эффекта фильтр `if (!info || !info.triggers || !(info.radius > 0)) continue;`
  (:4205) — круги получают ВСЕ видимые ТРИГГЕРЯЩИЕ группы с радиусом > 0 (поверженные
  сегодня отсекает `groupVisible`, :4203), а не буквально «всех мобов»: нейтральные и
  пугливые (радиус 0) без круга, как и до 000350.
- Сужение eff (cold_breath/dark_presence, 000235.08/.09) живёт ВНУТРИ того же seOn-прохода
  (:4194–4210) — текст оговорки ничего не обещает про eff при выключенном эффекте.
- Триггеринг зон эффект НЕ меняет: скан `zoneCombatInfo()` (main.js:2766–2784) от seOn не
  зависит. Это единственная часть буквы ТЗ, которая коду соответствует.
- retro-b19 (tasks/result/000350-retro-b19-20261113.md, finding №3 [major]) требует
  зафиксировать ровно «условие видимости агро-окружностей» — то есть гейт, а не
  «оверлей поверх». Описание в `assets/spells/show_enemies.json` («всех видимых мобов») —
  flavor-текст, норму из него не выводим.

  сравниваются с базой напрямую.

  прогоны) пришлось ждать ~32 мин; ждать корректно отвязанным (setsid+nohup) скриптом-жуком
  (гейт проверяет `pgrep -x node` + `ps -o args=`, НЕ `pgrep -f` — собственная cmdline не
  матчится), который сам поднимает прогон, как только машина освободилась; сам прогон
  переживает ход агента (проверено: PID жил между вызовами).
- Правка строчности spec/*.md красит guard'ы НЕ только в spec-split — перед правкой снимать
  `grep -rn "specLines(" tests/*.test.js`.
