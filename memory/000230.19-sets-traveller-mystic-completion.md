**D-01 Слот: torso для ОБОХ предметов** (ТЗ: «.09 ears/neck, .10 torso,
.11 forearms/palms, .13 left_hand, .14 ring, .15 legs/feet»). — Почему:
torso — ЕДИНСТВЕННЫЙ слот из ТЗ-списка БЕЗ точного слот-пina по всему
каталогу: head «ровно 25» (H1 :4889), ears/neck «ровно 25» ×2 + «ровно 50
файлов» (EN1 :5549-5567), left_hand «ровно 25» (:7518), ring «ровно 25»
(T1 .14 :8063-8068), legs/feet «ровно 25» ×2 + «ровно 50 файлов» +
deepEqual id-множеств (LF1 .15 :8654-8680); у torso ловушка задокументирована
самими пирами (items.test.js:6025 «НЕ пируем "ровно 25 torso" — в GREEN 28
= 25 волновые + 3 legacy remap»). forearms/palms тоже не пинованы (T1 .11
анкорит фикс-файлами 000283–000332), но тематически слабее. Альтернативы
отклонены: **feet** (arch-план) — ломает LF1 .15, который фильтрует ВЕСЬ
каталог по slot: «slot feet — ровно 25» (25→26) + deepEqual
set(ids slot feet) с FEET_IDS_00023015 (нужна правка волнового
ростер-константа — семантическая смена контракта волны) + «слот legs+feet
— ровно 50 файлов» (50→51, и 000459 не входит в «50 последовательных
файлов» блока); LF2/LF3/LF5 .15 безопасны (итерация по фикс-id волны).
**ring** (arch-план) — ломает T1 .14 «slot "ring" — ровно 25 предмета»
(slot-фильтр по всему каталогу, :8066-8068; T4 .14 безопасен — итерация по
фикс-константе RING_IDS_00023014, «ровно 8/17/3» не сдвигаются); правка
T1 = 25→26 + перенос смыслового якоря «блок = все предметы слота» —
тоже семантическая смена. Оба варианта нарушают инвариант «семантических
правок существующих тестов нет (только технические под новый путь)».
Достижимость: head + torso — порог 2 тривиально заносится, слоты не
конфликтуют.
