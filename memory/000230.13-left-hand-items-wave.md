  Почему: резерв 2026-10-22 (зафиксирован в focus-текстах 10 живых волн,

  Блоки строго по номерам — append-якорь валиден при любом порядке мержей.
- **D-02. Щиты — ТОЛЬКО stats.armor, НЕТ stats.hitBonus.**
  Почему: схема assets/items/schema.json stats = {damage, armor} +
  additionalProperties:false (hitBonus не проходит валидацию);
  equipmentStats (src/items.js:1314-1323) читает hitBonus только из
  оружия right_hand (sword→swordHitBonus, bow→archerHitBonus); ТЗ прямо
  разрешает «минимально — только armor, как у брони». Схема не трогается.
- **D-03. «Левая рука — отдельный пул» = append 25 id КОНЦОМ каждого тира
  в EQUIP_POOLS (loot-equip-data.js), НЕ per-slot пул.**
  Почему: live-инварианты EQ2 (combat.test.js:8766) / CH4 (dungeon.test.js)
  — `pool[тир] deepEqual allItems().filter(rarity===тир)` — запрещают
  исключать/делить; per-slot пул = новая механика («не больше, не меньше
  чем просит ТЗ» + «существующие механики не трогаются»); паттерн .08/.09/.10.
- **D-04. Распределение kind × rarity: щиты 10C+2R (12), артефакты
  5R+5E+2L+1I (13).** Почему: ТЗ п.3 «artifact — реже, epic+» —
  максимальное возможное сжатие в верхние тира: строго epic+ невозможно
  (5+2+1=8 < 13), 0 common-артефактов, epic+ = 8 из 13 (62%) против
  2 из 12 у щитов; согласованно a1 §4.3 и a3 §6.2. a2-дизайн-дефолт
  (4 common-артефакта) ОТКЛОНЯЕТСЯ — слабее читается «реже, epic+».
- **D-05. Armor щитов: common = 1, rare = 2** (epic/legendary-armor 3/4 в
  этой волне не используются — epic+/legendary-щитов в волне нет).
  Почему: ТЗ «stats.armor (1–4 по редкости)» — шкала значения в пределах
  диапазона по редкости; следствие D-04; epic+ щиты — не обязательство ТЗ
  (если потребуются — отдельная волна/ретро).
- **D-06. free_cast — РОВНО 2: epic ward_crystal (000375) → magic_shield;
  legendary snow_focus (000381) → ice_armor.**
  Почему: ТЗ «free_cast у epic+ (1–2)» — максимум 2, распределены по
  epic и legendary («epic+» во множественных тирах); оба заклинания live
  в assets/spells и НЕ из 6 уже использованных (mend/light_heal/ward/
  greater_heal/heat_shield/stone_skin — все epic); поле `spell` = id
  заклинания (pattern ^[a-z][a-z0-9_]*$), НЕ номер файла (паттерн .10 §2.2);
  impossible-флагман — без free_cast (двойной affix, D-11).
- **D-07. Наборов — РОВНО 2, оба DORMANT (порог 2 при 1 слоте left_hand):
