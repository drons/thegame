## Контракты и границы

* **Ключ состояния**: plain `'x,y'` (целые, без пробелов,
  отрицательные возможны) → int день сбора ≥ 1. Суффикс ':loot'
  НЕТ (раздел отдельный; DAY_MAP_KEY_RE принимает и 'x,y:effectId' —
  поддельный такой ключ в сейве восстановится fail-open, безопасно).
* **Видимость**: лут на тайле ВИДИМ ⇔ `G.lootVisible(collectedLoot,
  x, y)` (нет ключа). fail-open: битое состояние → видим.
* **Респаун**: `respawn_days` (live, global-settings, дефолт 3) —
  ТОТ ЖЕ параметр, что у мобов; зачистка — только в `clock.onDay`
  (setDay/rest триггерят; fastForward — НЕ триггерит, 000031).
* **Сбор**: [E] (единый роутер toggle()) на тайле с ВИДИМЫМ лутом →
  `G.addItem(hero, id)` → успех: `collectedLoot.set('x,y', день)` →
  `saveNow` → flash «Собрано: <имя>» → `playerRender`; отказ
  addItem: flash(reason), БЕЗ марк/сейва (предмет остаётся на тайле).
* **Границы НЕ ТРОГАТЬ**: defeatedAt-секция сейва (отдельный блок),
  оверлеи buildingUI/npcUI/craftUI/combatUI, flash-строка дня
  («Мобилизуются…» + «День N.»), respawn-настройки (новых НЕТ),
  src/map.js (000158.03), city/dungeon-ветки [E], HUD-экспорты
  (ровно 6), index.html.
* **Порядок в toggle()**: ветка лута ПОСЛЕ всех гардов-оверлеев и
  close-if-active, ДО hasBuilding. Лут-тайл ⇒ !hasBuilding
  (взаимоисключающий контент 000158.03) — порядок ради читабельности.
* **Городские тайлы**: cover → loot = null → подсказки/сбора нет
  (и [E] в городе идёт через interactCity, не через toggle).

## Ленивые ссылки и guards

* building-actions: `deps.collectedLoot` (live Map из бандла init),
  `deps.game.lootVisible/getItem/addItem` (снапшот G, читается при
  ВЫЗОВЕ), `deps.hero`, `deps.clock.day`, `deps.saveNow/flash/
  playerRender`. Гарды: `!deps.collectedLoot || typeof
  deps.game.lootVisible !== 'function'` → console.error 1× +
  no-skip; `t.loot != null` — попытка; `!('loot' in t)` (поле
  отсутствует, старая map.js) → console.error 1× + fall-through;
  `t.loot === null` — тихий fall-through (норма).
* hud.js: `t.loot && ctx.collectedLoot && g.lootVisible &&
  g.lootVisible(...)` — ВСЕ гарды ТИХИЕ (кадр: ни исключений, ни
  логов; console.error деградации — только в building-actions при
  [E]). `ctx.collectedLoot` — ОПЦИОНАЛЬНОЕ поле (сырой live Map).
* main.js: `G.serializeDayMap ? ... : {}` в collectSaveData; restore —
  try/catch + typeof-guard + restoreDayMap + future-day-отброс.
* `__game.collectedLoot` — только КОПИЯ (мутации не попадают в
  состояние).
