## 2. Контракты и границы

### 2.1 castOutOfCombat — контракт 000235.02 §2.1 расширяется, не ломается

* Порядок проверок БЕЗ ИЗМЕНЕНИЙ: unknown → not-learned → вне_боя →
  days → мана. `free` вычисляется ПОСЛЕ days, ПЕРЕД маной — это не
  причина отказа (equipmentAffixes — чистая, без side-эффектов) →
  порядок reason'ов бит-в-бит.
* `free = isHeroFreeCast(p, spellId)`:
  * spell ∈ freeCast(экипировка) — ПРОПУСКАЕТСЯ ВЕСЬ мана-чек (включая
    `typeof p.mp !== 'number'`) И списание `p.mp -=`. Семантика —
    «заклинание бесплатно», не «скидка».
  * НЕ free — бит-в-бит текущий путь (те же выражения, те же reason).
* reason-строки — ПОБАЙТОВО без изменений: «не хватает маны»
  возвращается ТОЛЬКО когда spell НЕ в freeCast и маны не хватает
  (ТЗ «мало маны» — разговорный парафраз; пин — реальная строка :819).
* Возврат {ok:true, spell, expiresDay} — БЕЗ НОВОГО ПОЛЯ `free`
  (показ «бесплатно» в книге — UI-задача 000230.07; ТЗ «не больше и
  не меньше»).
* days/expiresDay, перезакливание in place, outOfCombatEffects,
  switch (5 id-кейсов .03/.04 — НЕ расширять), teleportOutOfCombat,
  невидимость, мана-реген, сейв — логика без изменений.

### 3.2 isHeroFreeCast — guards (по образцу affixSkillsFor, sheet.js
:84-101)

* Дешёвый выход ДО резолюции API:
  `!p || typeof p !== 'object' || typeof p.equipment !== 'object' ||
  Array.isArray(p.equipment)` → false. Герой без equipment не трогает
  items-API вообще → бит-в-бит КОНСТРУКТИВНО гарантирован для ВСЕХ
  существующих героев во всех ~50 vm-цепях/e2e (у fresh-героя поля
  equipment нет до equip/restore).
* Резолюция API: node — `itemsThunk()` в try/catch (catch → `{}`),
  МОДУЛЬ кэшируется в itemsApi (require-кэш — один и тот же);
  browser — property-read rootRef.Game ПРЯМОЙ (без кэша — в vm
  items.js может догрузиться позже; кэшируется только в node).
* `!api || typeof api.equipmentAffixes !== 'function'` → false.
* Duck-typed Set: `fc && typeof fc.has === 'function'` →
  `!!fc.has(spellId)`; НЕ instanceof (cross-realm: Set чужого realm
  не пройдёт instanceof — тестовые stub'ы); защитный фолбэк
  `Array.isArray(fc) && fc.includes(spellId)` — симметрия с боевым
  isFreeCast (c.freeCast там — plain-массив, D-05); в production
  equipmentAffixes всегда возвращает Set — фолбэк не срабатывает.
* equipmentAffixes (items.js :1410-1433) — ЧИСТАЯ: raw-read c.equipment
  (без ensureEquipment), итерация ТОЛЬКО EQUIP_PHYS_SLOTS (:113-118 —
  зеркальные weapon/armor НЕ итеруются, двойного подсчёта нет),
  ghost-id → getItem null → skip, null-safe, 0 RNG; включает
  set_bonus free_cast (000230.04) — единая агрегация по контракту
  000230.03 §2.1.
