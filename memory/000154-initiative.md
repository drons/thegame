## Решения (D1-D13)

* **D1 — формула (чистая, экспорт combat.js):** `unitInitiative(c, u)`:
  `u === c.player` → `c.player.primary.dexterity + c.player.primary.intelligence`;
  иначе `((u.attrs||{}).dexterity || 0) + ((u.attrs||{}).intelligence || 0)`.
  `|| 0` — деградация (юнит без attrs → 0).
* **D2 — порядок:** стабильная сортировка (Array.sort, ES2019+) прежней
  канонической базы ПО УБЫВАНИЮ `unitInitiative`; **тай-брейк = прежний
  порядок** (игрок → союзники → мобы, внутри — порядок c.units) = семантика
  до 000154 при равенстве. Одна точка — тело buildTurnOrder (резерв 000036).
* **D3 — очередь на РАУНД:** пересчёт в createCombat и в конце очереди
  (новый раунд); мёртвые/сбежавшие исключены при пересчёте, слоты в текущем
  раунде сохраняются (токен серый) — существующий паттерн.
* **D4 — цикл: `endTurn` = ПРОДВИЖЕНИЕ очереди (интерлевинг):**
  `turnIndex++` (пропуск мёртвых/сбежавших); активный моб → `mobAct`
  синхронно (инвариант 000036: в момент mobAct `c.turnOrder[c.turnIndex]` =
  id действующего — сохранён); активный союзник → 000161: `allyAct`/`efirTurn`
  синхронно; 000162: `c.phase='player'`, ждём ввода ИГРОКА. Очередь
  исчерпана → **НОВЫЙ РАУНД**: `round++`, `refillPools` (игрок), пулы Эфира
  c.efs (блок переезжает сюда), тики (яд/щиты/ослабление) — из «начало хода
  игрока» в «начало раунда» (семантика «1 раз за раунд» сохраняется; смерть
  от яда → `result {outcome:'dead'}` как сейчас), `turnOrder =
  buildTurnOrder(c)`, `turnIndex = 0`, `phase = 'player'`, `targetId =
  nearestMob`. `c.result` в любой точке — стоп. `playerFlee` (неудача) —
  работает без изменений (ход «сгорает»).
* **D5 — фазы: новых значений НЕТ.** 'player' = «действует юнит стороны
  игрока, ждём ввод» (000161: только игрок; 000162: игрок или союзник);
  'mob' — синхронный промежуточный; 'over'. `checkTurn` (гейт «не ваш ход») —
  формула без изменений; читатели phase (combat.js/combat-keys.js/
  combat-ui.js disabled) — работают без изменений.
* **D6 — БИТ-В-БИТ игрок-путь (инвариант):** все `playerX` — БЕЗ ИЗМЕНЕНИЙ
  ТЕЛА; диспатч на публичном API (`c.attack/c.move/c.spell/c.block/
  c.quickItem/c.invItem/c.selectTarget/c.endTurn`): `activeUnitId(c) ===
  'player'` → старый путь; иначе — союзный (000162). Пины порядка
  очереди/лога ОБНОВЛЯЮТСЯ (ТЗ предписывает новый порядок — допустимое
  «техническое изменение под новый путь»).
* **D7 — проводка атрибутов (3 шова):**
  1. Мобы: assets/mobs/*.json (36) + schema.json — новые ОПЦИОННЫЕ поля
     `"dexterity"`, `"intelligence"` (number 0..30); зеркало MOB_TYPES — те же
     поля (deepEqual-тест обязывает); `makeMob` → `u.attrs = {dexterity:
     t.dexterity || 0, intelligence: t.intelligence || 0}` (единый формат).
  2. Наёмники: `allyDataForEntry` — `+ attrs`: СВЕЖИЙ снапшот
     `entry.sheet.primary` (все 6; деградация — `|| 0` в D1).
  3. Эфир: `efirAttrs`/`efirAllyData` `+ dexterity` (sheet-путь:
     `p.dexterity`; legacy `efirStats`: `1` — по SPEC «Дух Эфира»: остальные
     характеристики 1). Контракт: attrs Эфира в бою ВСКРЫВАЕТ dexterity.
* **D8 — баланс инициативы мобов (таблица 36 мобов, зафиксирована):**
  * базовые melee — dex 2 + int 1 = **3**: orc_grunt, skeleton, wolf, boar,
    vampire, rot, scorpion, giant_larva, fire_elemental, water_elemental,
    salamander, lower_demon, **orc_mad** (ГЕП: в таблице a2-arch пропущен;
    melee/aggressive dmg 1.4 — предложено в базовую группу = 3, подтвердить
    на реализации);
  * ranged — dex 3 + int 1 = **4**: orc_archer, skeleton_archer, imp;
  * leader — dex 2 + int 2 = **4**: orc_captain, orc_chief, troll, ant_queen,
    abomination;
  * swarm — dex 3 + int 1 = **4**: crawling_bones, wolf_pack, spider, ant;
  * support/маги — dex 1 + int 4 = **5**: orc_shaman, fairy, succubus;
  * fast — dex 5 + int 1 = **6**: orc_rider, centipede; wind_elemental
    (ranged+fast) — dex 5 + int 2 = **7**;
  * shield/тяжёлые — dex 1 + int 1 = **2**: orc_warrior, bone_coloss,
    cave_bear, earth_elemental, stone_golem.
  Контрольные точки: герой старт (2) = тяжёлые, медленнее базовых; герой
  середины (dex4+int1=5) — быстрее базовых/лидеров/ranged/swarm, на равенстве
  с магами — ИГРОК ПЕРВЫЙ (тай-брейк), медленнее fast. Тесты пинят
  ОТНОСИТЕЛЬНЫЕ порядки (fast > basic > shield; shaman > grunt; rider >
  chief) + 2-3 конкретных значения — не всю таблицу.
* **D9 — управление союзниками (000162, строка 1 ТЗ):** на ходу союзника

    из [игрок, союзники], 0 c._rng) — без выбора цели (v1: детерминированное

  * Эфир: J — «Касание духа» (выделить из efirTurn: всегда попадает, игнор

  * Блок/предметы/побег — ТОЛЬКО игрок: canDoAction для союзника → reason
