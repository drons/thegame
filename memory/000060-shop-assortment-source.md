## Ключевые решения

1. **Вариант (а) задачи** — каталог = источник функционального
   ассортимента: `виды` = id из ITEM_KINDS, а не русская проза.
   Проза `ассортимент` (мечи/луки/посохи/щиты и т.п.) остаётся
   описательной для игрока, кодом не читается (закреплена
   golden-тестом tests/buildings.test.js). Таблица кода в items.js
   не удалена, а вынесена в `SHOP_KINDS_FALLBACK` — фолбэк для
   vm-песочниц без каталога (combat-ui.test.js / dungeon-ui.test.js
   грузят items.js БЕЗ buildings.js; без фолбэка торговля в песочнице
   умерла бы).
2. **Таблица соответствия прозы ↔ видов** (дизайн, закреплена
   golden-таблицей tests/buildings.test.js):
   | магазин | проза `ассортимент` | `виды` (ITEM_KINDS) |
   |---|---|---|
   | Оружейная (0) | мечи, луки, посохи, щиты | weapon |
   | Бронник (1) | доспехи, кольчуги, плащи | armor |
   | Аптекарь (2) | зелья, еда, травы | potion, food |
   | Магазин магии (3) | реагенты, свитки заклинаний, фокусы | reagent, skill_book |
   | Таверна (11) | (прозы нет) | food, potion |
   Значения — ровно прежняя таблица shopKindsFor (items.js до
   000060), поэтому торговля byte-идентична (golden-стоки
   makeShop в tests/items.test.js, включая seed'ы).
3. **Находка: пятый магазин — ТАВЕРНА = запись 000044 (id 44,
   map_index 11), НЕ map_index 4.** Текст задачи говорил
   «map_index 0..4» — неверно: map_index 4 — Арена (id 7,
   школа_навыков), не магазин. Таверна в каталоге категории
   «прочее» (пinned tests/buildings.test.js:123) и прозы
   `ассортимент` у неё НЕТ — `виды` добавлены впервые. Арена
   ОСТАЛАСЬ без `виды` (тест: ровно 5 записей с `виды`, id
   1,2,3,4,44).
4. **Лавка странника (id 5)** — без map_index, проза
   «вьюки/повозки/верёвки/факелы» несовместима с ITEM_KINDS —
   `виды` НЕ вводятся (guard их бы отклонил); товары — NPC-торговля
   (поле «торговля» в assets/npc), не в скоупе.
5. **id не перенумерованы** (сейв v1, 000031); торговля (цены,
   богатство, сток, seed = hash2(x,y)^(type+1), порог
   0.55+0.1*wealth, qty 1+floor(rng*(2+wealth))) — без изменений;
   универсам (богатство 3) — смесь всего, как было.

## УMD: как items.js берёт каталог

factory(perlin, P, DATA, mapmod, bld, rootRef):
- node: `bld = require('./buildings.js')` (6-й аргумент undefined);
- браузер: `bld = null`, `rootRef = globalThis` (как в map.js, 000055:
  factory-параметры, а НЕ замыкание на root IIFE — factory
  лексически вне скоупа параметров IIFE).

`buildingsCatalogRef()`: `bld` с массивом `BUILDINGS` → модуль;
иначе `rootRef.Game`, если там `Array.isArray(BUILDINGS)` (в МОМЕНТ
ВЫЗОВА — переживает Object.assign({}, Game, …)); иначе null →
фолбэк. Никакого кэша вывода.
