## 4. Финальное слово для будущих задач (коротко)

- Зона триггера = КВАДРАТ Чебышёва (код, 000135 findZoneCombat);
  окружность на карте = визуальная аппроксимация (000172), 12 из 16
  граничных тайлов 5×5 вне круга, но триггерят бой. Смена формы зоны
  или отрисовки — отдельная задача (пины M1–M5 + SPEC-пин правки 1).
- Боевые клавиши: J/K — удар (таблица COMBAT_KEYS); H — лечение
  support-наёмника (отдельная ветка combat-ui.js, в таблице НЕТ, только
  ход спутника); Q/R — книга заклинаний (таблица, primary Q); Space —
  конец хода. «(Space)» в ретро-000179 — опечатка, не повторять.
- Литеральный «(v1)» в SPEC — ровно 1 вхождение (буллет управления Эфира,
  L880); пометка «Свои заклинания» — bare «v1». Новое вхождение
  «(v1)» → апдейт счётчика spec-combat-wording в том же коммите.
- §«Дух Эфира → Характер» — ДИСПОЗИЦИЯ (характер), не контракт действий:
  в v1 бою Эфиром управляет игрок (000168 D9/D12), ИИ (allyAct/efirTurn)
  не вызывается. Введение ручного леч/щита или ИИ → переписать 4a/4b +
  пины в том же коммите.
- Любой оверлей, скрывающий ввод (D-пад/кнопки), ОБЯЗАН давать тач-путь
  снятия (memory/000170 §5; реализации: пикер воскрешения 000170, кнопка
  «Воскрешение» в бою 000171).
- SPEC.md — общий файл: правки семантики любого буллета + правка его
  пин-теста — в ОДНОМ коммите (протокол memory/000181 §5).
