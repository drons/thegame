## Решения (кратко — детали в tasks/result/000102.md)

* `не_сжимать` — свойство ЗАПИСИ, не категории, строго `=== true`:
  цепочка сжатия для города НЕ строится вообще (зафиксировано задачей
  против ловушки sizeChain: 7x7 молча → 3x3 → 1x1).
* id 50 «Мост/ворота» НЕ тронут (резерв 000064; внутренним элементом
  города не стал).
* Доли ЧАСТОТЫ типов при размещении (хутор част, столица редка) — НЕ
  в этой задаче: где живут (каталог vs global-settings) решает 000103.

## Для исполнителей 000103/000104/000106

* **000103 (размещение на карте)**: город НЕ слот — hash % 13 не
  трогать (ловушка детерминизма 000064: новый map_index сдвинул бы
  слоты на всех тайлах). Свой «городской канал»: отдельный hash
  (seed XOR константа, прецедент 000073) + доли частоты (решение
  каталог/global-settings — там). Размещение — через
  `placeBuilding(getBuilding(id), x, y, isFree)` — флаг `не_сжимать`
  уже работает: не влезло → null.
* **000104 (layout через подземельный движок)**: вход в запись города
  — явный, НА ПЕРИМЕТРЕ footprint (000026: снаружи свободный сосед);
  координаты входа: 51 [0,0], 52 [1,1], 53 [2,4], 54 [3,6].
* **000106 (содержание)**: читает `мин_постройки` и `доли_типов` из
  особых_параметры; внутренний тип — только существующие записи
  каталога (не «город»); хутор 1x1 — без внутренностей
  (мин_постройки = 0, footprint занят стеной/входом).
* ПРАВКА каталога = ДВЕ правки: assets/buildings/*.json +
  `npm run sync:buildings` (зеркало byte-identical, тест deepEqual,
  sync:check в CI).
