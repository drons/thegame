items-reagent-000321.10 — собственное семейство без суффикса I08:
VIRTNUM/DISK/FILES + NUM2ID/ID2NUM. Формы I08: `NUM2ID_I08`, `ID2NUM_I08`,
`SLUGI08(f)`, `VIRTNUMI08(f)` (диск-имя → прежний виртуальный
«000NNN.json»; для id БЕЗ строки в реестре — fallback: возвращает исходное
slug-имя), `DISKF_I08(x)` (номер → диск-slug; для отсутствующего номера
возвращает «<тот же номер>.json» ⇒ файла на диске нет и краснеет ЧТЕНИЕ
предмета самой волной, а не молча пустой набор), `FILES_I08()`
(отсортированный ВИРТУАЛЬНО-номерной список; сортировка строковая и
«0» < «a», поэтому вне-реестровый id попадает в КОНЕЦ списка, а не
перемешивается с рядом 000NNN). Схема: волны сохраняют numeric-позиционные
пины («000815–000864 подряд»), чтение с диска идёт через DISKF_I08 —
минимальный дифф.

## Грабли (повторяемые)
- Двухстрочные литералы: паттерн правки обязан включать перенос строки
  и точный отступ; count-assert ДО записи (`rep(src,dst,n)`).
- Гейт допускает КОНКАТ-форму `'assets/items/' + '000012' + '.json'`
  (нет смежности «assets/items/»+цифра) и bare-ординалы/`NNNNNN` —
  это НЕ остаток; негативы схем на numeric-путь пишутся конкатом.
- Дисциплина перевёрнутого негатива: schema-негатив должен краснеть по
  ИСПЫТУЕМОЙ причине — legacyEntry-фикстуры с numeric-путём после
  флипа проходили бы `notDeepEqual(validate…, [])` из-за паттерна, а не
  additionalProperties → слагифицировать; наоборот, «имя-файл вместо
  пути» негативы (мёртвые при slug-схеме) переворачиваются на
  numeric-путь конкат-формой (npc-000320.23 T2).
- HEAD-guard класс ЛЕГИТ ИМНЫХ пред-коммитных красных: spells W-08,
  craft-rename-000318.07 T8 (git show HEAD побайтово), sync-idempotency
  — зелёные по построению после коммита; НЕ «чинить».
- `__game.state` (src/main.js) — getter read-only снапшота: записи
  `g.state.hero.gold = …` в vm-тестах молча пропадают. Паттерн
  детерминированной покупки — клики по дешёвому item ('bread'), а не
  накрутка золота (building-effects B26/B29).
- `node -I` — НЕВЕРНЫЙ флаг (python-only); `cmd && next` при падении
  первой команды молча пропускает rest.
- ps-гейт полных прогонов: `pgrep -x node | xargs -r ps -o args= -p |
  grep -c 'node --test'` = 0. НИКОГДА `pgrep -f` (self-match deadlock).
- Пакетные matcher-правки ищутся по ТЕЛУ regex, а не по строке сообщения:
  N6 в npc-000320.01 (`assert.match(p.предмет, /^assets\/items\/\d{6}…`)
  был пропущен первичным свипом (сообщение на другой строке) и поймал
  только полный прогон.
- sync:check НЕ ловит numeric-путь items в NPC-торговле (buildRefMap
  shape-aware, не-ref проходит как есть) — зуб держат ТЕСТЫ npc-data
  («зеркало точная копия», «валиден по схеме») + свой T5 (матрица M2).
