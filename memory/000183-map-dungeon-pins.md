## Решение по тайлу босса ABYSS (ТЗ-4, 4-й пункт)

**Решение: клетка босса должна быть чистой → фикс (опция ТЗ «красный тест»),
не пин текущего поведения.**

- **Почему чистая**:
  - `dungeonMove` обрабатывает на тайле только ПЕРВУЮ группу — блуждающая группа,
    спавнувшаяся на тайле босса, заслоняет босса (игрок не может зацепиться с боссом,
    пока группа не уйдёт случайно);
  - сундук на тайле босса недосягаем до смерти босса;
  - `wanderStep` УЖЕ не пускает группы на клетку босса (`taken` строится из всех
    непобеждённых мобов, включая босса) — асимметрия «можно спавниться, но нельзя
    прийти» — регрессия, а не дизайн;
  - до 000177 exit стоял в дальней комнате (там же босс), т.е. клетка босса лежала
    внутри 5×5 safe-зоны вокруг выхода — спавн на ней был невозможен. После
    совмещения exit := entrance safe-зона переехала в комнаты входа, и клетка
    босса оказалась в зоне спавна (src/dungeon.js ~L389-431).
- **Почему реализация — `occupied.add(far.cx + ',' + far.cy)` в
  generateDungeonContents (до первого takeSpot, guard `d.type === ABYSS`),
  а не расширение safe-сета**:
  - эффект на распределение спавнов одинаков (отвергающая выборка равномерна по
    оставшимся клеткам), но `occupied` — минимум: 1 Set.add, `floorCells`/`safe`
    и их комментарии не трогаются;
  - guard по типу делает все НЕ-ABYSS подземелья бит-в-бит неизменными (проверено
    пробой);
  - 0 новых вызовов rng(), кроме отклонённых повторов takeSpot (≤200/попытка —
    то же, что для любой занятой клетки).
- **Проверенные числа** (пробы в /tmp/thegame-wf-000183/, в коммит не входят):
  - сетка 80 входов × 16 xp: 1280 ABYSS-подземелий, на мастере 35 с коллизией
    (сундук/блуждающий моб на клетке босса) → после фикса 0; сменили контент
    ровно эти 35 подземелий (влияние локализовано);
  - свип xp=1..3000: 69 коллизий на мастере, первая — xp=18 (сундук c3 (14,6)
    на золотом подземелье (11,3)) → 0 после фикса;
  - золотой ABYSS (11,3)/seed 2941640529: контент ПОСЛЕ фикса бит-в-бит тот же →
    существующий золотой пин НЕ перепинается;
  - репин D-BOSS-2 (post-fix контент): (11,3)/xp=18 + Case A (−25,−20)/xp=100
    + Case B (−15,−20)/xp=321 — значения в main-файле memory.
- **Сейвы**: контент персистентен в dungeon_memory — фикс не инвалидирует и не
  мигрирует старые сейвы (контракт: миграция не требуется).
- **Тесты**: D-BOSS-1 (красный на мастере: свип xp=1..3000, ни один не-босс-моб
  и ни один сундук не на клетке босса) + D-BOSS-2 (репин post-fix контента,
  зелёный с рождения) в tests/dungeon.test.js.
