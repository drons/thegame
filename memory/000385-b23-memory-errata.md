## 4. ПРАВИЛО ФИНАЛЬНОГО АГРЕГАТА (пункт (e) кросса b23)

При финальном sync-amend'е пересчитывать НЕ только «финальные числа» result,
но и агрегатную строку сообщения коммита «ФИНАЛЬНЫЙ ДИФФ N файлов +/−»:
после ПОСЛЕДНЕГО amend выполнить `git diff --numstat <база>..HEAD`, сверить
суммы added/deleted и число файлов с текстом сообщения; при расхождении —
домножать правку до неподвижной точки (числа в сообщении и result правятся
одним amend-циклом). Прецедент расхождения: коммит spec-эрраты .374
(f56802c0) нёс в сообщении дифф-агрегат «253+/6−» при numstat-факте
git diff --numstat f56802c0^..f56802c0 = «261+/6−»; дельта +8 — это тот
самый оркестраторский финальный docs-amend (вырос result), не попавший
в цифру. Прежняя запись «253+/147 при факте 261+/155» — ЭРРАТА 000391
(ретро-b24 V3-nit): путала разнородное — 147→155 это строчник
tasks/result/000374.md («147 строк» в том же сообщении при фактических
155), ДРУГОЙ измеритель, а не deleted-сторона диффа (deleted = 6 на
обоих замерах); обе пары сходятся на одну +8 — от одного аменда.
Пост-мерж сообщение не лечится (Р.3). Правило применимо ТОЛЬКО до
commit --amend — после мержа оно безвозвратно.

ВТОРОЙ прецедент (ретро-b24 F1, внесён эрратой 000390): коммит мержа
.28 (`17fb6aa7`, 2026-11-14) несёт в сообщении и в
tasks/result/000320.28.md:286 «39 файлов, 1522+/194−», при факте
`git diff --numstat 2a5a95f5 17fb6aa7` = **1578+/194−, 39 файлов**
(переснято живым numstat-ом; состав 194− и 39 файлов точны, искажён
только added). Причина того же класса: агрегат замерен на РЕ-БАЗЕ №8 —
доказательная пара `git diff --numstat a300efc2 17fb6aa7` = память
+24/−15 и tasks/result/000320.28.md +55/−8 = ровно **+56 чистых** строк
финальных docs-amend'ов, не попавших в цифру (1522 + 56 = 1578). Оба
носителя заморожены (коммит-сообщение и result .28 — Р.3), пост-мерж не
лечится — эррата только здесь. Станция .28 шла ДО кодификации этого
правила (тот же день, позже) — это ЕЁ ПРЕЦЕДЕНТ, а не нарушение
известного правила; рецидив лечится тем же: агрегат пересчитывать
numstat-ом ПОСЛЕ последнего amend, до неподвижной точки.

Куда внесено: этот файл, а НЕ memory/000373-b21-errata.md (его параллельно
правит волна 000380 — пересечение) и НЕ memory/000369-b20-frozen-literals.md
(реестр Р.1–Р.4 — вне скоупа). НЕ нумеровать «Р.5» вслепую (реестр-претендент
— 000369, двойная нумерация = новый дефект): кандидата в реестр перенести в
