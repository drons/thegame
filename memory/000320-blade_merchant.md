- src/building-effects.js `buildingActions(building, npc, state)` —
  `npc` принимает объект, МАССИВ NPC или null; на каждого — строка
  «Диалог: <имя>», id первой 'dialog' (совместимость data-buid/hotkey),
  остальных 'dialog:<id NPC>'; поле npcId на всех строках; эффекты —
  после строк диалога (порядок каталога).

  (deps.game.npcsForBuilding — иначе [npcForBuilding] для тестовых
  фейков); toggle (мир) и interactCity (город) передают СПИСОК в
  openBuildingUI; openBuildingUI нормализует список и вызывает
  buildingActions с `list.length ? list : null` (ловушка truthy-[]:
  городские фейки `if (npc) push` — пустой массив правдив, null нет);
  onBuildingAction(a, t, b, npc, npcs) — 5-й параметр необязателен;
  dialog-ветка: id 'dialog'/'dialog:*', маршрутизация по action.npcId
  из пула (нет npcId — 4-арг совместимость → npc).
- hud.js «Здесь:» — НЕ тронут (первый NPC постройки = npcForBuilding).
