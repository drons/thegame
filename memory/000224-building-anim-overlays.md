## 2. Ключевое решение: кадр-свитч, НЕ оверлей (a2 отклонён)

* Оверлей (прозрачный SVG поверх нетронутой базы) не может стереть СТАТИЧНЫЙ
  дым, вшитый в blacksmith.svg (canvas-композитинг без «стертия») → двойной
  дым: статичный + анимированный — визуально не «идёт дымок». Кадр-свитч
  переотрисовывает здание целиком — артефакта нет.
* Кадр-свитч — идиома проекта (вода water_1..4, мобы 2 кадра,
  PHLOGISTON/EFIR/MERC — все кадровые, SPEC: «Анимация — по кадрам
  (отдельные файлы), а не по времени внутри SVG»; SMIL в SVG запрещён
  spec/MOBS.md).
* a2 фактически ошибся в домене: утверждал «городского экрана с рендером
  зданий нет» — НЕТ, есть слой 000148.02 (G1) в dungeon-ui.js (L588+):
  cityContents.buildings → cityBuildingPath → drawImage на клетке. Игроки
  МОГУТ построить кузницу (id 8) и магазин магии (id 4) в городе: обе
  записи каталога имеют map_index (5/3) и .стройка.золото → входят в
  cities.buildableBuildingIds() → городские постройки id 4/8 реальны →
  «в городе» = dungeon-ui-канал, он анимируется (cityBuildingPath).
* a2 добавлял город 53 (третий контент-таргет 3×320×320) — за пределами
  ТЗ («например» = два названных примера) → отклонено; остальной контент
  (прочие здания/города 51/52/54/лагерь-костёр) — follow-up 000238.
* Цена кадр-свитча принята: 8 полных SVG (64×64, маленькие) + один
  технический репин svg.test.js + ВОЗМОЖНАЯ техническая синхронизация

## 3. Контракты и границы

* BUILDING_FRAMES — ЛИТЕРАЛ (прецедент MOB_FRAMES/TILE_FRAMES), ключи —
  СЛОТЫ BUILDING_TYPES: { 3: [magic_shop_1..4.svg], 5: [blacksmith_1..4.svg] }
  (каждая строка — 'assets/sprites/buildings/<name>_<n>.svg'). Каталог/JSON
  не расширяется.
* buildingFrames(slot) → string[] | null: null для 0..12 без анимации,
  NONE(−1), 999, undefined, мусора (конвенция null — как buildingSprite).
* buildingFrameIndex(nowMs, tx, ty, frameCount) → int [0; n):
  `t = max(0, floor(nowMs / BUILDING_FRAME_MS)); phase =
  (((tx*5 + ty*9) % n) + n) % n; return (t + phase) % n`. Чистая функция;
  фазовая схема — та же, что frameIndex (соседи рассинхронизированы,
  детерминизм Д10); нечисловое now (NaN/±Infinity/undefined) — клампится
  к 0 БЕЗ исключения (индекс валиден, рендер не падает).
* BUILDING_FRAME_MS = 800: медленный «экологический» дрейф (дым/мерцание) —
  медленнее мобов (FRAME_MS=480), не период воды (3200).
* СТРОГАЯ готовность (единственная легальная семантика):
  анимированный слот → ассет = ТЕКУЩИЙ КАДР; кадр не загрузился →
  legacy-маркер (карта, гейт buildFrame) / skip (город, клетка остаётся
  полом, контракт 000148.02). FALLBACK НА БАЗУ ЗАПРЕЩЁН: он ломает
  RM-9(c) глобальной карты семантически (reject нарисованного кадрового
  пути оставил бы базу готовой → спрайт нарисован → (N−1, 6 вершин)
  падают; строгость делает тест зелёным при ЛЮБОМ первом здании кадра —
  предикат onerror бьёт по нарисованному пути, селектор вернёт тот же
  путь). Прецедент: вода (кадр не готов → legacy-квад, без fallback).
* Око загрузочное: пока 4 кадра не загрузились — здание в legacy-маркере
  (карта) / без спрайта (город) — тот же класс поведения, что неготовый
  статичный спрайт сейчас; 8 путей в allAssetPaths → pre-лоад main.js L145;
  город использует ТОТ ЖЕ spriteLoader (startLocationUI → dungeonUI.start)
  → кадры приходят в город бесплатно.
* Каталог-override «спрайт» (slotSpriteTable): в начальном скопе каталог
  НЕ переопределяет 3/5 (проверено: 000004/000008 — пути по умолчанию).
  Если переопределит — кадр нарисован под ДЕФОЛТНЫЙ арт (ограничение,
  допустимо; в follow-up).
* z-порядок не меняется: кадр — это тот же единственный drawImage здания
  на том же прямоугольнике (p.x, p.y, rec.w*zoom, rec.h*zoom / клетка
  cr.x, cr.y, cr.w, cr.h) — все z-пины (000191.6b и др.) интактны.
* RM-9(c) baseline: в спавн-кадре (NOW+200, ZOOM_START) зданий слотов 3/5
  НЕТ (эмпирика a1: cave_entrance/arena/rune_stone) → тест побайтово не
  меняется; строгая семантика делает его зелёным и в общем случае.
* existing-фикстуры не содержат слоты 3/5: city-screen 000148.02 G1
  (деревня 52: id 1/44/5 → слоты 0/11/нет), dungeon-ui 000148.02 (id
  44/45/37/1/25/36/999/5 → слоты 11/11/8/0/12/7/—/—), CI-B5 (иконки 48/36/
  44/1/55), camp-map-e2e (id 47) → весь существующий набор зелёный БЕЗ
  правок (кроме репина svg-счётчика).
