## Формулы (ФИКСИРОВАНЫ ТЗ — не усложнять)

* **Ролл содержимого**: 40/30/30 — ЛУТ / ЛОВУШКА / ЗАПИСЬ.
  Один детерминированный ролл:
  `r = hash2(x, y, RUINS_ROLL_SEED ^ day) / 2^32` (∈ [0, 1));
  кумулятивные пороги из каталога `эффект.доли`, ПОРЯДОК фиксирован
  КОДОМ (лут → ловушка → запись), нормализация по сумме:
  r < лут/Σ → 'loot'; r < (лут+ловушка)/Σ → 'trap'; иначе 'note'.
  НИКАКОГО Math.random/Date (детерминизм, ТЗ; паттерн 000074).
  `доли` — ЦЕЛЫЕ ПРОЦЕНТЫ {лут: 40, ловушка: 30, запись: 30}:
  ТЗ говорит в процентах; целые избегают float-представления
  (0.4 не точно в bin); код нормализует по сумме — суммы ≠ 100 не
  ломают формулу. (Альтернатива 0.4/0.3/0.3 ОТВЕРГНУТА — эквивалент
  семантики, но дробные в каталоге без выигрыша.)
* **Лут**: предмет id ИЗ КАТАЛОГА `эффект.предметы` детерминированно
  по (tile, day): `предметы[hash2(x, y, RUINS_LOOT_SEED ^ day) % len]`
  (паттерн pickFragment 000074). НОВЫХ предметов НЕ ВВОДИТЬ (ТЗ) —
  16 существующих id (ниже). В инвентарь кладёт спец-хендлер
  (G.addItem(hero, itemId, 1)); отказ (слоты/вес/неизвестный id) —
  попытка ВСЁ РАВНО сгорает (раз-в-день, повтор — новый день;
  игрок с полным инвентарем не блокирует осмотр навсегда):
  сообщение «Осмотр развалин: не удалось подобрать лут (<reason>).»
* **Ловушка**: урон 2 БЕЗ БОЯ (просто урон по HP; startCombat НЕ
  вызывается; Конституция/Телосложение/снаряжение НЕ учитываются —
  ТЗ «формула фиксирована, не усложнять»). Урон — ИЗ КАТАЛОГА
  `эффект.урон_ловушки` (= 2). HP НЕ ПАДАЕТ НИЖЕ 1 (не убивает —
  ТЗ): clamp в спец-хендлере `hero.hp = Math.max(1, hero.hp - damage)`
  (hp=2 → 1; hp=1 → 1; герой жив).
* **Запись**: фрагмент лора ИЗ КАТАЛОГА `эффект.тексты`
  детерминированно по (tile, day):
  `тексты[hash2(x, y, RUINS_NOTE_SEED ^ day) % len]` (pickFragment).
  Расшифровка — проверкой ИНТЕЛЛЕКТА: ЧИСТАЯ проверка
  `level >= порог` (детерминированное сравнение, НЕ ролл — ТЗ
  «проверка Интеллекта: порог уровня» + тесты «кейсы на границе»).
  level = G.skillLevel(hero, 'intelligence') (npc.js:48;
  'intelligence' — primary skill; стартовое значение 1 —
  createCharacter player.js). Порог — ИЗ КАТАЛОГА
  `эффект.порог_интеллект` (= 5: стартовый интеллект 1 → порог
  недостижим в первые дни, mid-game гейт — данные-решение, ТЗ
  число не даёт). Успех → фрагмент в сообщении; провал →
  «Осмотр развалин: запись не читается.» (фрагмент НЕ выдаётся —
  ТЗ). Повторная попытка — в НОВЫЙ ДЕНЬ (новый ролл — ТЗ).
* **Семантика попытки (R3)**: ЛЮБОЙ валидный исход (лут, ловушка,
  запись-успех, запись-провал, loot-отказ) → ok:true — попытка
  СГОРЕЛА: роутер ставит daily-марку + saveNow (ок-ветка); повтор
  в тот же день — «уже использовано сегодня». ok:false — только
  «недоступно» (деградация: нет hash2/skillLevel, мусорный каталог,
  hero не-объект) — эффект не сработал, маркировки нет (паттерн
  000074/000075/000128 §2.6).
* **Раз-в-день** — ИЗ КАТАЛОГА (принцип 000053):
  `особые_параметры.раз_в_день: true` (паттерн 000072/000040);
  в записи реестра разВДень НЕ ставится (каталог побеждает).
* **Сиды**: RUINS_ROLL_SEED 0x5255494e 'RUIN', RUINS_LOOT_SEED
  0x52554c54 'RULT', RUINS_NOTE_SEED 0x52554e54 'RUNT' — свои
  ASCII-константы (паттерн TELEPORT_TIE_SEED/STONE_*; НЕ GLOBAL_
  SEED), экспорт — golden-пины; различны между собой и со
  STNR/STNT/OBLT/TELP/SUBT (сверено).
