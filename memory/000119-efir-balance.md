  И как реальные тесты (красные при сломанном балансе — mutation-проверено,
  §5).
* **D2. Герой = midGameHero() (L15, maxHP 62, 2 удара, блок), levelDeltaMax: 0;
  Эфир = свежий createEfir() L1 (hp 16, mp 11, Касание 4, книга [spark, mend])** —
  ТЗ не предписывает уровни: L15 «герой уровня группы» = паттерн 000027 (среды

  `u.mp = 20` прямо НЕ ставим (ТЗ-паттерн 000113 — только «если сценарий
  требует», сценарий не требует).
* **D3. Собственные mob-only хелперы (autoTargetMob119/autoPlay119/passivePlay119/
  battle119), существующие autoTarget/autoPlay НЕ ТРОГАТЬ** — КРИТИЧЕСКАЯ
  ЛОВУШКА: autoTarget (tests/combat.test.js:67) строит пул целей по ВСЕМ живым
  c.units и приоритизирует role 'support' — а Эфир = role 'support'
  (efirAllyData, efir.js:219): бот целит СВОЕГО Эфира → c.attack('efir') →

  (без Эфира — 35/35). Это артефакт тестового ИИ 000027 (писался «без

  ТЗ-буква «герой ПОЛУЧАЕТ урон (HP после < 100%)» per-combat НЕДОСТИЖИМА:
  в слабых группах (wolf_pack/skeleton_den/spider_nest) 13/35 боёв герой
