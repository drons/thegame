# 000065: «Найм» спутников — ключевые проектные решения (разбивка)

Статус: мета-задача выполнена как анализ + разбивка (10 дочерних в
pending: 000078–000087), SPEC.md дополнен разделом «Спутники» +
3 точечные правки. Игровой код не писался.

## Ключевые решения (зафиксированы в SPEC.md «Спутники» и в подзадачах)

1. **ЕДИНЫЙ фреймворк «союзные юниты» (side 'ally')**: Эфир и
   наёмники — одна модель союзного юнита. Это явное решение по
   000035; задаёт порядок: фреймворк (000080) → Эфир (000081) →
   найм (000079/000083).
2. **Эфир — постоянный союзник**: всегда на поле, свой
   НЕЗАВИСИМЫЙ пул навыков (100% боевого опыта), не умирает
   навсегда (реген 100% HP в следующем бою), без жалованья/
   лояльности. Данные пула изолированы в src/efir.js — подзадачи
   000035 правят только этот модуль, не combat.js. Файлы
   000034/000035 (master/pending) НЕ менять — только ссылаться.
3. **Найм**: NPC каталога assets/npc с новым опциональным полем
   `найм` {цена, жалованье, роль (melee/ranged/shield/support),
   dmg, hp, armor?, skills[], spells[]} + новое значение «найм» в
   enum `действие` диалога. Найм — в таверне building 44 (ТАВЕРНА
   ID 22 — школа Харизмы, на карту не генерируется — не использовать).
   Отряд ≤ 3 (max_companions, global-settings).
4. **Контракт**: разовая цена найма + жалованье в день; списание —
   в clock.onDay (main.js ~425, ДО saveNow). Нет золота → −20
   лояльности, уход: ≤20 — верно, 21…40 — 50%, >40 — остаётся.
   Увольнение — без возврата, повторный найм возможен; гибель —
   окончательна (dead_mercs в сейве).
5. **Лояльность**: 0…100, старт 50 + Харизма (cap 100), +2 за
   оплаченный день. Отказ при найме: 30% − 2%/ур. Харизмы −
   5%/ур. Артиста (min 0) — формулы зафиксированы в SPEC
   «Навыки»→«Харизма» (Предводитель/Артист — уточнены).
6. **Бой**: союзники — отдельные юниты 1×1 рядом с игроком (7×7
   вмещает 10 юнитов: игрок + 3 + 6 мобов); очередь игрок →
   союзники → мобы; ИИ — шаг к врагу + действие по роли (support
   лечит самого раненого, включая игрока); гибель ≠ поражение;
   Предводитель — companionMoraleBonus (player.js:230, +5%/ур.
   урона ВСЕМ союзникам). НЕ смешивать со вражеской ролью
   'leader'/hasLeader — разные сущности.
7. **Опыт**: игрок 100% (без изменений), выживший спутник —
   companion_xp_share (по умолч. 0.5); уровень — xpForNext, статы —
   makeMob; навыки фиксированы из каталога (очков НЕТ). V1:
   практика (000013/000041) — только навыки игрока; опыт квестов —
   игроку. Эфир вне механизма (свой пул, 000081).
8. **Сейв**: неломкое расширение v1 БЕЗ бампа CURRENT_VERSION
   (000031): companions [{npcId, level, xp, loyalty, hiredDay}],
   efir, dead_mercs. Старый сейв → пустой отряд, Эфир — уровень 1.
   «Призрак» (npcId не в каталоге) → тихий отброс + warn (000029).
9. **Детерминизм**: «мирового» rng НЕ вводится — все новые
   случайности (отказ найма, уход) — seed = perlin.hash2(day, npcId),
   генератор perlin.mulberry32 (src/perlin.js).
10. **UI**: вкладка «найм» в Game.npcUI (000083); панель «Отряд» —
    хоткей KeyC (RU «С» — «Состав»), свободна в мире и в COMBAT_KEYS;
    панель — ТОЛЬКО ПОСЛЕ 000051 (иначе двойной редизайн оверлея).
