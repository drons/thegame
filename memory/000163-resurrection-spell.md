## 2. Решения станции (итоговые)

* **R-1. Цель — мёртвый игрок в castSpell: автоцель БЕЗ маркера
  `targetId 'player'`.** Явный `targetId` — ТОЛЬКО юниты `c.units`
  (side 'ally', !alive, !fled); без `targetId` — авто: мёртвый игрок
  ПРИОРИТЕТНО (катастрофа выше), иначе первый мёртвый союзник в порядке
  `c.units`. Причина отказа — «нет цели» (та же, что у TARGETED).
  Почему: герой НЕ в c.units и поля `id` не имеет — строка 'player' была
  бы выдуманной адресацией; единственный живой потребитель воскрешения
  игрока — Эфир (000164), который по D4 вызывает
  `combatInternals.resurrectAlly(c, c.player)` НАПРЯМУЮ (не через
  castSpell); мёртвый кастер кастовать не может (кастер — сам игрок).
  (Заменяет вариант a1-анализа «targetId 'player' — маркер» и его
  «000166 использует 'player'»: пикер 000166 — по мёртвым СОЮЗНИКАМ.)
* **R-2. Дальность НЕ ограничена** — исключение из SPELL_MAX_DIST=4,

* **R-3. Строка лога ЗАКРЕПЛЕНА: «Возвращён в бой.»** — всегда, без

### 3.3 Цель-правило evalSpell (src/spells.js) — ветка ПОСЛЕ блока TARGETED
```js
} else if (spell.действие === 'воскрешение') {
  let t = null;
  if (targetId) {
    const u = c.units.find((x) => x.id === targetId);
    if (u && u.side === 'ally' && !u.alive && !u.fled) t = u;
  } else if (!c.player.alive) {
    t = c.player; // мёртвый игрок — приоритет автоцели
  } else {
    t = c.units.find((x) => x.side === 'ally' && !x.alive && !x.fled)
      || null;
  }
  if (!t) return { fail: { ok: false, reason: 'нет цели' } };
}
```
