## ПЕРЕРЕЗКА ХВОСТА: что обязан сделать мерж звена "41"

Хвостовые зубы .40 (T5/T9) сверяют СВОЙ инлайн-гард с `aggregateAll` и
требуют «свои 4 — НЕ в реестре». Это инвариант ХВОСТА: после вписания
звена "41" .40 перестаёт им быть. Коммит .41 обязан (прецедент перерезки
.39 в этом же диффе):

- добавить в .40 `const SELF_LINK = 40;` (после aggregateAll),
- T5: `deepEqual(ownInline, aggregateThrough(readLedger(), SELF_LINK), ...)`,
- T9: `agg = aggregateThrough(ledger, SELF_LINK)`; длина — формулой по
  `keys.filter(k => k <= SELF_LINK)`; `prev = aggregateThrough(SELF_LINK-1)`;
- вместо цикла «не в реестре»: `deepEqual(ledger.links['41'], MINE)`
  (резерв погашен) + цикл «в СВОЁМ агрегате своих нет»;
- guard-литерал и MINE .40 — ПОБАЙТОВО 0-diff (их пинует 000424 T4:
  агрегат через 40 ≡ extractGuard(40) навсегда = 147).
Сверка полного агрегата остаётся исключительным зубом хвоста 000424 T5.
Мутационно это доказано M6 (замена фразы в литерале гарда .40 красит
T5+T9+000424 T4/T5).
