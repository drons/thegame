## Что добавлено в код

* **src/map.js**:
  * `SUBTYPE_SEED_CONST = GLOBAL_SEED ^ 0x53554254` (ASCII «SUBT»;
    прецедент CITY_SEED_CONST «CITY») — экспортирована (golden-пины
    hash2 в tests/map.test.js; смена = смена карты подтипов).
  * `subtypeTable(slot)` — ленивый вывод таблицы долей слота
    (паттерн 000055: каталог через catalogRef() в момент вызова,
    функции не константы/getter'ы, кэш ПУСТОГО вывода запрещён —
    vm без buildings.js → null, после загрузки каталога в тот же
    sandbox — подтипы). Слоты 0..7 / вне 8..12 → null. Базовая запись
    — buildingForMapIndex(slot), доля = остаток 100 − Σдоля подтипов;
    остаток ≤ 0 → null (неверная конфигурация — деградация к базовой,
    buildingId null). Порядок кумуляции — **возрастание id**
    (записи [базовая + подтипы]; хвост — наибольший id).
  * `subtypeFor(x, y, slot)` — ЧИСТАЯ функция, экспортирована:
    u = hash2(x, y, SUBTYPE_SEED_CONST)/2^32, кумулятивные доли →
    id; нет таблицы → null.
  * `buildingAtAnchor`: запись СЛОТОВОГО якоря (anchor.buildingId ==
    null) получает `buildingId: subtypeFor(ax, ay, anchor.type)`;
    городская ветка (buildingId 51..54, type NONE) — БЕЗ ИЗМЕНЕНИЙ.
    Геометрия (placeBuilding по БАЗОВОЙ записи b, footprint/вход/
    wealth) — инвариантна.
  * JSDoc buildingAt/tileAt — новая семантика buildingId
    (51..54 города; подтип слотов 8..12; null у 0..7/без постройки).
* **assets/buildings (source of truth)** — 10 записей-подтипов
  получили `особые_параметры.размещение { слот, доля }`; schema.json
  не тронут (особые_параметры — свободный объект). Базовые 36/31/40/
  44/25 — БЕЗ ИЗМЕНЕНИЙ (доля = остаток). map_index у подтипов НЕТ
  (13 слотов не меняются, BUILDING_COUNT = 13).
* **src/buildings.js** — регенерация scripts/sync-buildings-data.js
  (write-atomic; byte-зеркало JSON).
* **src/main.js — ДВА изолированных ханка** (не пересекаться с
  000100: ui.js + проводка после createClock):
  * `maybeEnterDungeon`: гард `t.buildingId === 48` — развалины (подтип
    слота 9) — ПОСТРОЙКА, не вход: шаг НЕ открывает лабиринт.
    buildingId null (без каталога) — вход сохраняется (fail-open).
  * HUD «Здесь:» (блок 000105 расширен в общую ветку): `hint`
    пещеры подавлен для 48 (`t.buildingId !== 48`); ветка имени —
    `if (t.buildingId != null)` → запись по id, имя =
    название_карты || название (регистр buildingNameUi);
    `hint = ' (вход — шагните)'` — только у категории «город».
    Городская ветка 000105 — частный случай (регрессия:
    city-screen.test.js «Здесь: <имя города>» и «вход в пещеру
    (вход — шагните)» — базовая 31 даёт то же имя, что
    buildingNameUi(9)).

## РЕ-ПИН GOLDEN_TILES (tests/map.test.js, пометка «РЕ-ПИН 000073»)

те же — геометрия инвариантна): храм якорь [−119,9] → 36 (6 тайлов),

фонтан [−250,49] → 49; башня [−255,137] → 46; храм луны якорь
