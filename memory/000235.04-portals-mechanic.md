### 4.3 castFail (внутренний) — точный self-rollback (.02-контракт)

```
castFail(p, spell, info) {
  p.mp += spell['мани'] || 0;
  const eff = p.outOfCombatEffects;
  if (info.expiresDay !== null) {
    if (info.prior >= 0) eff[info.prior].expiresDay =
      info.priorExpiresDay;
    else if (eff.length > info.priorLen) eff.splice(info.priorLen);

}
```

expiresDay null) → обычный откат = только мана; путь

(prior ≥ 0 — in-place запись возвращается к прежнему expiresDay;
иначе удалён дописанный в хвост элемент).
Порядок причин .02 не меняется: «не хватает маны» ВСЕГДА раньше
игровых отказов (контракт OC1-OC7).

function zoneSuppressedReason(zone) {
  if (G.Spells && typeof G.Spells.isHeroInvisible === 'function'
      && G.Spells.isHeroInvisible(hero, clock.day)) {
    return 'невидимость';

  if (zone && G.Spells && typeof G.Spells.wardRadius === 'function') {

  if (zoneSuppressedReason()) return null;
