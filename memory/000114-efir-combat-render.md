## 2. Контракты и границы

* **EFIR_FRAMES — статичный литерал.** `efirFrames` НЕ читает диск
  и НЕ зависит от каталога (браузер file://, детерминизм, UMD-
  чистота). Семантика ТЗ «каталога нет → [] без ошибок» = деградация
  на УРОВНЕ ЛОАДЕРА: loadFn → null → state 'failed' (штатен, «кадры
  не обязательны для загрузки») → image() → null → фолбэк-
  прямоугольник + маркер «свой». Делать таблицу fs-зависимой —
  ЗАПРЕЩЕНО (ломает чистоту/детерминизм и паттерн PHLOGISTON_
  ACTIONS, на который ссылается ТЗ).
* **Не переименовывать/не трогать каталог в тестах**: симуляция
  отсутствия — только на границе лоадера (прецедентов tree-mutation
  в тестах нет; sync-all.test.js — только tmp-каталоги).
* **Имена экспортов EFIR_FRAMES/efirFrames(action) — контракт**
  (зафиксирован 000034 под 000114): переименование ломает
  combat-ui.js и тесты 000034.
* **allAssetPaths()** — main.js ставит в очередь лоадера РОВНО его
  результат; пропущенный путь = кадр никогда не загрузится. Блок
  Эфира — изолированный (sprites.js:667–668), дедуп — общий Set
  (тест «без дублей» L408).
* **svg.test.js**: `'sprites/efir': 8` (L447), всего 297 — 000114
  новых SVG не вводит, счёт ИНВАРИАНТЕН.
* **Геометрия/цвета ally-ветки** (44×44 @+2, 32×32 @+8, HP 32×4
  @+8/+2, 39×39 @+4.5, 41×41 @+2.5; rgba(140,242,252,0.25),
  #8cf2fc, #ffe27a, #3a0d0d) — пинины 000084 (styleCalls +
