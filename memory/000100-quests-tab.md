# 000100 — вкладка «Квесты» панели персонажа (контракт)

Задача 000100 (smержена 2026-09-30): read-only зеркало журнала
квестов во вкладке «Квесты» панели персонажа.

## Контракт
* Сеттер: `G.playerUI.setQuests({ npcs, book, day })` — паттерн
  setCharacter/setShop в src/ui.js. Вызывается ОДИН раз.
* Вкладка read-only: на строках квестов нет кликов/действий
  (действия — только в диалоге NPC). Тест-фиксатор: отсутствие
  обработчиков.
* Рендер: `renderQuestsPane(body)` вызывается в каждом
  `render()` панели. Журнал (questBook) мутируется in place при
  restore — производные данные НЕ кэшируются между render'ами.
* Проводка в src/main.js: ПОСЛЕ `const clock = G.createClock()`
  (TDZ: `clock.day` не читается раньше), гард `G.playerUI &&
  G.playerUI.setQuests &&` — vm-песочницы без ui.js не роняются
  (паттерн 000053).

## Для 000130 (разбиение ui.js на саморегистрирующиеся вкладки)
* Вкладка «Квесты» — ПЕРВАЯ, кто переносится в модуль
  (демонстрация паттерна). Её данные = снимок {npcs, book, day};
  модуль получает их через тот же канал, что и сейчас
  (setQuests-хранилище playerUI, чтение в render).
* При переносе сохранить: read-only семантику, per-render
  перерисовку (без кэша), гард проводки в main.js (1–2 строки
  main.js не трогаем вообще, если не потребуется).
