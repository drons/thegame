## Контракты и границы

### stateEl — ровно ДВЕ строки (фиксированность — по КОНТЕНТУ)
```
строка 1: `${c.groupName}, раунд ${c.round}`
строка 2: строка цели — ПОБАЙТОВО как до (L1502–1504):
```

фикс. высоту. CSS-высоты (`height:3em; overflow:hidden`) НЕ ВВОДИМ — магическое
число + overflow скрыл бы будущую регрессию; страховка = тест CU199-FIXED-2

контракт 000124) — НЕ ТРОГАЕТСЯ; всё новое — только в скоупе

### Полосы HP/MP следуют за активным персонажем
`barUnit = activeUnit(c) || c.player` (детерминированно, без доп. состояния):

| кто ходит | HP-полоса | MP-полоса |
|---|---|---|
| игрок (`activeUnitId='player'`) | `p.hp / d.maxHP` (d = G.derived) | `p.mp / d.maxMP` |
| Эфир | `u.hp / u.maxHP` | `u.mp / u.maxMP` |
| наёмник | `u.hp / u.maxHP` | `u.mp / u.maxMP` (000193: мана в модели, снапшот maxMP в makeAlly — 000193.01; юнит без поля maxMP — деградация `MP —`/0%) |
| фаза мобов / конец | герой (activeUnit null) | герой |

- HP: width = clamp(frac)·100%, color = `hpBarColor(frac)` (те же пороги,
  единая окраска), текст `HP x/y`.
- MP: width = clamp(mp/maxMP)·100% (maxMP 0 → 0%), color ФИКСИРОВАННЫЙ `#8cf2fc`
  (пороговой функции для маны НЕ вводим — memory/000038), текст `MP x/y`
  или `MP —` (юнит без maxMP — деградация, 000193.01).
- Источник maxMP Эфира (ревью 000199, major): СНАПШОТ `u.maxMP` из
  buildEfirUnit (`= stats.maxMP` — Sheet-истина 5+Int+Wis, растёт
  ОЧКАМИ 000144), НЕ замороженная legacy-таблица efirStats(level) —
  та расходится с фактом после level-up/роста primary (пример: L3 без
  очков — полные 11 маны, таблица дала бы знаменатель 13). Fallback —
  legacy (юнит без поля). Пины: CU199-MPBAR-ALIAS/`-SHEET` (combat-ui),
  EF-1 (efir.test), ES-4 (efir-sheet).
- Canvas-миниполоса героя в drawUnits (4px над ромбом) — ОСТАЁТСЯ геройской:
  `hpFrac`/`hpColor` (render L1404–1410) не трогаем, drawUnits не трогаем
  (регион 000197).
- Обновление полос/бейджей/stateEl — ТОЛЬКО в render() (контракт 000038/000047),
  rAF-цикл подхватит; отдельных слушателей/timers нет.

### Бейджи `.combat-actcount` (только attack + spellbook)
| кнопка | значение | источник |
|---|---|---|
| attack («Удар») | ВСЕГДА видим, включая 0 | игрок: `c.ps.attack`; наёмник: `u.attackLeft`; Эфир: `c.efs ? c.efs.touch : 0`; фаза мобов: `c.ps.attack` (барUnit = герой) |
| spellbook («Книга заклинаний») | игрок и фаза мобов: `«int/wis»` (напр. `1/1`); ход союзника: СКРЫТ (display none + text '') | игрок: `c.ps.spellInt / c.ps.spellWis` |

- Формат `int/wis` — два пула отдельно, порядок как в убранной строке
  «Огонь|Леч» (сумма отклонена: смешивает пулы).
- На ходу СОЮЗНИКА книга структурно недоступна (`canDoAction 'spellbook'` →
  allyCanDo «недоступно активному персонажу» — проверено в src/combat.js) →
  бейдж «0» отклонён (смешивает «нет пула» с «недоступно»).
- cast/heal/resurrect/block/quickItem/invItem/flee/endTurn — БЕЗ бейджа
  (пины CU171-BTN/CU178 `children.length===1` + `textContent===''` — живы;
  ТЗ счётчиков про строку ИГРОКА «Шаги, Удар, Огонь, Леч»).
- Бейдж — per-стентный span (создан в build, как кнопки — урок 000149:
  пересоздание в render убивает клик); render обновляет только
  textContent/display. Не зависит от disabled (opacity .3 — «0» читается).
