# 000013: практика навыков — опыт за применение эффектов

Статус: выполнено и закоммичено (тесты 192 → 211 pass).

## Решения

* **src/player.js** — вся механика (ядро):
  - `c.skillXp[id]` — опыт внутри текущего уровня вторичного навыка
    (поле создаётся в `createCharacter`).
  - `skillXpForNext(level) = 15 * (level + 1)` — порог перехода
    на следующий уровень.
  - `practiceCap(c, skillId) = primary[s.primary] * 2` — «потолок
    практикой» (SPEC.md, «Повышение вторичных навыков»).
  - `skillPractice(c, id, xp)` — практика: рост только до min(100,
    потолка); на потолке опыт не принимается, но копилка, накопленная
    ниже потолка, ХРАНИТСЯ и применяется, когда потолок поднимется.
  - `skillReadBook(c, id, xp)` — книги/свитки: игнорируют потолок,
    рост до 100.
  - `reprocessSkillXp(c, primaryId)` — вызывается из `raiseSkill` при
    повышении основного навыка: застрявший в копилке опыт конвертируется
    в уровни до нового потолка; `raiseSkill` возвращает `skillLevels`.
* **src/combat.js** — источники практики в бою: `PRACTICE_XP = { hit: 3,
  block: 2, spell: 3 }`; `attackSkillId(eq)` — меч → swordsman, лук →
  archer, тяжёлое → heavy, без оружия → fists. Результат attack/spell/
  block содержит `practice: { skill, xp, applied, level }`. Промашка —
  без практики (SPEC: «успешные применения»).
* **src/items.js** — `useItem`: зелье → +2 «Алхимик», еда → +2
  «Сердце природы» (за каждое применение, `USE_PRACTICE_XP = 2`);
  книги/свитки теперь идут через `P.skillReadBook` (ранее мастер имел
  «фрагмент»: addSkillXp только складывал xp в c.skillXp без уровней и
  потолка — заменён, дублирования нет).
* **src/dungeon.js** — в DUNGEON_ITEMS каждого типа подземелья есть
  книга/свиток с опытом навыка (связка с лут-задачами 000009/000007).
* **assets/items/000025–000032.json** — 8 новых предметов (skill_book,
  effect skill_xp): stone_fist_grimoire, iron_hide_tome, fire_spellbook,
  ice_spellbook, heavy_tome, archer_scroll, meditation_scroll,
  nature_scroll; дубликат в src/items-data.js (фолбэк, порядок =
  порядок файлов).
* Переношено вручную из OLD-черновика /home/sas/thegame-draft-000013.patch
  (база устарела; git apply не работал). SPEC.md НЕ меняли — раздел
