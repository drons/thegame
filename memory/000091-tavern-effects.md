# 000091. Эффекты таверны (44) — краткая карта

Полный контракт: `memory/000091-tavern-rest-rumors.md`.

- **Отдых** (`44_rest`) = `clock.rest()` (src/day.js, существующий): `steps = 0;
  advanceDay('rest')` → onDay (main.js): restoreDay по SPEC «Игровое время»
  (база 10% + Медитация +2%/ур. (HP+MP) + Глубокий вдох +5%/ур. (HP)), респаун,
  истечение баффов, `'День N.'`, `saveNow()`. Никаких новых формул.
  Реализация — спец-модуль `src/building-effect-44_rest.js` (сторона: день/шаги/save),
  саморегистрация `Game.buildingActions.registerSpecial('44_rest', …)` при загрузке;
  main.js и building-actions.js не трогаются (контракт 000128).
- **Слухи** (`44_rumors`) = детерминированы по **(tile, day)**: 1–2 лор-фрагмента из
  каталога `000044.json → особые_параметры.эффект.слухи.тексты` (сиды RUMC/RUMT/RUM2,
  hash2) + ближайший вход в пещеру (slot 9, buildingId ≠ 48) **через переиспользованный
  `moonDreamHint`** (000076) с типом подземелья (`dungeonTypeFor`, `DUNGEON_NAMES`).
  Чистый apply-профиль (не спец-модуль), результат → flash HUD (многострочный,
  `#hud { white-space: pre-line }`). 2–3 подсказки; входной строки нет →
  «Входы в пещеры не видны.»; карта отсутствует → не отказ (фрагменты всё равно).
- **Лимитов нет**: ни `раз_в_день` в каталоге, ни `разВДень` в реестре →
  `hasDailyLimit === false` для обоих эффектов; отметок `x,y:44_rest` / `x,y:44_rumors`
  в `buildingOncePerDay` никогда нет; повтор в тот же день разрешён (пinned B24/B25).
- **НАЙМ — за 000065** (NPC-схема, найм-вкладка). Здесь: NPC Берта только как
  существующий диалог (регрессия B26); найм не описан и не реализован.
- Оверлей таверны после задачи: `['dialog', '44_rest', '44_rumors']`
  (массив `особые_параметры.эффекты` в каталоге, 1:1-запись реестра не покрывает два
  действия). HUD «Здесь: … ([E] Берта, действия)» — автоматически (eHint, 000129).
