# Приключения Флогистона

![Логотип](assets/logo.svg)

Пошаговая одиночная фэнтези-RPG с открытым процедурно генерируемым миром,
написанная на WebGL + JS + HTML (ноль npm-зависимостей).

История: на город Флогистона, начинающего мага, напали орки. Игрок помогает
городу: путешествует по бесконечной процедурной карте (шум Перлина + глобальная
затравка из `assets/map.png`, детерминированная по глобальному сиду), сражается
с мобами в пошаговом бою, спускается в процедурные подземелья-лабиринты
(сложность и лут масштабируются от уровня персонажа), переживает игровые дни —
с респауном мобов и восстановлением сил.

## Запуск

- Двойной клик по `index.html` — игра открывается прямо из файла (file://),
  сервер не нужен. Данные каталогов продублированы в JS-модулях, поэтому
  `fetch()` локальных JSON не требуется.
- Для разработки удобнее поднимать локальный сервер: `python3 -m http.server`
  и открыть `http://localhost:8000/`.

## Тесты и утилиты

- `npm test` — запуск всех тестов (`node --test`, каталог `tests/`).
- `npm run gen:map` — генерация превью карты в `assets/map.png`
  (`scripts/generate-map-png.js`).

## Структура проекта

- `index.html` — входная точка (подключает модули `src/*.js` до `src/main.js`).
- `src/` — игровой код: униформные JS-модули (IIFE; в браузере складываются в
  `globalThis.Game`, в node — `module.exports`), чистое ядро без DOM.
- `assets/` — ресурсы: `logo.svg`, `map.png` (глобальная затравка карты).
- `tests/` — тесты на node (`node --test`).
- `tasks/` — задачи: `pending` (к выполнению), `done` (выполненные).
- `memory/` — заметки/контекст проекта.
- `SPEC.md` — спецификация игры; `CLAUDE.md` — правила работы.

## Рабочий процесс

Задачи берутся из `tasks/pending/` и переносятся в `tasks/done/`
(командами `git mv`). Перенос задачи в `done` обязательно сопровождается
коммитом в git всех изменённых файлов (в том числе файла задачи).
Детали — в `CLAUDE.md`.
