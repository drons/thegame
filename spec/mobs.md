# Мобы

## Общие правила
 * Правила создания SVG-ассетов мобов (именование, кадры, геометрия,
   бюджет деталей, стиль) — spec/MOBS.md.
 * На основной карте могут стоять стационарные группы мобов, закрывающих ключевые проходы
   (мосты, перевалы, сужения, ворота, перекрёстки дорог).
 * При победе над группой она помечается побеждённой, но по истечении нескольких игровых дней
   происходит респаун. Параметр `respawn_days` (количество дней до респауна) настраивается.
 * Уровень моба = уровень персонажа + дельта, где дельта ∈ [-N; +N]. Параметр `level_delta_max` (N)
   настраивается (по умолчанию 3). Значение дельты группы определяется шумом и типом локации:
   опасные локации (лунные равнины, бездны) дают дельту ближе к +N, безопасные (луга, поляны) — ближе к -N.
 * Группы в подземельях/лабиринтах — блуждающие. Содержимое подземелья (мобы, сундуки, лут)
   сохраняется, пока персонаж находится внутри, плюс несколько игровых дней (`dungeon_memory_days`),
   затем удаляется. При повторном визите всё генерируется заново (сид = опыт персонажа).
 * Сложность (уровень мобов, количество и редкость лута) зависит от уровня персонажа
   и типа локации.

## Роли моба (боевая функция)
 | Роль | Описание |
 |---|---|
 | Ближний бой | Атакует в ближнем бою |
 | Дальний бой | Атакует издалека (лук, метательное, магия) |
 | Поддержка | Лечит, баффа союзников, дебаффает врагов |
 | Лидер | Элитный моб, даёт группе бонусы (мораль, тактика) |
 | Щит | Высокая защита, держит линию (щит, панцирь, толстая кожа) |
 | Рой | Слабый поодиночке, но многочисленный, убивается долго |

## Агрессивность
 * **Нейтральный** — не атакует первым; злится при агрессии, краже, вторжении на «свою» клетку
 * **Пугливый** — убегает из боя или прячется
 * **Агрессивный** — атакует при обнаружении
 * **Территориальный** — атакует внутри территории (норы, логова)
 * Агрессия мобов подземелий/пещер (все типы, включая босса)
   растёт с разностью уровней D = уровень группы − уровень
   Флогистона (000303). D ≤ 0 — без изменений: блуждание, бой
   только при шаге игрока на клетку группы. При D > 0 на каждый
   шаг игрока группа в Чебышёве 1..aggroDistance(D) от героя с
   вероятностью aggroChance(D) делает шаг к герою (приоритет —
   ось с большим |дельтой|, тир — горизонталь; клетка занята
   или стена — вторая ось, обе — остаётся); выход группы на
   клетку героя — бой. aggroDistance(D) = min(4, ceil(D/2)),
   aggroChance(D) = min(0.6, 0.1·D) (src/dungeon.js; ролл — в
   потоке wanderStep, только для группы в зоне). Мобы глобальной
   карты — не затронуты (радиус триггера — по классу, «Состав
   групп»).

## Состав групп
 * Группа состоит из 2-6 мобов. Состав группы определяется шумом, типом локации и уровнем персонажа.
 * Стационарная группа всегда содержит минимум один моб «доминирующего» типа локации
   (для орочьего лагеря — орки, для склепа — нежить, и т.д.).
 * Группа с лидером имеет бонусы: +5% урон, +5% защита всем членам группы.
 * Примеры составов:
   * Орочий лагерь: 2 воина + 1 лучник + 1 шаман
   * Орочий набеги: 2 наездника на волках + 1 бешеный
   * Логово скелетов: 3 скелета + 2 ползучих костей
   * Колония муравьёв: 5 муравьёв + 1 матка
 * На основной карте у группы есть «зона» — квадрат 3x3 или 5x5
   клеток вокруг тайла группы (по Чебышёву). Размер/триггер — по
   агрессивности ПЕРВОГО МОБА группы: агрессивный/территориальный
   — 5x5, бой при входе в зону (расстояние ≤ 2); нейтральный/пугливый
   — 3x3, бой только на тайле группы (радиус агрессии 0 — может
   пройти мимо). Вокруг триггерящих групп рисуется окружность
   радиуса триггера (000172) — визуальная аппроксимация квадратной
   зоны: 12 из 16 граничных тайлов 5x5-зоны (8 полудиагональных и
   4 угловых) лежат вне окружности, но триггерят бой.
   Внебойные эффекты сужают радиус триггера (000235.08 cold_breath,
   000235.09 dark_presence): 5-й аргумент findZoneCombat
   (aggroReduceRadius) — для триггерящей группы, чей тайл в Чебышёве
   ≤ радиуса эффекта от героя: eff = Math.max(1, info.radius − 1);
   два источника — max, не сумма (−1, не −2); dist 0 (свой тайл) и
   non-trigger-группы не трогаются; вызов без 5-го аргумента —
   бит-в-бит; HUD-окружность — тем же eff (UI не врёт про радиус
   триггера); механика — spec/spells.md «Каст вне боя».
   Условие видимости окружности на глобальной карте (000350): она
   рисуется, только пока активен внебойный эффект «Показать врагов»
   (show_enemies, spec/spells.md §«Каст вне боя») — во время эффекта
   для ВСЕХ видимых триггерящих групп (радиус > 0), вне эффекта
   окружностей нет; нейтральные/пугливые (радиус 0) — без окружности
   в обоих случаях. Триггеринг зон эффект не меняет (гейт — только
   отрисовка).

## Отображение уровня
 * На мобах в подземелье не отображается их уровень (в бою отображение уровня остаётся).
