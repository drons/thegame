# Карта мира
 Карта разделяется на две категории:
 * Основная карта мира по которой проходят путешествия - является тайловой и генерируется процедурно 
   на основе нескольких гармоник шума Перлина с фиксированным глобальным
   сидом и файла assets/map.png (RGBA), в котором хранится "глобальная затравка" для карты.
   Замена глобального сида или assets/map.png генерируют полностью другую карту.
   Комбинация шума Перлина с assets/map.png должны давать карту бесконесного размера, по которой можно передвигаться.
   Состояние тайла должно полностью определяться значением нескольких октав шума и пикселя из assets/map.png,
   причём один пиксель это один тайл карты.
 * Единая таблица террейнов (задача 000056): `TERRAIN_DATA` в src/map.js — 8 террейнов,
   поля имя / passable / dense / цвет. Цвет — два представления: `base` — hex #rrggbb для
   текстур и фолбэка, `rgb` — 0..1 для WebGL-рендера; согласованы соотношением
   `rgb[i] = round(hex[i]/255·100)/100` (закреплено тестом). `TERRAIN_NAMES` и
   `PASSABLE` — производные от таблицы, не копии. Потребители без собственных копий:
   src/buildings.js (`passableTiles()`/`denseTiles()`, ленивое разрешение — buildings.js
   может грузиться и без map.js), src/sprites.js (`TILE_BASE`), src/main.js (`TILE_COLORS`).
   Копии имён на стороне данных (enum «допустимые_тайлы» assets/buildings/schema.json,
   enum «террейны» assets/visuals/schema.json, имена файлов assets/tiles/*.svg) связаны
   с таблицей тестами; имена файлов не переименовывать.

 * Процедурно генерируемый лабиринт нескольких типов пещеры/подземелья.
   Подземелье многоэтажное. Глубина (код `d.depth`) — каноническое имя
   шкалы: целое ≥ 1, первый этаж = 1 (000153).
   Форма лабиринта — от его координат на основной карте, значений
   шумов Перлина, assets/map.png и глубины: первый этаж — от координат
   (без изменений, бит-в-бит), глубины ниже — детерминированная ветка
   от сида формы первого этажа + глубина, без генератора случайных
   чисел (000153.02). Сид содержимого = сид формы этажа (координаты
   + глубина) + количество опыта персонажа (000153.01).
   Содержимое (мобы, сундуки, залежи, лут) сохраняется только пока
   персонаж находится внутри плюс несколько игровых дней (память
   этажа, параметр `dungeon_memory_days`), потом удаляется (респавн).
   При повторном посещении мобы, сундуки, лут и залежи генерятся
   заново.
   Залежи руды, минералов и самоцветов генерируются вместе с сундуками; редкость растёт с глубиной (000153); сбор — [E] (000157.03).
   Сложность растёт с глубиной: уровень мобов = уровень персонажа +
   (глубина − 1) (первый этаж — база = уровень персонажа; внутри
   группы — ± `level_delta_max`, босс ABYSS — +`level_delta_max`);
   лут — +1 сундук за этаж, золото растёт с уровнем.
   Размер: сторона `W = min(63, round(base·1.1^(глубина−1)))`, где
   `base` — «размер» типа из `assets/dungeons` (сторона ×1.1 за этаж →
   площадь ×1.21 за этаж; cap 63 — решение 000153.02, schema 5..63).
   Каждый этаж: лестница вниз (stairs-down) и подъём. Спуск — [E]
   на клетке stairs-down: спавн на клетке-выходе нового этажа;
   подъём — [E] на клетке-выходе (глубина > 1): спавн на клетке
   stairs-down этажа выше (если клетка занята живой группой мобов —
   на клетке-входе). Переходы не тратят день: шаги тикают день, как
   на карте, а выход из подземелья (глубина 1) в мир проводит день.
   Уровень моба на карте подземелья не отображается (в бою —
   отображается) — см. spec/mobs.md «Отображение уровня»
   (000153.04). Блуждающие группы мобов — по 1-3 моба в группе.
   Рендер подземелья (000258): кромка стены подземелья — автотайл
   по маске 4 соседей (000258): wall-клетка с floor-соседом (маска
   N=1/E=2/S=4/W=8, бит=1, если сосед пол; за пределами карты — стена)
   — краевой спрайт вида (rock/column/stalactite) по индексу маски +
   4 угловые плитки (ровно одна диагональ пола); внутренние стены
   без floor-соседа — фон (не рисуются); стеновой слой — под
   fog-гейтом 000136 (неисследованная клетка — не рисуется).

 * Чанковый рендер (000263): отрисовка мировой карты и подземелий —
   чанк 16×16, каждый — offscreen-канвас (буфер чанка) с запечённым
   статичным слоем (текстуры тайлов, пол/стены подземелья); кэш чанков —
   LRU по пикселям (бюджет 16 MP). Кадр рисует только видимые чанки —
   1 drawImage на чанк (мир — мир-якорная сетка 000228, подземелье —
   камерно-якорная 000215; формулы снап-сеток не меняются). Анимация
   воды не запекается: вода — по тайлу, динамическим pass'ом поверх
   блитов (биту-в-бит со старым путём). Ключ кэша чанка — канонический
   бакет зума 1.2^k от ZOOM_START; переиспользование запечённого
   канваса — только при ТОЧНО совпавшем зуме (гард 1e-6), ЛЮБОЕ
   изменение зума → re-bake. Инвалидация — при смене зума, смене
   данных тайла и explored (туман 000136: targeted re-bake только
   затронутых чанков; explored монотонен — клетка запекается не более
   чем дважды). Динамические слои (постройки, мобы, игрок, эффекты) —
   поверх блитов, порядок слоёв не меняется. Результат идентичен
   предыдущему рендеру на рабочих разрешениях до 4K (не включительно);
   на 4K (3840×2160) и выше, когда одновременно активен чанковый гейт
   и зум ≥ 24, — задокументированное отклонение 1–2px по оверхангу
   декораций (memory/000263-chunked-render.md §3.10). Гейт:
   чанкование только когда видимых тайлов/клеток > 8192 (мир) /
   > 1024 (подземелье); города не чанкуются (≤ 1024 клеток).

 * Базовый интервал шага по глобальной карте `move_interval_ms` (по умолчанию 420 мс) настраивается
   (единый источник — src/global-settings.js); навык «Ловкий шаг» (Ловкость) уменьшает интервал,
   но не ниже минимального.

 * «Контент тайла глобальной карты — единая функция по координатам
   (строительство, группа мобов, лут, пусто): 4 содержимых
   взаимоисключающие — тайл со строительством (любой тайл footprint,
   включая вход) не имеет ни моба, ни лута; тайл с группой мобов не
   имеет лута. Приоритет: строительство > моб > лут > пусто.
   Вероятности рассчитываются совместно из шума координат и пикселя
   map.png (детерминизм — см. пункт «Состояние тайла должно
   полностью определяться…»).»

 * «Природный лут (ингредиенты для крафта): ягоды, травы, коренья,
   плоды — на тайлах травы/болота/леса; грибы — на тайлах леса;
   самородки руды и самоцветы — на тайлах песка и на проходимых тайлах
   в 8-окрестности гор. Сбор: игрок входит на тайл и нажимает [E];
   собранный предмет становится невидимым и возрождается через
   несколько игровых дней (параметр `respawn_days`, общий с мобами —
   см. spec/mobs.md «Общие правила»). Какой предмет на тайле —
   детерминировано координатами (каталог: terrain/рядом-с-горами/
   частота — см. spec/items.md «Природные ингредиенты»);
   собранное состояние — в сейве (паттерн dayMap).»
