# Спутники

## Кто и где нанимается
  Наёмники — NPC каталога `assets/npc` с полем `найм` (цена контракта,
  жалованье в день, боевая роль melee/ranged/shield/support, статы,
  навыки/заклинания — ссылки на каталоги `assets/skills`/`assets/spells`).
  Найм — в таверне (постройка id 44), действие диалога «найм».
  Отряд — максимум 3 спутника (параметр `max_companions`).

## Контракт и жалованье
  * Найм — разовая цена контракта (золото).
  * Жалованье списывается при смене дня (всему отряду разом).
  * Нет золота на жалованье → −20 лояльности и проверка ухода:
    ≤20 — уйдёт верно, 21…40 — 50%, выше 40 — остаётся.
  * Увольнение — в диалоге, возврат денег нет.
  * Уход при низкой лояльности С экипировкой — экипировка
    возвращается в общий инвентарь героя (000242); инвентарь без
    места — уход откладывается до освобождения (предметы не
    теряются — то же правило, что увольнение, 000230.06.01).
  * Повторный найм после увольнения возможен; гибель записывается в
    список погибших С СОХРАНЕНИЕМ уровня/опыта/лояльности (запись —
    «Спутники → Сейв»); повторный найм после гибели нельзя;
    возврат — воскрешением (раздел «Спутники → Воскрешение»).

## Лояльность
  * 0…100; старт = 50 + Харизма (1:1, cap 100).
  * +2 за день с оплаченным жалованьем.
  * Отказ при найме: 30% − 2% за уровень Харизмы − 5% за уровень Артиста
    (min 0).
  * Все случайности — детерминированы (seed = hash2(день, npcId)).

## Бой
  * Спутник — отдельный союзный юнит на мини-карте боя; на своём ходу
    спутником управляет игрок: движение — 1 клетка (наёмник; Эфир —
    3 клетки и свои пулы, см. «Дух Эфира → Бой»); удар (дальность
    по роли) — 1 действие за ход (наёмник); лечение — заклинание:
    расход — пул/мана наёмника (те же механики, что книга игрока,
    000193); кроме случаев, когда заклинание входит в free_cast
    экипировки самого наёмника (000230.06; механизм u.freeCast — с
    000230.03); support-наёмник (до выбора из книги, 000227) лечит
    самого раненого из [игрок, союзники] (у Эфира — нет, см.
    «Дух Эфира → Бой»); блок/побег — только игрок. Предмет —
    активный персонаж: быстрый — своя единица в своём слоте
    (закрепление — перенос из общего инвентаря героя, «убрать» —
    возврат; в бою — расход из слота — 000223); из инвентаря — из
    общего инвентаря героя; эффект — на самого персонажа (000194,
    000223). Лечение наёмника — клавиша (H) (на ходу спутника;
    000227: последнее выбранное из книги, до выбора — самый раненый;
    000249: выбор — УСПЕШНЫЙ каст, id сохраняется между боями;
    тач-кнопка «Лечение» — 000178/000227: у любого наёмника с книгой;
    расход — пул/мана наёмника (000193)); кроме случаев, когда
    заклинание входит в free_cast экипировки самого наёмника
    (000230.06; механизм u.freeCast — с 000230.03). Книга заклинаний
    (Q/R) — активный персонаж: на ходу игрока — книга игрока, на
    ходу спутника — книга спутника; те же механики, что у
    Флогистона: расход — пул/мана активного персонажа (000193);
    кроме случаев, когда заклинание входит в free_cast экипировки
    самого наёмника (000230.06; механизм u.freeCast — с 000230.03);
    цель — по действию; гейт 000179 снят.
  * боевые статы наёмника = база + его экипировка (000230.06):
    урон — оружие в right_hand (+ set-бонусы, 000230.04), броня —
    сумма по слотам, skill-аффиксы и set-бонусы — через общие
    агрегаторы (000230.03); предметы берутся из ОБЩЕГО инвентаря
    героя (000194); возврат экипировки герою — при снятии и при
    увольнении (000230.06.01: инвентарь без места — увольнение не
    выполняется, предметы не теряются).
  * Цель удара — игрок выбирает кликом по мобо (по умолчанию — ближайший враг); выбранная цель недоступна — «нет цели», пул не сгорает.
  * Очередь хода — по инициативе (раздел «Боевая система»).
  * Гибель спутника — покидает бой, не поражение; победа/лут — без
    изменений.
  * Гибель Флогистона — окно смерти: ВСЕ союзники (включая Эфира)
    считаются погибшими; Эфир auto-возрождается (дух — полный reset).
    Спасение «Воскрешением» (Эфир, 22+) отменяет каскад — игрок
    возвращается в бой с 50% HP, бой продолжается. Без спасения —
    подъём (1/2 HP, −20% золота, 000008) и вся партия в списке
    погибших (раздел «Спутники → Воскрешение»).
  * Предводитель: +5% урона всех спутников отряда за уровень
    (companionMoraleBonus).

## Опыт и уровни
  * Боевой опыт делится поровну между ВСЕМИ участниками (Флогистон,
    Эфир, наёмники — в т.ч. погибшие в бою): base = floor(сумма/N),
    остаток (сумма mod N) — Флогистону; бонус «Учёный» — только к
    доле Флогистона.
  * Спутники повышают уровень сами: статистика по уровню, набор навыков
    фиксирован из каталога, очков навыков нет.

## Эфир (явное решение)
  Единый фреймворк «союзные юниты»: Эфир и наёмники — одна модель
  союзного юнита. Эфир — ПОСТОЯННЫЙ союзник: всегда вызывается на поле
  боя, сражается на стороне игрока, имеет собственный независимый пул
  навыков, растёт со своей равной долей боевого опыта (000205), не
  умирает навсегда (в
  следующем бою возвращается со 100% HP), жалованью и лояльности не
  подлежит. Детали пула навыков и дизайна — задачи 000034/000035
  (раздел SPEC об Эфире добавляют они; здесь — только механизм и ссылки).
  Эфир не экипируется (явное решение 000230.06): allyEquip/
  allyUnequip — отказ «Эфир — дух, не экипируется» (точная строка);
  read-путь — efirAllyData без equipment/freeCast.

## Сейв
  Поля data: `companions` (состав: npcId, уровень, опыт, лояльность,
  день найма), `efir`, `dead_mercs`. `dead_mercs` — записи о погибших
  наёмниках: `{npcId, sheet, loyalty, hiredDay}` (ровно 4 поля —
  форма serializeRoster, 000143; уровень/опыт — зеркала sheet).
  Backfill старого формата (плоский npcId) — тихий сброс записи:
  новый лист из каталога найма, лояльность 50, день найма 0
  (данные утрачены до появления воскрешения). Неломкое расширение v1
  без миграции (версионирование сейва — задача 000031, src/save.js);
  невалидные записи — тихий сброс (паттерн 000029).

## UI
  * Вкладка «найм» в диалоге таверны (`Game.npcUI`).
  * Панель «Отряд» (после редизайна панели персонажа, задача 000051).

## Воскрешение
  Кто: погибшие наёмники (записи `dead_mercs`, «Спутники → Сейв»).
  Эфиру воскрешение не нужно: он — дух и всегда auto-возрождается
  (полный reset) — и в момент гибели Флогистона, и между боями.

  * В храме (мир, вне боя): храмы солнца/луны/горы (36/37/38;
    заброшенный 39 — нет) — действие «Воскрешение»: пикер погибших,
    оплата, запись возвращается в отряд с сохранённым уровнем/опытом/
    лояльностью. Цена: `round(база + за_опыт × totalXp)` (параметры
    `база`/`за_опыт` — каталог постройки, totalXp — из записи
    погибшего); лимита «раз в день» нет; отряд полон (max_companions)
    — отказ.
  * Пикер: тач-кнопка «✕ Отмена» (close идемпотентна; Esc работает
    как раньше). Общий принцип: оверлей, скрывающий ввод, обязан
    давать тач-путь снятия (000170).
  * Боевое воскрешение: заклинание «Воскрешение» (000017, школа
    исцеления, действие «воскрешение») или свиток воскрешения
    (resurrection_scroll, быстрый слот) действуют в бою и возвращают
    МЁРТВОГО союзника (в т.ч. Флогистона): alive, HP — 50% HP
    максимума; дальность не ограничена. Свиток: цель не выбирается —
    первый мёртвый союзник в порядке юнитов боя; мёртвых нет —
    отказ, действие не сгорает.
  * Детерминизм: вся система — без RNG.
  * Поведение до спасения (000008, фиксация): гибель Флогистона —
    окно смерти («Спутники → Бой»); без спасения — подъём: 1/2 HP
    и −20% золота.
