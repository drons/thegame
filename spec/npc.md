# NPC
  С NPC можно взаимодействовать, вести диалоги, получать квесты, с некоторыми торговать
  NPC хранятся в каталоге `assets/npc` — см. раздел «Архитектура хранения NPC».
  В игре: стоя на тайле постройки с NPC, клавиша [E] открывает диалог
  (опции, торговля, обучение в школах, квесты).
  Действие диалога может быть и «найм» — наём спутника (раздел «Спутники»).

## Школы (обучение)
  Школа NPC обучает вторичные навыки из списка поля `обучение`
  (раздел «Архитектура хранения NPC»); прокачка — за золото по формуле
  `20 + 10 × L²`, где L — ТЕКУЩИЙ уровень навыка ДО повышения
  (первый уровень 0→1 = 20): 0→20, 1→30, 2→60, 3→110, 4→180, 5→270, …,
  граница 99→100 = 98030 (максимальный уровень 100).
  Цена не зависит от данных NPC (`цена_за_уровень` — наставничество
  по крафту, раздел «Крафт»). Требования — те же, что при трате очков;
  очки не тратятся. Реализация — src/npc.js (schoolTrainPrice).
