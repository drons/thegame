# Навыки

## Основные навыки
Навыки имеют древовидную структуру, начиная от шести основных:
 | Основной навык | Характеристика | Влияние в бою | Влияние на карте мира |
 |---|---|---|---|
 | Сила | Физическая мощь | Кол-во действий «Удар», урон в ближнем бою | Переносимый вес, разрушение объектов |
 | Ловкость | Проворство, рефлексы и равновесие | Дистанция хода 1 + Ловкость/10 (целая часть) клеток за ход, «Быстрые предметы» | Скорость перемещения по карте |
 | Телосложение | Здоровье и выносливость | «Постановка блока», макс. здоровье | Здоровье в мирное время, сопротивление усталости |
 | Интеллект | Логика и память | Кол-во действий «Заклинание» (школа Интеллекта), урон заклинаниями этой школы | Расшифровка записей, чтение карт и рунических текстов |
 | Мудрость | Восприимчивость и ментальная устойчивость | Кол-во действий «Заклинание» (школа Мудрости), сопротивление магическому влиянию | Восстановление между днями, устойчивость к страху и проклятиям |
 | Харизма | Уверенность, самообладание и обаяние | «Быстрые предметы» (часть), действия на мораль врагов | Диалоги, цены торговли, лояльность спутников |

## Рост навыков
 * При повышении игрового уровня персонаж получает очки навыков (по умолчанию 2 за уровень,
   параметр `points_per_level` настраивается).
 * Очки тратятся на повышение уровня основного или вторичного навыка.
 * Вторичный навык можно качать только при достижении требуемого уровня основного навыка
   (и, для узких веток, другого вторичного навыка) — так получается древовидная структура.
 * Перенос вложенных очков (возврат уровней в пул свободных очков) отменён
   (задача 000297): уровни, полученные в школах NPC, не возвращаются в пул очков.

## Ранги и переименование
Уровни навыков делятся на ранги. Название вторичного навыка меняется по рангу:
 | Ранг | Уровни | Имя (пример: навык «Мечник») |
 |---|---|---|
 | Новичок | 1-10 | «Начинающий мечник» |
 | Ученик | 11-25 | «Ученик фехтовальщика» |
 | Знаток | 26-50 | «Знаток клинка» |
 | Мастер | 51-75 | «Мастер меча» |
 | Гроссмейстер | 76-99 | «Гроссмейстер меча» |
 | Легенда | 100 | «Легенда клинка» (уникальное имя) |

## Повышение вторичных навыков
 * Вторичные навыки повышаются:
   1. Тратой очков навыков; в школах навыков у NPC — за золото (раздел «NPC» → «Школы (обучение)»);
   2. Практикой: успешные применения эффекта навыка дают небольшой опыт навыка
      (например, попадание мечом даёт опыт навыка «Мечник»);
      (попадание посохом даёт опыт навыка «Владение посохом» (staff, 000337));
   3. Книгами и свитками, найденными в подземельях.
 * Максимальный уровень навыка — 100.
 * Каждый навык имеет «потолок практикой» (уровень основного навыка * 2),
   выше которого навык растёт только очками навыков и книгами.
 * Опыт практики за применение боевого заклинания игроком (castSpell,
   src/spells.js, задача 000307): XP = round(мана × (1 + 0.1 ×
   max(0, D))), где мана — потраченная мана заклинания (поле `мани`
   каталога; free_cast (000230.17) — 0), D = уровень персонажа −
   уровень опорного моба: цель применения (урон/ослабление/контроль/
   дебаф) или ближайший живой моб (остальные действия); живых мобов
   нет — D = 0. Отрицательная разность — бонус нулевой (без
   штрафа). Навык — по школе заклинания: огонь → firelord
   «Повелитель огня», лёд → icelord «Повелитель льда»,
   исцеление → meditation «Медитация», природа → nature «Сердце
   природы»; школы Тень и Защита — навыка нет, опыта нет.
   Неудачный каст (отказ до расхода пула/маны, {ok:false}) — опыта
   нет. Практика союзников и Эфира — без изменений (000117/000193).

## Школы магии (каталог)
Школа магии — свойство заклинания (поле `школа` каталога assets/spells,
enum 000301). Шесть школ: защита, исцеление, лёд, огонь, природа, тень.
 * Каталог: по школе — один JSON assets/skills (000038–000043 — порядок
   вкладок книги заклинаний 000301): id (латиница, = имя иконки),
   type «school», name — байт-в-байт имена SCHOOLS src/spellbook-oc.js
   (000301), desc — одно предложение по факту распределения действий,
   icon — assets/school-icons/<id>.svg (иконки 000301, не создаются).
 * Зеркало: src/skills-data.js — экспорт SCHOOLS (скрипт
   scripts/sync-skills-data.js, порядок файлов каталога).
 * Дерево навыков [I] (src/ui-tab-skills.js): секция «Школы магии»
   МЕЖДУ группами вторичных навыков и «Книга заклинаний»: 6 строк
   (name, уровень «—», тултип desc), БЕЗ уровней и кнопок (школа —
   не навык: ни уровня, ни копилки, ни canRaise).
 * Навык-практика по школе (раздел «Повышение вторичных навыков»,
   000307): огонь → firelord «Повелитель огня», лёд → icelord
   «Повелитель льда», исцеление → meditation «Медитация», природа →
   nature «Сердце природы»; школы Тень и Защита — навыка нет.
 * Ссылки заклинаний (000327): `школа` → JSON школы assets/skills по name.toLowerCase() (id каталога — латиница), `атрибут` → id основного навыка assets/skills, `параметры.summon` → id моба assets/mobs; sweep — tests/spell-links-000327.test.js.
 * Навыки механик (000325): все навык-id, резолвимые изучением заклинаний и разборкой предметов (практика по школе — `PRACTICE_BY_SCHOOL`, атрибут школы, гейт «Рунопись», виды крафта через `CRAFT_TYPE_SKILL`/разборку), существуют в каталоге assets/skills; «виды крафта» — отдельный домен прогрессии (`c.craft`), НЕ навыки дерева [I]; связи навык↔вид — таблица spec/craft.md; sweep — tests/skill-tree-audit-000325.test.js.
